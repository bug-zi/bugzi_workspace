# 01 - 项目总览与业务规则

> 目标：15 分钟搞清楚这个 App「做什么、为谁做、有哪些不可逾越的规则」。
> （260919 依当前代码更新：六模块时代 → 12 模块 + 音乐吧 + 右缘四面板时代）

## 1. 产品定位

**「bugzi's workspace」= 生活化个人专属工作台**。关键词逐个拆：

- **生活化**：管理的是「学习、知识、格言、灵感、观点、书籍、信息、账目、推理」这类个人生活内容，不是工作任务。
- **个人专属**：单用户、无登录、无云同步。装好就是你的，数据在你电脑上（默认 D 盘，可在个人档迁移）。
- **工作台**：十二个模块各管一摊，右侧常驻一个感知上下文的 AI 助手 debugzi，右缘还有草稿本/资源管理器/画布三块副面板，底部内置终端。

典型的使用想象：早上打开 App 落在总导览——今日格言、学习队列、每日一题打卡状态、每日挑战、阅读热力图一眼扫完；晚上 10 点 App 自动按正式区格言风格生成 10 条新格言；推理角题池在后台悄悄补题，打开每日一题秒开；读到好书划一句存笔记；看到一个可疑观点丢进万象库辩真板块让它联网查证。

## 2. 模块速览

### 总导览（zonglan）—— 启动默认页
今日驱动聚合：问候头、今日格言（正式区随机）、学习队列、待学习区待消化数、每日一题打卡状态（只读不触发出题）、续读直达阅读器、轻数字条（信息源未读/本月支出/阅读连续）、每日挑战（本地随机日定一条、可逆打卡）+ GitHub 式热力图（学习/每日一题/挑战三源聚合，近一年 53 周四档色）。**纯渲染层并行聚合既有 IPC，零 AI**；深链经 `MODULE_NAVIGATE_EVENT` 跳各模块内部视图。

### 学习库（learn）—— 最重的 AI 模块
知识树三级（领域→主题→知识点），AI 建树/生成知识卡/主题展开/深挖；每日要求（新学 8-10 + 复习四档 + 每日小测，完成自动打卡）；实战任务（AI 出题、交作业 AI 点评）；卡片弹窗划词高光 + 「问 AI」拓展坞。配套预生成泵 `learnStock`（今日新卡后台补齐）与渲染层生成队列 `learnGenQueue`（3 并行线可视化）。

### 万象库（wiki）—— 三板块 tab
- **百科**：板块→词条两级，AI 两段式生成固定模板知识卡；划词高光/问 AI；待学习区（每日批次 5-10 张）+ 后库泵；测一测题库制（答对 2 次毕业，累计熟练度）。
- **辩真**（原辩真阁并入）：输入观点 → LLM 生成 3 组中英检索词 → MCP 联网检索 → LLM 综合给可信度，过程直播到「辩真·核查」频道。
- **问答**：单轮知识问答存档（qa_records）。

### 致知己（zhijiji）
「一个问题 + 我的多个答案版本」（保存即版本，AI 只追问检验不代笔）；**预言家**（写下判断，到期三选一评判可改判）；**十二问题**（想法碎片速记）；**我的画像**（profile_facts 注入全部 AI 上下文）；问题分级（AI 出题带星、四维标准评星）。配套「预言家」AI 频道。

### 灵感泉（inspirations）
四区看板 `draft→project→develop→archive`，跨区拖拽 + 区内排序（sort 半差插入 + 归一化）；AI「来5条灵感」（方向指引 `inspiration_guide` 注入）+ AI 自评 refine。

### 文笔坊（wenbi）—— 四 tab
- **格言库**（260911 并入）：三级流转 draft→settled→formal，AI 风格仿写 10 条/次（每晚 22:00 定时或手动），正式区每条独立 md 笔记。
- **经验书**（260917 新增）：一句话经验道理快记（Enter 连记、双击原地编辑），分类夹 + 拖拽排序，零 AI。
- **浮生记**：周记/月记/随心记时间线，大事件标记，零 AI 纯私密。
- **写作台**：文章四区流转 idea→writing→done→published，Copilot 式协笔（起稿/续写/润色/改写建议卡逐段采纳），完稿可导出。

### 信息源（feed）
RSS 聚合（预置三源；`rsshub://域名(:端口)/路由` 逐条指定实例展开）；AI 总结按需生成缓存；内置阅读视图（RSS 全文优先 + readability 抓正文兜底，Ctrl+滚轮缩放 80%–200%）；三视图 unread/archive/favorite；已读 30 天自动清理。

### 图书馆（zangyue）—— 双页签
- **书架**：epub/pdf 导入入库，双引擎阅读器（epub.js / pdfjs），进度记忆（CFI/页码），滚动/翻页双模式，WASD 导航，目录侧栏，epub 划词高光批注（book_notes），手动书签（book_marks），按书阅读统计（累计秒/连续天数），书级字号/字体/模式偏好，单层文件夹组织。删书二次确认直接物理删（不入回收站）。
- **收藏**：网站/文章两级分类（「未分类」系统锁定末位），URL 抓 meta 预填，置顶/拖拽/Ctrl+点系统浏览器打开。纯本地零 AI。

### 推理角（reasoning）—— 双板块
- **海龟汤**：AI 出题/审题/判问/判汤底/局终点评，问答逐条落库可中断续玩，净用时计时（切走模块暂停），对局记录 md。
- **思维墙**：每日一题打卡（wall.month 月历、连胜 streak），题库（wall_bank），练习场（任意出题）；三处题面 MdView 渲染。
- **题池预生成**：`wall_pool`（DB v26）+ 补充泵 `reasoningStock`，每日一题/练习场取池秒开，池空才现场生成；汤库同理（fresh 池）。

### 记账本（ledger）
逐笔流水（金额存**分**），多账户余额实时滚存（期初+收支），月度收支数字卡 + 分类占比条下钻 + 按日分组流水；账户/分类管理。纯本地零 AI；删除入回收站。

### 回收站（recycle）
按来源分块展示，**19 种来源**（mottos/wiki/inspirations/verify/zhijiji/reasoning_soup/reasoning_game/drafts/canvases/wenbi_journal/wenbi_article/wenbi_exp/ledger_tx/ledger_account/ledger_category/learn/prophet/twelve_question/qa + **ai_session** 归档的 AI 会话整包）。「恢复」回来源模块最初级区，「删除」彻底删（级联清理附属文件），3 天自动清理（启动 + 每日零点）。

### 个人档（profile）
个人信息（用户名/头像/签名）；字体大小/样式/粗细 + **导入字体**（ttf/otf/woff/woff2 存 `fonts/` 经 FontFace 运行时注册，上限 20 款）；LLM 多套配置（模型池溢出路由 maxConcurrent、拉取上游模型列表）；MCP 多套配置（bearer 鉴权、**AI 辅助配置** mcp:research）；数据目录迁移；「版本与更新」应用内更新；LLM 使用统计（llm_usage 按场景记账）。

### 音乐吧（noise，非模块）
全局背景音：**白噪音**（Web Audio 纯合成多场景混音 8 层级 + 自定义混音 + 播放队列）+ **轻音乐**（歌单/曲目，260915 新增）。双引擎互斥（`audioExclusive`），切模块声音不断；左栏「记账本与回收站之间」常驻控件整块单击进主栏混音器页；重启记参数默认暂停。

### 右缘四面板 + 内置终端
右缘细条四图标**互斥**展开：debugzi AI / 草稿本（general+turtle 双频道，海龟汤对局联动）/ 资源管理器 / 画布（Excalidraw，标准 JSON 可互导）。展开态记忆持久化（`right_panel_expanded`）。四面板全收起时右下角出现主题切换、终端呼出、音源快捷播放、AI 活动指示四按钮。内置终端（Ctrl+J 呼出、Ctrl+Shift+J 新建页签）node-pty 真实 shell，输出合帧防 IPC 洪峰，退出杀光进程。

## 3. 全局硬性规则（「宪法」，改任何代码前先背下来）

来自 `docs/project/左侧边栏/左侧边栏.md` 与 `docs/project/样式/design.md`：

| # | 规则 | 代码落点 |
|---|---|---|
| 1 | **所有丢弃/删除必须二次确认弹窗** | `ConfirmDialog`，各模块丢弃按钮先 `setDiscardTarget` |
| 2 | 双主题：浅色=樱花粉+黑字，深色=宝蓝+白字；背景用户上传图 | `src/theme/global.css` 的 `[data-theme]` 变量 + `ThemeProvider` |
| 3 | **禁止 emoji 作图标**，一律用 Material Symbols | `material-symbols` npm 包本地引入 |
| 4 | 组件框/按键/弹窗禁止彩亮颜色，须贴近主题色系 | CSS 全部走 `--color-*` 变量 |
| 5 | 三栏布局：左（12 模块+音乐吧控件）→ 中（模块内容，keep-alive）→ 右（四面板互斥） | `App.tsx` 的 `.app-shell`/`.app-body` + `App.css` |
| 6 | md 弹窗为全局统一组件，默认渲染态、双击进编辑态 | `MdDialog` 组件 |
| 7 | LLM/MCP 未配置时按钮**不置灰**，点击弹提示 +「去配置」直达个人档 | `GoConfigDialog` 组件 |
| 8 | 定时任务错过即跳过 | `scheduler.ts` 的 `alreadyRanToday` 逻辑 |
| 9 | 首次启动有欢迎引导 | `WelcomeGuide`，由「无 user_name」判定 |

规则 7 的反直觉之处：常规做法是没配置就把按钮 disabled，这里明确**不让**——个人工具配置是顺手的事，不该让界面看起来"坏了"。

两条后来长出来的架构级约定（同属宪法级）：

- **模块 keep-alive**：切模块只隐藏不卸载（AI 生成任务不中断），模块经 `useModuleActivated` 监听激活事件自行刷新。
- **AI 调用一律带 jobId**：渲染层生成随机 jobId 传入 IPC，主进程 `ai/jobs.ts` 登记 AbortController，`ai:cancel` 可取消，AI 活动面板可视化在途调用。

## 4. 文档体系（你在哪能找到"为什么这么设计"）

```
docs/
├── project/
│   ├── 左侧边栏/<模块>/        ← 每模块一目录：design.md（开发者写）+ designs-specs.md（AI 写）
│   │                            落地/废弃的设计记录进各目录 archive/
│   ├── 右侧边栏/              ← debugzi、草稿本等右栏功能的同类文档
│   ├── 全局/                  ← 跨模块专题设计（如 AI 生成全局取消）
│   ├── 样式/                  ← 主题规范
│   ├── 白噪音/                ← 音乐吧设计文档
│   ├── idea/                  ← 开发者的点子库，AI 不碰
│   ├── 优化建议区.md          ← 开发者记使用反馈，AI 据此实施（代码注释常引「第 N 轮」）
│   └── project.md / README.md ← 文档协作权责总则
├── log/<YYMMDD>.md            ← 开发日志（AI 按天记，每小节带创建时间行）
└── study/                     ← 你正在读的这套笔记
```

**工作流**：开发者写 `design.md`（人话需求）→ AI 生成 `designs-specs.md`（结构化开发规格）→ AI 按 specs 写代码。代码注释里大量出现 `（specs §3.1）`、`（优化建议区第 N 轮）`、`（DB vN）`这样的引用，那就是回溯需求的线索。**优化建议区是本项目最强的迭代引擎**——大量体验打磨直接来自那里按轮次编号的反馈。

## 5. 新人第一个练习

打开 `src/App.tsx`，找到 `MODULES` 数组（36-49 行）。对照左栏实际顺序「总导览→学习库→万象库→致知己→灵感泉→文笔坊→信息源→图书馆→推理角→记账本→〔音乐吧控件〕→回收站→个人档」，确认渲染顺序即数组顺序（音乐吧控件在 `m.id === 'recycle'` 处插入）。然后思考：如果产品要加第十三模块，**最少**要改哪几个文件？

（答案：`src/shared/types.ts` 的 `ModuleId`、`App.tsx` 的 `MODULES` 数组与主栏 keep-alive 分支、`preload.ts` 与 `src/renderer/api.d.ts` 加桥方法、`electron/ipc.ts` 注册处理器、`electron/db/db.ts` 加版本迁移、新建 `src/modules/xxx/`；若可删除则再登记 `recycle.ts` 的 `RECYCLE_MAP`。这个"扩散面"正是 03/04 篇要讲清的主线。）
