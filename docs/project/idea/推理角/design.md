# 推理角

### 定位：把 AI 当陪练的推理健身房。（需要再加工细化）

### 板块 A · 海龟汤

举个例子：【海龟汤】汤面：一间屋子两个人听了一首歌，之后相继死去；汤底：霸王别姬。

注：海龟汤游戏，提问者只能提问那种表示判断类型的句子，AI的回答也只能是“是/否/与汤无关”，不能有其他多余的信息。

以上面的汤为例，

玩家提问：“这两个人是互相杀害的吗？”，AI应该回答“否，这两个人不是互相杀害”

玩家不能提问“这两个人是怎么死的”——这不是一个表示判断的类型；

玩家提问“这间屋子里除了他们两个还有别人吗”——AI应该回答“与汤底无关”

当然，AI能做出正确应答的前提是AI本身对汤面和汤底有足够深的理解。比如说本汤汤底是霸王别姬，AI应该清除知道霸王别姬这个历史典故。知道霸王别姬的这个过程：一间屋子两个人听了一首歌，这两个人是项羽和虞姬，歌是四面楚歌，之后虞姬为了不拖累项羽而自刎，项羽突围失败，无颜面对江东父老而在乌江自刎。
