# 万源库

介绍：万源库是我的「外接记忆体」模块——把思源笔记（我的主笔记文档库）与本地文件夹接入工作台，只建索引、不做阅读：我的读写习惯全部留在原处（笔记读写继续在思源里完成），工作台负责把其中内容检索出来、作为上下文补充喂给 AI，让整个工作台更懂我。因为接入的内容不只有知识笔记，还有日记、资源备份等，所以按思源笔记本 / 本地文件夹逐个勾选纳入，不默认全收；检索用本地 embedding + 全文关键词混合，索引全程在本机、零 API 成本。本文档由草稿本「关联本地数据库」想法经 260919 与 AI 多轮对齐定稿。

v1.0：

**定位（读写分离的检索层）：**

- 万源库只做三件事：接入源（思源笔记本 / 本地文件夹）→ 后台建索引（提取文本、切块、本地向量化）→ 向右栏 AI 频道供料（检索注入）。
- 不做工作台内文档预览/阅读——本地文件夹与思源内容一律纯检索；检索命中后跳回原处看原文（本地文件用系统默认程序打开，思源唤起思源定位到块）。
- 全程只读：绝不写入、移动、修改关联文件夹与思源库内的任何文件；删除源只删本工作台的索引，源文件原样不动。

**模块结构（主栏内四段式单视图，无页签）：**

- ① 状态条（顶部数字卡风格）：本地 embedding 引擎状态（未安装 →「启用」按钮 / 下载进度；已加载 → 就绪）、思源连接状态（未配置 → 「去配置」直达个人档；未运行 → 提示但不影响其他源；已连接）、总量数字（已纳入源数 / 索引块数 / 上次同步时间）、「全量刷新」按钮、**RAG 总开关**（开/关「向右栏 AI 供料」，一期全局一个闸）。
- ② 思源笔记源区：笔记本列表行（笔记本名 + 文档数/块数 + 纳入开关 + 上次同步 + 单本刷新）。**新增笔记本默认不纳入**，勾选才进索引——日记、资源备份不勾就永远不进；有未确认的新笔记本时列表顶部提示。
- ③ 本地文件夹源区：「＋关联文件夹」按钮（系统目录选择弹窗，**关联个数无上限**）；文件夹行 = 路径 + 文件数/块数 + 纳入开关（添加即默认纳入）+ 刷新 + 移除（二次确认，只删索引）。
- ④ 检索试验场（页面主体）：搜索框 + 命中块列表（内容预览 + 来源标注「思源·笔记本·文档标题」/「文件夹·文件名」+ 相关度得分）。行尾两个动作：「打开原文」（跳回原处，见下）与「以此为上下文问 AI」（携命中块直达右栏频道）。
- 首次进模块给轻量三步引导（启用 embedding 模型 → 配思源 token → 关联第一个文件夹），每步可跳过。

**来源一：思源笔记（Kernel API 只读接入）：**

- 直连思源 Kernel HTTP API（默认 `http://127.0.0.1:6806`，`Authorization: Token xxx`）；token 与端口在**个人档**新增「思源配置」区（照 LLM/MCP 配置样式，settings 键存储），模块内只放连接状态与「去配置」引导。
- 检索与索引用 `/api/query/sql` 查 blocks 表——思源自己的块就是天然对齐的分块（段落/标题/表格/代码各一块），直接按块入库，不自建分块；思源块带块 ID、所属笔记本、文档标题、hpath 与 `updated` 时间戳。
- 增量同步按 `blocks.updated > 上次同步时间` 拉取；「全量刷新」/单本刷新按笔记本清空重建；思源未运行时跳过同步并在状态条提示，不阻塞其他源。
- 进模块时检测内核连通性；不做实时监听（思源自身写盘频繁），同步时机 = 进模块 + 手动刷新。

**来源二：本地文件夹（无上限）：**

- 支持格式：md / txt（直接读）、pdf（pdfjs 按页提文本）、docx（mammoth 提文本）、xlsx（SheetJS 按 sheet 转文本表格）；**图片一期不进索引**（仅文件名可搜，OCR 二期再议）。
- 提取与切块全部在主进程后台分批进行（进度在状态条可见，不阻塞 UI）；索引时机 = 关联后首次全量 + 进模块按 mtime 增量 + 手动刷新；不做实时文件监听。
- 切块：md 按标题层级 + 段落切（约 300–700 字/块）；docx/xlsx/pdf 提取文本后按自然段落/页切块。

**本地 embedding 引擎：**

- transformers.js（onnxruntime-node，CPU 推理）+ bge-small-zh-v1.5（中文优化小模型，512 维）——无外部服务依赖、无 API 成本；索引与查询用同一模型。
- 模型获取两条路：首次启用从 hf-mirror.com（国内镜像）下载缓存到用户数据目录 models/ 下（进度可见）；或手动导入已下载的模型文件夹（网络不便时用）。
- 向量以 BLOB 存 SQLite，检索时 JS 暴力余弦遍历（个人规模毫秒级），不引入向量库；embedding 未就绪时检索自动降级为纯关键词路，不阻塞使用。

**混合检索：**

- 双路召回：FTS5 trigram 关键词路（中文按三字滑窗建索引，2 字内短词 LIKE 兜底）+ 向量语义路，分数融合取 top-k（5–8 块）。
- 专有名词、代码等精确命中靠关键词路，口语化语义检索靠向量路，两路互补。

**右栏 AI 频道联动（RAG 注入）：**

- 右栏各频道问答时自动以我的问题做混合检索，命中的 top-k 块连同来源标注注入 prompt，回复中标注引用来源（来自哪篇笔记/哪个文件）。
- 受状态条 RAG 总开关控制；一期只作用于右栏频道问答，其他模块的 AI 功能（格言生成、词条生成等）不注入。
- 隐私边界：索引与向量全程不出本机；问答时被命中的笔记片段会随 prompt 发往已配置的 LLM——与现有右栏问答同一边界，不再多做提示。

**跳回原处（读写分离的闭环）：**

- 本地文件命中 → 系统默认程序打开原文件。
- 思源块命中 → 通过 `siyuan://blocks/<块ID>` 协议链接唤起思源并直接定位到该块（实施时验证协议唤起细节）。

**存储与回收站：**

- SQLite DB v47+ 新增：`wys_folders`（本地文件夹源）、`wys_notebooks`（思源笔记本纳入态）、`wys_files`（本地文件索引：相对路径/类型/大小/mtime）、`wys_chunks`（块：来源、块 ID/文件关联、文档标题、路径、正文、向量 BLOB、更新时间）+ `wys_fts`（FTS5 虚表）。
- 不涉及回收站：删除源 = 二次确认后彻底删本工作台索引（同信息源删订阅、图书馆删书先例），源文件永不触碰。

**侧边栏位置与图标：**

- 左栏第 13 项，位于万象库下方、致知己上方（总导览 → 学习库 → 万象库 → **万源库** → 致知己 → 灵感泉 → 文笔坊 → 信息源 → 图书馆 → 推理角 → 记账本 → 白噪音 → 回收站 → 个人档）；ModuleId `wanyuan`。
- 图标取 Google Material Symbols（禁 emoji），候选 hub（多源汇入），备选 merge、storage，以样式设计文档风格为准。

v2.0 备选：

1. OCR 进索引：图片按需识别文本并入 FTS（优先复用 LLM 视觉 API，tesseract 离线备选）。
2. 思源离线兜底：思源未运行时直读工作空间 .sy 文件解析（方案 B）。

5. 反向写回思源：如「AI 问答结论一键存回思源」（createDocWithMd），等场景明确再做。
6. 其他模块 AI 功能接入注入（万象库词条生成、文笔坊协笔等引入万源库检索）。
7. 更大 embedding 模型可选（bge-base-zh / bge-m3），接口不变只换模型。
8. 最近更新笔记块时间线、检索命中统计。
