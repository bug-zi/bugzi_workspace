## 1. 右栏「文献·追问」场景（统一会话流接入）

- `AiChannel` 增 `'literature'`（src/shared/types.ts:27 与 src/renderer/api.d.ts:18 双侧）。
- `electron/ai/services.ts`：`ACTIVE_SESSION_KEYS.literature = SettingsKeys.AiActiveSessionLiterature`（键批次 A 已占位）；`CHANNEL_PERSONAS.literature`：『当前频道是「文献·追问」，你是论文研读助手：围绕当前注入的文献（导读卡/全文上下文）回答提问，解释概念、评估方法与结论、联系领域背景；资料之外的问题明说超出文献范围。』
- **上下文注入**（新服务 `electron/services/agent/ask.ts`）：`startLiteratureAsk(paperId)`——
  1. 定位/新建 literature 激活会话（`getActiveSessionId` → 无则 `createAiSession('文献追问：{title前20字}','literature')` + `setActiveSessionId`）；
  2. 同会话同文献只注一次（系统消息含 `<<<LIT:{paperId}>>>` 标记查重）：组装上下文 = 导读卡全文（mdRead）|| 摘要 + 全文缓存截 40k 字符（**全文走 wrapMaterial 包裹**）+ 元信息头；
  3. `appendAiMessage('system', …)` 后经 `BrowserWindow.send('ai:message', msg)` 推送（AiSidebar onMessage → followSession 自动跟随，推送必达机制现成）。
- **LLM 可见性关键**：`aiChat` 现有 history 过滤掉全部 system 行（辩真进度只作展示）。为 literature 通道开特例——aiChat 内 `ch === 'literature'` 时，取该会话**最新一条**含 `<<<LIT:` 标记的 system 消息，作为额外 system 条目加入 LLM messages（不改动其他通道行为）。
- 入口：文献详情弹窗加「追问」按钮（`agent:askLiterature(paperId)` → FeedModule 新 prop `onOpenAi={openAiWith}` → `openAiWith('', { channel: 'literature' })`；`openAiWith` 的 CHANNEL_BY_MODULE 守卫改 `module !== 'noise' && module !== 'agent'`（MainView 扩 'agent' 后类型成立）。
- 场景标签：`AiSidebar.channelInfo` 加 `literature: '文献·追问'`；三选条（ChatDisposition）不覆盖该场景（保持 learn/wiki/zhijiji 现状），归档对话对其可用。

## 2. 左栏底部呼吸灯 + 任务中心页

- **MainView** 增 `| 'agent'`（App.tsx:61）；主区渲染 `{module === 'agent' && <AgentCenterPage />}`（不 keep-alive，照 NoisePage 先例）。
- **AgentBreathLight.tsx**（新组件，渲染于左栏 MODULES.map 的 recycle 前插位，与音乐吧控件同款 nav-item 形态）：订阅 `onAgentStatus`——`working` = 图标主题色缓脉动（CSS animation，`--color-primary` 呼吸光晕）；`paused` = 灰色常驻 + title 悬停显暂停原因；`idle` = 主题色静默。label「工作台」，点击 `activateModule('agent')`。样式追加至 App.css（agent-breath-* 类，主题变量取色、零 emoji）。
- **AgentCenterPage.tsx**（`src/modules/agent/`，module-page 布局）：
  - 状态条：引擎相位 chip（运行中/暂停（原因）/空闲）+ CPU%/内存实时（onAgentStatus 快照）+ 今日预算消耗（`agent:tokensToday`）+ 引擎快捷开关（`agent:configSet(agent_enabled)`，与个人档同副作用）；
  - 待办行：发现箱待终选 N 条 → 按钮 `MODULE_NAVIGATE_EVENT` 派发 `go('feed','literature')`；
  - 台账表：`agent:runsList`（task_runs 倒序 LIMIT 100）——类型/触发/状态/开始时间/耗时/token/错误（load_pause 等行照显）；顶部手动刷新按钮。
- **IPC**：`agent:runsList(limit?) → TaskRunRow[]`；`agent:dayStats() → { enabled, phase, pausedReason, pendingDiscover, budgetToday, runningTypes, today: {collect,digest,lecture,translate,done按task_type计数}, yesterday: 同构 }`（本地日界换算同 budget.ts 口径；新服务 `electron/services/agent/center.ts`）。

## 5. 验收清单（批次 C → 一期收官）

1. 文献详情「追问」→ 右栏自动切到场景徽章「文献·追问」的会话，能正确回答「这篇论文的方法是什么」等文献内问题；换一篇再追问注入新上下文；会话重启保留。
2. 海选/解读运行中呼吸灯主题色脉动；CPU 打满 15s+ → 灯灰 + 悬停原因；任务中心相位「已暂停」；恢复自动续。
3. 任务中心台账完整（含批次 B 任务与 load_pause 行）；待终选直达跳文献页签；预算消耗与 AI 使用统计口径一致（agent:% 场景）。
4. 总导览新块数字与任务中心一致，点击进任务中心。
5. 模拟升级首启 → 向导出现一次；走完首跑发现箱有货；再启不弹；跳过则引擎保持关。
6. 既有频道/会话流回归（助手/学习/万象/致知己/辩真）无异常；`typecheck`/`build` 全绿。
