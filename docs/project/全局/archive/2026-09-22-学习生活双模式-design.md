# 学习/生活双模式 + 工作台入口迁移（design）

> 创建于 2026-09-22 23:53。源自优化建议区 260922 待完成 5 条（第 4 条「双模式背景」明确后置，本轮只留接口）。brainstorming 四问定稿，开发者逐项拍板。

## 0. 背景与范围

优化建议区待完成五条：

1. 工作台放到总导览和学习库之间；
2. 设置两种模式：学习模式和生活模式——常驻模块（公共模块）、学习专属、生活专属；
3. 模式切换组件放右下角（当前深浅色切换的位置），右下角现有组件上移腾位；
4. 双模式的背景丰富（**后面再说，本轮不做**）；
5. 总导览排版重设计——考虑是否按学习/生活模式设置。

本轮实施 1/2/3/5；4 仅确认接口已留（`app_mode` 持久化后，背景层将来按模式选图即可，零预留改动）。

## 2. 模块归属与左栏渲染

模式 = 左栏的**两套入口视图**，纯显隐控制；数据零动，keep-alive 照常（被隐藏模块不卸载，AI 生成任务不中断）。

| 模式 | 左栏序列（各组内保持现有相对顺序） |
|---|---|
| 学习模式 | 总导览 → **工作台** → 学习库 → 万象库 → 文笔坊 → 信息源 → 音乐吧 → 回收站 → 个人档 |
| 生活模式 | 总导览 → 致知己 → 灵感泉 → 图书馆 → 推理角 → 记账本 → 音乐吧 → 回收站 → 个人档 |

实现要点：

- `App.tsx` 的 `MODULES` 数组每项加 `mode: 'learn' | 'life' | 'common'` 字段；左栏渲染按当前模式 `filter`（`common` 恒显）。
- **工作台**：`AgentBreathLight` 挂载点从「recycle 前插位」（现于记账本之后）改插到 **总导览之后、学习库之前**（即 `m.id === 'learn'` 前插，同现有 recycle 特插范式）。形态不变：nav-item 同构 + 三态呼吸（工作中主题色脉动 / 暂停灰显 + title 悬停显原因 / 空闲主题色静默），label「工作台」，点击 `activateModule('agent')`。属学习专属 → 生活模式下不渲染。总导览「超级工作台」聚合块点击进任务中心照旧。
- **音乐吧**：常驻控件，位置仍在列表尾段（回收站之前），不受模式影响；播放态图标高亮规则不变。

## 3. 模式状态与切换行为

### 3.1 状态存储（settings 键值，零 DB 迁移）

| 键 | 值 | 说明 |
|---|---|---|
| `app_mode` | `'learn'` \| `'life'` | 当前模式；缺省 `'learn'` |
| `mode_last_learn` | MainView 字符串 | 学习模式 last 专属模块（可含 `'agent'`） |
| `mode_last_life` | MainView 字符串 | 生活模式 last 专属模块 |

新增 `SettingsKeys` 三常量（`shared/types.ts`，与既有键同表机制）。

### 3.2 切换组件（右下角）

- 新按钮 `right-col-mode`，置于 `right-col` flex 列**末尾**（最底、原主题按钮位）；自下而上变为：**模式 → 主题（上移一位）→ 音源 → 终端 → AI 活动**。
- 单按钮往返：图标 = 将切去的模式——当前学习模式显示生活图标，点击切到生活；当前生活显示学习图标。图标从 Google Material Symbols 选取（候选：学习 `school` / 生活 `home`，实施时目测定稿）。
- 样式同款三件：钉宽 `var(--ai-width-collapsed)`、`border-left/top` 同边框、hover `--color-primary-soft`；title 提示「切换到学习/生活模式」。
- 显隐规则沿用现状：右栏四面板（debugzi/草稿本/资源管理器/画布）任一展开即不渲染，收起态显示。

### 3.3 切换动作与记忆口径

- **点击切换**：写 `app_mode` → 主栏 `activateModule` 到**目标模式的 last 模块**；无记录（首次）落 `'zonglan'`。
- **last 记忆口径**：仅在当前模式停留**专属模块**时写对应 `mode_last_*`（总导览/音乐吧/回收站/个人档四个常驻不记；切走再切回语义 = 回到上次工作现场）。
- **重启**：启动恢复 `app_mode`（左栏列表按其过滤）；主栏仍固定落总导览（现状不变）。
- **深链跟随**：`MODULE_NAVIGATE_EVENT` / `bugzi:open-agent-center` 等深链，目标模块不在当前模式时**自动切到目标模式**（写 `app_mode`）再跳转——深链是明确意图，模式跟着走。回收站「恢复」跳转同规则。
- 音乐吧/回收站/个人档常驻可达，模式切换不影响右栏 debugzi/草稿本/资源管理器/画布/终端等全局面板。

## 4. 总导览随模式换块（第 5 条）

`OverviewModule` 按当前模式条件渲染（订阅模式状态，模式切换即时刷新）：

| 分组 | 块 | 两模式 |
|---|---|---|
| 公共 | 问候头（用户名+日期）、我是谁、每日挑战、GitHub 式热力图 | 都显示 |
| 学习 | 今日格言（换一条）、学习队列、待学习区待消化数、超级工作台聚合块、轻数字条·信息源未读 | 仅学习模式 |
| 生活 | 每日一题打卡状态（wall.month 被动查，绝不触发出题）、续读直达阅读器、轻数字条·本月支出+十二问题 | 仅生活模式 |

- 轻数字条按模式拆源（实际三源 = 信息源未读 / 本月支出 / 十二问题〔致知己〕）：学习模式只显信息源未读；生活模式显本月支出+十二问题。
- 块内逻辑（聚合 IPC、独立 catch、深链事件）全部照旧，只动显隐与顺序；排版随模式自然分组，不重做样式。
- 生活模式当前 4 个专属块偏少属预期（生活侧聚合块将来按需增补，如灵感泉待办等，本轮不做）。

## 5. 实施边界

- **纯渲染层**：`App.tsx`（MODULES/filter/挂载点/切换按钮/切换逻辑）、`App.css`（mode 按钮样式）、`OverviewModule`（条件渲染）、`AgentBreathLight` 挂载位置、`shared/types.ts`（SettingsKeys + ModuleMode 类型）。**零 DB 迁移、零主进程改动**。
- keep-alive 主栏挂载逻辑不变（MODULES.map 全量挂载，仅左栏入口过滤——**注意**：主栏 keep-alive 列表仍全量渲染所有模块，模式只控左栏可见性，防卸载打断任务）。
- 第 4 条（双模式背景）不做；`app_mode` 即将来背景层的模式依据。
- 深链目标为 `'agent'`/`'noise'` 这类非 ModuleId 视图的处理照旧（独立事件通道不动公共类型）。

## 6. 验收清单（冒烟）

1. 左栏两套序列正确：学习 9 项 / 生活 9 项，工作台在学习模式列第 2 位、呼吸灯三态正常；生活模式下工作台不可见但任务中心经总导览聚合块不可达（聚合块本身仅学习模式显示，符合设计）。
2. 切换按钮：位置最底、图标显目标、点击切换、主题/音源/终端/AI 活动依次上移一位；四面板展开时全列隐藏。
3. 切换落点：学习库→切生活→回生活上次模块（首次落总导览）→再切回→回学习库；常驻页（总导览/音乐吧/回收站/个人档）不记 last。
4. 重启：模式恢复、主栏仍落总导览。
5. 深链跟随：生活模式下经 debugzi/回收站恢复等路径跳学习专属模块时模式自动切到学习。
6. 总导览：两模式块组合正确、轻数字条拆源正确、模式切换即时刷新、深链照常。
7. 被隐藏模块 keep-alive 回归：学习模式触发 AI 生成→切生活→切回，任务不中断。
8. 双主题目检；typecheck 双配置 + build 通过。
