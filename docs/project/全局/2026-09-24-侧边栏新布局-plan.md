> 设计正本：`docs/project/全局/2026-09-24-侧边栏新布局-design.md`（下称 design）。

**Goal:** 左栏改为「上固定 + 中模式区 + 下固定」三段式并落定新条目（含 4 个占位、音乐吧列表化、工作台入口迁入个人档），同时完成收藏夹/论文库/答疑店三个拆分迁移（组件搬家、数据层冻结）。

**Architecture:** 渲染层单侧改动——`App.tsx` 的 MODULES 数组从 `mode` 改为 `seg` 段位模型，侧边栏按三段拼装；三个拆分全部是「现有面板组件移动文件 + 新薄壳模块 + 接线重指」，DB/IPC/AI 频道键零改动。

**Tech Stack:** Electron 44 + React 19 + TypeScript（electron-vite）；验证 = `npm run typecheck` + `npm run build` + dev 手测（本项目无测试套件，TDD 不适用，以类型检查与手测清单为门禁）。

**总原则（每个任务都适用）：**
- 面板搬家 = bash `mv` 移动文件 → Edit 改头部注释与指定行；三个面板（QaPanel/VerifyPanel/ProphetPanel）与 LiteraturePanel 的相对导入都是 `../../` 深度，移动到同级新目录后**导入路径不变**。
- 每任务结束跑 `npm run typecheck`，期望零错误再进下一任务。
