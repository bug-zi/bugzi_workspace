# 侧边栏新布局（学习/生活双模式细分）design

> 创建于 2026-09-24，基于 `docs/project/左侧边栏/侧边栏模块布局.md`（开发者需求稿）经 brainstorming 对齐定稿。
> 需求稿中的编号结构（1,2 / 3-9 / 10-13）经确认为「上固定 + 中模式区 + 下固定」三段式。

## 一、目标与范围

双模式已落地但布局未细分。本轮完成：

1. **①纯布局**：左栏改为三段式（上固定 / 模式区 / 下固定），定稿各段条目与顺序。
2. **②拆分迁移**：收藏夹拆出、论文库拆出、答疑店聚合（组件搬家，数据层冻结）。

本轮**不做**（后续逐个立项，各自 design.md → designs-specs.md → 开发）：

- 新模块开发：播客台、副本库、赋诗苑、娱乐城（本轮仅左栏占位）。
- 惊喜林：已从规划中删除（生活区第 7 位改由灵感泉顶替）。

## 二、定稿布局

| 段 | 条目（顺序即排列顺序） |
|---|---|
| 上固定 | 总导览、文笔坊（学习→常驻） |
| 学习区 | 学习库、论文库(拆)、万象库、信息源、播客台(占位)、答疑店(拆)、致知己（生活→**学习**） |
| 生活区 | 图书馆、副本库(占位)、赋诗苑(占位)、推理角、娱乐城(占位)、记账本、灵感泉 |
| 下固定 | 收藏夹(拆)、音乐吧、回收站、个人档 |

关键归属变化：**致知己从生活区改归学习区**；**文笔坊升常驻**；灵感泉留在生活区（顶替惊喜林位置）。

启动默认页仍为总导览；最后访问模块恢复逻辑不变；主栏 keep-alive 全量挂载不卸载原则不变（占位项除外）。

## 三、三段式结构模型（实现形态）

- `MODULES` 数组条目由 `mode: 'learn' | 'life' | 'common'` 改为段位模型（如 `seg: 'top' | 'learn' | 'life' | 'bottom'`），渲染时按 `上固定 → 当前模式区 → 下固定` 拼装；各组内保持数组相对顺序。
- 音乐吧作为列表项进入下固定段（见 §五）。
- 占位项带 `pending: true` 标记（见 §四）。
- 学习/生活切换按钮（右下角最底位）与主题按钮原地保留，与本次改动无关。

## 四、占位项规范

- 四个占位：播客台（学习区）、副本库、赋诗苑、娱乐城（生活区）。
- 置灰样式渲染（视觉上区别于可用模块），点击 toast 提示「待建」。
- 不占 keep-alive 挂载，不设 MainView，无任何 IPC/DB。
- 图标从 Google Material Symbols 选（禁 emoji，全局硬性规则），候选见 §九图标表。

## 五、音乐吧列表化

- 删除左栏底部音乐吧专用控件（含其「整块单击进混音器页」交互），成为下固定列表项。
- 点击进现有混音器页（'noise' 视图，页面内容零改动）。
- 音乐/白噪音任一在播时，列表项图标主题色高亮（沿用现控件的播放态判定逻辑）。
- 重启记参数默认暂停等既有行为不变。

## 六、工作台入口迁移

- 左栏删除工作台特殊项（含任务中心呼吸灯入口）。
- 个人档页内新增「超级工作台」入口卡，点击切到现有 'agent' 整页视图；后台巡检/任务队列/负载卫兵/预算零改动。
- 总导览「超级工作台聚合块」深链照旧直达 'agent' 视图，不受左栏入口删除影响。
- **呼吸灯改挂个人档列表项图标**：任务队列运行时呼吸提示，保留全局可见性（AgentBreathLight 组件复用，仅换挂载点）。

## 七、拆分迁移（方案 A：组件搬家、数据层冻结）

总原则：**动的只有渲染层组件归属，DB 表、IPC、AI 频道键完全冻结**。右侧边栏场景徽章、历史会话、人设注入按频道键天然兼容。

### 7.1 收藏夹拆出（图书馆 → 常驻）

- 新 ModuleId `favorites`，下固定段，双模式可见。
- 图书馆「收藏」页签内容整体搬出为 `FavoritesModule`（`src/modules/favorites/`）；分类/子类/置顶/拖拽/URL 抓取/Ctrl+点外开等功能零改动。
- 图书馆瘦身为单视图（只剩书架）：页签条删除，「进阅读器时隐藏页签条」逻辑随之消失。
- 数据表不动；收藏不入回收站，无回收站联动。

### 7.2 论文库拆出（信息源 → 学习区第 2 位）

- 新 ModuleId `literature`。`LiteraturePanel` 整体搬出为 `LiteratureModule`（`src/modules/literature/`）；发现箱/正式文献/AI 海选/导读卡·精讲·精译零改动。
- 信息源回归纯订阅：删 `feed | literature` 主页签，回单视图；未读数角标只服务订阅。
- 后端 `window.api.agent.*`（海选/解读/队列）零改动；`agent:status` 实时刷新订阅随面板走。
- 接线重指：文献追问入口（AiChannel `literature`）与「相关内容 → 打开文献详情」深链（原 `litPaperId` 路径）改指新模块。

### 7.3 答疑店聚合（万象库 + 致知己 → 学习区第 6 位）

- 新 ModuleId `answers`，三页签：**问答｜辩真｜预言家**（按需求稿顺序）。
- 面板搬家：万象库 `QaPanel`、万象库辩真面板、致知己预言家面板 → 新 `AnswersModule`（`src/modules/answers/`）。
- 万象库瘦身为：**百科｜科普**（待学习区/笔记本/划词高光留在百科）。
- 致知己瘦身为：**沉淀｜十二问题**。
- AI 频道键不动（verify / prophet / wiki / literature）；面板的 channel 覆盖参数随身带走。
- 回收站数据块不迁移（来源表没变）：辩真/问答/预言家存量记录恢复路径照常工作，回收站块文案本轮不折腾。

## 八、联动收尾

- 全量审计 `MODULE_NAVIGATE_EVENT` 各 target 指向：verify/qa/预言家/文献相关深链重指新模块；总导览「十二问题」块仍指致知己，不受影响。
- keep-alive 全量挂载名单加入 favorites / literature / answers 三新模块。
- `CHANNEL_BY_MODULE` 映射按新归属更新。
- 文档同步：`docs/project/左侧边栏/侧边栏模块布局.md` 写入定稿（含灵感泉替换惊喜林）、CLAUDE.md、README.md、当日 `docs/log/`。

## 十、验收标准

1. `npm run typecheck` + `npm run build` 通过。
2. dev 手测：
   - 学习/生活双模式切换，三段式顺序与定稿表一致；占位项置灰、点击 toast。
   - 致知己出现在学习区；文笔坊/收藏夹在双模式下均可见。
   - 音乐吧列表项进混音器页，播放态图标高亮；底部旧控件已删；切换按钮/主题按钮正常。
   - 个人档「超级工作台」入口进 agent 页；呼吸灯在任务运行时于个人档列表项图标上呼吸。
   - 收藏夹/论文库/答疑店功能回归：分类拖拽、海选/解读、问答/辩真/预言家全流程。
   - 万象库只剩百科|科普、致知己只剩沉淀|十二问题、图书馆单视图、信息源单视图。
   - 深链抽查：总导览各块、相关内容→文献详情、划词问 AI 各场景会话频道正确。
