### 已完成（从新到旧排序）

1. 在万象库中点击“随机来一条”，生成过程中如果切换到其他页面，再重新回到万象库，之前的“随即来一条“就会失效。我希望生成能够不受页面切换影响，就是让AI自己在后台生成，我过个几十秒切回来的时候就可以直接看结果。项目中其他有用到AI生成的地方也要同样支持后台生成，不要被打断，不要把用户束缚在当前页面。
   → 已修复（260902，开发者实测通过）：根因是 App.tsx 用条件渲染（`{module === 'wiki' && <WikiModule/>}`）切换模块——切走即卸载组件，`generating` 状态与完成回调全部丢失；IPC 生成在主进程其实会继续完成并入库，但渲染层结果永不呈现，看起来就是「失效」。修复改为 **keep-alive**：六个模块启动即全部挂载、仅当前模块可见（wrapper `display:contents` / 隐藏 `display:none`），组件永不卸载，切页生成照常进行、回来直接看到结果弹窗，格言库/万象库/辩真阁三个 AI 生成场景一并受益。配套处理了两个次生问题：①MdDialog 的 window 级 Esc 监听在隐藏模块会误关不可见弹窗——改为先探测弹窗可见性（祖先 display:none 时 getBoundingClientRect 为 0）再响应；②keep-alive 后失去「切回重挂即刷新」的隐式刷新——新增 `MODULE_ACTIVATED_EVENT` 自定义事件，切回模块时通知其刷新数据（格言/万象/辩真/灵感/回收站均已接入）。
2. 当前万象库中点击”随机来一条“，半天也生成不出来，我怀疑是生成功能有问题。请你帮我进行验证：1.点击随机来一条，成功生成；2.在手动输入生成中选择博弈论，输入”纳什平衡“，最终成功生成。
   → 验证结论（260902，开发者实测通过）：**生成功能本身正常，无需修复**。用真实 LLM 配置（token.aiedulab.cn / gpt-5.6）逐步复现：「随机来一条」两步（LLM 构思词条名 2.8s + 卡片正文 11.6s，全流程约 15s）正常返回且模板完整；「博弈论+纳什平衡」手动场景 10.7s 正常返回，一句话定义提取成功、四个模板标题全部命中。主进程代码无 bug。「半天生成不出来」的体验实为上一条问题的表现：点击后等待期间切走页面 → 组件卸载 → 结果丢失，看不到任何反馈像卡死。keep-alive 修复后此体验一并解决（等待时按钮保持「生成中…」，切走再回来直接看到新卡片弹窗）。注意 LLM 生成本身需 10~15 秒，期间按钮显示「生成中…」为正常等待。
3. 在格言库中尝试“来十个格言”返回的失败结果：Error invoking remote method 'mottos:generate': Error: LLM 未返回 JSON 数组
   → 已修复（260902，开发者实测通过）：根因是所配 LLM 中转服务（token.aiedulab.cn）的 `json_object` 模式强制 JSON 顶层必须是对象、无法返回顶层数组，模型在「返回数组」指令与该约束冲突时输出 `{"error":"无法按要求生成内容"}`（合法 JSON 但非数组），恰好命中解析器的「LLM 未返回 JSON 数组」报错，且内容固定所以自动重试一次也失败。修复两层：①生成 prompt 改为要求 `{"mottos":[...]}` 对象包裹格式（已实测该服务此模式下正常返回）②`parseJsonArray` 解析器增强——遇对象形态自动取第一个数组字段（mottos/items/data/list 等），同时保留原顶层数组与 \`\`\`json 包裹兼容，换其他 LLM 服务也有容错。
