## 项目总介绍：这是一个打造生活化的个人专属工作台app（电脑端）

这是一个AI coding 的项目。

D:\Code\myapp\bugzi_workspace\docs\project目录是开发者与AI共同维护的项目文档库，确保项目能够稳定推进。

每个子文件夹下面放有design.md和designs-specs.md两个md文档，其中design.md主要由开发者编写维护，AI可以提供修改建议，但是以开发者为主导；designs-specs.md文档则是AI基于design.md严格生成的AI coding的prompt文档，完全由AI自己生成维护，开发者只负责简单的审核，由AI根据designs-specs.md进行开发。
