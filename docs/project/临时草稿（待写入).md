# 临时草稿本

注：仅开发者读取，AI不需要读取该文档。

当前的开发顺序：用户先在文档中写需求——>然后与AI交互对齐需求——> AI编写代码——>用户校验成果，有需要再让AI调整。

然后在AI编写代码或者后期AI调整优化的时候，用户可能就会有更多的需求想要写到文档里，但是有两个问题：

1.目前AI正在读取文档进行操作，添加进内容可能会对AI工作产生干扰；

2.想到的需求适合放到下一轮在进行，否则不好git提交，commit区分每次提交的进度

所以有了这个md文档。这个文档是完全的开发者文档，AI不需要编辑甚至读取这个文件。

- [X]  今天和朋友出去玩，然后谈到线性代数，朋友吐槽说这门课没啥用，我说这门课其实和AI息息相关，有很深的渊源，但是当我想要详细展开讲解我的观点的时候，缺发现我不太能讲出来。这就暴露了一个问题：我对AI的本质可能掌握的还不是很熟练。然后我就有一个想法，就是在工作台中添加一个那种存放我通过不断学习不断成长，自己得到的一些属于自己的独特的答案，然后这个答案也可能会随着我的阅历我的经历然后不断去变化。这个是和我自己学习方向相关的问题——我是计算机相关专业的学生，然后就是在研究AI开发，也在学习python全栈知识等等。然后我突然就想到：现在你对我还不够了解——不知道我的信息。我觉得就是我需要我的工作台足够懂我，才能更好的和我协作，为我服务。除了相关专业的问题以外，还有些问题，比如说，家里长辈会问我未来的规划，有没有考研的打算，然后我自己也对生活有一些自己的想法与认知，以及自己如何看待事件的，自己的人生观价值观等等等等这些问题，很多很多。我现在讲出来的，所描述的，可能也只是冰山一角。不过没关系，我相信在和你交流协作的过程中，我们可以一起慢慢地构造出一个懂我的很了解我的平台助手，也可以构建一个很好的工作角，让我静下来更全面的看自己，复盘自己，整理自己。充实调整总结提高。
