# 万象库知识卡板块标签（优化建议区第 25 轮之一）

- **日期**：2026-09-08
- **状态**：已实施（260908 当轮落地，见优化建议区第 25 轮归档）
- **来源**：优化建议区待完成——「万象库中的每个知识卡，标题处显示该知识点，除此之外我希望在标题右侧再补充上该知识点属于的板块，比如在"棘轮效应"右侧标上"经济学"」

## 背景与问题

卡片弹窗（MdDialog）标题只传词条名（`WikiModule.tsx` 中 `title={cardEntry?.term}`），打开卡片后看不到它属于哪个板块。总览页、笔记本跳转、生成审核弹窗这些入口没有板块上下文，用户读到一半想知道「这属于什么领域」只能关弹窗去看。

数据现成：模块内已加载全量 `sections`（`loadSections`），`WikiEntry.section_id` 直接可查板块名——**零后端改动**。

## 已确认决策

- 展示位 = 弹窗标题**右侧**小 pill（开发者原文「标题右侧」；否决复用现有 `subtitle`——那是标题下方小字行，位置不符；否决拼进 title 字符串——污染标题内容且无样式区分）。
- 形态 = 主题色小胶囊：`--color-primary-soft` 浅底 + 主题色描边 + 主题色文字，0.75em 小字，圆角 999px，`flex-shrink: 0`。

## 实施方案

1. **MdDialog 新增 `titleTag?: string` prop**：渲染在标题文字同一行右侧，常显（含可编辑标题的模块——编辑 input 态下 tag 照常显示在右侧，不冲突）。标题行改横排（标题文字可省略、`title` 属性悬停看全文，tag 固定右侧不被挤掉）。
2. **WikiModule 传值**：`titleTag={cardEntry ? sections.find((s) => s.id === cardEntry.section_id)?.name : undefined}`。所有打开卡片的入口（板块页/总览点击、笔记本跳转、生成审核）自动生效。
3. **CSS**：`.dialog-title-tag` 小 pill，挂 MdDialog.css，双主题用既有主题变量自然适配。

## 边界

- 现阶段仅万象库传入；其他模块弹窗不传则不渲染，行为不变。
- 板块被删除后（词条随板块删除走回收站），恢复/查看路径中 sections 查不到时 `?.name` 为 undefined——不渲染 tag，不报错。

## 验证

typecheck 通过；冒烟——板块页/总览/笔记本跳转/生成审核四个入口打开卡片，标题右侧均显示板块 pill，标题超长时 pill 不被挤掉。
