# 论文库 / 万象库·科普：阅览室收藏夹与回收站临时收存设计

> 创建于 2026-09-29 01:58

来源：开发者 260929 brainstorming 拍板——正式文章区只进不出导致越积越多，改为三页签流转：**发现箱（不变）｜阅览室（原「正式文献/正式文章」更名，功能不变）｜收藏夹（新增，长期保存）**；阅览室读完「收入收藏夹」，不想要的「移除」入回收站临时保存（3 天），替换现有「删除即彻底删」。两模块同口径，一篇覆盖（沿用 260929 抓取三页签先例）。

## 1. 现状与差距

| 模块 | 现有页签 | 删除行为 |
|---|---|---|
| 论文库 | 发现箱｜正式文献 | `deletePaper` 立即彻底删（连解读产物、全文/PDF 缓存、向量、知识链接） |
| 万象库-科普 | 发现箱｜正式文章 | `deleteScienceArticle` 立即彻底删（连解读产物、高光、向量、知识链接） |

差距：读完的文章无处安置，只能留着积压或彻底删（误删无挽回）；无「长期保存」与「看完清理」的分层。

## 2. 定稿流转

```
发现箱「接受」（不变）
   ▼
阅览室（原正式区，favorited_at IS NULL）
   ├── 收入收藏夹（列表行 / 阅读视图头部均可） → UPDATE favorited_at = now
   └── 移除（二次确认） → 置 deleted_at + 回收站快照
收藏夹（favorited_at 非空，按收藏时间倒序）
   ├── 移回阅览室 → UPDATE favorited_at = NULL
   └── 移除（二次确认） → 同上入回收站
回收站（3 天）
   ├── 恢复 → 清 deleted_at；favorited_at 保留 → 自动回原所在区
   └── 到期 / 手动彻底删除 → hardDelete 特判连解读产物、向量、链接、缓存文件
```

页签：`发现箱（n）｜阅览室（n）｜收藏夹（n）`；领域筛选行三页签共用（scopeList 扩收藏夹）；模块头副标题改「发现箱 · 阅览室 · 收藏夹」。

## 3. 数据与迁移（DB v66）

```sql
ALTER TABLE papers ADD COLUMN favorited_at TEXT;
ALTER TABLE papers ADD COLUMN deleted_at TEXT;
ALTER TABLE science_articles ADD COLUMN favorited_at TEXT;
ALTER TABLE science_articles ADD COLUMN deleted_at TEXT;
```

- 存量行两列均 NULL → 全部落阅览室，零感迁移；四条 ALTER 即可，无重建表。
- `PaperRow` / `ScienceArticleRow`（`src/shared/types.ts` 与 `src/renderer/api.d.ts`）加 `favorited_at: string | null`、`deleted_at: string | null`，hydrate（`hydratePaper` / `hydrateScience`）带出。
- `deleted_at` 列为 `discardToRecycle` 的前置要求（其实现是 `UPDATE 表 SET deleted_at` + 快照入 `recycle_bin`），v66 先行满足。

## 4. 服务层

### 4.1 papers.ts / science.ts（同构）

- 列表：`listPapers` / `listScienceArticles` 加 `WHERE deleted_at IS NULL`（「就绪但缓存缺失」自愈重抓随之只作用于未删行）。
- 新增 `setPaperFavorite(id, on)` / `setScienceFavorite(id, on)`：UPDATE favorited_at（收 now / 移回 NULL）+ 触碰 updated_at。
- `deletePaper` / `deleteScienceArticle` 改造为移除语义 `removePaper` / `removeScienceArticle`：直接调用 `discardToRecycle('paper' / 'science_article', id)`（其内部即「UPDATE 置 deleted_at + 快照入 recycle_bin」）；**不再现场清理文件与关联表**（下沉到回收站 hardDelete）。软删行仍在表内，在队抓取任务照常跑完置 ready（runner 按行操作不受影响），恢复后即就绪。
- 原彻底删除逻辑整体迁入 recycle.ts hardDelete 特判，papers.ts / science.ts 不再保留删除函数。

### 4.2 recycle.ts

- `RecycleSource` 增 `'paper' | 'science_article'`；`TABLES`：paper→`papers`、science_article→`science_articles`；`MD_FIELDS` 两源 null（全文缓存与解读产物路径均派生，无表列）。
- `hardDelete` 特判两分支（同 learn/interview_q 内联 SQL 模式，不 import agent 服务防循环依赖）：
  - paper：删 `interpretations`（owner_type='paper'）、`embeddings`、`knowledge_links`、papers 行，连删 `papers/<id>.{md,txt,pdf}`；
  - science_article：删 `interpretations`、`science_highlights`、`embeddings`、`knowledge_links`、science_articles 行，连删 `science/<id>.{md,txt}`。
- `restore` switch 加两 case：清 deleted_at + 触碰 updated_at（favorited_at 不动 → 回原所在区）。

### 4.3 IPC

- 新增 `agent:paperFavorite` / `wiki:scienceArticleFavorite`（id + on）。
- 原删除 IPC（agent:paperDelete / 科普删除）改挂移除（软删）语义，签名不变；渲染层确认弹窗与 toast 文案同步（「已移入回收站，3 天内可在回收站恢复」）。
- 回收站 list/restore/delete IPC 通用，零改动。

## 5. 渲染层

### 5.1 列表（LiteraturePanel / SciencePanel）

- `SubTab` 扩 `'favorites'`；papers 与 favorites 同源列表按 `favorited_at` 拆分（收藏夹按收藏时间倒序），发现箱不动。
- 阅览室行：「收入收藏夹」（即时生效）+「移除」（icon-btn danger → ConfirmDialog「移入回收站，3 天内可恢复」）。
- 收藏夹行：「移回阅览室」+「移除」（同上确认）。
- 领域筛选 scopeList 扩收藏夹，三页签共用同一筛选状态；空态文案两区各配。
- 抓取中徽章 / 门禁（就绪才可点开）逻辑不动，两区行同规则。

### 5.2 阅读视图（PaperReader / ScienceReader）

- 头部操作区加「收入收藏夹 / 移回阅览室」切换按钮（按当前 favorited_at 显态），操作后经 onChanged 回调刷新列表；其余（三页签、划词高光、AI 功能、侧栏能力）零改动。
- 深链（openPaperId / openArticleId、相关内容、知识网络直达）不受影响——文章在哪个区都能打开。

### 5.3 回收站（RecycleModule）

- 筛选下拉新增「论文库」组（tabOf('paper')→新组 key，GROUP_MODE='learn'，组序插「万象库」组后）；`science_article` 归入现有「万象库」组；两者均学习模式视图。
- `backToOf` 按快照 payload 的 favorited_at 细分文案：「论文库阅览室 / 论文库收藏夹」「万象库·科普阅览室 / 收藏夹」；`srcTag`、`summaryOf`（取 payload.title）加条目。
- 恢复后目标模块列表经 useModuleActivated 刷新，无需事件外加分发。

## 6. 边界与取舍

- 移除必经二次确认（全局硬性规则）；收藏/移回即时生效不确认。
- 收藏文章照常参与 A1 知识网络、相关推荐、向量检索、词条链接（行未搬家，关联零断链）；软删行在彻底删除前仍在 embeddings 表内，相关推荐/知识网络查询处需过滤 `deleted_at IS NULL`（实施要点）。
- LLM 未配置不受影响（收藏/移回/移除零 AI）。
- 到期清理走现有 `cleanupExpired`（启动 + 每日零点），hardDelete 特判自动覆盖两新来源。
- 回收站模式视图：两新来源均属学习档。
