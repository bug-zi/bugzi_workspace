# 论文库 + 万象库科普「长文阅读视图化」— 设计

> 创建于 2026-09-27 02:04
> 来源：开发者需求——两模块长文（解读产物/原文）以弹窗呈现不利阅读，改为与信息源文章一致的主栏阅读视图
> 范围：`src/modules/literature/`、`src/modules/wiki/SciencePanel.tsx`、共享 hooks、一条新 IPC；零 DB 改动

## 一、已确认决策

1. **论文库加「原文」视图**：读全文缓存 `papers/{id}.txt`（新增 `agent:paperFulltext` IPC）；仅元信息态在原文视图显示「手动传 PDF」引导。
2. **编辑能力**：阅读视图默认只读（信息源口径），顶栏「编辑」按钮进编辑态，保存后回阅读态。
3. **呈现模式**：FeedModule/ArticleView 同款——点列表行整页切换阅读视图，顶栏「返回列表 + 标题 + 动作区」，正文滚动区居中限宽，Ctrl+滚轮缩放。

## 二、共享件

### 1. `src/hooks/useReaderZoom.ts`（新）

- 从 ArticleView 同款逻辑抽出：滚动容器原生非 passive wheel 监听（Ctrl+滚轮）、clamp 80–200 步进 10、settings 持久化、指示条显隐状态。
- **复用全局 `feed_reader_zoom` 一档**——信息源/论文库/科普三处长文阅读共用同一字号偏好。
- 信息源 ArticleView 本次不动（行为不变，后续可换用 hook）。

### 2. `src/hooks/useSelectionBubble.ts`（新）

- 自 MdDialog 内联划词气泡 effect（约 50 行）原样抽出：`useSelectionBubble(active, bodyRef, selectionActions)`；含「选区落在 `<mark>` 内出取消高光」「气泡自点击不消散」「500 字上限」等既有口径。
- MdDialog 改用此 hook（21 处调用方行为不变）；两个阅读视图复用。
- `.sel-bubble` 三条 CSS 规则自 MdDialog.css 上移 App.css（全局）。

### 3. `src/hooks/useFillHeight.ts`（新）

- 阅读视图根节点量视口 top 贴底自适应高度——论文库（整页切换）与科普（万象库页签容器内嵌、头部/页签仍可见）两种挂载场景通用，免写魔法数高度。

## 三、论文库 PaperReader（新组件）

- LiteraturePanel 加 `readingId` state：点正式文献行 → 整页切换 `<PaperReader>`；`openPaperId` 深链（相关内容/知识网络）直达阅读视图；reader 内点相关内容中的 paper 项就地切换阅读目标。
- 视图页签（recycle-tab 小号）：**导读卡｜精讲｜精译｜原文**：
  - 解读产物：`MdView` 只读渲染；无产物显示「生成」按钮态；生成中按 `runningTasks`（任务类型+refId）精确匹配显示进度，可围观逐章落盘半成品（5s 轮询）。
  - 原文：`agent:paperFulltext` 读全文缓存，纯文本转 md 段落展示（同科普原文视图口径，只读无划词）；`meta_only` 显示传 PDF 引导（importPaperPdf 照旧）。
- meta 行（作者 · 日期 · 语言 · 状态 badge · 来源 badge）+ 摘要（无任何产物时正文区以摘要 + 生成引导为主体）。
- 顶栏动作：编辑、追问（askLiterature 照旧）、关联知识（KnowledgeLinksDialog 照旧）、删除（二次确认）。
- 划词仅「问 AI」气泡（`selectionActions={onAskAi}`；论文无高光载体，不引入高光）。
- 原 640px 详情弹窗与 viewMd 二层 MdDialog 移除。

## 四、万象库科普 ScienceReader（新组件，详情逻辑自 SciencePanel 平移）

- SciencePanel 加 `readingId` state：点正式文章行 / `openArticleId` 深链 → 阅读视图。
- 视图页签：**解读版｜精讲｜原文**（现 `view: 'auto'|'lecture'|'source'` 口径原样平移：语言分流 autoKind、生成中围观半成品 md、进度文案、按任务类型+refId 精确忙碌判定、5s 详情轮询）。
- 划词高光/取消高光/问 AI、`wiki://` 词条链接（onOpenEntry/onCreateEntry props 透传）、「关联与相关」折叠 chips、重试抓取/网页原链——全部保留。
- 顶栏动作：编辑、追问、重试抓取或网页原链（按 status）、关联知识、删除（二次确认）。
- 详情 MdDialog 移除；正文 md 只读渲染 + 编辑态同论文库口径。

## 五、IPC 新增

- `agent:paperFulltext`（ipc.ts + preload.ts + api.d.ts）：读 `papers/{id}.txt`（主进程 `readFulltext` 已有，直接暴露），返回 `string | null`。科普 `agent:scienceFulltext` 今日已加，直接复用。

## 六、样式

- 新增通用 `.module-reader-page` / `.module-reader-bar`（App.css）：整页纵向布局、顶栏单行、正文区居中限宽（max-width ≈ 860px）长文排版；缩放作用于正文容器 font-size（ArticleView 同款）。
- 视图页签复用 `.recycle-tabs .domain-tabs` 小号胶囊变体；主题色系一致。

## 七、不做（YAGNI）

- 不动信息源 ArticleView 与播客台/副本库阅读器。
- 阅读进度不记忆（每次打开从头读，同原弹窗口径）。
- 零 DB 迁移；论文阅读视图不引入高光（无载体表）。
- 导读卡/精讲/精译产物仍走既有 md 落盘与 interpretations 台账，生成链路零改动。

  - 科普：解读版/精讲/原文三视图、划词高光/取消高光/问 AI、wiki:// 词条跳转与建词条、重试抓取、生成中围观；
  - MdDialog 回归：万象卡片划词高光、格言笔记双击编辑等抽查（hook 抽取无感）；
