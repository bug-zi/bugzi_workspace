# 学习库v2.0计划

当前的学习库本身还需要进行一个优化，优化完之后我希望再进行一个升级。


## 优化区

1.生成知识树后，树中的每个知识点在我第一次点击查看的时候还需要再让AI生成一次，这样就导致需要等待30-60s，学习体验不连贯。而且还未生成的知识点和已经由AI生成的知识点没有一个明显的区别。我希望这么改：1.生成树之后，所有的知识点的具体内容都还没生成，没生成具体内容的知识点组件条应该呈现阴影，表示尚未生成内容，只有生成内容，可以马上查看以后才显示当前这种正常颜色；

2.当前如果已经有知识条在加载，就不能再去点击加载其他知识条。我觉得很有必要就是建立一个待加载队列，就是用户通过点击那些还未加载的知识条，把它们放到待加载队列中，按照顺序去一个一个加载。甚至在允许的情况下也可以建立2-3条并行的加载线，提高整体效率；

3.每个树是由多个主题组成的，我希望主题是可以展开收起的，方便我去快速定位。


## 升级区

请你先完成优化区的的内容再来看这里。

首先我对当前的学习库的机制还是有点不清楚：比如我对今日新学给我ONAT网络地址转换；OMIPS与FLOPS；磁盘调度算法这三个知识点就不知道是什么情况——是随机给的吗？请你先和我讲讲当前学习库的整个机制。

然后讲讲当前我想要升级的原因：1.就是这个学习库过于单调，只有通过AI生成知识树，粗略学习相关知识，总感觉缺了些什么，但是我也说不上来到底要学些什么，怎么学。所以这一块如何升级我们还需要好好商讨一下。
