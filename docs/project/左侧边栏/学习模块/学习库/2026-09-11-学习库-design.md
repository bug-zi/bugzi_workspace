## 一、需求结论（brainstorm 摘要）

| 维度 | 结论 |
|---|---|
| 目标 | 系统补专业基础 + 工作即学即用 + 随机涉猎（不考证） |
| 专业范围 | 计算机（与万象库「非专业领域」定位互补） |
| 形态 | 知识树：领域 → 主题 → 知识点，挂卡片，有进度 |
| 建树 | AI 一键生成整树骨架（懒建树），后续可增删改、AI 继续展开 |
| 闭环 | 每日新卡 3-5 张（未学中轮转均摊抽）+ 间隔复习 1/3/7/15 天 |
| 复习毕业 | 走完 15 天档即毕业不再出现；「忘记了」重置回第 1 档 |
| 布局 | 主栏三 tab：今日学习（默认）｜知识树｜高光笔记 |
| 生成时机 | 骨架先行 + 按需生成 + 泵预生成（拒绝建树全量生成 300+ 次调用） |
| 出厂领域 | 8 个：计算机网络、信息安全、Linux 与运维、操作系统、计算机组成原理、算法与数据结构、数据库、编程开发 |
| 删除策略 | 领域/主题「清空才能删」（同万象库空板块规则）；知识点删除入回收站 |
| 划词 | 高光 + 问 AI 带入学习库；问 AI 走右栏新增「学习·问答」频道 |
| 开发者拍板项 | 领域删除选 B（清空才能删）；问 AI 频道选 A（新增学习·问答） |

## 二、数据模型（DB v33）

> 版本号以实施时实际递增为准（v32 已被今日并行会话书架字体占用；实况条款同 v18/v19、v29、v32 先例）。

```sql
CREATE TABLE learn_domains (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  sort INTEGER NOT NULL DEFAULT 0,
  tree_ready INTEGER NOT NULL DEFAULT 0,   -- 0=骨架未生成（懒建树态）1=已生成
  created_at TEXT NOT NULL
);

CREATE TABLE learn_nodes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  domain_id INTEGER NOT NULL,
  parent_id INTEGER,                        -- NULL=主题（挂领域）；知识点挂主题
  level INTEGER NOT NULL,                   -- 1=主题 2=知识点（固定两层，不做多级）
  title TEXT NOT NULL,
  summary TEXT NOT NULL DEFAULT '',         -- 一句话简介（骨架内容）
  state TEXT NOT NULL DEFAULT 'todo',       -- todo|learned
  review_stage INTEGER NOT NULL DEFAULT 0,  -- 0=未学 1..4=复习四档 5=毕业
  next_review_at TEXT,                      -- 本地日期 YYYY-MM-DD；NULL=未学/毕业
  content_ready INTEGER NOT NULL DEFAULT 0, -- 卡片 md 是否已生成
  source TEXT NOT NULL DEFAULT 'ai',        -- ai|manual
  deleted_at TEXT,                          -- 回收站软删（对齐全局模式）
  created_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_learn_nodes_domain ON learn_nodes(domain_id, level);

CREATE TABLE learn_daily (
  date TEXT PRIMARY KEY,                    -- 本地日期 YYYY-MM-DD
  new_ids TEXT NOT NULL,                    -- 当日新卡节点 id JSON 数组（定档不重抽）
  review_ids TEXT NOT NULL                  -- 当日到期复习节点 id JSON 数组
);

CREATE TABLE learn_highlights (          -- 对齐 wiki_highlights 现行模式
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  node_id INTEGER NOT NULL REFERENCES learn_nodes(id),
  text TEXT NOT NULL,
  created_at TEXT NOT NULL
);
```

- 卡片正文存**真实 .md 文件**：`md/learn/<节点id>.md`——仓库扁平路径惯例（与 `md/wiki/<id>.md` 同构：文件名即节点 id，改名/移动不失效），实施偏差已定（原稿嵌套目录作废）。
- `learn_daily` 表本身即幂等记录，不需要 settings key（区别于万象库 `wiki_daily_learn_date` 方案）。

### 状态机

```
                 学会了                    记住了(升档) … 15天档记住
  todo ────────────────▶ learned(stage1,次日复习) ────────────────▶ 毕业(stage5, 不再出现)
                            │  ▲                                     
                            │  └────────── 忘记了(重置 stage1, 次日) ──┘（毕业态无操作入口）
```

- 学会了：`todo → learned`，stage=1，next_review_at = 明天。
- 记住了：stage 1→2（+3 天）、2→3（+7 天）、3→4（+15 天）、4→5 毕业（next_review_at 置 NULL）。
- 忘记了：stage 重置 1，next_review_at = 明天（state 保持 learned）。

## 三、建树与树管理

- **出厂 seed**：首启预置 8 领域（`tree_ready=0`，sort 0-7，按 brainstorm 顺序）：计算机网络、信息安全、Linux 与运维、操作系统、计算机组成原理、算法与数据结构、数据库、编程开发。
- **懒建树（显式触发）**：领域首次点开显示空态页 +「生成知识树」按钮（不偷跑 LLM 调用）；点击后 AI 生成骨架——5-8 主题 × 每主题 5-8 知识点（单领域 30-50 节点，仅 title+summary，`content_ready=0`），一次性事务写入后 `tree_ready=1`；生成中显示进度态，失败保持空态可重试。
- **领域**：可新建（输入名称 → 同款建树流程）/ 改名 / 删除——**清空才能删**：领域内无主题行方可删（二次确认）；可新建领域随时追加，无数量上限。
- **主题**：可增 / 改名 / 删除（判空口径 = 该主题下无知识点节点，**含回收站中未彻底删的**——保证回收站恢复目标永远存在，无孤儿）；主题行操作含**「AI 展开」**：为该主题补生成 3-5 个新知识点（查重跳过已有，事务追加）。
- **知识点**：**手动添加**（输入关键词 → AI 生成完整卡片挂到指定主题，`content_ready=1, state=todo`——「工作即学即用」入口，万象库手动输入同款）；MdDialog 双击编辑（全局一致）；删除入回收站（二次确认），恢复回原主题。
- **进度显示**：主题行「已学 x/y」；领域名旁显示领域总进度（已学/总知识点）。
- 排序：领域按 sort、主题/知识点按创建序追加，v1 不做拖拽调序。

## 四、每日队列（learn_daily 定档）

- **触发**：main.ts 启动延迟 10s + scheduler.ts 午夜零点钩子（同万象库每日批次双触发）。
- **幂等**：`learn_daily` 已有今日行 → 跳过。
- **今日新学**：数量 `3 + Math.floor(Math.random() * 3)` → 3..5；从全部 `tree_ready=1` 领域的 todo 知识点中，领域洗牌 round-robin 轮转均摊（同万象库均摊口径）；无已建树领域（全部 tree_ready=0）则空态提示「还没有已建树领域，去知识树生成知识树」；有树但无 todo 节点则空态提示「树都学完了，去知识树 AI 展开或手动添加」。
- **到期复习**：`next_review_at <= 今日` 且 state=learned 且未毕业，按 next_review_at 升序取前 **10** 张；超出部分不做任何标记，次日查询天然再含（零成本顺延，防假期雪崩）。
- **定档不依赖 LLM**：队列生成只写 learn_daily 行，内容由泵后台补齐。没生成完的点开时该行转生成中、等 `learn:getCard` 现场生成完再开弹窗（可取消）——泵常态秒开，等待态极少出现（实施简化，原稿骨架预览作废）。
- 当日未学完不补救：次日新卡重新抽（todo 节点自然回池），到期卡自然到期。
- 「随机来一条」抽中的卡若恰在今日队列中，列表行状态点实时更新，队列 ids 不变。

## 五、预生成泵（`electron/services/learnStock.ts`，仿 wikiStock.ts）

- **职责**：为「今日队列中的 `content_ready=0` 新卡」串行生成完整卡片 md（每张一次 LLM 调用，携带领域+主题+骨架上下文）；每张完成即写文件、置 `content_ready=1` 并推 `learn:stockChanged`。
- **三触发**（同款）：main.ts 启动延迟 10s ／ 每日队列生成后（fire-and-forget）／ 进入学习库模块（`learn:stockCheck`，覆盖 LLM 事后配置场景）。
- 单飞标志防重入；LLM 未配置静默跳过；单张失败 warn 后继续下一张，残留给下次触发补齐。
- **「随机来一条」**（今日学习页头按钮）：优先从 `todo AND content_ready=1` 均匀随机抽 1 张（平时秒开，泵产即备选池）；无已生成卡才现场生成（生成中态，万象库池空兜底同款）。学完照常走状态机，不影响队列定档。

## 六、学习操作与卡片（MdDialog 扩展 `studyBar`）

MdDialog 新增 `studyBar` prop（不复用万象库 `learnBar`，语义不同避免纠缠；复用其 footer 样式槽位）：

- **未学卡**（今日新学 / 树上点开 / 随机来一条）：单钮「学会了」。
- **到期复习卡**：双钮「记住了」/「忘记了」。
- **已学未到期 / 毕业**：只读态显示状态徽标 + 下次复习日期（毕业显示「已毕业」），无操作钮。
- 关闭/遮罩/Esc = 保留现状，不强制操作（同万象库 learnBar 口径）。
- 操作后刷新队列列表与树进度；toast 确认（「已学会，明天见」/「已记住，x 天后复习」/「没关系，明天再来」）。
- **手动学也算**：从知识树任意点开未学卡读完点「学会了」同样入状态机——队列只是每日推动力。

## 八、卡片模板与划词

AI 生成模板（计算机特化，区别于万象库「定义+解释+举例+启示」）：

```markdown
# <知识点标题>
> 一句话定义（即树节点 summary）
## 原理详解
## 实操示例        ← 命令/代码/配置用代码块呈现
## 工作应用场景    ← 结合运维/安全/开发实际场景
## 延伸（可选）    ← 关联知识点、深入方向
```

- 划词高光 / 问 AI 带入学习库卡片弹窗（复用万象库气泡组件与交互）：高光 = 卡内持久高亮 + 记入「高光笔记」tab（文本+来源知识点+时间，点击跳回原卡，可单删）；问 AI = 引用发送右栏「学习·问答」频道。

## 十、容错与边界

- LLM 未配置：建树/展开/手动添加/随机来一条现场生成路径 → 全局提示 +「去配置」直达个人中心；每日队列定档与复习流转**完全不受影响**（不依赖 LLM）；泵静默跳过。
- 建树失败：`tree_ready` 保持 0，空态页可重试；单卡生成失败：重开重试（getCard 兜底）；泵静默失败下次触发补齐。
- .md 文件读不到（外部损坏）：卡片弹窗显示 MdDialog 既有「（读取失败）」提示（实施简化，原稿「summary 占位 + 重新生成按钮」作废——极端场景，YAGNI）。
- 领域名 UNIQUE 冲突：创建/改名时拦截提示。

## 十一、不做（YAGNI）

- 不做多级嵌套树（固定两层：主题/知识点）。
- 不做拖拽调序、复习日历视图、导出、搜索、按领域筛选今日队列。
- 不做毕业后「重新学」专门入口（「忘记了」重置已覆盖遗忘场景）。
- 不做领域学习优先级/权重设置（轮转均摊即公平）。
- 不做今日队列批量操作。
