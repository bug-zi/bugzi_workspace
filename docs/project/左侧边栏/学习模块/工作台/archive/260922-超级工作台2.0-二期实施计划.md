# 超级工作台 2.0 二期实施计划（收官）

> 创建于 2026-09-22 15:30。依据同目录《260921-超级工作台2.0-design.md》（总纲）第 8 节二期范围与《260921-超级工作台2.0-一期实施计划.md》§5 二期概要产出；一期三批次已全部落地并验证（DB v50）。本文档是二期任务拆解与执行顺序的正计划，逐批 designs-specs.md 依此生成。

> **执行方式（与一期相同）**：按「批次」推进，每批流程固定为——① 生成本批 designs-specs.md（开发者过目，可直接「继续」）→ ② 实现 → ③ `npm run typecheck` + `npm run build` 全绿 → ④ **停下，交给开发者按验收清单在 App 内验证**。**git 全部操作由开发者自行完成，AI 只做代码与文档**（项目 CLAUDE.md 纪律）。

**Goal**：二期交付 2.0 收官三件套——科普线（万象库科普页签/解读阅读视图/词条↔文章双向链接）+ 书籍解读（图书馆 AI 解读入口）+ A1 知识网络扩展（统一链接+手动建链），随后发 **2.0.0** 正式版。

**Architecture**：全部复用一期引擎底座（queue/收集器/解读骨架/guardrails/embedding），零新依赖；科普线走「发现箱 article 分区 → 转正 → science_articles → 自动解读（英文全文解读/中文轻加工分流）→ 万象库科普页签」；书籍解读挂图书馆入口复用解读引擎（kind=`book_digest`）；A1 在既有 knowledge_links/embeddings 上扩实体类型与手动建链 UI。

**Tech Stack**：零新依赖——epub 全文抽取用既有 `fflate` 的 `unzipSync`（books.ts 同款）+ fast-xml-parser；PDF 抽文本复用 papers.ts 的 pdfjs legacy 路径；网页正文 `@mozilla/readability` + `linkedom`（papers.ts 同款）；LLM 走 `chatCompletion`；向量走既有 embedding.ts。

### Task D1：DB v51 + 类型

新表（**迁移前必查 db.ts 实际最新版本号，v51 被挤占则顺延**）：

```sql
CREATE TABLE science_articles (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  authors TEXT NOT NULL DEFAULT '[]',
  year INTEGER,
  date TEXT,                             -- YYYY-MM-DD（渠道原始值，papers 同口径）
  summary TEXT NOT NULL DEFAULT '',
  tags TEXT NOT NULL DEFAULT '[]',
  language TEXT NOT NULL DEFAULT 'zh',   -- en/zh 分流解读方式
  url TEXT NOT NULL,
  source TEXT NOT NULL DEFAULT '',       -- 渠道标识 'mcp:{配置名}' 等
  domain_id INTEGER REFERENCES agent_domains(id),
  status TEXT NOT NULL DEFAULT 'meta_only' CHECK (status IN ('ready','meta_only')),
  fulltext_path TEXT,                    -- userData 相对路径 science/{id}.txt
  glossary TEXT,                         -- 英文全文解读术语表 JSON
  concepts TEXT NOT NULL DEFAULT '[]',   -- JSON [{term, entry_id|null}] 词条关联
  discovery_id INTEGER,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE science_highlights (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  article_id INTEGER NOT NULL REFERENCES science_articles(id),
  text TEXT NOT NULL,
  created_at TEXT NOT NULL
);
```

## 8. 全程纪律（每批自检，同一期）

- AI 不执行任何 git 操作；每批完成由开发者验证后自行提交。
- 后台 prompt 默认零个人上下文（白名单默认全关）；抓取内容仅存本地；科普/书籍解读属**按需任务**不受搜集预算限制，但受负载卫兵与单飞行约束。
- 防注入包裹、抓取限速、UA 标识——全部共用 `guardrails.ts`，不另起炉灶。
- UI 零 emoji 图标（fonts.google.com/icons 取材），组件配色贴主题色系；删除一律二次确认。
- 每小节开发日志记 `> 创建于 YYYY-MM-DD HH:MM`（`docs/log/` 惯例）。
- 每批 spec 生成先行，spec 不得偏离总纲 14 条决策与本文档 §0 已确认项。
