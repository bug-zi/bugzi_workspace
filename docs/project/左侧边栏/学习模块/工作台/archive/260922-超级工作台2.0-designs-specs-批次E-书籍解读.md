# 超级工作台 2.0 · 批次 E（书籍解读）designs-specs.md

> 创建于 2026-09-23 00:08。基于总纲《260921-超级工作台2.0-design.md》§5.3/决策 #9 与《260922-二期实施计划》批次 E 范围生成，依赖批次 D 已落地（interpretations kind CHECK 已含 book_digest、ask.ts owner 模式、任务队列/解读骨架均就绪）。范围：书籍全文抽取（epub/pdf）→ `book_digest` 全书导读任务（产物一律中文）→ 图书馆书卡「AI 解读」入口 + 导读弹窗（查看/重新生成/追问）。**零新依赖；不做自主搜集；入口范围照确认项 #4 全书放开；链接/索引留批次 F。**

## 1. 书籍全文抽取 `booktext.ts`（新文件）

- `ensureBookFulltext(book): Promise<string>`：
  - 缓存命中：`books/{id}.txt`（与书文件同目录、扩展名区分）存在且 ≥200 字符直接返回；
  - **epub**：`readBookFile` 同款读 `books/{id}.epub` → `unzipSync`（books.ts 同款 fflate）→ `META-INF/container.xml` → OPF（`parseEpubMeta` 解析骨架：XMLParser + textOf/toArray 同款容错）→ **spine 顺序**：`spine/itemref[@idref]` → `manifest/item[@id]` 中 `media-type` 含 xhtml 的 href 逐项取 zip 内文件（href 相对 OPF 目录、decodeURIComponent 容错）→ 剥标签（去 `<style>/<script>/<head>` 块 + 全部标签 + 常见 HTML 实体解码）合文（项间 `\n\n`）；**spine 缺失/解析失败兜底 manifest 全部 xhtml**（manifest 顺序）；
  - **pdf**：复用 `papers.extractPdfText`（**本批改为 export**），直接传 `books/{id}.pdf` 绝对路径；
  - 抽取文本 < 200 字符 → 抛错（调用方 toast：扫描版 PDF 无文本层或 epub 结构异常），**不写缓存不置任何库状态**。
- 成功写 `books/{id}.txt` 缓存（一次性生成后复用；删书时随删，见 §4）。
- 章节结构感知（供导读 prompt）：`extractOutline(text)` —— 全文扫描常见章节行（`第[一二三四五六七八九十百0-9]+[章节篇部卷]`、`Chapter \d+`、`数字. 标题` 行首模式，行长 ≤40），去重后最多 80 行，供 E2 注入 prompt（书仅截断时导读仍能感知全书骨架）。

## 2. `book_digest` 任务 `bookDigest.ts`（新文件）+ 追问扩展

- `registerTask({ type: 'book_digest', priority: 15, singleton: true, maxRetries: 1 }, runner)`，`bootstrap.ts` 无需补 import（与批次 D 不同：本任务无自动触发源，仅 IPC 手动，注册放本文件顶层 + `ipc.ts` 已有 bootstrap 引入链……**实际经 ipc.ts import bookDigest 模块即完成注册**，main.ts 引入链不变）。
- 状态机（`interpretations` 行 owner_type='book'、kind='book_digest'）：
  - `runBookDigest(bookId, force)`：已有 running 抛「任务进行中」；已有 done 且 !force 抛 `INTERPRET_EXISTS`（渲染层转确认）；通过后 `enqueue('book_digest', { refId: bookId, trigger: 'manual' })`。
  - runner 开始：先自愈——该 owner 既有 `running` 行（App 重启残留）改 `failed`；随后写 `running` 行（**状态以库为准**，避免 queue.runningRuns 不带 refId 的盲区）；结束 `upsertInterpretation` 置 done；异常先置 failed 再抛。
- runner 流程：取书行（title/author/format/file_path）→ `isLlmConfigured` 守卫 → `ensureBookFulltext` → 读 txt → **输入组装**：全文 ≤60k 字符直接用；超长取「`extractOutline` 章节清单 + 开头 50k + 结尾 10k」（wrapMaterial 包裹，章节清单单独一段）→ 单调用生成**中文**全书导读（英文书即中文导读式重述，决策 #9 一律中文），固定骨架五节（与论文线导读卡同风格、H2 分节、总长 600-1200 字）：`## 这本书讲什么` / `## 全书结构` / `## 各部分要点` / `## 适合谁` / `## 怎么读`；卡头 `# 导读：{title}` + `> {author} ｜ 来源：本地书籍`。产物 `md/interpretations/book-{id}-digest.md`（`writeInterpretationMd` 复用），登记 interpretations（kind='book_digest'）。
- scene `agent:book-digest`；token 记账 `tokensSince` + `ctx.addTokens`；负载暂停/单飞行照既有 queue 纪律（按需任务不受搜集预算限制）。
- `bookDigestStatus(bookId): { status: 'none'|'running'|'done'|'failed', md_path: string | null }`（库行查询，无行=none）。
- **追问扩展**（`ask.ts`）：owner 联合扩 `{ type: 'book'; id: number }`——`bookContext`：注入导读 md（interpretations book_digest done 行读文件）|| 全文节选 40k（wrapMaterial），标记 `<<<LIT:B:{id}>>>`（aiChat `LIKE '%<<<LIT:%'` 零改动）；`agent:askLiterature` / preload / api.d.ts type 枚举同步扩 `'book'`。

## 3. 图书馆入口 UI（`BookDigestDialog.tsx` 新文件 + `BookshelfModule.tsx` 挂入口）

- **书卡入口**：书卡 hover 区现有两颗图标钮（移动到/删除）旁加第三颗 `psychology`「AI 解读」（同款 icon-btn bk-menu，零新菜单体系）；点击开 BookDigestDialog。
- **BookDigestDialog**（props：`book: BooksRecord`、`onClose`）：
  - 打开即查 `agent:bookDigestGet`：
    - `none` → 小弹窗：说明文案（「AI 通读全书生成中文导读，需数分钟；扫描版 PDF 无文本层会失败」）+「生成全书导读」主钮；
    - `running` → 旋转态 +「生成中，可先关本窗，完成后再次打开查看」；订阅 `onAgentStatus`（`book_digest` 事件）自动刷新，done → 直接打开导读 MdDialog，failed → failed 态；
    - `failed` → 失败说明 +「重试」；
    - `done` → 直接打开 **MdDialog**（readOnly，title `导读：{title}`，filePath=md_path）；
  - 导读 MdDialog 扩展：`headerAction`「重新生成」（ConfirmDialog 二次确认 → `agent:bookDigestRun(bookId, true)`，覆盖现有产物）；`footerBar`「追问」（`agent:askLiterature('book', bookId)` → 右栏文献·追问频道自动跟随）+「关闭」；
  - 生成中任务在任务中心可见（既有感知层，零改动）。
- 样式复用全局 dialog/btn 体系，Material Symbols 图标，零 emoji，主题色系。

## 6. 验收清单（批次 E，开发者 App 内验证）

1. 任一 epub 书点书卡「AI 解读」→「生成全书导读」→ 任务中心见 book_digest 行 → 完成后导读 md 可读（五节骨架完整、中文、长书结构感知不限于开头）。
2. PDF 书同流程；扫描版（无文本层）给明确失败提示且不影响其他功能。
3. 同书重复点生成 → 确认弹窗；重新生成后产物覆盖更新。
4. 导读弹窗「追问」→ 右栏切文献·追问频道，能答「这本书整体讲什么」；换书追问上下文随新标记生效。
5. 删书后导读产物与全文缓存连带清理；既有阅读/笔记/书签功能回归零变化；`typecheck` / `build` 全绿。
