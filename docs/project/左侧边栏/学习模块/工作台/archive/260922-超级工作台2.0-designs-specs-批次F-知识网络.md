## 1. 索引与相关推荐扩展（`embedIndex.ts`）

- 新任务 `embed_science` / `embed_book`（均 priority 20 / singleton / maxRetries 1）：
  - `embed_science`（refId=articleId）：`getScienceArticle` → 已有 embedding 跳过 → 输入 = `标题。{轻加工/解读产物 md 节选 8k || 摘要}`（产物取 translation||light 优先读 md）→ `storeEmbedding('science_article', …)` → 相关推荐 `searchSimilar(vec, 10, ['paper','wiki','science_article','book'])` 过滤自身、score ≥0.6 取前 3 → `recordLink('science_article', …)`（同现行 INSERT OR IGNORE similarity）。
  - `embed_book`（refId=bookId）：`getBookRow`（booktext）→ 已有 embedding 跳过 → 输入 = `书名。{作者}。{导读 md 节选 8k || ''}`（interpretations book_digest done 行读文件）→ `storeEmbedding('book', …)` → 相关推荐同上（src='book'）。
  - EmbedUnavailableError → runner 正常返回 + console.warn（批次 B 口径：不重试不炸）。
- **学习库知识点补索引 `backfillLearnNodes`**（照 backfillWikiIndex：`learn_nodes WHERE level = 2 AND deleted_at IS NULL` 且缺 embeddings 行，批量 32，输入 `title：summary`，entity_type='learn_node'）；既有 `embed_index` 与新 `embed_science` / `embed_book` runner 开头均顺带推进一批（wiki + learn 两个补索引都跑，失败静默留待下次）。
- **挂载**：`interpretScience.scienceRunnerOf` 完成尾 `enqueue('embed_science', { refId: articleId, trigger: 'auto' })`（D 时留位兑现）；`bookDigestRunner` 完成尾 `enqueue('embed_book', …)`。
- `science.ts` 扩展：`resolveEntityTitle` 补 `'book'`（books.title）/`'learn_node'`（learn_nodes.title，level=2）；`entitySearch` 补同两类型（learn_node 限 level=2 未删，title LIKE）。

## 2. 手动建链共享弹窗（`src/components/KnowledgeLinksDialog.tsx` + `KnowledgeLinksDialog.css` 新文件）

- props：`{ open, srcType, srcId, title, onClose }`（srcType：'paper' | 'science_article' | 'book' | 'wiki'）。
- **现有链接双向列表**：`links.list(srcType, srcId)` 全量（两方向合并）——行 = 类型图标（description/science/menu_book/auto_stories/school）+ peer 标题 + 来源徽章（`相似 N%` = similarity / `手动` = manual）+ 移除 icon-btn → ConfirmDialog 二次确认 → `links.del(link_id)` → 重载。
- **添加关联**：目标类型下拉（论文 / 科普文章 / 词条 / 书 / 知识点）+ 标题搜索输入（onChange 即搜 `links.entitySearch(type, q)`，≥1 字符，前 10 条）→ 点结果行 `links.add(srcType, srcId, type, id)`（origin='manual'，UNIQUE 冲突主进程静默跳过）→ 清空搜索 + 重载。
- 移除与添加后列表即时刷新；弹窗为共享组件（dialog-overlay 体系，零 emoji，主题色系）。
