# 设计：文笔坊新增「经验书」标签页

> 创建于 2026-09-17 20:35
> 来源：docs/project/新功能开发区.md 待完成区「文笔坊中再添加一个"经验书"的标签页模块——不需要AI功能，由我自己手动增删改查即可。我会记录一些自己认为有用的经验道理在这里面」

## 背景与决策记录

文笔坊新增第四个 tab「经验书」：纯本地零 AI 的一句话经验道理手册，手动增删改查。经澄清确认的决策：

| 决策点 | 结论 |
| --- | --- |
| 条目形态 | 一句话短条目（类似格言，但内容是开发者自己的经验道理）；无标题、无 md 正文 |
| 组织方式 | 平铺单列表，按创建时间倒序；无分类、无置顶 |
| 编辑交互 | 行内快记 + 行内编辑（零弹窗）；顶部输入框 Enter 新建，列表行双击/点编辑钮原地改 |
| tab 位置 | 文笔坊 tab 顺序改为「格言库｜经验书｜写作台｜浮生记」（开发者指定，经验书居第二位）；默认 tab 仍格言库 |
| 存储 | 方案 A——SQLite 新表 `wenbi_experiences`（DB v44）；不存 md 文件（一句话条目配 md 纯属浪费）、不存 settings JSON（违背结构化数据分层惯例且回收站接入困难） |
| 删除 | 入回收站文笔坊块（新增 source `wenbi_exp`），二次确认弹窗，可恢复，3 天后自动彻底删除——走现有通用逻辑零特判 |
| AI 边界 | 零 AI——无任何 AI 入口、无右栏频道、无定时任务 |

## 改动清单

### 1. 数据层（DB v44）

新表：

```sql
CREATE TABLE wenbi_experiences (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  deleted_at TEXT
);
CREATE INDEX idx_wenbi_experiences_deleted ON wenbi_experiences(deleted_at);
```

- 时间戳口径与全库一致（本地时间 ISO 字符串）。
- `electron/services/recycle.ts`：`RecycleSource` 联合加 `'wenbi_exp'`，`TABLES` 映射加 `wenbi_exp: 'wenbi_experiences'`——恢复/彻底删除/过期清理全走通用路径，零特判。
- 回收站渲染侧 `RecycleRow['source']` 联合类型（`src/shared/types.ts` 与 `src/renderer/api.d.ts` 两处）同步加 `'wenbi_exp'`；回收站 UI「文笔坊」块分组纳入 `wenbi_exp`（与 `wenbi_journal`/`wenbi_article` 同块，实施时核对分组映射表）。

### 2. IPC 通道（electron wenbi 服务 + preload + api.d.ts）

仿 journal 通道四条：

| 通道 | 入参 | 行为 |
| --- | --- | --- |
| `wenbi:expList` | — | `deleted_at IS NULL`，`created_at DESC, id DESC`，返回整行数组 |
| `wenbi:expCreate` | content | trim 后非空才建行；返回新整行（供列表头部插入） |
| `wenbi:expUpdate` | id, content | trim 后非空才回写；回写 `updated_at`；返回更新后整行 |
| `wenbi:expDiscard` | id | 复用 `discardToRecycle('wenbi_exp', id)` |

- preload `window.api.wenbi` 挂 `expList / expCreate / expUpdate / expDiscard`；`api.d.ts` 补 `WenbiExperienceRecord` 接口（id / content / created_at / updated_at / deleted_at）与四方法签名；`src/shared/types.ts` 同步类型定义。

### 3. 渲染层

#### `src/modules/wenbi/WenbiModule.tsx`

- board 联合类型 `'mottos' | 'exp' | 'writing' | 'journal'`，默认仍 `'mottos'`。
- tab 行四按钮顺序：格言库、经验书、写作台、浮生记（recycle-tabs 胶囊样式不变）。
- 经验书面板包 `module-live`/`module-hidden` 保活容器，接 `active={board === 'exp'}`（与 JournalPanel 同构）。
- 头部副标题 `格言库 · 写作台 · 浮生记` → `格言库 · 经验书 · 写作台 · 浮生记`。
- `useModuleNavigate('wenbi')` 深链不动（总导览无经验书深链需求）。

#### 新组件 `src/modules/wenbi/ExperiencePanel.tsx`

- **快记框**：顶部自适应高度 textarea（CSS `field-sizing: content`，Electron 44 内置 Chromium 原生支持，配 max-height 滚动兜底），placeholder「记一条经验道理…」；Enter 新建（清空并插到列表顶部，焦点留在输入框连记多条）、Shift+Enter 换行；trim 为空 Enter 不建。
- **列表行**：创建日期（`2026/9/17` 格式同 JournalPanel）+ 内容全文（`whitespace-pre-wrap`，不截断）；行操作=编辑（pencil 图标）+ 丢弃（delete 图标，danger）；**双击行**或点铅笔 → 该行原地 textarea 进入编辑态。
- **行内编辑**：textarea 自适应内容高度；Enter 保存、Esc 取消、失焦保存；保存内容 trim 为空 → 视为取消 + toast 提示「内容为空，未保存」；同时只有一行处于编辑态。
- **丢弃**：点丢弃钮 → ConfirmDialog（标题「放入回收站」，正文「放入回收站，3 天后自动彻底删除」，danger 丢弃钮）→ `expDiscard` → toast「已放入回收站」→ 刷新。
- **刷新时机**（与 JournalPanel 三处一致）：挂载、`useModuleActivated('wenbi')`（回收站恢复后切回刷新）、`active` false→true。
- **空态**：主题色系 Material Symbols 图标 + 引导文案（如「把踩过的坑和悟出的道理记在这里」），无 emoji。
- **样式**：全部复用现有 row-item / zone / btn / journal-date 等类与主题色 CSS 变量，零新彩亮色，双主题自适应。

### 4. 边界与错误处理

- IPC 全部走现有 try/catch + toast 报错模式；列表加载失败 toast 提示、保留旧列表。
- 内容一律 trim 后校验非空：快记空 Enter 不建（无 toast，静默）；行内编辑保存空内容视为取消 + toast。
- 行内编辑切走即保存：切 tab/切模块触发失焦 → 失焦保存兜底生效，不会丢改动（keep-alive 不卸载组件，仅状态自然收束）。
- 无并发冲突场景（单机单窗口）。
- 回收站恢复：恢复条目 `deleted_at` 清空回列表（倒序按 created_at 钉位，位置符合直觉）。
