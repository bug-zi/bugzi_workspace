# 设计：经验书优化（分类夹 + 拖拽排序 + 去时间列）

> 创建于 2026-09-17 23:08
> 来源：开发者同日口头需求——①不需要记录时间消息；②希望可以拖拽调整顺序（和格言库的格言条拖拽功能一致）；③可以建立分类夹（系统整理、处事准则等等）

## 背景与决策记录

经验书（当日上一轮落地，DB v44）三项升级。经澄清确认的决策：

| 决策点 | 结论 |
| --- | --- |
| 分类形态 | **顶部分类 tab 式**——「全部」+ 各分类 + 「未分类」（锁定常驻末位）；开发者指定 |
| 归类方式 | 行操作「移动到…」菜单 + **拖条目到顶部 tab 即归入**（拖拽中 tab 高亮）；开发者选后者合并案 |
| 新建落点 | 快记条目落**当前激活分类**（「全部」tab 下落未分类） |
| 时间列 | 行不显示日期（纯展示移除，created_at 仍存库——回收站 payload 与钉位兼容） |
| 拖拽排序 | 格言库同款：HTML5 draggable + 目标行半差插入 + 区内归一化 |
| 数据模型 | 方案 A——分类独立表 + 条目加 category_id/sort 两列（TEXT 列方案否决：重命名批量 UPDATE、分类排序无处安放） |
| 预置分类 | 迁移预置「系统整理」「处事准则」两夹（开发者举例），同普通分类可改名可删 |
| DB 版本 | **v46**（v45 已被同日并行会话 AI 会话归档占用） |

## 数据层（DB v46）

```sql
CREATE TABLE exp_categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  sort INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL
);
ALTER TABLE wenbi_experiences ADD COLUMN category_id INTEGER REFERENCES exp_categories(id);
ALTER TABLE wenbi_experiences ADD COLUMN sort REAL NOT NULL DEFAULT 0;
```

- 预置：INSERT「系统整理」(sort=0)、「处事准则」(sort=1)。
- 存量回填：`wenbi_experiences` 全部归未分类（category_id NULL），sort 按 created_at DESC、id DESC 赋 0..n-1（迁移后观感与现列表一致）。
- 删分类：该分类**全部行**（含在站条目）`category_id` 置 NULL——在站回未分类；在站外的由恢复守卫兜底（下条）。
- **恢复防孤儿**：`restoreFromRecycle` 的 `wenbi_exp` 分支改为——清 deleted_at，且 `category_id` 不在 `exp_categories` 时置 NULL（顺序：先删条目后删分类场景）。

## 类型

- `ExpCategoryRecord { id, name, sort, created_at }`——shared/types.ts + api.d.ts 双处。
- `WenbiExperienceRecord` 增 `category_id: number | null`、`sort: number`——双处同步。

## IPC（新增六通道 + 复用一通道）

| 通道 | 签名 | 行为 |
| --- | --- | --- |
| `wenbi:expCategoryList` | `() => ExpCategoryRecord[]` | sort ASC, id ASC |
| `wenbi:expCategoryCreate` | `(name) => ExpCategoryRecord` | trim 非空；重名（trim 相等）拒绝抛 `DUP_NAME`；sort=MAX+1 |
| `wenbi:expCategoryRename` | `(id, name) => boolean` | 同重名校验（排除自身） |
| `wenbi:expCategoryDelete` | `(id) => boolean` | 删行 + 该分类全部条目 category_id 置 NULL |
| `wenbi:expMove` | `(id, categoryId: number \| null) => boolean` | 置分类 + sort 取目标夹 MIN-1（插顶；同夹不重复移动时为无感刷新） |
| `wenbi:expReorder` | `(moves: { id, sort }[]) => boolean` | 夹内拖拽归一化批量回写（格言 `mottos.reorder` 同构，不动 updated_at） |
| `wenbi:expList` | 既有 | 保持无参全量，渲染层按 tab 过滤排序 |

preload 与 api.d.ts 的 `window.api.wenbi` 内联声明同步补六方法。

## 渲染层（ExperiencePanel 改造）

- **tab 行**：`recycle-tabs` 胶囊——「全部」｜各分类（按 cat.sort）｜「未分类」（锁定）｜行尾「＋」快建｜「管理」钮。activeTab 会话内保留、重启回「全部」。
- **「＋」快建**：点击弹输入小弹窗（复用现有输入弹窗模式），确认后建分类并切到该 tab；重名 toast 提示。
- **分类管理弹窗**（新组件 `ExpCategoryManageDialog`，ChallengeManageDialog/收藏夹分类管理先例）：列表 + 行内改名（Enter 保存）+ 删除（ConfirmDialog 二次确认，提示「条目将回未分类」）；预置夹同权。
- **视图**：
  - 具体 tab：单列表，按 sort ASC、id ASC。
  - 「全部」：按分类小节分组（节头=分类名 + 数量；未分类节居末；空节不显示）。
- **行**：去日期列——内容 + 操作钮（移动 drive_file_move / 编辑 pencil / 丢弃 delete）；编辑/丢弃交互与上轮一致。
- **拖拽排序**（格言库同款，含 rAF 自动滚动辅助移植）：
  - 可拖范围：具体分类 tab 与「未分类」tab 内自由拖；「全部」视图节内可拖（等价该夹内排序），跨节松手忽略。
  - 落点：目标行上半/下半插入——目标 sort 减半差，随后该夹内归一化 `expReorder`。
- **拖到 tab 归类**：分类/未分类 tab 挂 onDragOver（preventDefault + `drop-target` 高亮类）与 onDrop——`expMove(id, 目标)`，toast「已移入 ××」；拖到「全部」tab 或原夹 tab 为无操作。「移动到…」菜单同走 `expMove`（菜单列表=各分类+未分类，当前夹项置灰）。
- **快记**：落当前激活分类（全部→未分类），sort=该夹 MIN-1 插顶；焦点回输入框连记不变。
- **样式**：新 tab 复用 recycle-tabs；`drop-target` 高亮 = 主题色描边/浅底（color-mix 或 primary-soft 变量）；管理弹窗走现有弹窗体系，零彩亮。

## 边界与错误处理

- 重名分类：创建/改名均拒绝，toast「分类已存在」。
- 删光全部分类：仅剩「未分类」照常工作；「全部」视图仅未分类一节。
- 拖拽中切 tab：dragend 兜底清理 dragIdRef 与高亮类。
- expMove 后渲染层本地更新（免全量重拉）；归一化失败静默（下次进入刷新自然归位）。
- 回收站恢复：孤儿分类守卫（见数据层）；恢复仅清标记、sort/category 保留原值——条目回原夹原位（原夹已删则由守卫落未分类），符合「恢复即回原处」直觉。

## 冒烟清单（交付开发者）

1. 预置两夹出现；「＋」建夹/重名拒绝/改名/删夹（条目回未分类，二次确认）。
2. 快记落当前 tab 夹；「全部」下快记落未分类且插顶。
3. 行无日期；内容与操作钮正常。
4. 夹内拖拽排序（含长列表自动滚动）；「全部」节内拖有效、跨节忽略。
5. 拖条目到 tab 归入（tab 高亮、toast）；「移动到…」菜单等效；「全部」/原夹 tab 拖入无操作。
6. 删夹后回收站恢复条目回未分类（孤儿守卫）；恢复普通条目回原夹原位。
7. 双主题目检（tab、拖拽高亮、管理弹窗）。
