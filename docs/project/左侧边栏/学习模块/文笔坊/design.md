# 文笔坊

介绍：文笔坊是我的写作生活模块，双板块结构——**浮生记**（记录线）+ **写作台**（写作线）。浮生记名取《浮生六记》，自由记录心情感想（不是罗列完成了什么），是整个 App 里第一块 AI 永不涉足的私密自留地；写作台是我博客文章的创作输出台，我为主笔、AI 以 Copilot 方式协笔。本文档由 260907 brainstorming 会话与 AI 协作定稿（原始三件套想法中的「文笔挑战」「文曲星」延后至 v2 备选）。

v1.0：

**模块结构（双板块制）：**

- 照推理角先例：模块顶部两板块切换，浮生记 / 写作台各占完整主栏；两条线气质相反（零 AI 自留地 vs AI 协作创作台），分板块让隐私边界成为物理边界。
- 侧边栏位置（260908 重排后）：信息源下方、致知己上方（格言库 → 万象库 → 藏书架 → 信息源 → **文笔坊** → 致知己 → 灵感泉 → 推理角 → 记账本 → 白噪音 → 回收站 → 个人档）。
- 图标取 Google Material Symbols（禁 emoji），候选 history_edu（鹅毛笔），以样式设计文档风格为准。

**板块一：浮生记（记录线，纯私密零 AI）：**

- 自由记录制：顶部「+ 记一条」随时新建，不限篇数、不选类型、不设标题字段——新建即写，零压力。
- 时间线列表，行组件 = 创建日期 + 首行摘要（截断）+ 大事件标记（如有）。日期取创建日期——日记钉在写下那天，事后编辑不挪动时间线位置。
- 分节粒度可切换：按周 / 按月（默认按月，周按周一至周日计）。「周记」「月记」由此成为同一批记录的两种翻页方式，而非两种要选择的类型。
- 大事件：编辑态一个标记开关；被标记条目除正常出现在时间线外，顶部另有「大事件」置顶小节（倒序聚合），方便回看人生节点。
- 条目弹窗：全局统一 md 弹窗，默认渲染态、双击编辑，与其他模块交互完全一致；弹窗头部显示日期。
- 零 AI 边界：无任何 AI 按钮、不注入我的画像、无 AI 边栏频道联动，AI 永远读不到这里的任何字。
- 删除：行组件回收站 icon，二次确认后进入回收站「文笔坊」板块；md 随条目封存，恢复还原，彻底删除时 md 一并删除（照格言笔记模式）。

**板块二：写作台（写作线，Copilot 式 AI 协笔）：**

- 四区流转（灵感泉同构）：构思区 → 写作区 → 完稿区 → 已发布区。区标题旁「+」新建：弹窗输入标题，创建专属 md 文档并打开进入编辑态；行组件 = 标题 + 更新时间；拖拽跨区自由移动，另配「移动到××区」菜单按钮兜底。
- 「已发布」是手动状态记录：我在博客站发布后自行拖入；已发布区不自动删除（同灵感泉归档区待遇）。
- 文章弹窗：全局统一 md 弹窗 + 写作台专属扩展位（移动菜单、copilot 入口），不影响其他模块对弹窗的使用。
- Copilot 协笔（仅编辑态，AI 永远不直接改正文）：
  - 正文为空 / 构思阶段：工具栏「AI 起稿」——基于标题生成大纲或开头建议；
  - 未选中文本：光标处「续写」——接着当前内容往下写；
  - 选中文本：浮动条「润色 / 改写」——只作用于选中段落。
  - 三种操作的产出均以建议预览卡呈现（原文 vs AI 版对照），我「采纳」（替换/插入）或「放弃」，可重新生成——笔权始终在我手里。
  - 采纳后的文本即成为正文一部分，不做 AI 段落标记——文章是作品，署名是我（与灵感泉「AI 补充」打时间戳的做法刻意不同）。
  - system prompt 注入：我的画像 + 文章标题与正文上下文，让协笔懂我的文风与领域。
  - LLM 未配置：按钮不置灰，点击弹窗提示并「去配置」直达个人档（全局规则）。
- 发布支持：弹窗菜单提供「复制 Markdown」「导出 .md」两个动作；发布本身在博客站手动完成。
- 删除：同浮生记进回收站「文笔坊」板块；恢复时回构思区（最初级区）。

**回收站（第八块，第七块已由草稿本占用）：**

- 新增「文笔坊」板块：浮生记条目与写作台文章同块混放，条目标注来源板块。
- 恢复规则分线：浮生记条目 → 浮生记时间线；文章 → 构思区。3 天自动彻底删除照旧（启动 + 每日零点检查）。

**存储：**

- SQLite 两张表：浮生记条目（id、md 路径、大事件标记、创建/更新时间，无标题字段）；文章（id、标题、md 路径、分区、创建/更新时间）。
- md 真实文件存用户数据目录：文笔坊/浮生记/ 与 文笔坊/写作台/ 两目录。
- copilot 走主进程后台 LLM（同格言库生成模式），不新增 AI 边栏频道——五频道保持不变。
