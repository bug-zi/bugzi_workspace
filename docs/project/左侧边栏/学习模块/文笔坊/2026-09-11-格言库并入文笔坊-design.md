格言库从左栏独立模块移除，并入文笔坊成为其第一块 tab。经澄清确认的决策：

| 决策点 | 结论 |
| --- | --- |
| tab 顺序 | 格言库、写作台、浮生记（开发者指定） |
| 文笔坊默认 tab | 格言库（承袭格言库曾是启动首页的地位） |
| App 启动默认模块 | 万象库（左栏新第一项；现状启动固定落格言库） |
| tab 会话内保持 | 沿用现状——module-hidden 保活，组件不卸载、tab 状态会话内保留，重启回默认（格言库） |
| 头部 | 文笔坊统一头保留，副标题改「格言库 · 写作台 · 浮生记」；格言面板不再有自己的标题行 |
| AI 解读路由 | 格言面板调用 onOpenAi 时显式传 `channel: 'motto'`（当前模块已变 wenbi，CHANNEL_BY_MODULE 不再命中；万象库辩真板块同款显式覆盖先例） |
| 刷新时机 | 切回格言库 tab、从其他模块切回文笔坊，两路径都刷新格言列表（定时生成可能在后台完成） |
| 零改动区 | 格言数据/IPC/DB、回收站格言页签与恢复逻辑、定时生成、「格言·解读」频道、浮生记/写作台面板、文章页层级（写作台 tab 内 openDoc 切文章页、tab 行保留现状） |

- tab 状态 `'journal' | 'writing'` → `'mottos' | 'writing' | 'journal'`，默认 `'mottos'`。
- tab 行三按钮顺序：格言库、写作台、浮生记（recycle-tabs 胶囊样式不变）。
