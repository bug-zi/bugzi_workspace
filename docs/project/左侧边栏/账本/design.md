# 记账本

介绍：记账本是我的轻量记账模块——记资金流水，随时知道手头有多少钱、一个月开支大概多少、大概用在哪些方面。不追求精细记账，纯本地零 AI。本文档由 260908 brainstorming 会话与 AI 协作定稿（设计全记录见同目录 `2026-09-08-账本-design.md`；开发者原始想法见 `docs/project/新功能开发区.md` 待完成区）。

v1.0：

**模块结构（单主视图一体页）：**

- 顶部标题行 +「管理」「＋记一笔」按钮。
- 卡片区：总资产卡（各账户余额合计，实时，不随月份变）+ 月份切换（`<`/`>` 箭头）+ 本月收入/支出卡（随月份）。
- 占比条区：当月支出按分类汇总排行（分类名 + 占比条 + 金额 + 百分比），纯 div + 主题色实现，无图表库；点击某分类 → 流水列表筛选至该分类，再次点击取消。
- 流水列表：按日分组倒序，组头带当日支出小计（今天/昨天相对称呼）；每行 = 分类 · 账户 · 备注 + 金额（支出加负号，颜色仅主题文字色）；行尾 ActionMenu（编辑/删除）。
- 侧边栏位置（260908 重排后）：推理角下方、白噪音上方（格言库 → 万象库 → 藏书架 → 信息源 → 文笔坊 → 致知己 → 灵感泉 → 推理角 → **记账本** → 白噪音 → 回收站 → 个人档）。
- 图标取 Google Material Symbols（禁 emoji），候选 `account_balance_wallet`，以样式设计文档风格为准。

**记一笔弹窗（新增/编辑复用）：**

- 金额（回车提交）→ 支出/收入切换（默认支出）→ 分类宫格点选（随收支切换）→ 账户点选 → 日期（默认今天，可改）→ 备注选填。
- 编辑模式字段预填，弹窗内额外提供「删除」按钮（二次确认）。

**管理弹窗（tab 切账户/分类）：**

- 账户：名称 · 当前余额；新建/编辑均可设**期初余额**（存量资金一次性录入，余额 = 期初 + 流水滚存）；可改名/删除。
- 分类：支出、收入两组；可增/改名/删。

**记录模式与数据：**

- 逐笔记流水（金额+分类+账户+可选备注），多账户（预设：现金/微信/支付宝/银行卡）可增删改名，无转账概念。
- SQLite 三张表（账户/分类/流水）；金额一律存「分」（INTEGER，UI 输元两位小数）；余额不落字段、实时聚合（期初 + 未删收支滚存）；流水日期精确到天。
- 预设分类：支出（餐饮/交通/购物/居住/娱乐/医疗/学习/其他）+ 收入（工资/理财/副业/红包/其他），单级可维护。

**删除流转（回收站由八块变九块，新增「记账本」块）：**

- 流水：软删 + 快照入站；恢复原样回来（原日期/账户/分类不变）。
- 账户：软删入站（站内只见账户一条）；**名下流水一并软删但不单独入站**；恢复级联拉回流水，3 天彻底删级联清除。
- 分类：软删入站；在用流水断为「未分类」（流水本身不动）；恢复后分类回列表，历史流水不自动回挂。
- 删账户/在用分类的二次确认文案写明后果（如「该账户下有 12 笔流水，将一并移入回收站」）。

**边界：**

- 金额必须 > 0、最多两位小数、上限 1 亿元防手滑；账户名/分类名非空查重；无网络无 AI 无外部文件依赖，错误一律 Toast。
