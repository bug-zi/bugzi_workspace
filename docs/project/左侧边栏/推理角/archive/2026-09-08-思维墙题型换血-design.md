# 思维墙题型换血设计（2026-09-08）

> 优化建议区待完成条目：「思维墙的题目还需要进一步升级。当前题目还是过于偏向数学理论知识，我想要的是偏向推理的思维游戏。」
> 经 brainstorming 商讨定稿，2026-09-08。

## 一、背景与问题

思维墙现行题型体系（v1.2）为三选一：`insight_invariant` 不变量与构造 / `strategy_protocol` 策略协议设计 / `counter_probability` 反直觉概率——全部是数学/逻辑理论向；精选题库种子（`WALL_BANK_SEED` 11 题）也全是经典数学谜题（蓝眼睛岛民、和积问题、囚徒抽屉、海盗分金等）。开发者反馈题目过于偏数学，想要「偏向推理的思维游戏」。

## 二、决策记录（brainstorming 敲定）

| 决策点 | 结论 |
| --- | --- |
| 题目方向 | 四方向全要：侦探案情式 / 情境谜题 / 文字语言类 / 生活化逻辑题 |
| 旧数学题型 | **完全替换**——每日一题与练习场以后只出新四类；精选题库已有数学题保留可玩 |
| 种子题库 | **AI 起草、开发者逐题人工验证**（沿用「人工策展」定位）；v19 迁移只追加不动旧 |
| 难度基准 | **整体上移**——难度来自推理链深度与误导强度，而非计算量；脑筋急转弯式题目任何档位都不合格 |
| 连胜升档 | 保持不动（答对 1 天升一档、答错清零回简单） |
| 例题校准 | 四道例题已经开发者确认「质量还不错」（第三题索引由 3-6 修正为 3-7），作为首批种子收录 |

## 三、新题型体系

| 标识 | 中文名 | 定位 |
| --- | --- | --- |
| `detective_case` | 侦探断案 | 案情/场景叙述，破绽藏在细节里——证词矛盾、时间线不对、不可能知道的信息；任务是还原真相/指认说谎者 |
| `lateral_puzzle` | 情境谜题 | 一个奇怪现象问「为什么」，答案需要换掉一个默认假设才能想通；有唯一合理解（与海龟汤开放式问答相区分：题面含足够约束，独立推理可解） |
| `word_logic` | 文字谜题 | 字谜、密码、藏头、语言逻辑、文字规律——纯语言文字游戏，零数学符号 |
| `life_logic` | 生活逻辑 | 生活情境里的推理：谁先推断出什么、信息在人与人之间如何传递；题面是故事不是符号 |

### 难度标尺（写入出题与审题 prompt）

- **简单**：单一关键洞察，但伪装到位——题面有一个「顺理成章的错误解释」挡在真相前面，戳破它才能解题；说破就懂、没有推理过程的脑筋急转弯**不合格**。
- **中等**：多条线索交织，至少一条主动埋设的误导；或需要连续两次转换默认假设；表面解释与真相要有真实的迷惑性竞争。
- **困难**：完整推理链（需整合 4 处以上细节）+ 强误导；单条线索都不致命，合起来才能唯一锁定真相；或需要发明一个解释框架统一所有异常——侦探的「唯一假设」方法。

### 核心禁令（继承 v1.2 反模板精神，措辞改造）

- 不出「套路 + 表面装饰」的题——纯真假话列表逐条排除、纯网格排除、看破套路后机械操作即解的题一律不合格。⚠️ v1.2 开发者曾明令删除「真假话推理」模板：`life_logic` 若只是给真假话模板套生活皮，仍不合格。
- 任何难度档禁止脑筋急转弯式题目（答案靠「知道冷知识」而非「推理出来」）——简单档也要有可陈述的推理过程。
- 答案必须唯一可判定（每日一题依赖 AI 判对错 + 连胜打卡）。

## 四、出题/审题/判答管线适配（prompt 层重写，机制不动）

### 题 1 · 侦探断案（hard）：《雨夜失窃的怀表》

**puzzle**：

暴雨夜 21:35，别墅主人报案：书房书桌上的收藏怀表失窃。警察到场，分开讯问四人。

别墅两层：二楼书房、客房，一楼客厅、厨房、洗衣房；老宅有前后两道楼梯——前梯开口正对客厅，后梯出口紧邻书房门口、楼下通洗衣房。

**主人**：20:00 起在二楼书房看书。21:00 整经前梯下楼到厨房烧水泡茶，21:30 端茶回书房，发现怀表不见了。

**夫人**：20:00–20:40 在客厅与妹妹视频通话（妹妹证实），随后在客厅沙发看书，位置正对前梯。她表示：20:40 之后没有任何人经过前梯。

**管家**：20:30–21:35 一直在一楼洗衣房熨衣服，洗衣房门口能看到后梯。警察随口问「失窃大概发生在什么时候」，她想了想说：「应该是 21:10 大雨下起来那阵——雨声那么响，小偷挑的就是那个时候。」

**客人（留宿的朋友）**：在二楼客房备明日的课，客房与书房相邻。21:00–21:30 间他听到走廊里两回脚步声：21:00 许（远去）、21:30 前后（走近）。21:10 暴雨响起后他戴上耳机，没再留意走廊动静。

**物证**：① 气象记录：21:10 起暴雨，此前全天无雨；② 书房门窗完好，怀表展架平放桌面，无翻动；③ 书房窗从内闩死、窗台无攀爬痕迹，但窗台**内侧有一小片洇湿**；④ 厨房水壶尚温，泡了两杯茶，一杯在书房，一杯还在灶台——主人习惯泡两杯，一杯给管家；⑤ 主人整晚未提过失窃时间，21:35 喊人时只喊了「怀表不见了」。

**问：窃贼是谁？给出完整推理链，并解释窗台洇湿的真正来历。**

**answer**：管家。她持有不可能得知的失窃时间信息（21:10），只有当时动手的人才能把失窃时间与雨起时刻挂钩；窗台洇湿是老宅窗框不严、暴雨随风渗入的自然痕迹，与贼无关。

**solution**：

1. **不可能知识（硬矛盾）**：失窃时间从头到尾无人宣布——主人 21:30 才发现，喊人也只喊「怀表不见了」。失窃发生于 21:00–21:30 之间这件事，只有两个人知道：主人（事后）与窃贼（当时）。管家全程在一楼熨衣，看不见二楼书房，却把失窃时间准确挂到「21:10 大雨下起来那阵」。能拥有这个信息的，只有 21:10 动手的人。
2. **时机自洽**：21:00 主人经前梯下楼（管家从洗衣房门口看得见后梯动静——确认主人离开书房）。她不动手，专等 21:10 暴雨：雨声盖住后梯的脚步与门响，也让隔壁客人戴上耳机。21:10–21:20 间她经后梯上楼（出口紧邻书房门）取表后原路返回。
3. **排除误导一（窗台洇湿）**：洇湿看似「有人雨中进出」，但窗从内闩死、无攀爬痕迹，外贼不成立。实情是老宅窗框不严，21:10 后暴雨随风渗入——自然洇湿。
4. **排除误导二（主人离房）**：主人唯一的 30 分钟空档使他成为头号嫌疑。但水壶尚温、两杯茶（含管家的那杯）坐实烧水属实；客人听到的两回脚步（21:00 远去、21:30 走近）与主人一下一上完全吻合——若主人中途折返，脚步应是四回。
5. **唯一假设**：全部细节在「管家雨中行窃」下无一例外；在其它任何人身上都至少撞上第 1 条的死结。

**hints**：
1. 失窃时间从头到尾没人宣布过——把四人证词里所有提到「时间」的地方与物证对一遍。
2. 窗台洇湿和两回脚步声都是「支线」，不影响主案定人；先放下它们。
3. 管家那句「小偷挑的就是 21:10 雨下起来那阵」预设了她知道什么？谁才可能知道？

### 题 2 · 情境谜题（medium）：《1208 房》

**puzzle**：

午后两点，酒店服务员小周敲响 1208 房的门准备清扫，里面一个男人应声：「不必了，谢谢。」她转去清扫隔壁 1209。14:35 收工时，她发现 1208 的门**虚掩着**——敲门无人应，推门进去，房内无人。房间干净整齐，床铺平整得像没人碰过；书桌上放着半杯咖啡，还冒着热气；窗户大开，窗帘翻飞；一根手指粗的绳索从房内穿出窗外——一端系在卫生间的承重管上，绳结打得又紧又齐整，另一端垂在窗外，坠着一块深蓝色木板。

小周冲到窗边往下看了一眼，立刻拨打了报警电话。

**问：她看到了什么？实际上发生了什么？**

**answer**：她看见一个人悬在十二楼窗外，以为有人坠楼而报警；实际上那是高楼外墙清洗工（蜘蛛人）正在作业——他开 1208 房是当作业平台：安全绳锚在卫生间承重管上，踩着悬吊的深蓝色木板（作业踏板）下放清洗外玻璃。

**solution**：

所有反常细节被「房间用途＝作业平台」一个假设统一解释：床铺平整＝他从没打算住宿；咖啡冒着热气＝刚刚还在房间（开工前提神）；绳结紧而齐整＝专业承重锚点，非临时起意；木板＝作业踏板（自缢或攀逃都不需要踏板和承重锚）；门虚掩＝方便收工翻回、给绳留通道。

小周冲到窗边往下看，看见「一个人悬在十二楼窗外」，第一反应是有人坠楼——受惊报警。

两次翻转：①房间的用途（住宿→工作平台）；②报警的性质（发现案件→她自己看错了）。

**hints**：
1. 系在承重管上的绳结为什么打得那么齐整？什么人才需要这样的锚点？
2. 床没动过、咖啡还冒着热气——这位客人「住」过吗？他开房是干什么来的？
3. 如果你站在十二楼的窗边往下看，看见一个人挂在楼外的空中，你的第一反应会是什么？

### 题 3 · 文字谜题（medium）：《祖父的信》

**puzzle**：

祖父去世后，家人在他留给孙子的信里发现正文之外、角落多了一行谁也看不懂的字——三对数字：

「2-13　2-14　3-7」

信的正文按一句一行誊抄如下：

　我们一起生活过的院子里，槐树比房檐还高。
　每逢六月，白花开满枝头，落在石桌上，浸进你奶奶的茶碗里。
　你总爱蹲在树下数蚂蚁，数着数着就睡着了，阳光透过叶隙洒在你的发梢上。
　如今石桌还在，槐树也还在，只是比房檐更高了。
　你回来的时候去看看吧，今年的花，应该又开了。

**问：祖父想告诉孙子什么？给出完整解法。**

**answer**：「石桌下」——有东西埋在院子里那座石桌下面。数字对是（行-字位）索引密码。

**solution**：

数字对是（行-字位）索引：每对取「第 X 行的第 Y 个字」。

- 2-13 → 第 2 行第 13 字 = **石**（每(1)逢(2)六(3)月(4)白(5)花(6)开(7)满(8)枝(9)头(10)落(11)在(12)石(13)）
- 2-14 → 第 2 行第 14 字 = **桌**
- 3-7 → 第 3 行第 7 字 = **下**（你(1)总(2)爱(3)蹲(4)在(5)树(6)下(7)）

连读＝「石桌下」。信的通篇都在写石桌与槐树，与暗号互相印证。计数细节：只数汉字、标点不计、一句一行——这是解密的第二道坎（起草时原索引误为 3-6，人工数数复核修正为 3-7，恰好说明这道坎真实存在）。

**hints**：
1. 一对数字有两个数——一句话恰好有两个可数的属性：第几句，第几个字。
2. 2-13 和 2-14 同行相邻：取出来的两个字应该挨得很近。
3. 按索引逐字取出来连读（只数汉字，标点不算），别忘了一句一行。

### 题 4 · 生活逻辑（hard）：《额头上的红漆》

**puzzle**：

郊游途中，老师带四个孩子路过一处工地。一阵风起，四个孩子中有若干人额头沾上了红漆。每个人都能看见别人的额头，却看不见自己的；没有镜子、没有互相告知。四个孩子都是完美的逻辑学家，并且彼此知道这一点。

老师对四人宣布：「我确定，你们当中**至少有一个人**额头上有漆。」随后老师说：「谁能**确定**自己额头上有漆，请举手。」老师一共问了四轮。

前三轮：无人举手。
第四轮：四人**同时**举手。

**问：到底几个孩子额头上有漆？给出完整推理——前三轮的沉默各排除了什么，第四轮的集体举手又是如何被逼出来的？**

**answer**：四个孩子全部有漆。

**solution**：

- **归纳奠基**：若只有一个孩子有漆，他看见三张干净额头，老师的「至少一个」只能落在他自己头上——第一轮就该举手。第一轮无人举手 ⇒ 至少两人有漆。
- **归纳递推**：若恰有两人有漆，每个有漆者看见一张有漆的脸，心想「若我是干净的，他在第一轮就会举手」；他没有 ⇒「我也有漆」——两人会在第二轮举手。第二轮无人 ⇒ 至少三人。同理，第三轮无人 ⇒ 至少四人——总共只有四个孩子，于是人人有漆。
- **第四轮**：每个孩子看见三张有漆的额头，推理「若我是干净的，全场只有三人有漆，他们仨第三轮就该举手；第三轮的沉默戳破了这个假设 ⇒ 我也有漆」——四人同时举手。
- **点睛**：老师的「至少一人有漆」对每个孩子（人人看见三张花脸）是废话——但它把这句话变成了「人人都知道人人都知道……」的公共知识，归纳链条由此才能一环扣一环；每一轮的沉默不是没有信息，是信息本身：它宣告「上一轮的推断上限被击穿」。（结构上与种子库「蓝眼睛的岛民」同源——共同知识归纳，但本题由行为轮次反推人数，方向相反。）

**hints**：
