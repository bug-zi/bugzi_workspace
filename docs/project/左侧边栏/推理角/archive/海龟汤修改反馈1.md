# 海龟汤修改反馈1


我玩了几个你生成的海龟汤：有些汤我觉得很不错，有意思；但是也有一些汤过于拘束于专业信息和固定套路，失去了海龟汤的汤味道：

先说我觉得不错的汤：

1.《蓝饭盒》

汤面：周三16:20，小学放学。戴墨镜、拄白杖的父亲在校门口接女儿。女孩隔着口罩叫他“爸爸”，手里却拿着蓝色饭盒；父亲早晨明明给她带的是红色饭盒。女孩解释饭盒是同学借的，午餐吃了八片苹果，盒盖内还贴着星星。父亲握住她的右手，摸到平整的袖口，立刻松手，请保安封闭校门并报警。

汤底：女孩不是他的女儿。父亲失明，绑匪便让一名年龄、身高和声音相近的女孩戴上口罩，在嘈杂的放学时段冒充女儿，企图拖延失踪被发现的时间。假女孩背熟了“星星贴纸”等饭盒细节，却不知道真正的女儿对苹果严重过敏，绝不会吃八片苹果；她也不知道女儿当天右腕受伤，早晨还戴着硬质护具，袖口不可能平整。蓝色饭盒、苹果和缺失的护具连续暴露身份，父亲因此判断女儿已在离校途中被调包。
点评：

亮点：

**核心诡计设计巧妙，逻辑自洽**；**极强的画面感与情绪张力**；

不足之处：

**绑匪的“智商”设定略显单薄（强行降智）**
为了让主角识破诡计，绑匪犯下了几个极其低级的错误。一个精心策划的绑架案，绑匪不仅不知道目标儿童有严重的食物过敏，甚至没有检查受害儿童身上的护具。这种“为了推进剧情而让反派变蠢”的做法，在推理严谨度上稍微欠缺了一点，少了一点“高智商犯罪对决”的窒息感。

** **汤面信息的“刻意感”稍重****
在短短几句汤面中，密集地抛出了“蓝色饭盒”、“八片苹果”、“星星贴纸”、“平整袖口”四个线索。对于有经验的玩家来说，这种“报菜名”式的异常罗列，很容易让人猜到“这些细节里肯定有致命破绽”。如果能在汤面中稍微隐藏一两个细节，或者让父亲的试探过程更具互动性，悬疑感会更自然。

然后说一下我觉得不好的汤：

1.《昨日离场》

汤面：6月17日深夜，档案馆经理死在资料室，死亡时间为22:20至22:50。助理称自己21:55已经离馆；门禁也有他的离场记录，电梯录像显示他22:02穿灰外套、拿着湿条纹伞下楼。然而当天22:40才开始下雨，录像中的广告屏还写着“明日停水：6月17日”，而这条通知中午已改成“今晚停水”。真相是什么？

汤底：助理挪用经费的证据即将被经理发现，于6月17日22:35左右在资料室杀害了经理。他拥有门禁和监控系统的管理权限，先伪造21:55的离场记录，又用6月16日22:02的电梯录像替换当晚画面，并故意让大堂摄像头在关键时段显示网络故障。6月16日晚下过雨，所以旧录像中的伞是湿的；当时广告屏显示的也正是“明日停水：6月17日”。助理忽略了通知在17日中午已经更新，也没料到17日当晚直到22:40才下雨。两处细节共同证明所谓离场录像属于前一天。

点评：汤过于简单，线索过于明显，没有挑战难度。

2.《北窗》

汤面：6月21日下午，绑匪送来一张当天拍摄的拍立得，证明人质仍活着。警方已将藏身处缩小到两座同图纸的废弃气象站：河北承德或海南万宁。照片中，人质举着当天报纸；指南针的N端正对狭窗，阳光从窗内直射，一根竖杆的影子指向S端，旁边日晷的影线恰好压在午线。照片无合成、补光或磁干扰。警方随即奔赴万宁。

汤底：指南针证明狭窗朝北，日晷影线压住午线，证明照片拍摄于当地太阳正经过子午线的真太阳正午。6月21日前后，太阳直射点位于北纬约23.4度。承德在北纬约41度，正午太阳必在正南方，竖杆影子应指向北方，阳光也不可能直接穿过北窗。万宁约在北纬19度，比太阳直射点更南，因此正午太阳反而位于正北方，能照进北窗，并使竖杆影子指向南方。照片中的三项方向证据只能在万宁成立。

点评：汤需要过硬的专业知识，如果不去查阅相关地理知识，很难答上来；而这个汤除了能让玩家学习到新地理知识以外，没有任何作用。没有什么思维推理含量在，汤的浓度不够。

其实像《北窗》这种可以让用户学习到一些知识也挺好，感觉可以在万象库中新增刑侦推理解谜相关模块的知识库。但是没有必要刻意做成一个海龟汤。

然后我不知道你当前生成三个海龟汤是纯随机类型，还是遵照某种特定格式去生成。我希望让汤尽量不要有重复类型的感觉，比如都是在时间上做把戏，重复的话会很无聊。
