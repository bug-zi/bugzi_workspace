# 推理角

介绍：推理角是把 AI 当陪练的推理健身房（侧边栏第 6 个功能模块）。两个板块各练一种推理：海龟汤练横向思维（开放探索、排除、联想），思维墙练精确推理（每日一题、逻辑推演、打卡连胜）。AI 贯穿三种角色：出题人、裁判、教练（局终点评）。每局留档可复盘，看得见自己提问与推理的轨迹。

### 模块结构

- 侧边栏顺序更新为：格言库 → 万象库 → 灵感泉 → 辩真阁 → 致知己 → 推理角 → 回收站 → 个人中心（总需求文档条目 12 与回收站板块数已于 260907 同步更新）。
- 模块内双板块切换（沿用万象库板块切换 UI 惯例）：海龟汤 / 思维墙。
- 全模块依赖 LLM（出题、裁判、点评），未配置时照全局规则 8：按钮不置灰，点击弹「去配置」直达个人中心。

### 板块 A · 海龟汤

**玩法规则：**

我（提问者）只能提判断类问题，AI 只答「是 / 否 / 与汤无关」三种，不给任何多余信息。以经典汤为例：

【海龟汤】汤面：一间屋子两个人听了一首歌，之后相继死去；汤底：霸王别姬。

- 我问「这两个人是互相杀害的吗？」→ AI 答「否，这两个人不是互相杀害」。
- 我不能问「这两个人是怎么死的」——这不是判断句；AI 应回「请提能用是/否回答的问题」引导改问法。
- 我问「这间屋子里除了他们两个还有别人吗」→ AI 答「与汤底无关」。

AI 判答准确的前提是它对汤底有足够深的理解：本汤汤底是霸王别姬，AI 须清楚整个典故——屋中二人是项羽和虞姬，歌是四面楚歌，虞姬为不拖累项羽自刎，项羽突围失败、无颜面对江东父老而在乌江自刎。因此每道汤生成时都要附带一份「裁判解析」（供判答的完整背景），对局时注入裁判 prompt。

**汤库：**

- 「来 3 碗汤」按钮：AI 一次生成 3 道汤，每道三件套：汤面 + 汤底 + 裁判解析。
- 生成时可自选难度偏好（简单 / 中等 / 困难 / 随机，默认随机）；AI 自评难度并打一枚题材标签。
- 汤库列表标记状态：未玩 / 进行中 / 已破 / 弃汤，可按难度筛选。
- 出题 prompt 注入「我的画像」（贴兴趣、避开我熟到秒破的题材）；裁判环节不注入。
- 出题质量标准：汤面须铺足可供盘问的具体事实（抓手），汤底须逐一回收汤面全部细节（无悬空元素、无超自然、本格自洽）；出题 prompt 内置此标准，生成时 AI 逐条自检回收性。

**对局（自由局）：**

- 点汤开局，主栏内嵌对局视图（汤面 + 问答流）；玩法在主栏，不走 AI 边栏频道。
- 提问 → AI 只答「是 / 否 / 与汤无关」（裁判 prompt = 该汤三件套）；非判断句引导改问法，不计入有效问答。
- 「我猜汤底」随时可点：输入完整推理 → AI 判「破汤 / 未破」；未破给方向反馈（哪些点已命中、哪些方向偏了，不泄露关键缺失信息），可继续问继续猜，次数不限。
- 「放弃」：二次确认弹窗后揭示汤底，本局记为弃汤。
- 中断续玩、多局并行：对局状态持久化，「进行中」可挂起多碗汤。

**存档与复盘：**

- 局终（破汤 / 弃汤均）自动存档：汤面、汤底、问答全程、最终推理、结果、提问数、用时。
- AI 局终点评（破汤弃汤都点评）：提问效率点评——哪个问题问在关键上、哪些是浪费、推理链评价；弃汤点评指出卡点。
- 对局记录列表按时间倒序，点击弹窗查看：复用全局 md 弹窗，问答流 + 点评渲染为 md 文档（照辩真阁验证记录模式）。
- 对局记录是快照式（含汤面汤底全文），删汤不影响已有记录。
- 对局记录可删除：二次确认 → 回收站「推理角」板块。

1.致命日记

汤面
2月18日
我在一场聚会上遇到了他，他好像也知道我的想法，主动和我聊天。
2月20日
原来我们有那么多共同爱好啊，和他真的相逢恨晚。
2月28日
他今天又来找我了，也向我表达了他的心意，我们终于在一起了。
3月1日
他和我说一些我不知道的事情，什么女人什么偷情的，我完全听不懂。
3月4日
我不想活了，这就去死。

汤底

主角患有双重人格，人格A(写日记)与人格B(不写日记)每天交替出现。日记日期显示人格A通常在偶数日出现(18日、20日、28日)。然而当年是闰年，二月二十九日(人格B)的存在导致顺序顺延，三月一日变为人格A出现。当天男友来访，因发现人格B(前一日出现)留下的“出轨”痕迹而误会主角，愤而将其杀害。凶手为了掩盖罪行，按照之前的“偶数日写日记”规律伪造了三月四日的遗书，殊不知按规律当天应是不会写日记的人格B，这一逻辑漏洞最终暴露了凶手的身份。

母亲在哭，我被盖住，勉强活了下来。技不如人，我被盖住，都说无人看得上我。羽毛黄沙，我被盖住，最终回到了家。迟迟未睡，我被盖住，我不认识他。

主角出生在重男轻女的习武世家，婴儿时险些被父亲摔死，母亲用厚厚的襁褓将她盖住才保住性命。长大后主角因比武受伤毁容，常年用纱布盖住伤口，导致无人愿娶。为了家族，她女扮男装代弟从军，装成男人当了兵，最终在黄沙漫天的战场上被乱箭射死。尸体盖着白布运回故乡后，贪财的家人为她盖上红盖头，将她卖给大户人家，与一具陌生的男尸合葬配了冥婚。


### 板块 B · 思维墙（每日一题 + 打卡墙 + 练习场 + 精选题库）

- 「墙」取打卡墙之意。每天首次进入思维墙，若当日无题则当场出一道（打开现出，无定时器；v1.3 起优先从预生成题池转正，见「题库预生成」小节）；当天没来，墙上就是空格。连胜 = 连续天数「打开并答对」。
- 题型（v1.2 洞察题重做）：不变量与构造（答案藏在守恒量里，常设一层恰好放行的假守恒当诱饵）/ 策略协议设计（设计必胜或必达协议并论证无懈可击）/ 反直觉概率（结论违反朴素直觉，需严格论证）。核心命题标准：计算难度 ≠ 洞察难度——不出「已知套路 + 更大计算量」的模板题，方法本身要被发明出来；旧四类（逻辑网格 / 真假话推理 / 序列推理 / 文字逻辑陷阱）全部退池。
- 出题质量管线（v1.2 两阶段）：先命题（prompt 内置硬性质量标准自检、三级提示一次生成、标准论证全文随题存库），再审题——审题人只看题面与标准结论、独立重新推演，过结论正确 / 结论唯一 / 条件自洽完备 / 难度达标且不被模板套解四关，不过关回炉重出一次，仍不过不落库。
- 难度锚定（v1.2，难度来自洞察链深度而非计算量）：简单 = 单工具但映射不显然；中等 = 两层洞察链或含诱饵；困难 = 三层以上链或需发明本题特有构造、结论反直觉。
- 难度递进：简单起步，答对 1 天即升一档、封顶困难；答错连胜清零、回简单。题型轮换（近 2 日不重出）+ 近 20 题题面避免清单防同构重出（v1.2）。
- 作答：文字提交 → AI 验证式判答（v1.2，注入标准论证），宽松等价——结论实质相同即算对（同一数值 / 同一结论 / 同一策略或等价构造），只给结论不论证也算对。答错即终局：揭示标准答案 + 完整论证讲解，当天格子记 ✗，明日再战。
- 提示救济：卡住可要分级提示（最多 3 级，方向 → 工具 → 关键构造递进，不直接给答案）；用提示答对仍算打卡成功，记录标注用了几级。
- 打卡墙 UI：月历视图，格子三态——空（没来）/ 亮（答对，标提示级数）/ ✗（答错）；点格子弹窗回看当日题 + 作答 + 讲解（复用全局 md 弹窗）。
- 每日题记录不可删除——墙是真实历史，不进回收站。

**精选题库（v1.2 双层题源第二层）：**

- 人工策展的存量难题随库种子入库（首批 10 题：蓝眼岛民、和积问题、100 囚徒抽屉、海盗分金、千桶毒酒、2017 卡片变体、全装错的信、约瑟夫环、37% 法则、分赌本问题），AI 只判答不出题。
- 一题一命：作答判答（结论 + 论证，结论对即算对）或「看解答」（二次确认后直接揭示）均为终态，不可重做；记录不进回收站。
- 详情 md 含题面 / 我的作答 / 判定 / 标准答案 / 讲解 / 标准论证。

**练习场（v1.1 落地，原 v2 备选「练习场」提前）：**

- 不限每日一题随时刷题：自选难度与题型「来一道」即出，不计入打卡墙 / 连胜 / 月历。
- 会话级数据（重启即清），不落库、不写 md。
- 交互照每日一题同款：三级提示、一题一命（判答即终局）、结果卡内联讲解 + 「再来一道」；换题即弃当前题。

**题库预生成（v1.3 已批准，待实现）：**

- 三处取题（汤库开局 / 每日一题 / 练习场）改为题库预存取用，消除「现场等 AI 出题」的等待：每日题与练习场共用预生成题池，命中即秒开。
- AI 后台补充泵维持库存：汤库未玩汤、预生成题池各维持 10 道，低于 5 自动后台补；触发时机 = App 启动（延迟 10 秒错峰）/ 每次取题消耗后 / 进入推理角时；LLM 未配置时泵静默跳过。
- 「来 3 碗汤」保留为手动补充入口，与泵互不干扰；题池见底或无匹配时兜底现场生成。

### 模块整合与存储

- 回收站第 6 板块「推理角」：汤、对局记录可删（照旧二次确认、恢复回原列表），每日题与精选题库记录不进回收站。
- AI 边栏不新增频道（v1）：对局玩法在主栏，赛后讨论用「助手」频道。
- 画像注入照全局规则 9，统一口径：出题类（海龟汤出汤、思维墙出题）注入；判答类（海龟汤裁判、思维墙判答）不注入。
- 存储照全局分工：汤库 / 对局与问答 / 每日题 / 精选题库元数据存 SQLite；对局记录、每日题详情、精选题档案存真实 md 文件（用户数据目录推理角专属目录）。
- LLM 未配置：出汤 / 出题按钮照全局规则 8；对局中每问都走 LLM，开局入口即拦截提示。
