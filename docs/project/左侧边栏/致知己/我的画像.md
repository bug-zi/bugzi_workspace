
# 我的画像

我是一名杭州电子科技大学25级网络空间安全专业的学生。出生于2007年1月4日，老家温州苍南。我是左右手都用——吃饭拿筷子，打篮球用左手，写字，打乒乓球用右手。由于当今互联网生态成熟发展，很多大学生都以电子游戏为主要爱好，我则不然。游戏对我没有很大的感染力，我也不会沉迷于打游戏。举个例子，如果一天24h，别的大学生用10h睡觉，2h，剩下12h基本就在娱乐。我一天24h大概是8h睡觉，8h学习，8h娱乐——我的娱乐是看书，看电影，运动健身，听歌，弹吉他弹电子琴甚至自己写歌，这是我的日常生活，和别的大学生的一个不同。然后就是周末或者放长假——周末我一般还是和日常生活一致，该学习学习该娱乐娱乐，偶尔有同学找我出去玩或者来我学校找我玩，或者我去上海找同学玩——频率大概是2周一次。然后我喜欢去看演唱会，频率大概1个月一次。然后长假的时候，我喜欢旅游——虽然长假很多时候旅游人很多，不过我还是喜欢到不同地方多看看。我认为自己擅长的地方：有创造力和创新力，可能想象力没有那么丰富，在写小说和绘画方面不太行，但是在和朋友玩的时候，我总会有很多的点子，可以让大家玩得开心。思维能力远超同龄人——外在表现出来的是成熟和包容，内在表现不好用语言表达，举一些具象的例子：我有自己的笔记系统，包括线性笔记和思维导图式笔记，从获取信息——信息沉淀加工——知识库迭代；我会有自己的想法和主张，不拘泥于学校教学的知识，也不看不起学校的课程——基于自己的长期学习方向的需要，去有选择性的听课，获取自己需要的东西。更多的还是通过课外资源去补充更多的学习知识这些。前面提到我的专业是网络空间安全，不过我对自己专业不是很感兴趣，只作为一个学习的次选方向，主方向是AI和开发岗位——程序中的后端开发或者测试开发方向，然后也会借助AI弄全栈开发。我觉得在我把AI和开发掌握的比较好了，有精力了，在回来看一些和安全相关的知识——也不需要精通，就是有一个基本的掌握，掌握一些为开发服务即可。我当前是准大二学生，我可能想要尝试再花2个月时间做一些准备，在11月份期中考试之后开始找一些公司的日常实习——从中小岗位的AI全栈开发或是后端开发找——争取积累一些实习经验，然后在大二寒假看有没有机会到大厂实习，没有就先继续在小厂实习，积累经验。然后到大二下的期中或是暑假开始面试大厂实习，争取拿到，然后看大三能不能拿到大厂offer。在大厂积累经验，然后也是观望AI时代的发展，最终看能不能找到合适的时机，遇到合适的志同道合的同事，一起出来创业。

---

目前就想到这些，当然上面这些远远不足以说明我的全部我的一切。不过我暂时也没想到补充啥，你可以主动提一些比较重要的但是我还没提到的点，让我继续补充完善。你先好好看看——因为是我直接写出来的，也没有经过加工，所以可能看着有些乱，需要整理一下的。
