介绍：致知己是一个自我认知沉淀模块（名取「格物致知」+「知己」双关）。我把自己在不断学习、成长过程中得到的、属于自己的独特答案存放在这里——每个答案今后还会随阅历变化而重写。核心实体是「一个问题 + 我的多个答案版本」：答案只能由我自己写，AI 不代笔，只负责「追问检验」，帮我把答案想透。本文档同时覆盖两项配套改动：个人档新增「我的画像」一节（让 App 懂我），以及右侧 AI 边栏的「频道制」改造（各 AI 场景互不串味）。

v1.0：

**主列表：**

- 侧边栏位置（260908 重排后）：文笔坊下方、灵感泉上方（格言库 → 万象库 → 藏书架 → 信息源 → 文笔坊 → **致知己** → 灵感泉 → 推理角 → 记账本 → 白噪音 → 回收站 → 个人档）。
- 列表按最近更新时间倒序，每行显示：问题标题、领域标签、版本数、最近更新时间。
- 顶部「+ 新问题」按钮：弹窗输入问题标题（必填）+ 领域标签（可选、可多个），创建后自动建立空白 v1 版本并打开弹窗进入编辑态。
- 领域标签用于归类展示（如：线性代数 / AI / 职业规划 / 人生观）；按标签筛选等进阶能力放 v2。

**问题详情弹窗（复用全局 md 弹窗）：**

- 与格言笔记 / 灵感文档同一弹窗组件：默认渲染态，双击任意处切换编辑态，退出编辑恢复渲染。致知己专属的版本切换条、「让 AI 追问」按钮、覆盖勾选以扩展位加在弹窗上，不影响其他模块对弹窗的使用。
- 版本切换条位于弹窗顶部：列出该问题全部版本（倒序，如 v3-260905 / v2-260902 / v1-260901），当前版本高亮，点击切换查看；一次只呈现一个版本，不做并排对比。
- 保存即版本：退出编辑默认保存为新版本，版本标识 `v{序号}-{YYMMDD}`（同日多次保存新版本靠序号区分）；弹窗内提供「覆盖当前版本」勾选项，勾选后保存时序号不变、日期更新为覆盖当日。
- 「让 AI 追问」按钮：点击后右侧边栏自动展开并切到「致知己·追问」频道，带入当前问题与当前版本答案，AI 自动发起第一轮追问。AI 人设是「较真的朋友」：找逻辑漏洞、要例子、问边界，只提问不代笔，绝不输出答案文本。追问是多轮对话，保留在频道历史中；我作答后回到弹窗改写答案、存新版本。
- LLM 未配置时按钮不置灰，点击弹窗提示并「去配置」直达个人档（全局规则）。

**删除与回收站：**

- 每条问题可删除：二次确认后进入回收站「致知己」板块（第五块），恢复时回到主列表；存放满 3 天自动彻底删除照旧。
- 问题进回收站时其全部版本 md 封存，恢复时还原，彻底删除时 md 一并删除（照格言笔记模式）。

**存储：**

- 问题与版本信息存 SQLite（问题一张表，版本挂在问题下：序号、日期、md 路径），每个版本正文是一个真实 .md 文件（沿用格言笔记 / 灵感文档模式），存于用户数据目录致知己专属目录。

**种子问题：**

- 首次使用时预置一条种子问题「线性代数和 AI 有什么渊源？」，文档内预填四个思考锚点材料：① 神经网络每层即矩阵乘法 y=σ(Wx+b)，训练即学出 W；② 词语表示为向量，语义相似度 = 向量夹角；③ 注意力 QKᵀV 本质是线性代数运算，LoRA 靠低秩近似；④ AI 每生成一个字背后都是海量矩阵运算。由我用自己的话写出 v1。

**配套改动一：个人档「我的画像」**

- 个人档新增「我的画像」一节（位于个人信息与 App 设置之间）。
- 画像 = 一组结构化条目，每条 = 类别 + 内容；类别如：基本档案、性格特质、擅长能力、兴趣爱好、生活方式、社交出行、学习与技能、职业规划、价值观、其他（可自定义；260907 按开发者自述细分同步）。一条一记录，可手动增删改。
- AI 提炼入档：AI 对话中识别到关于我的稳定信息（专业、规划、观点、偏好等）时，主动提议存入画像——提议以卡片形式出现在对话流中，我确认后才入档，可忽略。
- 画像注入：我的画像注入全部 AI 功能的上下文（格言生成、万象生成、辩真验证、AI 助手各频道），让所有 AI 功能「知道我是谁」。v1 全量注入即可。
- 存储按一条一记录设计，预留未来接本地向量库（sqlite-vec）做检索式注入的升级路径。

**配套改动二：右侧 AI 边栏「频道制」**

- 边栏外壳不变（可收起 / 展开），内部按场景分频道：一个频道 = 一个独立会话空间，各有独立会话历史（沿用现有会话列表管理）与独立的 system prompt 人设，互不串味。
- 首期四个频道：助手（现有自由对话）、万象·问答、致知己·追问、辩真·核查。格言库 AI 生成走后台不经边栏，暂不设频道。
- 频道切换栏常驻边栏顶部，随时可切；手动展开边栏时停在上次所在频道。
- 触发联动：模块内点「问 AI / 让 AI 追问 / 开始验证」→ 边栏自动展开并切到对应频道、带入上下文。
- 人设注入：每频道 system prompt = 频道人设（助手 = 通用助手、万象 = 知识讲解员、致知己 = 较真的朋友、辩真 = 核查员）+ 我的画像 + 模块上下文。
- 数据兼容：AI 会话表加 channel 字段，存量会话全部归入「助手」频道，零迁移成本。
