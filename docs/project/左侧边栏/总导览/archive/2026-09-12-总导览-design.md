## 一、需求拆解

1. 左栏最上方加「总导览」（原任务表述「具体放什么还没想好」→ 本次 brainstorming 定稿为今日驱动页）。
2. 启动项目初始默认显示总导览页（现默认学习库，260912 优化建议区第 41 轮设定）。
3. 零 AI：所有取数均为本地 SQLite 既有端点；出题/生成等 LLM 动作一律留在目标模块内，总导览绝不触发。

## 二、接线

- `ModuleId` 增 `'zonglan'`（拼音，沿 zhijiji/wenbi 先例）；`MODULES` 首位插 `{ id: 'zonglan', label: '总导览', icon: 'space_dashboard' }`，左栏 11→12 项。
- 启动默认：App.tsx `useState<MainView>('zonglan')` 且 `moduleRef` 初值同步改（moduleRef 与 state 不一致会在首个模块切换时误发失活事件——第 41 轮教训）。欢迎引导流不受影响。
- `CHANNEL_BY_MODULE` 不列（零 AI，默认助手频道）；App 传 `onNavigate` prop（activateModule 包装；feed `onNavigateToProfile` / ZhijijiModule 同款先例）。
- 新建 `src/modules/zonglan/`（OverviewModule.tsx + zonglan.css）；主进程/IPC/preload/api.d.ts 业务区/DB 全部零改动。

## 三、页面结构（module-page 纵向定序，不做拖拽自定义）

1. **问候头**：`{用户名}，X月X日 周X`（用户名取个人档 settings；未设置退「你好」；日期本地拼接）。
2. **今日格言卡**：`mottos.list(正式区)` 客户端随机一条（内容 + 出处），卡角「换一条」icon `refresh` 本地重摇；点击卡片深链文笔坊格言库 tab。正式区空 → 整卡隐藏。
3. **今日学习卡**：`learn.daily()` → `{ new, review }` 汇总行「新学 X · 复习 Y」+ 条目列表（两组各列前 5 条，超出「…等 N 项」）；整卡点击深链学习库「今日学习」tab（不逐卡定位）。队列空 → 引导文案 + 「去学习库」（LLM 未配置或未生成场景）。
4. **待消化卡**：`wiki.learnEntries().length` → 「待学习区 N 张待消化」→ 深链万象库待学习区视图；N=0 显「今日无待消化」置灰不可点。
5. **每日一题卡**：`wall.month(当年, 当月)` **被动**查今日打卡状态与连胜——「未打卡 / 已完成 · 连胜 N 天」→ 深链推理角思维墙每日一题。⚠ 绝不调出题端点（打开现出会现场生成耗 LLM）。
6. **续读卡**：`books.list()`（最近阅读在前）首条 → 书名 + 进度% + 今日阅读分钟（`books.readStats().todayMinutes`）；点击深链藏阅阁并直接 `openBook` 进阅读器。无在读书（list 空或全部未读）→ 「去藏阅阁导入」。
7. **轻数字条**（页尾一行三项，点击直达）：信息源未读合计（`feeds.list()` 各源 unread 求和 → 信息源）/ 本月支出（`ledger.stats(当月)` → 记账本）/ 阅读连续 N 天（readStats → 藏阅阁书架）。

## 四、数据流与加载

- 挂载 + `useModuleActivated('zonglan', loadAll)`：7 个现有 IPC `Promise.all` 并行，**逐块独立 catch**（单块失败/空数据仅该块空态，不拖垮整页）。
- 全部端点既有且本地：`learn.daily` / `mottos.list('formal')`（正式区，status 码已核） / `wiki.learnEntries` / `wall.month` / `books.list` / `books.readStats` / `feeds.list` / `ledger.stats`。

## 五、深链机制

- App.tsx 新增 `export const MODULE_NAVIGATE_EVENT = 'bugzi:module-navigate'`（与 `MODULE_ACTIVATED_EVENT` 同处），detail `{ module: ModuleId; target: string; payload?: Record<string, unknown> }`。
- 新 hook `src/hooks/useModuleNavigate.ts`：`useModuleNavigate(moduleId, handler)`——与 useModuleActivated 对称的 window 事件监听（keep-alive 组件常驻，藏于后台也能接住）。
- 总导览点击 = `window.dispatchEvent(CustomEvent)` + `onNavigate(module)`；keep-alive 下目标模块监听器先收事件切内部视图，模块切换完成即见目标视图。
- 六个目标监听（各约 10 行）：

| 目标模块 | target | 行为 |
|---|---|---|
| 学习库 | `today` | 内部 tab 切「今日学习」 |
| 万象库 | `learn-zone` | View 切 `{ kind: 'learn' }`（待学习区） |
| 推理角 | `daily` | 切思维墙每日一题 tab |
| 藏阅阁 | `read`（payload.bookId） | 壳切书架页签 + BookshelfModule 找书 `openBook` 进阅读器（items 未载完则等 `books.list()` 后开） |
| 文笔坊 | `mottos` | board 切「格言库」 |
| 信息源 / 记账本 | 无 target | 纯切模块（默认视图即目标） |

## 六、明确不做

- 不放回收站/个人档/白噪音状态；无消息中心/通知聚合；块不支持自定义排序与显隐配置；无 AI 日报/AI 问候语；总导览侧零 LLM 调用。
- 不改学习库/万象库/推理角/藏阅阁等模块既有功能（仅各加一个导航监听）。
