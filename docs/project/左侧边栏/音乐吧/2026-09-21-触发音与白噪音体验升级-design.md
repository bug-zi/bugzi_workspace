# 触发音与白噪音体验升级 设计记录

> 创建于 2026-09-21 20:08
> 来源：`docs/project/新功能开发区.md` 待完成区任务（开发者 260921 提出，当日 brainstorm 商定）。
> 定位：音乐吧白噪音侧升级——触发音（ASMR 助眠触发声）并入混音层 + 立体声声像 + 新场景 ×4 + 淡入淡出过渡。本文件为实施设计记录。

## 一、需求结论（brainstorm 摘要）

| 维度 | 结论 |
|---|---|
| 触发音来源 | **混合**——内置合成近似（合成效果好的脉冲型）+ 导入真实录音（耳语/刷头等合成永远做不像的，咖啡馆人声近似先例证明此路有上限） |
| 使用形态 | **并入白噪音混音层**——触发音作为跨场景叠加层，任意场景之上自由勾选叠加，随机间隔触发；自定义混音/播放队列/右栏快捷控件全部自然复用（不做独立声板页签） |
| 立体声 | 每层可调左右声像；触发音可设「游移」——每次发声随机左右摆位（耳机 ASMR 标志体验） |
| 新场景 | 雷雨 / 雪夜 / 风 / 溪流（复用稳态+事件层架构，各配 3 出厂预设） |
| 过渡 | 播放/暂停/切场景淡入淡出（现为硬切） |
| 睡眠定时器 | **本轮不做**（开发者明确未选） |

架构路线取舍：触发音若塞进各场景层表会跨 5+ 场景重复声明且导入项逐场景重复出现；做成独立场景则无法与雨声叠加——均排除，取「跨场景叠加层」。

## 二、总体架构：跨场景叠加层

- 场景（雨/森林/海浪/篝火/咖啡馆/+新增 4）仍是基础氛围层；触发音是与场景**并行**的全局层组，任意场景之上叠加。
- 触发层机理 = **随机间隔单发声**：每 2~8 秒随机抖动触发一次（区别于场景事件层的固定模式调度）。导入样本走 AudioBuffer 单次播放；内置走合成函数单发。
- 混音状态扩展：`{sceneId, layers, master}` → `{sceneId, layers, triggers, master}`，`triggers: Record<id, {on, vol, pan, roam}>`。`NoiseState`（settings JSON）同形扩展。
- 自定义混音保存/召回、播放队列项自动携带触发层状态，队列逻辑零改动；场景层与触发层音量独立，主音量统一管总输出。

## 三、触发音素材

**内置合成 9 个**（选合成效果好、助眠视频流行款）：

| 触发音 | 合成思路 |
|---|---|
| 木桌轻叩 | 短噪声脉冲 + 低频谐振衰减，随机音高微变 |
| 玻璃杯轻敲 | 高频谐振 ping 短衰减（咖啡馆杯盘同族） |
| 翻书页 | 带通噪声 swish 快扫（纸摩擦） |
| 机械键盘簇 | 3~5 连 click 短脉冲簇 |
| 剪刀开合 | 金属短促 snip 两连 |
| 泡泡纸 | pop 单发（短促爆破噪声） |
| 塑料袋窸窣 | crinkle 碎脉冲簇（篝火噼啪同族变体） |
| 风铃 | 多泛音 chime 随机 2~3 音错落长衰减 |
| 颂钵 | 低频基音+泛音长衰减嗡鸣（助眠向） |

**导入真实录音**（补耳语、刷头、梳发类）：
- `trigger:importDialog`：对话框多选 mp3/wav/ogg（Chromium decodeAudioData 原生支持，零新依赖）→ 复制入 `userData/triggers/<id>.<ext>`（同音乐入库模式，DB 存相对路径）→ 登记进 DB v49 新表 `trigger_sounds`（id / name 默认文件名去扩展名 / file_path / created_at，同 music_tracks 范式；v48 已被并行会话占用顺延）。
- 播放时经 `trigger:read` 读字节 → 渲染层 decodeAudioData 解码缓存（同 id 只解一次）。
- 管理：导入/改名/删除集中在混音器触发音区；删除**二次确认彻底删**（连文件），不入回收站（同轻音乐曲目口径）。

## 四、立体声声像

- 每层（场景层+触发层）链路加 StereoPannerNode + 声像滑杆（左↔右 -100~100，默认居中）。
- 触发音额外「游移」开关：开启后每次发声在左右耳间随机摆位（滑杆声像作为游移范围基准或失效，实施取「游移优先，滑杆置灰」更简）；场景层默认居中，可手动偏。
- 声像/游移随 `triggers` 状态与场景层状态一并持久化。

## 五、新场景 ×4

| 场景 | 构成 |
|---|---|
| 雷雨 | 现有雨层基础上 + 远处闷雷事件层（低频噪声脉冲长衰减，间隔稀疏随机） |
| 雪夜 | 雪本体无声——轻风稳态 + 偶发树枝吱呀/落雪簌簌事件层 |
| 风 | 多段滤波噪声慢扫稳态 + 偶发呼啸起伏事件层 |
| 溪流 | 高频流水稳态 + 偶发水花溅跃事件层 |

各配 3 出厂预设，同 260911 新场景惯例（场景卡/混音/恢复自动生效零 UI 特判）。

## 六、淡入淡出

- 播放开始：主增益 0 → 目标 0.8s 缓升；暂停：缓降后再挂起。
- 切场景：旧层缓出 + 新层缓入（约 1s），复用播放队列切歌的 token 代际模式防异步链串扰。
- 滑杆拖动不经过淡入淡出，即时生效。

## 七、容错与边界

- 导入的触发音文件丢失（外部被清）：调度到该触发时静默跳过该次并 toast 提示一次，行内正常显示。
- 导入格式不支持/解码失败：导入时即校验，失败计入 toast 汇总。
- 开箱默认：所有触发音关闭、声像居中、游移关——零新依赖、纯本地零 AI，不开启时行为与现状完全一致。
- 触发音上限不做硬限（个人单机，导入量级可控）；内置 + 导入统一编号空间（内置 `builtin:xxx`、导入数字 id）。

## 八、不做（YAGNI）

睡眠定时器（本轮明确不做）、独立声板页签、触发音音高/间隔自定义调节、淡入淡出时长自定义、导入音频裁剪、波形/频谱可视化、触发音进轻音乐侧。
