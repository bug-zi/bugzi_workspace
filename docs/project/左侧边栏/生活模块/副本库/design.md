介绍：副本库是「人生副本」体验模块（生活区）——每天抽一段别样人生，也可以定制一段属于自己的。核心是阅读体验：第二人称沉浸式人生故事（6000-8000 字、8-12 个人生阶段，细节密度高、有挫折有高光有回归），读的是「另一种可能」。v1 走精简核心：每日副本 + DIY 定制 + 收藏库三板块，追问/名人堂/命运星图/明信片等留作以后扩展。

### 模块结构

- 侧边栏位置：生活区，现有「副本库〔占位〕」转正（图书馆下方、赋诗苑上方），占位灰置提示取消。
- 模块内三页签切换（照万象库/推理角板块切换惯例）：**每日副本**（默认）｜**DIY 定制**｜**收藏库**。
- 全模块 AI 能力依赖 LLM（补库生成、DIY 生成），未配置时照全局规则：按钮不置灰，点击弹窗提示并「去配置」直达个人档；补库泵静默跳过；每日三选一照常（用现有库存）。

### 页签 A · 每日副本

**三选一预览：**

- 每天首次进入（或零点后首次访问）从待选池随机抽 3 条生成当日候选，展示为三张候选卡：标题 + 副标题 + 类别/情绪/时代三标签 + 字数。
- 未选定前可「换一批」（本地重抽，不限次数）。
- 选定即锁定当日（当日不可再换），候选副本转正入收藏库，状态「进行中」。
- 内容标签体系（照参照项目三维）：类别（科技/艺术/体育/商业/冒险/犯罪/日常…）× 情绪（热血/治愈/暗黑/荒诞/震撼/温馨/讽刺…）× 时代（古代/近代/当代/未来）。

**读毕打卡：**

- 阅读到末尾阶段结束，弹「读毕」确认，确认后当日打卡完成 → 热力图第四源（见「系统联动」）。
- 中途退出不丢进度（进度记忆跨日保留），次日续读，读毕时打卡仍记当日完成。
- 当日未选不强制；未选定的日子热力图该源不计。

### 页签 B · DIY 定制

**两步式流程（照参照项目）：**

1. 输入想体验的人生方向（一句话或一段描述，如「我想体验 90 年代县城开音像店的人生」）→ 点「生成定制问题」→ AI 出 4 道个性化问答题（开放式，如「你更怕稳定还是怕悔恨？」）。
2. 逐题作答（4 题全部作答后方可生成，答案不限字数）→ 点「生成我的副本」→ 分段生成（按阶段分 2-3 次调用拼接，规避单次 max_tokens 限制）→ 完成自动入收藏库（来源 diy），状态「进行中」。

**生成质量标准（写入生成 prompt）：**

- 注入「我的画像」；正文须为第二人称沉浸式叙事，8-12 个人生阶段，每阶段带小标题。
- 密度指标：每 500 字至少 3 个具体数字、2 个命名地点、1 段对话；全文有贯穿性物件/动机（照参照项目「U 盘」式母题）；结局回归式收束。
- 生成标题与库内已有标题 norm 查重，重复则自动重拟。

**任务保护：** 同一时刻仅允许一个 DIY 生成任务进行中；生成中页面锁定展示进度；失败可重试（重试重新生成，不产生半成品入库）。

### 页签 C · 收藏库

- 列表展示全部副本（内置官方 + 每日转正 + DIY 生成），按最近活动倒序。
- 状态标记：未读 / 进行中（带进度 %）/ 已读（附读毕日期）。
- 筛选：按来源（官方/每日/DIY）/ 按状态 / 按三标签。
- 点击任一副本直接进阅读视图；读非当日副本不触发每日打卡（打卡只认当日选定的那份）。
- 删除：二次确认后入回收站「副本库」块（回收站新增该块，恢复回收藏库；3 天自动彻底删照全局机制）。

### 阅读视图（三页签共用）

- 主栏满栏阅读（照图书馆进书头部隐藏满栏阅读惯例），左侧阶段导航（8-12 阶段小标题，当前章高亮），顶部返回。
- 进度记忆：按阶段 + 滚动位置节流落库（照图书馆 3 秒节流惯例），重开恢复到上次位置。
- 字号跟随全局字体设置（个人档 App 设置），不做独立缩放；双主题配色遵循全局样式规则（主题相近色系、无彩亮色、无 emoji 图标）。
- 正文为 .md 文件，全局 md 弹窗亦可打开（照「md 弹窗全局统一组件」惯例，双击切编辑态）。

### 内容生成与补库泵

- **库源构成**：内置 3 篇官方副本（由参照项目「副本1：顶级黑客」「副本2：电竞冠军」「副本3：DJ的一生」docx/md 转换入库，source=official）+ AI 预生成待选池（copies 表 state='pool' 行）。
- **补库泵**（照推理角/万象库补充泵模式）：待选池 < 5 自动补到 10；触发时机：启动 / 进模块 / 池被消耗后。静默失败，池变动发 `copies:stockChanged` 事件渐进刷新（照 `reasoning:stockChanged`）。
- **补库生成**：随机主题方向（三维标签随机组合，避开库内已有同标签组合）+ 注入「我的画像」贴兴趣偏好 + 密度指标 prompt；标题 norm 查重。
- **每日三选一候选源**：copies 表中 state='pool' 全部 + state='unread' 且 source='official' 的副本合并随机抽 3（排除上一批已展示的 3 个，剩余不足放宽）；pool 项在选定后原地转正。

### 数据模型

- **copies 表**（单表含待选池，照 wiki_entries state 惯例）：id、title、subtitle、category、mood、era、source（official/daily/diy）、word_count、stage_count、state（pool=待选池｜unread｜in_progress｜finished）、progress（阶段索引+滚动位 JSON）、md_path、finished_at、created_at、updated_at、deleted_at。待选池与正式库同表，转正 = 原地改 state（id 与 md 文件不变）。
- **copy_daily 表**：date（YYYY-MM-DD UNIQUE 本地时区）、candidate_ids（当日候选 JSON）、chosen_id、finished_at；当日打卡判定 = chosen_id 非空且 finished_at 非空。
- **正文文件**：`md/copies/<id>.md`（照 files.ts md 目录惯例），结构：`# 标题` + 副标题行 + `## 阶段小标题` × N。
- DB 版本号在现有基础上顺延（实施时取当前最新 +1）。

### 系统联动

- **热力图第四源**：总导览 `overview:heatmap` 读时聚合加第四源「每日副本」——copy_daily 当日已选定且读毕记 done；挑战打卡同款即时联动。
- **总导览直达块**：生活模式追加「今日副本」聚合块——未选：三张候选迷你卡（选定直达阅读）；已选未读完：续读卡（进度 %，点击深链续读）；已读毕：完成态收尾。深链经 `MODULE_NAVIGATE_EVENT` + `useModuleNavigate` 照既有惯例（copies → 副本库阅读视图）。

### 边界与规则

- LLM/MCP 未配置：按全局规则 8 处理；补库泵静默跳过；每日候选只从现有库存抽。
- 「换一批」仅本地重抽，不消耗任何资源；选定锁定后当日不可撤销（读毕打卡以选定记录为准）。
- 删除正在进行的每日副本：允许（二次确认），当日打卡视为放弃，热力图该日该源不计。
- 已读副本可重读（重读不改变读毕日期，不重复打卡）。
