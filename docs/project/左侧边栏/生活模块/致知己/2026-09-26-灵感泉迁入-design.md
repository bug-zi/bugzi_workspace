# 灵感泉迁入致知己 设计

> 创建于 2026-09-26
> 来源：`docs/project/新功能开发区.md` 260926 开发者指令——生活模式的灵感泉模块迁入学习模式致知己模块，作为新页签「灵感泉」出现（放在「沉淀」页签左侧）；生活模式腾出的位置另建对弈社（见 `左侧边栏/生活模块/对弈社/2026-09-26-对弈社-design.md`）。

## 1. 决策（brainstorm 与开发者商定）

1. **仅页签迁移，数据层零改动**：inspirations 表、`md/inspirations/`、回收站「灵感泉」筛选组、inspirations 全套 IPC 全部原样；迁移只动 UI 归属。
2. **致知己三页签 keep-alive**（灵感泉｜沉淀｜十二问题全部 `module-live/module-hidden`）：灵感泉 AI 批量生成/完善进行中切页签不中断（照答疑店面板先例）。
3. **默认页签保持「沉淀」**（灵感泉排第一位不改变默认落点）。
4. 深链扩展位：`useModuleNavigate('zhijiji')` 增加 `target === 'inspirations'` 直切灵感泉页签（当前无调用方，留扩展位）。

## 2. 方案

### 2.1 左栏（App.tsx）

- `MODULES` 删除 `{ id: 'inspirations', ... seg: 'life' }` 行；keep-alive 渲染行与 import 一并删除。
- `ModuleId` 类型联合移除 `'inspirations'`（`src/shared/types.ts` 与 `src/renderer/api.d.ts` 两处镜像）。
- `item.discard` 表名联合中的 `'inspirations'` **保留**（DB 表名不变，回收站链路不动）。

### 2.2 致知己（ZhijijiModule）

- `src/modules/inspirations/InspirationsModule.tsx` → `src/modules/zhijiji/InspirationsPanel.tsx`：
  - 组件改名 `InspirationsPanel`，props 形状不变（`onOpenAi: (prefill?: string) => void`，App 层经 ZhijijiModule 已有的 `onOpenAi={openAiWith}` 透传）；
  - `useModuleActivated('inspirations', ...)` 改监听 `'zhijiji'`（切到致知己即刷新）。
- `ZhijijiModule`：tab 类型 `'core' | 'inspirations' | 'twelve'`；页签顺序 **灵感泉｜沉淀｜十二问题**；原「条件渲染」改三块 keep-alive（`module-live/module-hidden`，照娱乐城容器模式）；`useModuleNavigate` 增 `inspirations` 分支。

### 2.3 回收站

零改动（source `'inspirations'` 与「灵感泉」筛选组原样保留）。

## 3. 边界

- electron 层（inspirations 服务/IPC/生成函数）零改动。
- 不新增 AI 频道；灵感泉 AI 功能照旧走 `window.api.inspirations` 与助手频道。
- README.md / CLAUDE.md 模块描述随本次一并同步。

## 4. 验证

- `npm run typecheck`（双 tsconfig）通过；`npm run build` 通过。
- 冒烟：左栏无灵感泉入口；致知己三页签显示与切换正常、灵感泉拖拽/生成/弹窗功能不回归；回收站「灵感泉」组删恢复正常；总导览生活模式无灵感泉块（原本就没有，确认无残留引用）。
