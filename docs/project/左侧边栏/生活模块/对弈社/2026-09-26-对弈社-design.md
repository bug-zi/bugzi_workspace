# 对弈社 设计

> 创建于 2026-09-26
> 来源：`docs/project/新功能开发区.md` 260926 开发者指令——生活模式新增棋类模块「对弈社」，置于「赋诗苑」与「推理角」之间；需中国象棋、国际象棋、日本将棋、五子棋、围棋五种棋。

## 1. 决策（brainstorm 与开发者商定）

1. **仅人机对弈**：内置自研引擎，不做双人同屏。
2. **对局留档 = 记录 + 战绩**：终局入库、战绩统计读时聚合；删除二次确认入回收站；**不做 AI 复盘**（棋谱 LLM 点评质量有限）。
3. **围棋 9/13/19 全做**；19 路 AI 为启发式陪玩水平，UI 明示「娱乐级」。
4. **纯本地零 LLM**：不接娱乐城筹码钱包、不进热力图/连胜体系、不新增 AI 边栏频道。
5. **AI 计算放渲染层 Web Worker**（alpha-beta 迭代加深 + 时间盒），思考不卡 UI。
6. **中断续玩**：进行中快照节流落库（照德扑 `pokerSaveState` 模式），进模块自动恢复。
7. **悔棋可退**：一次退回「我上一手走之前」（我+AI 各撤半回合），可连续悔；每局不限次数。
8. **不引第三方棋类库**：五种规则引擎全部自研 TS 纯函数（照娱乐城引擎惯例），npm 棋类库质量参差且 AI 仍需自写。

## 3. 引擎（每棋 engine.ts，纯函数：入 state 出新 state）

统一形状：`initState(difficulty, boardSpec?)`、`legalMoves(state)`、`applyMove(state, move)`、`statusOf(state)`、`search(state, difficulty)`（worker 侧调用）。AI 三档：**入门**（时间盒 0.3s、深度≤2、近优着软采样带随机）/ **进阶**（0.9s、深度≤4）/ **挑战**（2s、深度≤6）；alpha-beta + 迭代加深 + MVV-LVA 吃子排序。

### 3.1 中国象棋（9×10，我红先手）
- 全走法：蹩马腿、塞象眼、象不过河、仕困九宫、将帅九宫一步+照面禁、兵过河可横。
- 合法着 = 伪合法着过滤「走后被将/照面」；无合法着：被将=将死、未被将=困毙，均判负。
- 评估：子力（车9 马4 炮4.5 兵过河2/未过河1 仕相2 将∞）+ 过河/卒位微调 + 轻机动性。

### 3.2 国际象棋（8×8，我白先手）
- 全规则：王车易位（王车未动、路径空、王不在将中且不经被攻格）、吃过路兵、升变（弹窗四选：后/车/象/马）、逼和、将死；王对王自动和。
- 三次重复、五十回合不做。
- 评估：子力（P1 N3 B3.25 R5 Q9）+ piece-square tables + 轻机动性。

### 3.3 日本将棋（9×9，我先手）
- 走子 + 升变：入敌阵三段可选升（UI「成/不成」弹窗）；步/香抵底线、桂抵底线两行**强制**升；成子走法（と全马竜…）。
- 持驹打入：任意空点；禁**二步**（同列已有己方未成步）、禁死子打入（步/香抵底线、桂抵底线两行）、禁**打步诘**（打步直接将死对方）。
- 王手/诘み判定同象棋思路（合法着过滤）；千日手不做。
- 评估：子力（金银3.5~5、角飛5/7+成子加成、歩0.1）+ 持驹价值 + 轻位置。

### 3.4 五子棋（15×15，我执黑先手，无禁手自由规则）
- 连五即胜（长连也算胜）、满盘和。
- AI：候选点=任意棋子切比雪夫距离 ≤2 的空点；活四/冲四/活三/眠三等棋型打分，攻防双向加权；挑战档在 top-K 候选上做深度 2-4 极小极大。三档以搜索深度与候选宽度区分。

### 3.5 围棋（9/13/19，我执黑先手，中国规则）
- 规则：禁自杀点；**简单劫**（被提一子后该点当轮禁立即回提，落子后劫点更新）；连续两次 pass → **死子标记**阶段。
- 死子标记：点任一棋子整组切换死/活（死子灰显），「确认数子」收尾；可跳过（全按活子）。
- 数子（中国规则区域法）：死子移除后，黑=黑子+黑独围空点，白=白子+白独围空点，白加贴目 **7.5**（贴 3¾ 子等效）；黑 - (白+komi) 定胜负，允许半子差。
- AI：启发式——开局定式点（星/小目/三三）→ 拆边/挂角 → 中盘紧气提子/救被打吃子/连接拆二 → 避自紧气；全档同源，仅随机度与候选宽度不同（大棋盘明示娱乐级）。

## 4. 数据（DB v62 单表 + 读时聚合战绩）

```sql
CREATE TABLE duiyi_games (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  game TEXT NOT NULL,          -- xiangqi|chess|shogi|gomoku|go
  status TEXT NOT NULL,        -- playing|finished|abandoned
  difficulty INTEGER NOT NULL DEFAULT 2,
  board_spec INTEGER,          -- 围棋 9|13|19；其余 NULL
  result TEXT,                 -- win|loss|draw（我方视角；finished 才有）
  reason TEXT,                 -- 终局原因（将死/认输/数子黑185¼子胜…）
  move_count INTEGER NOT NULL DEFAULT 0,
  state TEXT,                  -- playing 快照 JSON（恢复续玩）
  record TEXT,                 -- finished 棋谱 JSON（着法数组+开局参数摘要）
  started_at TEXT NOT NULL,
  ended_at TEXT,
  duration_ms INTEGER,
  updated_at TEXT NOT NULL,
  deleted_at TEXT
);
```

- **每棋种至多一局 playing**：开新局时同棋种旧 playing 自动置 abandoned（被顶掉局无排名意义，记录列表不显）。
- 记录列表只显 `finished`；战绩 = finished 按 result 读时聚合（各棋种胜/负/和 + 总计），不建汇总表。
- 回收站 `source 'duiyi'`（TABLES→duiyi_games、MD_FIELDS→null、restore 仅清 deleted_at、hardDelete 走默认删行路径）；RecycleModule 筛选组加「对弈社」。

## 5. IPC（`window.api.duiyi.*`，service `electron/services/duiyi.ts`）

| 通道 | 说明 |
|---|---|
| `duiyi:start` (game, difficulty, boardSpec?) | 建 playing 局（先顶掉同棋种旧局），返回行 |
| `duiyi:saveState` (id, state, moveCount) | 节流快照（仅 playing 生效，终态竞速丢弃） |
| `duiyi:finish` (id, result, reason, record, durationMs) | 终局落库（仅 playing） |
| `duiyi:list` (game?) | finished 记录列表 |
| `duiyi:stats` () | 五棋种战绩聚合 |

删除复用通用 `item:discard`（表名联合加 `'duiyi_games'`）；认输 = `finish(loss,'认输')`；悔棋/走子纯前端引擎态，仅靠节流快照落库。

## 6. 交互与 UI

- **开局面板**（无进行中局时）：棋力三档单选（入门/进阶/挑战）+〔围棋〕路数 9/13/19 单选（19 路标「AI 娱乐级」）+「开始对弈」；下方战绩行 + 历史记录列表（时间/难度/结果/原因/手数/时长 + 删除）。
- **对局视图**：棋盘居中 + 状态条（轮到你 / AI 思考中 spin / 手数 / 执方说明）+ 控件条（新开一局〔进行中二次确认〕、悔棋〔我方回合才可用〕、认输〔二次确认〕、帮助）。
- **棋子表现**（零 emoji，全部文字/图形）：象棋=圆形汉字子（帅仕相马车炮兵）；国象=国际惯例浅深格 + 中文单字（王后车象马兵）；将棋=木牌方形+日文汉字（歩香桂銀金角飛王 + 成子 と成香成桂全馬竜）；五子棋=黑白圆点；围棋=黑白云子 + 星位点。
- **走子**：点选己子 → 高亮合法落点（主题色圈）→ 点落点走；将棋另有持驹区点选 → 高亮可打点；升变/国象升变弹四选小窗。
- **终局浮层**：胜/负/和 + 原因 + 该棋种战绩更新；「再来一局」回开局面板。
- **帮助弹窗**：各棋规则简述 + 操作说明（照娱乐城 HelpDialog 样式，本地组件）。
- **恢复**：进模块时查 playing 局，反序列化快照续玩（坏快照丢弃置 abandoned 兜底）。

## 7. 样式

- 棋盘用中性色（浅色=米纸/木色系，深色=墨蓝灰系），选中/合法点/将军提示用主题色（粉/宝蓝）低饱和变体，遵守「禁彩亮、与主题色相近」。
- 棋盘规格：象棋 9×10 含河界与九宫斜线（SVG 画线）；国象 8×8 棋盘格；将棋 9×9 素格；五子棋 15×15 线格；围棋 N×N 线格+星位。

## 8. 边界

- 零 AI（LLM）、零 MCP；对局数据不进热力图/连胜/挑战/钱包任何体系。
- 无每日任务、无定时任务、无后台泵。
- 记录删除走回收站（3 天期）+ 二次确认；无 md 附属产物。
