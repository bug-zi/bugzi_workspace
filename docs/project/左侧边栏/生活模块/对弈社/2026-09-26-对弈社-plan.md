# 对弈社 实施计划

> 创建于 2026-09-26
> 依据：同目录 `2026-09-26-对弈社-design.md`（开发者已确认）。
> 本计划无 git 步骤（本项目 git 由开发者自管）；无单测设施，验证 = `npm run typecheck`（双 tsconfig）+ 冒烟清单。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生活模式新增对弈社模块（赋诗苑与推理角之间）：五种棋（中国象棋/国际象棋/日本将棋/五子棋/围棋）纯本地人机对弈，自研引擎 + Web Worker AI，终局留档 + 战绩聚合，删除入回收站。

**Architecture:** 渲染层每棋一个子目录（engine.ts 纯函数规则引擎 + *.worker.ts AI + Pane.tsx 棋盘 UI），照娱乐城页签 keep-alive 模式；主进程单表 `duiyi_games`（DB v62）+ services/duiyi.ts + 5 IPC；快照节流落库支持中断续玩。

**Tech Stack:** Electron 44 + React 19 + TypeScript（electron-vite，node:sqlite，Vite module worker）。

### Task 4: 日本将棋引擎（shogi/）
