# 娱乐城

介绍：娱乐城是生活区的轻娱乐模块（260925 立项设计）。四个板块各玩一样：塔罗牌抽牌问事（AI 个性化解读）、德州扑克 SNG 人机锦标赛局、21 点快节奏牌桌、麻将房灵溪麻将人机对局（260926 增）。全娱乐城共用一套持久筹码钱包，破产可领救济金。AI 在塔罗解读、德扑局终复盘、麻将圈终讲牌三处出现，游戏本体零 LLM 依赖，断网也能玩。

### 模块结构

- 左栏生活区「娱乐城」，260925 去 pending 化正式上线，icon 维持 `casino`；主栏新增 `'yule'` 视图进 keep-alive 挂载，占位置灰逻辑移除。
- 主栏内四页签：**塔罗 | 德扑 | 21点 | 麻将房**（照万象库/答疑店板块切换惯例，260926 增第四页签，四页签 keep-alive 切页签不断局）；模块头右上角常驻钱包筹码数，四页签共用。
- 玩法全在主栏，AI 边栏不新增频道。
- LLM 未配置：塔罗「AI 解读」、德扑「AI 复盘」、麻将「AI 讲牌」按钮不置灰，点击弹「去配置」直达个人档（全局规则）；抽牌翻牌、德扑、21 点、麻将本体照玩。

### 钱包体系（全娱乐城共用）

- 单一持久钱包存 SQLite，首次进入娱乐城赠送 **5,000** 筹码。
- **破产救济**：余额 < 1,000（低于德扑买入）时可领 2,000，每日限一次（按本地日期判断，钱包区按钮触发）。
- 德扑开局扣买入、局终按名次返奖；21 点每手即时结算进出钱包；塔罗不涉及筹码。
- v1 不做流水明细，只存余额；收益统计由各游戏战绩各自聚合。

### 板块 A · 塔罗牌

- **牌堆**：韦特塔罗 78 张（大阿卡纳 22 + 小阿卡纳 56），本地随机洗牌抽牌，正逆位各 50%，全程本地零等待。
- **牌阵 v1 两种**：单张（每日指引）/ 三张（过去-现在-未来）；凯尔特十字进 v2 备选（摆阵 UI 复杂）。
- **流程**：选牌阵 →（可选）输入所问之事 → 点牌堆抽 N 张（牌背朝上）→ 逐张点击翻开（CSS 翻牌动画）→ 摆阵完成 → 点「AI 解读」。
- **AI 解读**：注入我画像 + 所问之事 + 每张牌的正逆位与牌位含义，LLM 流式生成个性化解读，md 实时渲染。
- **存档**：解读完成自动入库——元数据（日期/牌阵/所问之事/牌面正逆位）存 SQLite，解读全文存 md 文件（用户数据目录娱乐城专属目录）；板块下方记录列表点击弹全局 md 弹窗回看，可删除 → 回收站「娱乐城」块。
- LLM 未配置：抽牌、翻牌、看牌面基础牌意照玩，「AI 解读」点击弹「去配置」。

### 板块 B · 德州扑克（SNG 锦标赛局）

- **赛制**：4 人桌（我 + 3 AI），买入 1,000 开局从钱包扣，每人起始 1,000；盲注 10/20 起、每 8 手翻倍；奖池 4,000 全额返（无抽水）：冠军 2,000 / 亚军 1,200 / 季军 800 / 第四 0。
- **AI 对手**：三个性格预设——紧凶（强牌才进池、加注果断）/ 松凶（宽范围 + 爱诈唬）/ 跟注站（很少弃牌、被动跟注）。决策用本地启发式引擎：简化手牌强度 + 底池赔率 + 位置系数 + 性格参数 + 少量随机扰动，秒响应零成本；AI 行动加约 800ms 假延时保留节奏感。
- **对局 UI**：椭圆牌桌、四座位、庄钮与盲注标识、公共牌逐街发放（翻牌/转牌/河牌）、底池额实时显示、我的底牌大图；行动条 = 弃牌 / 过牌 / 跟注 / 加注（滑条 + ½池/满池/全下快捷）/ 全下；发牌翻牌动画从简（CSS）。
- **淘汰与终局**：筹码归零出局；我出局即局终结算离场；打到只剩我 = 冠军。中途退出 = 弃赛按第 4 名计（不退买入），二次确认弹窗。
- **中断续玩**：进行中对局状态快照持久化 SQLite，重启 App 回到牌桌续打；同时只允许一场进行中 SNG（不做多桌并行）。
- **局终存档**：名次 / 用时 / 收益 / 总手数自动入库；每手牌流水随局存 SQLite；可选点「AI 复盘」让 LLM 基于关键手牌出决策点评，生成复盘 md 文档，与塔罗同款记录列表 + md 弹窗回看，可删 → 回收站「娱乐城」块。
- 德扑全程零 LLM 依赖（对手本地算法），LLM 只服务可选的「AI 复盘」。

### 板块 C · 21 点

- **规则**：4 副牌靴（剩约 ¼ 重洗）、庄家软 17 停、Blackjack 赔 3:2、支持要牌/停牌/加倍；保险与分牌进 v2 备选。
- **玩法**：下注（快捷筹码按钮）→ 发牌 → 要牌/停牌/加倍 → 开牌结算，钱包即时进出；未结算中途退出则该手作废退回注额（手内状态不做持久化，会话级）。
- **战绩统计卡**：总手数 / 胜率 / 净收益累计展示；纯本地零 AI。

### 板块 D · 麻将房（灵溪麻将，260926 增）

- **规则蓝本**：灵溪麻将（开发者老家苍南规则，全量按百度百科词条实现）：144 张牌 = 万/筒/索各 9×4 + 东南西北风 16 + 中发白 12 + 8 花牌（春夏秋冬梅兰菊竹），白板归字牌类；掷骰两次定庄与拿牌位、翻出 2 张财神（百搭，不可吃碰杠打出）；庄 17 张闲 16 张；亮花牌白板逆时针补花（起手 4 同花=暗杠补 1 张）；行牌权力 **胡 > 碰/杠 > 吃**、按座次截胡（财神单钓不可截胡）；末 4 张摸进不打、不补花、不暗杠/补杠；牌池剩 10 墩流局、每杠 +1 墩；诈胡（推倒喊胡/打财神花白板/相公等）罚 26 子（庄翻倍）、本局禁吃碰胡可杠。
- **对局形态**：我 + 3 个本地启发式 AI（激进/均衡/稳健三性格，照德扑先例），全程零 LLM、断网可玩；AI 出牌走牌效率评分 + 向听数计算（财神作万能牌枚举代入，财神永不打），副露决策看推进听牌与台数潜力，他人大副露转防守扣牌；AI 行动约 800ms 假延时保留节奏。
- **台数与结算**：**基本台**人人算（含未胡家）——风位/字牌刻 1、明杠 3 暗杠 4（风字 +1）、花/白板 1/3/5 台与 13/10 杠、财神持有台（基本牌 2/5/8，字风花 3/7/11；双财神 7/15）、未胡家财神配风字单张 +1；**附加台**仅胡家——自摸+1、杠开/抢杠/海底各+3、混一色/对对胡/硬打硬/财神汇各+7、清一色/四风齐/单钓将（非财神）/天胡/地胡各+13、平胡 13、杀猪 13（无视牌型）、杀猪胡+13/26/52、花胡 52（无视牌型）/集齐 8 花+52；**翻倍**：胡家累计 ≥13 台 ×2、未胡家不翻；结算 = 胡家向三家各收 台数×10 筹码 + 未胡三家两两互算台差，**庄家收付一律 ×2**，四风齐放炮者包赔三家；结算明细弹窗展示后自动落钱包。
- **赛制**：一圈 8 局（每人坐庄两轮），胡牌方为庄则连庄否则下庄；每局终了即时结算进出共用钱包（1 台 = 10 筹码，v1 固定）；一圈终了落战绩。
- **对局 UI**：主栏内四方桌俯视——上/左/右 AI 家（头像位+副露+牌河+花牌区），我方底部手牌大牌横排；顶部信息条（局数/庄标记/财神两张牌面/牌池剩墩/单价）；点选牌抬起再点出牌防误触，响应条按合法性浮现胡/杠/碰/吃/过，吃多候选弹选择条；牌面纯 CSS 绘制（数字+汉字，风字花牌用汉字本体），配色主题色系衍生，无 emoji 无图片素材；出牌飞入、摸牌滑入等轻 CSS 动画。
- **中断续玩**：进行中引擎状态快照持久化 SQLite（摸牌前/响应窗口粒度落盘），重启续打；同时只允许一场进行中对局（照德扑口径）。
- **AI 讲牌**：圈终可选一键生成——LLM 基于圈牌谱关键决策点（副露选择/放炮局/最大台数局牌型构成）出讲解 md；不注入我画像（分析类，照德扑复盘口径）；LLM 未配置点击弹「去配置」；生成物存娱乐城专属目录 `mahjong/` 子目录。
- **战绩与回收站**：圈战绩（输赢/局数/胡牌次数/最大台数）列表照塔罗/德扑样式，删除二次确认 → 回收站「娱乐城」块；逐局结算流水随圈存 SQLite。

### 存储与全局规则对齐

- **SQLite 新表**：钱包（余额 + 救济领取日期）、塔罗记录元数据、德扑对局（含进行中状态快照与手牌流水）、21 点战绩聚合、麻将对局（含进行中快照与圈流水/圈战绩，**DB v60**，260926 增）；DB 版本号自当前最新顺延。
- **md 文件**：塔罗解读全文、德扑复盘文档、麻将讲牌文档，存用户数据目录娱乐城专属目录（讲牌在 `mahjong/` 子目录）。
- **回收站**：新增「娱乐城」板块——塔罗解读记录、德扑对局记录（连复盘 md）、麻将圈战绩（连讲牌 md）可删（二次确认）；21 点战绩为聚合统计不可删；钱包不进回收站。
- **画像注入**：塔罗解读注入我画像（个性化解读类）；德扑 AI 复盘、麻将 AI 讲牌不注入（分析类，照「判答类不注入」口径）。
- **视觉**：无 emoji 图标（Material Symbols，fonts.google.com）；牌桌、卡牌、按钮配色用主题色系衍生，禁彩亮饱和色（全局硬性规则）。
