# 飞花令对局存档自动续局 — 设计

> 创建于 2026-09-26 11:33
> 来源：优化建议区第 58 轮任务 2（飞花令玩到一半退出重进，对局丢失）

## 一、现状与病根

对局态（`playing`/`lines`/`finished`）全在 FeihuaPanel React state；FushiModule 面板常驻挂载只保证**会话内**切页签不丢，App 退出即丢。`fushi_games` 表只落终局。

## 二、方案（零 DB 迁移）

### 1. 存档（settings 键）

- 新 `SettingsKeys.FushiOngoing = 'fushi_ongoing'`，JSON：`{ keyword: string, daily: boolean, lines: FeihuaLine[], startedDate: 'YYYY-MM-DD', savedAt: string }`。
- **写入时机**：我方出句落 state 后写一次；AI 回复落到 state 后再写一次——任何时点退出最多丢「AI 思索中」的一轮（我方句已在档）。
- **清除时机**：终局落库成功（`feihuaEnd` 返回）后；放弃此局确认后；开新局覆盖（startGame 即写入新空局存档）。
- 坏 JSON / 缺字段 → 忽略并清键（容错同 noise_state 口径）。

### 2. 恢复（自动续局）

- FeihuaPanel `load` 时读存档：存在即 `setPlaying`/`setLines` 直接回到对局画面，顶部横幅「已恢复上次对局（N 句）」+「放弃此局」按钮。
- 放弃此局：ConfirmDialog 二次确认（文案明示不留档不入回收站），确认后清存档回面板。
- 有存档必然已在对局态 → 「开始今日飞花令/自由练」入口自然不可达，无开局冲突分支；恢复的每日局若跨日，完成时打卡归开局日（见下）。

### 3. 跨日打卡修正（feihuaEnd 签名扩展）

- `feihuaEnd(keyword, daily, result, lines, startedDate?)` 第五参可选（存档恢复局必传，新鲜局不传=今天）。
- `saveFeihuaGame`：
  - INSERT `created_at` = `${startedDate}T<当前时刻>`——留档日期归开局日，`fushiDailyView` 的 todayGameId 查询（`substr(created_at,1,10)=today`）不串局。
  - 每日局 `UPDATE fushi_daily SET done=1 WHERE date = startedDate`——昨日局玩完标昨日，连胜回溯如实；该日无行则 UPDATE 零行无害。
  - 留档 md 时间行同用 created_at。
- preload / api.d.ts 签名同步。

## 三、不改的部分

- 引擎/判字/查重/AI 出句链路、终局留档 md 格式、自由练口径、回收站流转、`FushiDailyView` 结构。零 DB 迁移。

## 四、验收

- typecheck 双配置通过。
- 冒烟：对局中退出 App → 重进自动回到对局画面且句子完整 → 继续玩到终局正常留档打卡；恢复后放弃此局（确认弹窗）清档；存档损坏不崩；跨日恢复每日局完成后昨日打卡、今日留档列表不误指；新鲜局行为与旧版完全一致。
