# 赋诗苑

介绍：赋诗苑是我的诗词生活模块，三页签结构——**飞花令**（每日一令的诗词回合游戏）+ **斗诗台**（同题斗诗、AI 对照点评）+ **诗集**（我的诗词创作，AI Copilot 协笔）。气质介于推理角（玩法 + 打卡）与文笔坊（协笔创作）之间：玩中练笔，练笔成集。本文档由 260925 brainstorming 会话与 AI 协作定稿（诗谜互猜玩法与文笔挑战诗词版砍掉延后至 v2 备选）。

v1.0：

**模块结构：**

- 生活区第 5 位转正：`pending: true` 移除，正式注册 ModuleId `fushi` 视图与 keep-alive 挂载；图标沿用已定稿的 auto_awesome。
- 顶部三页签「飞花令｜斗诗台｜诗集」（推理角/文笔坊板块切换同构），默认落飞花令——打卡锚点在最前。
- 页签内对局全程主栏完成（海龟汤先例），不新增 AI 边栏频道。

**页签一：飞花令（每日一令 + 自由练）：**

- 每日一令置顶卡：今日关键字 + 连胜数字 + 「开始今日飞花令」按钮。关键字由出厂字库按日轮转（月/花/风/雪/春/江/夜/酒/山/云/柳等约 30 字），零 LLM 幂等定档（同 ensureInterviewDaily 模式）。
- 对局规则：轮流说出含关键字的诗句，我一句、AI 一句。判字走**本地精确判定**（归一化后必须含关键字），AI 不当裁判；AI 出句同样过本地校验，与本局已出诗句重复判负（归一化查重）。我说不出 / 主动放弃 / 重复 / 不含字 → 判负；AI 连续两次接不上 → 判胜。
- AI 职责边界：AI 只负责出句与逐句讲解，胜负判定全部本地规则。
- 自由练：每日卡下方入口，自选关键字或随机开局，规则同款，不计打卡。
- 留档：对局全程（双方诗句 + 胜负 + 逐句讲解）留档 md 复盘，海龟汤先例；终局可只读回看，不可重开。

**页签二：斗诗台（同题斗诗）：**

- 「新斗诗」→ AI 当场出题：主题（如「秋夜独酌」）+ 体裁（绝句 / 律诗 / 词牌小令 / 现代诗四选一）。
- 对局视图：我方写作框（纯文本多行，不带 Copilot——保持斗诗紧张感）与 AI 作品区并列；我提交后 AI 才亮出它的诗。
- AI 点评：双方诗对照，四维打分（切题 / 格律 / 意象 / 意境，各 10 分）+ 总评 + 胜负判定；近体诗附平仄标注提示。
- 留档同飞花令；「存入诗集」按钮把我的诗一键转入诗集（标题 + 体裁标签随之）。

**页签三：诗集（轻诗集 + 诗词 Copilot）：**

- 单列表：行组件 = 标题 + 体裁标签 + 更新时间；顶部「+ 新作」；体裁筛选胶囊（绝句 / 律诗 / 词 / 现代诗 / 自由体，可自定义）。
- 条目弹窗：全局统一 md 弹窗，默认渲染态、双击编辑，与全 App 交互一致。
- 诗词 Copilot（仅编辑态，产出以建议预览卡呈现，我采纳或放弃，笔权在我；写作台同款交互）：
  - 起稿：标题 + 体裁 → 立意方向 / 开头建议；
  - 续写：接着当前内容往下写；
  - 润色 / 改写：作用于选中文本；
  - 对句（诗词特化）：我给上句 AI 出下句候选，或反向；
  - 格律点评（诗词特化）：全诗平仄 / 押韵 / 对仗审查 + 修改建议（近体诗与词牌向；现代诗只给节奏与意象建议）。
- system prompt 注入我的画像 + 当前诗全文；AI 产出采纳后不做 AI 段落标记——作品署名是我（同写作台）。

**打卡连胜与热力图：**

- 每日一令终局分出胜负即当日打卡 done；连胜推导同推理角连胜口径。
- 热力图接入第四源：总导览 heatmap 聚合追加「飞花令打卡」，近一年四档色，打卡即时联动（260924 总导览挑战打卡同款机制）。

**AI 边界与降级：**

- Copilot / 斗诗出题与点评 / 飞花令 AI 出句走主进程后台 LLM（同格言库生成模式）；不新增 AI 边栏频道。
- LLM 未配置：AI 按钮不置灰，点击弹窗提示并「去配置」直达个人档（全局规则）。每日一令的定档与打卡不依赖 LLM（字库本地轮转）；AI 不可用时对局无法开局（提示配置）。

**回收站：**

- 新增「赋诗苑」块：诗集诗作与对局留档混放，条目标注来源页签；恢复：诗作回诗集、对局回各自页签历史列表；3 天自动彻底删除照旧。对局与诗作删除均二次确认。

**存储：**

- SQLite 三表：诗集（id、标题、体裁、md 路径、创建/更新时间、软删）、对局（id、类型 feihua|doushi、关键字或主题、胜负、md 路径、创建时间、软删）、每日一令（date 主键、keyword、done）；DB 版本随实施顺延。
- md 真实文件存用户数据目录：md/fushi/poems/ 与 md/fushi/games/ 两目录。
