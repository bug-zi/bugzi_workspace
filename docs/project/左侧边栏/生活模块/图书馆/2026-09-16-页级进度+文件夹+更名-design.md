## 一、需求原文拆解

1. **页级进度**：书的阅读记录需要保存到当前页——只保存到当前章节不够（有些章节很长），要能记住当前阅读的页。
2. **文件夹整合**：书多起来之后可以在书架中创建文件夹，把书籍放入文件夹中。
3. **更名**：藏书架更名为图书馆。

### 已商定决策（brainstorming 260916）

| 决策点 | 结论 |
| --- | --- |
| 页级进度问题定位 | 开发者确认场景为 **epub 重开回到章首**。技术现状：PDF 已按页记忆（`progress_page`）；epub 存的 CFI 比页更细，但 epub.js `display(cfi)` 在目标章节 iframe 未渲染完成时常解析失败回落章首——**存了精确位置、恢复丢了** |
| 修复方向 | **验证-重试恢复**：display 完成后取实际落点比对，不一致重发 display(cfi)（最多 2 次），不改存储结构 |

| 更名范围 | **整个藏阅阁模块 → 图书馆**：左栏入口、模块头部；ModuleId `zangyue` 等内部标识不动 |

## 二、epub 页级进度恢复修复

**根因**：`EpubReader.tsx` 开书链路 `rendition.display(curCfiRef.current ?? book.progress_cfi)` 一次性调用。epub.js 内部把 CFI 解析为目标章节后渲染 iframe，再解析 CFI→DOM 定位滚动/翻页；首开时该解析常在章节文档就绪前执行，失败即回落章首。书内跳转（目录/书签/笔记回跳）走的是已渲染状态，不受影响。

**方案**（改动收敛 `EpubReader.tsx` 恢复链路一处）：

1. 开书 `display(目标CFI)` 完成后进入**验证**：取 `rendition.currentLocation()` 实际落点。
2. 比对口径：
   - `book.locations` 已有产出 → `percentageFromCfi(目标)` vs `percentageFromCfi(实际落点)`，差 > 1% 判「未命中」；
   - locations 未就绪（大书生成中）→ **无条件补发一次** display(cfi)（幂等，已命中再发一次无害）。
3. **重试**：判未命中时重发 `display(cfi)`（此时目标章节已渲染、布局收敛，第二次解析必中），最多 **2 次**；重试仍失败保持现状（章首），不弹错不阻塞。
4. 重试期间用户已手动操作（翻页/跳章/滚动/按键）则**放弃重试**（监听到用户交互即 cancel，不与用户抢位置）。
5. **恢复进行中抑制 saveNow**（restoreActiveRef 守卫）：恢复若落在章首，该中间位置不得经节流/退出 flush 覆盖库里存的精确 CFI；恢复结束（命中/重试耗尽/取消）后恢复正常保存。

**不改**：

- PDF 恢复零改动（`curPageRef` → `scrollIntoView` 已页级精确）。
- 进度存储结构不变（仍存 CFI + percent；CFI 比固定页码更准——字号/视口变化后页码会漂移，CFI 不会）。
- 书架卡片进度角标维持百分比；阅读条维持现有文案（epub 百分比 / pdf「N / M」）。

## 三、书籍文件夹（卡片式，单层）

### 数据模型（DB v42）

```sql
CREATE TABLE book_folders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  sort INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL
);
ALTER TABLE books ADD COLUMN folder_id INTEGER REFERENCES book_folders(id);
```

- `folder_id` NULL = 未分组；书籍删除 / 阅读进度 / 书签 / 笔记链路零改动。
- `shared/types.ts` + `src/renderer/api.d.ts` 同步（BookFolder 类型、BooksRecord 加 `folder_id`）。

### IPC（books 域扩展，ipc.ts + preload + api.d.ts 三处同步）

| 通道 | 行为 |
| --- | --- |
| `books:folderList` | 全部文件夹按 sort, created_at 排序，附各夹书数 |
| `books:folderCreate(name)` | 名称 trim 后非空；重名拒绝（throw，前端 toast） |
| `books:folderRename(id, name)` | 同重名拒绝 |
| `books:folderDelete(id)` | 事务内：夹内书 `folder_id = NULL`（**书籍与阅读进度不受影响**）+ 删夹行；前端二次确认 |
| `books:moveTo(bookId, folderId \| null)` | 移动单书；folderId null = 移出 |

`books:list` 返回行自然带上 `folder_id`，前端过滤；导入的书落未分组。

### 交互（全部在书架页签内，`BookshelfModule.tsx` + css）

- **根视图**（默认）：文件夹卡行（`folder` material 图标 + 名称 + 「N 本」；hover 出 `more_vert` 菜单：重命名 / 删除）→「＋ 新建文件夹」卡（点击变就地输入，Enter 确认 / Esc 或外点取消，空名不建）→ 未分组书封面网格（现 bk-grid 复用）。
- **夹内视图**：只显夹内书；顶部面包屑「‹ 全部 / {夹名}」，点「全部」回根。
- **移动**：
  - **主路径拖拽**：书卡 `draggable`；文件夹卡为 drop 目标（dragover 主题色描边高亮，drop 调 moveTo）；仅根视图可拖书入夹。
  - **兜底菜单**：书卡 hover 键区在现有删除键旁新增「移动到…」键（`drive_file_move` 图标），ActionMenu 列出「未分组 + 全部文件夹」（当前所在项打勾），点选即移——换夹/移出一步到位，不依赖拖拽。
- **删夹确认**：ConfirmDialog「删除文件夹『X』？夹内 N 本书将回到未分组，书籍与阅读进度不受影响。」
- **书籍删除回归**：夹内视图删书二次确认文案不变；删除后列表刷新。
- **总导览续读深链**：按书 id 打开，与文件夹无关零改动；从阅读器返回时保持出发时的文件夹视图状态（组件 state 自然保持）。

### 边界

| 场景 | 处理 |
| --- | --- |
| 文件夹重名 | 拒绝并 toast「已有同名文件夹」 |
| 夹名空/全空格 | 不创建/不保存 |
| 删空文件夹 | 同流程，确认文案 N=0 |
| 拖拽中误放到书卡上 | 书卡不是 drop 目标，drop 事件不响应自然无效 |
| 导入多本重复弹窗 | 落未分组，与文件夹无关 |
| 阅读统计面板 | 按 book 全量统计，零改动 |
