## 背景与定位

> **书架 = 本地电子书阅读模块：导入 .epub/.pdf、书架陈列、内置阅读、进度记忆。纯本地零 AI。**

「生活化工作台」的阅读一角——技术书闲书都往里放，每次打开自动接续上次读到的地方。无 LLM/MCP 依赖，离线可用。

## 模块结构

```
src/modules/bookshelf/
├─ 书架视图（默认）：封面网格，每卡 = 封面 + 书名/作者 + 进度%
│   ├─ 顶栏：「导入书籍」按钮
│   └─ 排序：最近阅读在前（从未读过的按导入时间排后）
└─ 阅读视图（点书进入，主栏整体切换）
    ├─ 顶部细工具条：返回 | 书名 | 进度%（pdf 加页码）
    └─ 正文区：epub → epub.js 渲染；pdf → pdfjs 连续滚动
```

## 进度记忆（核心需求）

- **epub**：存 epub.js 的 CFI 字符串（精确定位）+ 百分比；恢复时 `rendition.display(cfi)` 直达。
- **pdf**：存当前页码；恢复时跳到该页。
- 写入时机：翻页/滚动**节流 3 秒** + 退出阅读视图时落库——App 中途强杀也不丢大体进度。
- 字体与双主题跟随 App 全局设置：epub 注入主题 CSS（浅色樱花粉黑字 / 深色宝蓝白字）；pdf 纸面本身白底，容器背景跟主题。

## 文件与数据

- 书籍文件复制到 `<userData>/books/<id>.epub|pdf`；封面提取后存 `<userData>/covers/<id>.jpg`（epub 取内嵌封面图，pdf 渲染第 1 页为缩略图；提取失败用书名占位卡）。
- 封面与文件经 **bzres:// 协议**加载——需给协议补 `books/`、`covers/` 两个目录映射。
- SQLite `books` 表：`id, title, author, format, file_path, cover_path, file_size, progress_cfi, progress_page, progress_percent, added_at, last_read_at`。
- 主进程新增 `BookService`（导入复制/元数据解析/进度读写/删除），IPC 通道以 `books:` 为前缀。

## 交互与边界

- **导入**：按钮 → 系统文件对话框（可多选 .epub/.pdf）→ 复制入库 → 解析元数据（书名/作者/封面）。按「文件名 + 文件大小」查重，疑似重复弹确认；解析失败的副本自动回滚清理，Toast 报错。
- **删除**：ConfirmDialog 全局组件二次确认 → 删记录 + 物理文件，彻底删除。
- **坏文件**：打开时解析失败 → Toast「文件无法解析」，不影响模块其他功能。
- 图标取 Material Symbols（禁 emoji），候选 `auto_stories`，最终以样式设计文档风格为准。

## 明确不做的事（v1）

- 书签、划词高亮、阅读笔记（决策 #1，进 v2 备选）。
- 阅读器内独立字号调节（跟随个人中心全局字体设置）。
- 书籍分类/标签/搜索（个人书量级不需要）。
- mobi/azw3/txt 等其他格式。
- 内容级查重（不做整本书 SHA 校验，文件名+大小提示即可）。

## v2 备选

1. 手动书签（页码/CFI 标记，可跳转）。
2. 划词高亮 + 高亮笔记（可导出 md，接全局 md 弹窗体系）。
3. 阅读器内字号独立调节。
4. 阅读统计（时长 / 在读总览）。
