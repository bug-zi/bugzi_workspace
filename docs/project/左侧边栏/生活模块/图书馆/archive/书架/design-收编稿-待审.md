# 藏书架（收编稿——待开发者审核，通过后替换 design.md 并删除本文件）

> 260910 书架 v2.0 落地后由 AI 依实况起草。合并 v1.0（260908）+ 优化第 1 轮（260908-260909）+ v2.0（260910）三轮内容；设计全记录见 `archive/` 三份（2026-09-08-书架-design.md / 2026-09-08-书架优化-design.md / 2026-09-10-书架v2-design.md）。

介绍：藏书架是我的本地电子书阅读模块——导入 .epub/.pdf 书籍，复制入库统一管理，内置阅读器打开即接续上次读到的位置（进度记忆）。纯本地零 AI，无 LLM/MCP 依赖，离线可用。

**模块结构（单板块双视图，主栏内切换）：**

- 藏书架视图（默认）：顶部阅读统计条（今日时长 · 连续天数 · 在读本数，三项全零隐藏；点击展开每书累计面板）+ 封面网格，每卡 = 封面 + 书名/作者 + 进度%（未读/在读/%）；顶栏「导入书籍」按钮；排序最近阅读在前（从未读过按导入时间排后）。无封面显书名占位卡。
- 阅读视图（点书进入，主栏整体切换）：顶部细工具条（返回 | 书名 | 进度% | 字号组〔仅 epub：A- 档位% A+ 默认〕 | 加书签 | 目录侧栏 | 模式切换），正文区 epub/pdf 双引擎渲染，左侧可滑出三页签侧栏（**目录 | 笔记 | 书签**，约 240px，当前章节高亮）。
- 侧边栏位置：万象库下方、信息源上方（格言库 → 万象库 → **藏书架** → 信息源 → …）。图标 auto_stories（Material Symbols，禁 emoji）。

**导入：**

- 「导入书籍」→ 系统文件对话框（可多选 .epub/.pdf）→ 复制到用户数据目录 `books/`，藏书架只认入库副本——原文件之后移动/删除/改名都不影响阅读。
- 复制后解析元数据：epub 从包内取书名/作者/封面图（存 `covers/`）；pdf 书名取文件名（去扩展名），封面用占位卡。
- 按「文件名 + 文件大小」查重，疑似重复弹确认；解析失败的副本自动回滚清理并提示，不留坏数据。

**阅读与进度记忆（核心需求）：**

- epub 用 epub.js 渲染，**双阅读模式**（上下滚动 / 翻页，全局「最近使用」为默认 + **每书独立记忆**，切换保位置）；pdf 用 pdfjs-dist（连续滚动懒渲染 / 单页翻页防闪白）。
- 进度记忆：epub 存 CFI 定位 + 百分比，恢复直达；pdf 存页码。写入节流 3 秒 + 退出阅读时落库——中途强杀也不丢大体进度。
- **键盘导航**：WASD 与方向键同权（滚动模式 W/S 按住流式滚动、A/D 换章；翻页模式 A/D 翻页、W/S 换节）；输入框内打字不触发。
- epub 宽容器（1200px）+ 内容护栏（宽图/宽表收缩、代码块块内横滚）防横向拖拽；pdf 维持 980px。
- 主题注入跟随双主题（浅色樱花粉黑字 / 深色宝蓝白字；pdf 纸面白底容器跟主题）；划词色/高光色主题色同源。
- **字号独立调节（仅 epub，每书记忆）**：阅读条 A± 步进 5%（0.75~1.5 倍），「默认」清除书级值回落个人档全局字体；即时生效不丢进度。

**手动书签（v2.0）：**

- 阅读条一键收藏当前位置（epub 存 CFI、pdf 存页码；标签自动取章节名，兜底「约 X%」「第 N 页」）；同位置去重。
- 侧栏「书签」页签管理：时间倒序、点击跳回、删除走二次确认彻底删。epub/pdf 都支持。

**划词笔记（优化第 1 轮，仅 epub——pdf 无文本层）：**

- 划词浮窗：高光（纯底纹）或批注（底纹+下划线，气泡内写批注）；CFI 区间定位存 `book_notes`。
- 书内点高亮 → 气泡查看批注/编辑/删除（删除二次确认）；笔记页签列表点击跳回划词位置。

**笔记总览与导出（v2.0）：**

- 笔记页签「总览」入口（空笔记禁用）→ 按需生成整书读书笔记 md（摘录 + 批注 + 时间，阅读顺序），全局 md 弹窗**只读**打开（打开即快照）。
- 弹窗「导出」→ 系统保存对话框（默认名《书名》读书笔记.md）另存 md 文件。单一数据源在 DB，总览不落盘。

**阅读统计（v2.0）：**

- 计时口径：阅读视图内且页面可见 + 窗口聚焦（切走模块/最小化/失焦即暂停），30 秒批量落库，强杀最多丢 30 秒。
- 书架顶部统计条：今日 X 分钟 · 连续 N 天 · 在读 M 本（在读 = 读过且未读完）；点击展开每书「累计时长 · 进度% · 最近阅读」面板。

**删除（不入回收站）：**

- 书卡菜单删除 → 二次确认 → 直接彻底删除（删记录 + `books/`、`covers/` 物理文件，级联清该书笔记/书签/统计记录）。书是可重新导入的外部文件副本，不值得回收站再存 3 天大文件；回收站保持现有八块。

**存储：**

- SQLite 四表：books（元数据 + 进度 + 书级偏好 reading_mode/font_scale）、book_notes（划词笔记）、book_marks（书签）、book_read_log（按书按日累秒）；文件双目录 `books/`、`covers/`；封面经 bzres:// 协议加载，书籍二进制经 IPC 读出喂渲染引擎。

**后续备选（v2.x）：**

1. pdf 划词笔记（pdfjs 文本层渲染成本高，两轮均顺延）。
2. 书签备注/改名（与批注体系重叠暂缓）。
3. 阅读统计图表化（按日趋势、每书排行）。
4. pdf 宽度缩放。
5. 翻页动画、双栏 spread（第 1 轮明确不做，维持）。
