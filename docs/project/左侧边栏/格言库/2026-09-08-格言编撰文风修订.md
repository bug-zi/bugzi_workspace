### Task 1: 口语化正则 + 正反行为验证

**Files:**
- Create: `scripts/verify-colloquial.mjs`（一性子验证脚本，跑完删除）

- [ ] **Step 1: 写验证脚本（先于实现——正则行为的失败测试）**

创建 `scripts/verify-colloquial.mjs`：

```javascript
// 口语化兜底正则的正反行为验证（优化建议区第27轮，第23轮同款做法）
// 应命中 = AI 编撰的口语化句子；不应命中 = 合格格言（含真实名言风格句）
const PATTERNS = [
  /(?:呢|吧|啊|嘛|啦|呗|了)[。！？…"」]?\s*$/, // 1 句尾语气词（句尾「了」为口语完成体）
  /其实|真的|确实|反正/, // 2 口语虚词填充
  /^(?:你要|你应该|你们|别再|记得|赶紧|千万)/, // 3 句首叮嘱式
  /^.{23,}/s // 4 编撰条限长 22 字（标点计入；摘录条不受限）
]

const shouldHit = [
  '今天的事别拖到明天，拖着拖着就忘了。', // 句尾「了」
  '做事要用心才行呢。', // 句尾「呢」
  '算了，一切都会好起来的吧。', // 句尾「吧」
  '其实我们都不懂什么是爱。', // 「其实」
  '真的努力过就不会后悔。', // 「真的」
  '确实，人不能太贪心。', // 「确实」
  '反正明天还有机会。', // 「反正」
  '你要相信自己的选择。', // 句首「你要」
  '别再为小事烦恼了。', // 句首「别再」（兼句尾「了」）
  '记得按时吃饭，照顾好自己。', // 句首「记得」
  '赶紧去追，风不会等人。', // 句首「赶紧」
  '人生就像一场旅行，我们都是背着行囊赶路的旅人，不必回头。' // 25 字超长
]

const shouldMiss = [
  '刀刃上没有多余的话，锋利就是全部语言。', // 正例本体（19 字符）
  '了解自己，是所有清醒的开始。', // 句中「了」（了解）不误杀
  '认识你自己。', // 短句
  '风可以吹起一张白纸，却无法吹走一只蝴蝶。', // 21 字符，「却」不违禁
  '沉默是金。', // 短句
  '黑夜里最亮的光，往往来自最深的伤口。', // 21 字符，「往往」不违禁
  '路漫漫其修远兮，吾将上下而求索。', // 真实名言（18 字符）
  '守时是对他人时间的敬畏。' // 12 字符，断言体
]

let fail = 0
for (const s of shouldHit) {
  if (!PATTERNS.some((p) => p.test(s))) {
    console.error('MISS(应命中未命中):', s)
    fail++
  }
}
for (const s of shouldMiss) {
  if (PATTERNS.some((p) => p.test(s))) {
    console.error('FALSE(不应命中误杀):', s)
    fail++
  }
}
if (fail === 0) {
  console.log(`ALL PASS（命中 ${shouldHit.length} 例 / 放行 ${shouldMiss.length} 例）`)
} else {
  console.error(`${fail} 例不符`)
  process.exit(1)
}
```

- [ ] **Step 2: 运行验证**

Run: `node scripts/verify-colloquial.mjs`
Expected: `ALL PASS（命中 12 例 / 放行 8 例）`。任何 MISS/FALSE：先修脚本正则与预期对齐（保持正则克制，宁可放过不可误杀），记录调整理由，正则终稿同步 Task 3。

Run: `rm scripts/verify-colloquial.mjs`（目录若空一并删；一性子脚本不留在库）

### Task 2: buildPrompt 五条文风标准 + 正反例

**Files:**
- Modify: `electron/ai/services.ts:408`（buildPrompt 模板内编撰条段）

- [ ] **Step 1: 替换编撰条文风段**

在 `buildPrompt` 模板中，把：

```
编撰条请像正式区样本那样平实、具体、有画面，靠内容本身立住，不要靠句式端着。摘录条（kind 为 "excerpt"）不受此限，如实引用原文。
```

替换为：

```
你自行编撰的 ${nComposed} 条必须写出**格言的文体**，遵守五条标准——
1. 凝练：一句成型，一般不超 20 字，删一字则伤；
2. 断言：是一个判断或主张，不是描述、不是叮嘱——说出来就站住，无需论证；
3. 普遍：脱离具体情境依然成立，面向一类人生状况；
4. 可诵：有顿挫节奏，读出声不拗口（但禁止上述 7 类空洞对仗）；
5. 画面是载体不是目的：可以用具体意象承载抽象道理，但意象必须为断言服务。

正例（编撰应有的样子）：「刀刃上没有多余的话，锋利就是全部语言。」——意象承载断言，凝练立得住。
反例一（大白话型，不合格）：「今天的事别拖到明天，拖着拖着就忘了。」——是叮嘱不是格言，缺断言力与普遍性。
反例二（散文型，不合格）：「秋天的落叶铺满了小路，每一步都发出细碎的声响。」——有画面但无观点，画面成了目的。
另有代码侧口语化检测，命中即剔除：句尾语气词（呢/吧/啊/嘛/啦/呗/了）、口语虚词（其实/真的/确实/反正）、句首叮嘱（你要/你应该/别再/记得/赶紧/千万）、超过 22 字——请自检规避。摘录条（kind 为 "excerpt"）不受以上文体约束，如实引用原文。
```

注意：该段位于 7 类句式禁令清单之后（「编撰条请像正式区样本那样…」原位置），第 4 条「禁止上述 7 类空洞对仗」的指代保持成立；墓碑/避免清单段不动。

Expected: PASS
