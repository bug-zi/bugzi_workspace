> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 格言生成单趟 141~250s → ~8s——`ChatOptions` 增 `thinking` 可选控制，格言调用点标注 disabled，glm 系模型附加智谱 `thinking` 参数。

**Architecture:** 主进程两文件三处小改：llm.ts 咽喉点加「按模型家族映射」的请求体附加逻辑（缺省不发参数，现有场景零变化），services.ts 格言 `callAndParse` 一行标注（生成轮/补足轮/解析重试共用自动生效）。渲染层、DB、prompt 零改动。

**Tech Stack:** Electron 44 + TypeScript。验证：实施前探测已定预期（关思考 8.3s / 277 tok），实施后 `npm run typecheck` + 冒烟看 `llm_usage` 记账骤降。

### Task 1: llm.ts——ChatOptions 扩字段 + 按模型家族附加请求体

**Files:**
- Modify: `electron/ai/llm.ts:106-113`（ChatOptions）、`electron/ai/llm.ts:198-204`（chatWithConfig 请求体构建）

- [ ] **Step 1: ChatOptions 增 thinking 字段**

在 `jsonMode?: boolean` 之后追加：

```typescript
  /** 思维链控制（260910 格言提速）：缺省 = 不发参数（上游默认行为，现有场景零变化）。
   *  仅 glm 系模型实际生效（chatWithConfig 内映射），见下。 */
  thinking?: 'enabled' | 'disabled'
```

- [ ] **Step 2: chatWithConfig 附加请求体**

在 `if (opts.jsonMode) body.response_format = { type: 'json_object' }` 之后追加：

```typescript
  // 思维链按模型家族映射（260910 格言提速）：glm 系 → 智谱 thinking 参数；其余模型一律不发送
  // ——防 OpenAI 严格端点对未知参数 400，防溢出路由把调用甩给非 glm 配置时炸请求（甩到即按其默认行为跑）
  if (opts.thinking && /^glm/i.test(cfg.model)) body.thinking = { type: opts.thinking }
```

- [ ] **Step 3: typecheck**

Run: `npm run typecheck`
Expected: PASS。若出现陈旧诊断（本仓 tsbuildinfo 增量缓存重放旧报错的已知问题，第 23/30/31 轮均遇），先 `rm -f tsconfig*.tsbuildinfo` 再跑。
