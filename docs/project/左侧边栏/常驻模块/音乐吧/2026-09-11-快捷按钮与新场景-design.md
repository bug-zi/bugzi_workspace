## 一、需求原文拆解

1. 在右侧边栏右下角、主题切换按钮上方添加播放组件，快速播放/暂停白噪音。
2. 丰富音效：新增声音场景（现仅「雨」1 个场景 8 层）——本轮加 4 个：森林、海浪、夜晚篝火、咖啡馆。

## 二、快捷按钮（App.tsx right-col）

- **位置/显隐**：`right-col` 内、AI 活动指示（LlmActivity）之下、主题按钮之上；渲染规则与两者同款——仅右侧三面板（debugzi/草稿本/画布）全部收起（`rightPanel === null`，右缘 36px 细条态）时渲染。
- **样式**：`.right-col-noise` 复制 `.right-col-theme` 同款（钉宽 `var(--ai-width-collapsed)`、border-left/top、`--color-surface` 底、hover `--color-primary-soft`），App.css 新增。
- **图标/状态**：`graphic_eq` 图标；播放中图标主题色高亮（复用左栏白噪音入口的 `.noise-playing` 类；若该类仅作用于左栏选择器则放通用）。
- **title**：`白噪音 · {场景名} · 播放中，点击暂停` / `白噪音 · {场景名}，点击播放`（场景名 = `sceneById(noiseEngine.getState().sceneId)?.label`）。
- **点击**：`noiseEngine.toggle()`，catch 后 toast「音频初始化失败」（同 NoisePage 口径）；播放态经 Shell 已有的 `useSyncExternalStore` 订阅自动同步，无需新增状态。

## 三、新场景（noiseScenes.ts 注册 4 个 NoiseScene）

场景卡（NoisePage `SCENES.map`）、滑杆、出厂预设、自定义混音按 sceneId 归属过滤全部自动生效，零 UI 改动。分层与参数为初始蓝图，**实机听感微调**：

### 森林 forest（icon `forest`）

| 层 | 类型 | 构成 |
|---|---|---|
| 树叶沙沙 | steady | 白噪 bandpass 1500Hz + 幅度慢抖（am ~0.3Hz） |
| 阵风 | steady | 棕噪 lowpass 400Hz + 滤波扫调（lfo ~0.07Hz） |
| 林涛 | steady | 棕噪 lowpass 150Hz |
| 鸟鸣 | event | chirp：1~3 连发短滑音，随机 2~8s |
| 远处鸟语 | event | chirp 高频细碎变体，稀疏 |

预设：晨林（鸟鸣多）/ 午后微风（风多鸟少）/ 深夜林语（纯风与林涛）。

### 海浪 ocean（icon `waves`）

| 层 | 类型 | 构成 |
|---|---|---|
| 浪涌 | event | wave：棕噪 bandpass + 慢起慢落包络，周期 6~12s |
| 浪花碎沫 | steady | 白噪 highpass 3500Hz + 滤波扫调（起伏感） |
| 海风 | steady | 粉噪 bandpass 800Hz + 幅度慢抖 |
| 鸥鸣 | event | chirp 长下滑音变体（低频缓滑），稀疏 |

预设：沙滩缓浪 / 礁石激浪（浪涌密、碎沫多）/ 深夜潮声（无鸥）。

### 夜晚篝火 fire（icon `local_fire_department`）

| 层 | 类型 | 构成 |
|---|---|---|
| 火苗噗噗 | steady | 棕噪 lowpass 300Hz + 幅度快抖（am ~2.5Hz） |
| 噼啪爆裂 | event | crackle：高通窄脉冲（5~30ms），密集短促 |
| 炭火低鸣 | steady | 棕噪 lowpass 100Hz |
| 夜风 | steady | 粉噪 bandpass 500Hz + 滤波扫调（慢） |

预设：围炉噼啪 / 余烬低语（噼啪少炭火多）/ 夜话轻焰。

### 咖啡馆 cafe（icon `local_cafe`）

| 层 | 类型 | 构成 |
|---|---|---|
| 人声嗡嗡 | steady | 粉噪 bandpass ~350Hz 低谐振 + 慢幅度起伏（人声低频近似） |
| 人声细碎 | steady | 粉噪 bandpass ~1100Hz + 幅度抖动（语音频段闪烁感） |
| 杯盘轻碰 | event | clink：高频谐振 ping，稀疏 |
| 环境杂响 | event | tap 变体（现成），中频短脉冲 |
| 空调底噪 | steady | 棕噪 lowpass 200Hz |

预设：午后闲谈 / 角落安静（人声低、杂响少）/ 打烊时分。
（人声为滤波噪声近似，效果不及真实录音——已与开发者对齐预期。）

## 四、引擎扩展（noiseEngine.ts spawnEvent）

`EventLayerDef.spawn` 联合类型加 4 种合成器（参数随机化区间内嵌实现，多层可共用）：

- **chirp**：振荡器频率指数滑音（随机音高区间与滑向）+ 快起缓落包络；鸟鸣 = 高频短滑音连发，鸥鸣 = 低频长下滑（spawnCfg 覆盖参数）。
- **wave**：棕噪 bandpass（400~900Hz 随机中心）+ 慢 attack（1.5~3s）/ release（3~6s）包络——比 thunder 亮、比 thunder 短。
- **crackle**：白噪 highpass ~4kHz 极短脉冲，偶发双击——tap 的高频密集版。
- **clink**：振荡器谐振 ping（2~4.5kHz、衰减 0.1~0.3s）+ 少量噪声瞬态——drip 的金属版。

`EventLayerDef` 增可选 `spawnCfg` 字段（音高区间/时长/连发数覆盖），缺省用类型默认值，避免每种变体单列类型。

## 五、兼容性

- 启动恢复 `loadState` 对未知 sceneId 已有回落 `SCENES[0]` 逻辑，存量 NoiseState 无忧。
- 自定义混音（noise_custom_mixes）按 sceneId 过滤，新场景自动独立分组。
- 场景切换/预设/落库/重启恢复全部沿用现有机制，零主进程改动。

## 六、不做（YAGNI）

- 不做场景内分层增删（层随场景固定，滑杆调配比——现有机制）。
- 不做音频文件采样（坚持纯 Web Audio 合成）。
- 不做快捷按钮上的场景切换/音量调节（就是播放/暂停；调场景进混音器页）。
- 不做定时停止/渐隐等播放计划类功能。
