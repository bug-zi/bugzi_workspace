# 音乐吧（白噪音更名 + 轻音乐）设计记录

> 创建于 2026-09-15 22:03
> 来源：`docs/project/新功能开发区.md` 待完成区任务一（开发者 260915 提出，当日 brainstorm 商定）。
> 定位：白噪音模块扩展更名为「音乐吧」——轻音乐｜白噪音双大 tab，轻音乐支持 mp3 导入与歌单分组。本文件为实施设计记录。

## 一、需求结论（brainstorm 摘要）

| 维度 | 结论 |
|---|---|
| 更名 | 白噪音 → 音乐吧（左栏控件与页头用户可见名）；ModuleId `noise`、settings 键、现有引擎代码全部不动 |
| 页面结构 | 页顶大 tab「轻音乐｜白噪音」，默认轻音乐，会话内保留切换、重启回默认（同藏阅阁口径）；白噪音 tab 内原样保留「混音器｜播放队列」子 tab，MixerPanel/QueuePanel 零改动 |
| 音源关系 | **互斥**——播轻音乐时白噪音自动暂停，反之亦然；一次只有一种背景音 |
| 轻音乐范围 | 最小集（多选导入 mp3、列表、上/下首、循环三模式、进度条、音量、删除）**＋ 歌单分组** |
| 播放队列 | 完全独立——现有分钟制播放队列仍只管白噪音；轻音乐有自己的连播逻辑 |
| 快捷控件 | 左栏控件与右栏快捷钮控制**当前活跃音源**：谁在播控谁；都停着控「上次播放的音源」，从未播过默认白噪音 |

## 二、引擎与互斥

- 新建独立 `src/services/musicEngine.ts`：HTMLAudioElement 播 mp3，全局单例（同 noiseEngine 模式，组件外持有，切模块播放不断）。
- **不塞进 NoiseEngine**：白噪音是 Web Audio 合成调度器、音乐是文件播放，机理不同，分开各自简单。
- 互斥协调：MusicEngine play 前调 `noiseEngine.stop()`；NoiseEngine 各播放入口 play 前调 `musicEngine.stop()`。两引擎无共享状态，只互发停止指令。

## 三、数据与文件

DB 新增两表（v38，以实施时实际递增为准）：

```sql
CREATE TABLE music_playlists (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  created_at TEXT NOT NULL
);

CREATE TABLE music_tracks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,             -- 默认文件名去扩展名
  file_path TEXT NOT NULL,         -- 相对 userData 的路径 music/<id>.mp3
  duration_sec REAL,               -- 懒获取：首次播放读 audio.duration 回写，NULL 显示 --:--
  playlist_id INTEGER,             -- NULL=未分组
  added_at TEXT NOT NULL
);
```

- mp3 文件复制进 `userData/music/<id>.mp3`（同书籍入库模式，DB 存相对路径）。
- **导入**：`dialog.showOpenDialog` 多选 .mp3 过滤 → 逐个复制入库；同名同大小视为重复跳过并 toast 汇总；导入完成 toast 汇总（成功 N / 跳过 M / 失败 K）。
- **时长懒获取**：不引入 mp3 解析库；首次播放时由引擎读 `audio.duration` 回写 DB。

## 四、轻音乐 tab（MusicPanel）

- **播放上下文**：在哪个列表点播，就按该列表连播——歌单页签 = 该歌单曲目（按加入时间序）；「全部」= 全部曲目。曲目行点击即播（再点当前曲 = 暂停/继续）。
- **循环模式**：列表循环 / 单曲循环 / 随机，三态按钮切换，全局记忆（settings JSON `MusicState`）。
- **控制条**：面板底部常驻——上一首 / 播放暂停 / 下一首、进度条拖拽、音乐音量滑杆（与白噪音主音量各自独立记忆）。
- **歌单管理**：顶部歌单条「全部 ＋ 各歌单 ＋ ＋新建」；歌单可改名/删除（**删歌单不删曲**，曲目回未分组，二次确认）；曲目行「加入歌单」菜单选目标（含「移出歌单」回未分组）；「未分组」不作为歌单条目显示，仅作兜底归属。
- **删除曲目**：二次确认，**彻底删除**（连 `music/<id>.mp3` 文件），不入回收站（同删书口径）。
- v1 曲目移动用菜单，**不做拖拽**（YAGNI）。

## 五、全局接入

- **左栏控件**：文案「白噪音」→「音乐吧」；播放态高亮口径 = 任一音源在播（图标仍 `graphic_eq`，音乐活跃时同款高亮）；整块单击进音乐吧页（MainView `noise` 不变）。
- **右栏快捷钮**（主题按钮上方）：按当前活跃音源口径播放/暂停；title 提示跟随实际音源（如「轻音乐 · 正在播放，点击暂停」）。
- **页头大播放按钮**：两 tab 共用，同活跃音源口径。
- **启动恢复**：`MusicState`（settings JSON）记上次曲目 id + 循环模式 + 音量；重启默认暂停、进度从头（同白噪音口径）。
- **白噪音侧**：MixerPanel/QueuePanel 及其队列逻辑零改动，仅外壳套大 tab。

## 六、容错与边界

- 文件丢失（外部被清）：播放该曲 toast 报错并自动跳下一首；列表行正常显示不隐藏。
- 纯本地零 AI、零 LLM 依赖。
- App 关闭即停，不后台常驻；`.npmrc` 现状不变，零新依赖。

## 七、不做（YAGNI）
