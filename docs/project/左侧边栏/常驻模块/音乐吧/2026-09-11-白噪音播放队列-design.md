# 白噪音·播放队列 设计记录

> 创建于 2026-09-11 21:45
> 来源：`docs/project/优化建议区.md` 待完成区（开发者 260911 提出）。
> 定位：白噪音子功能（非新模块），直接开发；本文件为实施设计记录，落地后归档。
> 已确认决策：①打断规则 = 队列是可选「接管模式」，队列运行中任何手动混音操作（拖滑杆/点预设/切场景/召回混音）自动退出队列、声音不断；②UI = 页面顶部胶囊 tab「混音器 | 播放队列」双视图；③时长 = 预设档 + 自定义分钟混合；④播放模式四选（顺序播完即停/列表循环/单曲循环/列表随机，默认顺序播完即停）；⑤架构 = 队列控制器并入 NoiseEngine 单例（否掉独立服务/渲染层驱动两案）。

## 一、需求原文拆解

1. 定义「音效」为一种组合音：出厂预设（如篝火场景的「围炉噼啪」）与用户自定义混音（如自定义的篝火配比）统称音效。
2. 以音效为单位增加播放队列：队列逐项轮换播放，每项播够设定时长切下一个。
3. 每项时长可自定义（如 5 分钟/10 分钟等）。
4. 播放模式：列表循环 + 单曲循环 + 列表随机（+ brainstorming 补入的「顺序播完即停」，睡前定时听场景）。

## 二、数据模型（音效引用，不复制配比）

```ts
interface NoiseQueueItem {
  id: string                          // 行唯一 id
  kind: 'preset' | 'custom'           // 出厂预设 / 自定义混音
  sceneId: string
  presetId?: string                   // kind=preset 时（代码注册表，永远有效）
  mixId?: string                      // kind=custom 时（指向 noise_custom_mixes 条目，可能被删）
  minutes: number                     // 播放时长，1–480 分钟
}
type NoiseQueueMode = 'sequence' | 'list-loop' | 'single-loop' | 'random'
```

- **显示名动态解析**为「场景 · 名称」（「雨 · 暴雨」「篝火 · 我的围炉」）；自定义混音被删 → 行灰显「已删除」、播放时跳过。
- **持久化**：settings 新 key `noise_play_queue` = `{items, mode}`（SettingsKeys 增 `NoisePlayQueue`）。零 DB 迁移零主进程改动（settings 读写通道现成）。运行态（当前项索引/剩余时间）**不持久化**——重启默认暂停、恢复配置后从头开始（与既有「重启默认暂停」规则一致）。
- 队列程序性切歌**不写** `noise_state`：重启后自由混音回到进队列前的状态，自由模式与队列模式互不污染。

## 三、引擎队列控制器（noiseEngine.ts 并入）

新增状态：`queue: {items, mode, activeIndex(运行中才非 null), remainMs, shuffleOrder?}` + 切歌计时器。

**启动/停止**：

- `startQueue()`：从首个有效项（random 为洗牌序头）开始；队列空/全失效 toast 不启动。
- `stopQueue()`：清计时器、activeIndex 置 null、emit。被打断路径**声音不断**——保持当前混音继续自由播。

**切歌时序 `playSoundAt(i)`**：

1. 解析音效，失效 → 按模式推进跳下一有效项；
2. 主音量淡出（~1.2s，setTargetAtTime）→ **私有路径**切场景 + 应用层配比（不经过公开 `setLayer/setScene`，不触发打断）→ 淡入回用户当前主音量；
3. 计时从淡入完成起算（过渡时间不占播放时长），每秒 tick 驱动倒计时 UI，`remainMs` 到点触发 `advance()`。

**四模式推进 `advance()`**：

| 模式 | 行为 |
|---|---|
| sequence 顺序播完即停（默认） | 下一有效项；越过末尾 → 淡出 → 引擎 pause() → 队列态清（保留配置） |
| list-loop 列表循环 | 下一有效项，末尾回绕到头 |
| single-loop 单曲循环 | 不切歌只重置 remainMs（音频层不动，真无缝） |
| random 列表随机 | Fisher-Yates 整轮洗牌按序播，播完一轮重洗（不连播同一首） |

**打断规则（核心语义）**：队列运行中，公开 `setLayer`/`setScene`（应用预设/召回混音均经由它们）= 用户接管 → 引擎内部自动 `stopQueue()` + toast「已退出队列播放」；**主音量不打断**（与队列正交，切歌淡入目标动态取当前值）；**播放/暂停与队列正交**——`pause()` 冻结计时（存 remainMs、清 timer），`play()` 恢复计时。

**竞态**：淡出/淡入进行中用户暂停或打断 → `cancelScheduledValues`，master 立即归位（暂停=0 / 打断=用户值）；暂停时 timer 已清，无漂移（remainMs 为剩余毫秒倒扣口径，非绝对时间戳）。

## 四、UI（NoisePage tab 化 + QueuePanel）

**NoisePage 薄壳化**（文笔坊面板化同款手法）：

- header 增胶囊 tab「混音器 | 播放队列」（万象库「百科|辩真」同款范式）；播放/暂停大按钮留 header 两 tab 共用；tab 态本地 useState 默认混音器（会话内切换，不持久化）。
- 现有场景条/滑杆/预设/我的混音原样搬入 `MixerPanel`（同目录新文件，纯搬运零行为变化）。
- 队列运行中 MixerPanel 顶部提示条「队列播放中 · 第 N 项 · 点击查看」，点击跳队列 tab。

**新组件 `QueuePanel.tsx`**（自上而下）：

1. 状态行（队列运行时）：「正在播放 ② 海浪 · 沙滩缓浪 · 还剩 12:34」+「■ 停止队列」。
2. 队列列表行：序号｜场景·名称（失效灰显「已删除」）｜时长下拉（预设档 1/5/10/15/20/30/45/60 分钟 +「自定义…」选项转数字输入，clamp 1–480）｜上移/下移｜删除（ConfirmDialog 二次确认——全局硬性规则「所有删除操作二次确认」）。运行中的行主题色高亮。
3. 「+ 添加音效」弹窗：按场景分组列出全部出厂预设 + 自定义混音，**多选**批量加入 + 统一默认时长（30 分钟，加入后可逐行改）。
4. 播放模式四选 pill：顺序播完即停（默认）｜列表循环｜单曲循环｜列表随机。
5. 「▶ 开始队列播放」大按钮（队列空时点击 toast 引导）；空态引导文案（先去混音器认识预设/保存混音）。

**App.tsx**：启动恢复处（现有读 `noise_state` 的 useEffect 旁）读 `noise_play_queue` 灌 `engine.loadQueue()`；左栏图标与右下角快捷按钮的播放高亮照旧（引擎 playing 态）。

## 五、边界与容错

- **失效音效**：显示灰显；播放解析失败跳下一有效项（按当前模式推进）；全部失效时 `startQueue` toast「队列中的音效均已删除」不启动。
- **主音量**：队列全程共用一个用户主音量（切歌不重置）。
- **页面隐藏/App 生命周期**：队列调度在引擎单例，切模块/页面隐藏照常播（模块根基「切模块声音不断」）；App 关闭自然停。
- **每秒 emit**：倒计时驱动整页重渲染，单页面组件量级可接受（现有全量版本号模式不变）。
- **快速连续操作幂等**：重复 startQueue / 停止后再启 / fade 中打断，均收敛不叠音。

## 六、不做（YAGNI）

- 不做跨音效 true crossfade（同时挂两套层）——淡出淡入已无爆音，复杂度减半。
- 不做队列另存多套/导入导出（一套队列够用，items 自由编辑）。
- 不做自由模式的睡眠定时（v2.0 备选维持；sequence 模式已覆盖「定时听完即停」主场景）。
- 不做随机模式「不重复整轮」以外的权重/收藏加权。
- 不做拖拽排序（上下移按钮已够；行内含下拉/多按钮，拖拽手柄徒增复杂度）。
