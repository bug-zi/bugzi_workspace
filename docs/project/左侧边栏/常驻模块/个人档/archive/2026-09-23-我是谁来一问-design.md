# 我是谁·「来一问」（design）

> 创建于 2026-09-23 00:58。260923 开发者指令（会话内提出，非优化建议区条目）：在我是谁组件加「来一问」按键，点击让 AI 根据当前情况实时生成一个问题加入；**明确不走万象库式缓存/预生成机制**——实时性优先。

## 0. 已定决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 触发形态 | `WhoamiZone` 展开时正文顶部右侧常驻「来一问」按钮；点击实时生成 1 问追加今日列表末尾（未答计数自动 +1），后续作答/提炼/入档照旧 |
| 2 | 生成机制 | **纯实时**：点击时现读 `aggregateWhoamiContext()`（点击时刻的画像/致知己/十二问题/格言/万象/学习/记账/在读书/订阅快照）+ `recentAsked(40)` 防重复；复用 `buildDailyPrompt(1)`（prompt 本就参数化「恰好 N 个」）+ `parseQuestions(…, 1)`；**零缓存零预生成零定时器**，不新增任何 settings 键/DB 迁移 |
| 3 | 与每日批次关系 | 默认沿用既有幂等语义：当日批次未跑时先点「来一问」，则当日 3-4 问批次视为已供（想要更多继续点「来一问」即可）；`generateTodayBatch`/`ensureWhoamiDaily`/`WhoamiDailyDate` 标记零改动。不做来源列区分（需 DB v52 迁移，不值当） |
| 4 | 防护 | 单飞守卫（独立 `askingOne` 标志，连点静默拒绝 BUSY）；LLM 未配置抛 `LLM_NOT_CONFIGURED` → 渲染层走既有「请先在本页上方配置 LLM」toast；生成中按钮「思考中…」禁用 |
| 5 | 记账 | token 记账 scene `whoami:askOne`；顺带补挂 `LLM_SCENE_LABELS` 缺失的 `whoami:daily`/`whoami:extract` 标签（AI 使用表可读性） |

## 1. 实现

- **主进程** `electron/services/whoami.ts` 新 `whoamiAskOne(): Promise<WhoamiQuestionView>`：BUSY/未配置预检 → `chatCompletion({ messages: [buildDailyPrompt(1)], temperature 0.8, scene 'whoami:askOne' })` → `parseQuestions(…, 1)` 取首条（空抛 `PARSE_EMPTY`）→ `INSERT whoami_questions (今日日期)` → 返回 `toView`。
- **IPC**：`whoami:askOne` 三件套（ipc.ts handle / preload `whoami.askOne()` / api.d.ts）。
- **渲染层** `WhoamiZone.tsx`：正文顶部 `.whoami-toolbar`（右对齐）放「来一问」按钮；成功 `setData` **追加**今日行（新行不走 `patch`）；失败 toast（LLM_NOT_CONFIGURED 专属文案，BUSY 静默）。
- **CSS**：`.whoami-toolbar`（flex 右对齐、与列表留距）。

## 2. 验证

typecheck 双配置 + build；冒烟：点击出一问入列且可作答入档、连点不并发、每日批次先在时为纯追加、LLM 未配置提示、AI 使用表出现「我是谁·来一问」行、双主题。
