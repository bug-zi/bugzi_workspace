# 回收站「模式视图」— 设计

> 创建于 2026-09-27 01:29
> 来源：260926「全部列表 + 筛选下拉」落地后的第二轮优化——来源组已有 16 个，纯下拉翻找仍费劲，再叠一层学习/生活模式维度收窄范围。

## 一、行为规则

1. **两档视图 = 学习 / 生活**；常驻来源（格言库、文笔坊、草稿本、画布、AI 会话——上固定/右栏模块产物）**两档都显示**。
2. **默认跟随左栏**：进回收站时对齐当前 `appMode`；左栏切模式时回收站（keep-alive 常挂载）自动跟随切换视图。
3. **页内可切换**：工具条新增「学习｜生活」分段切换，只改本页显示、**不动全局模式**（不写 AppMode 设置、左栏不受影响，避免看一眼另一侧就要全局切模式）。
4. **边界**：切换视图时若当前来源筛选组不属于新视图，来源筛选自动重置为「全部」。

## 二、来源归属（按 tabOf 组 key，RecycleModule 内新增 GROUP_MODE 表）

| 视图 | 来源组 |
| --- | --- |
| 学习（5 组） | 学习库 learn、面试题库 interview、万象库 wiki（含辩真 verify·问答 qa）、灵感泉 inspirations、致知己 zhijiji（含预言家 prophet·十二问题 twelve_question） |
| 生活（6 组） | 推理角 reasoning、副本库 fuben、娱乐城 yule、记账本 ledger、赋诗苑 fushi、对弈社 duiyi |
| 常驻·双视图（5 组） | 格言库 mottos、文笔坊 wenbi、草稿本 drafts、画布 canvases、AI 会话 ai |

- 下拉菜单动态生成 = 「全部（N）」+ 当前视图的来源组（沿用 TABS 现顺序过滤，常驻组保持其在 TABS 中的原位穿插）；各项计数按视图范围统计。
- 视图内列表仍按 created_at 倒序全量混排，行首来源前缀 srcTag 照旧。

## 三、UI 与改动面（纯渲染层，零主进程改动）

- **工具条**：左「共 N 条」（N 改为当前视图范围条数）·「存放 3 天后自动彻底删除」说明；右侧新增「学习｜生活」分段切换（当前档高亮、主题近色系，复用既有点选/分段样式，必要时 recycle.css 补少量样式）+ 原筛选下拉按钮。
- **数据流**：App.tsx 挂载处 `<RecycleModule appMode={appMode} />` 传 prop（1 行）；RecycleModule 内 `viewMode` state（初始 'learn'），`useEffect` 跟随 appMode prop 变化同步；页内分段只 set viewMode。
- 恢复/彻底删除/二次确认弹窗/`recycle:changed` 事件刷新/keep-alive 激活刷新/超期天数文案全部照旧。

## 四、验收

- typecheck 双配置通过。
- 冒烟：默认跟随左栏模式；页内切换互不干扰（左栏模式不变）；左栏切模式时已打开的回收站自动跟随；下拉组与计数随视图变化；跨视图残留筛选自动重置为「全部」；恢复/彻底删除回归；空态与双主题目检。
