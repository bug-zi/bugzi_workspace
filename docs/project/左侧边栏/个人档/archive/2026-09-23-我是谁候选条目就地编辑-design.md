# 我是谁·候选画像条目就地编辑（design）

> 创建于 2026-09-23 00:34。源自优化建议区 260923 待办（第 51 轮）：个人档——我是谁模块中 AI 的总结并不够合适，需要自己再手动编辑微调，但当前只有「加入 / 忽略」两个选项无法编辑。brainstorming 一问定稿（行内就地编辑，否掉「加入时弹窗改」）。

## 0. 现状与缺口

我是谁链路：每日 AI 出 3-4 问（`whoami_questions` 表）→ 用户一句话作答 → AI 提炼 0-2 条候选画像条目 `{category, content}`（`suggestions` JSON 列，经 `parseSuggestions` 校验十类清单、内容 ≤120 字）→ 候选行仅「加入画像 / 忽略」。加入后可在画像区编辑，但**加入前无法微调**。

## 1. 已定决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 编辑形态 | **行内就地编辑**：候选行加铅笔入口，点后类别变 `<select>`、内容变输入框，保存/取消；保存写回候选记录**持久化**（重启仍在、待确认列表所见即改后版本）；否掉「加入时弹窗改」（改动不持久、候选列表永远是 AI 原文） |
| 2 | 可改字段 | 类别（十类固定清单 select，与提炼校验同清单）+ 内容（一句话口径，trim 非空，≤120 字与提炼截断一致） |
| 3 | 范围边界 | 答案「提交即定稿」既有决策不变；已入画像条目仍去画像区编辑；提炼中/失败态不显铅笔；today 与 pending 两列表共用 `WhoamiItem` 自动同享；编辑为纯本地操作不涉 LLM |

## 2. 详细设计

### 2.1 后端（electron/services/whoami.ts）

新函数 `whoamiSuggestionUpdate(id, index, category, content): WhoamiQuestionView`：行存在性 → suggestions 解析 → index 越界 → 类别 trim 后须在 `PROFILE_CATEGORIES` 内（否则 `BAD_CATEGORY`）→ 内容 trim 非空、slice(0,120)（否则 `CONTENT_EMPTY`）→ 原位替换 `items[index]` → UPDATE `suggestions` + `updated_at` → 返回 `toView`。加入/忽略的 `whoamiResolve` 零改动（读的就是存后的候选）。

### 2.2 类别清单收敛（顺带小整理）

十类清单现有两份拷贝（`whoami.ts` L13、`ProfileModule.tsx` L18），本轮编辑下拉需要第三处——提升为 `src/shared/types.ts` 导出 `PROFILE_CATEGORIES`，whoami.ts 与 ProfileModule 改 import 删本地，杜绝第四份。

### 2.3 IPC

新通道 `whoami:suggestionUpdate (id, index, category, content) → WhoamiQuestionView`：`electron/ipc.ts` handle + `electron/preload.ts` whoami 命名空间 + `src/renderer/api.d.ts` 三处同步。

### 2.4 渲染层（src/modules/profile/WhoamiZone.tsx）

- 父组件新 handler `doUpdateSuggestion(q, index, category, content): Promise<boolean>`：调 IPC → `patch(row)` 行级回写，成功 true / 失败 toast 后 false（失败保持编辑态不丢字）。
- `WhoamiItem` 新 prop `onUpdateSuggestion`；行内局部 state `editIdx/editCat/editText`；默认态候选行 action 区加铅笔（`edit` 图标，title「编辑此条」）置于「加入画像」左侧；编辑态整行替换为 select（十类 option）+ input（Enter 保存 / Esc 取消）+ 保存（内容空禁用）/取消。
- CSS：`.whoami-suggestion-editing`（实线边框 + surface-strong 底）与 `.whoami-select`（对齐 `.whoami-input` 风格），主题变量取色零彩亮。

## 3. 验证

typecheck 双配置 + build；冒烟：改类别/改内容保存后行即时更新、重启后候选保持改后版本、改后加入画像落库为改后内容、取消不落库、today/pending 两处、保存失败（空内容禁用兜底）不退出编辑态、双主题。
