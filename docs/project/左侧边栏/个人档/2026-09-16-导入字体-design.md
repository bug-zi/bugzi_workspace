# 个人档：导入字体（优化建议区第46轮）

## 需求

个人档支持导入字体：用户导入本机字体文件后，可在个人档全局字体与书架阅读器字体浮层中选用。

## 决策

- **文件系统为真相源**（同背景素材库范式，第36轮）：`userData/fonts/` 目录扫描即清单，零 DB 迁移零 settings 键。文件名 `<时间戳>-<随机4位>.<原扩展名>` 保证唯一；删除即删文件。
- **支持格式** ttf / otf / woff / woff2，上限 20 款（超限拒整批并提示）。
- **family 与显示名**：取导入文件原始文件名去扩展名（导入时从原名提取，与落盘唯一名解耦存储）。CSS value 统一回落链 `'family', 'KaiTi', serif`（同打包字体模式，字体缺失时优雅回落）。
- **运行时注册**：渲染层 FontFace API（`new FontFace(family, "url(bzres://fonts/x.ttf)")` → `document.fonts.add`），App 启动注册 + 导入/删除后刷新。ThemeProvider 只设 `--font-family` 变量，无需改动，注册后即生效。
- **删除在用回退**：删除的字体若正被全局字体使用 → 全局字体回退默认（系统）并 toast 提示（同背景素材库「删在用图回退纯色」口径）。书级 font_family 存的是 CSS 串，字体删除后 iframe 解析不到 family 自然走回落链，不崩溃、不做数据迁移。
- **bzres 协议扩展**：新增 `fonts` 命名空间 host → `userData/fonts/`；index.html CSP `font-src 'self'` 放行 `bzres:`（epub iframe 为 srcdoc 继承父文档 CSP，不放开则 iframe 内导入字体加载失败）。
- **清单缓存**：渲染层 `theme/customFonts.ts` 模块级缓存 + 失效函数，ProfileModule / BookshelfModule / EpubReader 三处消费免重复 IPC；导入/删除后失效并重注册。

## 方案细节

### 主进程（electron）

- **bzres.ts**：host 判定加 `fonts` 分支（`fonts/ + path`）；mime 表补 ttf/otf/woff/woff2（`font/ttf` 等）。
- **ipc.ts 三通道**（镜像 image:bg* 范式）：
  - `font:list` → 扫 `userData/fonts/`，返回 `{file, label, family, url}[]`（label/family 为原始名去扩展名；url 为 `bzres://fonts/<file>`）
  - `font:import` → 对话框多选（filters 限四格式）→ 超限 throw → 逐个 copyFile 唯一名落盘 → 返回刷新后清单；原始名与落盘名映射在主进程单点完成
  - `font:delete(file)` → 文件名 `^[\w.-]+$` 安全校验（同 bgDelete）→ 删文件；原始名解析：唯一名格式 `<时间戳>-<随机4位>-<原名去扩展><.ext>`（时间戳与随机段拼接后接原名，保证从唯一名可反解显示名）
- **preload.ts / api.d.ts**：`fonts.list / fonts.import / fonts.delete` 三方法同步暴露。

### 渲染层（src）

- **theme/customFonts.ts**（新）：`getCustomFonts()`（缓存优先）、`invalidateCustomFonts()`、`registerCustomFontFaces(list)`（Set 记录已注册 family 防重复 add）、`customFontCssValue(family)` 纯函数。
- **theme/fonts.ts**：新增合并助手 `globalFontOptions(customs)` / `readerFontOptions(customs)`（导入字体追加在打包字体之后），BookshelfModule「跟随全局（X）」反查改查合并清单。
- **ProfileModule**：字体下拉换合并清单；「导入字体…」按钮；当前选中为导入字体时显示「删除此字体」（ConfirmDialog 二次确认，文案说明若为当前生效字体将回退默认）；导入/删除后失效缓存 + 重注册 + 刷新表单。
- **BookshelfModule**：字体浮层 items 换合并清单（epub 限定现状不变）；挂载时加载导入字体清单。
- **EpubReader**：iframe @font-face 注入清单由 `BUNDLED_FONTS` 扩为「打包 + 导入」合并（经 getCustomFonts 取清单；bzres:// 本就是绝对 URL 免 new URL 绝对化）；format 按扩展名映射 truetype/opentype/woff/woff2。
- **App.tsx**：启动时注册导入字体（保证全局字体设置为导入字体时重启即生效）。
- **index.html**：CSP `font-src 'self' bzres:`。

### 范围界定

- PDF 阅读器无字体浮层（书级字体本就 epub 专属，setBookFont 有 format 守卫），不涉及。
- 不做字体预览渲染、不做子族/字重解析（font-weight:100 900 一刀切，同打包字体）。
