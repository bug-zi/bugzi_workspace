# 灵感泉——完整点子文档（优化建议区第 28 轮）

> 创建于 2026-09-09（brainstorming 会话定稿）

## 背景与诊断

第 18 轮（口味注入 + 两阶段管线）、第 22 轮（标题锚点 + summary 两句白话 + form 配额 + 风向标）之后，开发者实测反馈（本轮澄清确认）：

- **唯一痛点 = summary 两句模板太薄**：「这是什么 + 第一步：」100 字装不下点子本身，核心机制、玩法、长什么样完全没有载体——卡片和 md 正文都只有这一行，看不出实际想法、无法判断值不值得立项。
- 标题锚点、腔调、form 标签、风向标、配额**均无问题，全部不动**。

问题本质：**点子的完整内容没有载体**。第 22 轮把 summary 压到两句白话治了「谜语化」，却同时把展开空间压缩没了（钟摆问题）。

## 方案（三选一，定 A）

| 方案 | 思路 | 结论 |
| --- | --- | --- |
| **A. 完整点子文档（ adopted ）** | 两阶段结构不动，自评阶段为选中的 5 条写完整 md 文档；卡片短预览 + 弹窗全文分层 | **采纳**——扫读/细读分层清晰，零 DB 改动 |
| B. summary 放宽到 250~300 字 | 改动最小 | 否——300 字仍说不清点子，卡片被撑爆，文风规范还得重调 |
| C. 三阶段管线（发散→自评→逐条深写） | 每条单独一趟调用 | 否——2 趟变 7 趟，「来5条灵感」等待时间暴涨 |

## 设计

### 1. 发散阶段（不动）

12 条粗点子仍为短格式 `{title, summary, form}`——完整文档不写在会被淘汰的条目上。标题锚点、禁拼装句式、风向注入、形态分散规则全部保持现状。

### 2. 自评阶段（升级）

JSON 输出每条从 `{title, summary, form}` 变为 `{title, form, body}`，`body` 为完整点子 md 文档，**骨架固定**：

```markdown
（一句话引子：这是什么 + 好玩/值得在哪——原 summary 第一句的进化版，不带小节标题）

## 这是什么
做出来长什么样、给谁用、核心体验，一段说清

## 核心机制
这个点子最有意思的部分：怎么转、为什么有趣

## 最小版本
第一步做什么；一个周末能跑起来的版本长什么样
```

- 每条 body 300~400 字，五条约 2000 字输出（阶段二耗时略增，可接受）
- 原「summary 两句模板」「第一步：」句式从卡片层规则改写为 body 写作要求：「第一步」内容并入「最小版本」小节；「禁文艺化压缩、每个名词落到具体动作/物件」保留为小节写作要求
- 评审规则（五维打分、批内 form 配额、淘汰口径）、title/form 沿用候选原文的约束不变

### 3. 入库

`mdCreate(mdPath, body)`——md 正文直接是完整文档（不再写单行 summary）。标题精确查重（含回收站 + 批内互斥）、插草稿区末尾逻辑不变。`GenerateInspirationsResult`（generated/inserted/winds）不变。

### 4. 卡片预览微调（InspirationsModule.tsx）

`load()` 的预览从「全文压平取前 120 字」改为「**取首段**（首个空行前）压平截 120 字」：

- AI 条预览 = 完整引子句；手动条 = 正文第一行
- 预览不再混进 `## 标题` markdown 标记符

### 5. 降级路径

自评两趟均失败走 `pickDiverseFive` 时候选没有 body——按旧格式用 summary 单行入库（降级批次为短文档，可接受；用户可手动「AI 完善」补充）。`pickDiverseFive`、`parseInspirationArray`（body 非必填）容错同步适配。

### 6. 存量不迁移

旧 AI 条保持单行 summary 原样，无 DB 迁移。

## 改动范围

- `electron/ai/services.ts`：`generateInspirations` 阶段二 prompt 与 JSON schema、`parseInspirationArray`、入库 `mdCreate`、降级路径
- `src/modules/inspirations/InspirationsModule.tsx`：`load()` 预览取首段
- 零 DB 改动、零新 IPC、零样式改动

## 验证口径

- 冒烟：来 5 条灵感 → 5 条 md 弹窗均为完整文档（引子 + 三小节）；卡片预览为引子句无 markdown 标记符；两批之间无同质化回潮
- typecheck 通过
