## 3. 方案选型（音频来源）

- **方案 A（采纳）Web Audio 纯合成**：渲染层噪声源（白/粉/棕）→ 滤波器组 → 分层增益，叠加随机事件声（雷/水滴/打窗）。零素材零版权、安装包不变大；每层滑杆直接映射滤波/增益参数，与 mynoise 交互模型天然契合；雨/海浪/风/篝火都是合成友好型场景。缺点是调参需下功夫（开发侧工作，不是需求风险）。
- 方案 B（否）打包 CC0 音频素材循环：真实感最强，但素材体积几十上百 MB、版权逐一甄别、滑杆只能调音量调不了音色、循环接缝要处理。
- 方案 C（否）合成打底 + 素材点缀：两套引擎都要建，首版开发量最大且素材问题一点没少。

## 4. 设计正文（三节呈现稿，均逐节确认通过）

### 4.1 总体形态与入口

- **定位**：全局背景音——切模块、开关右栏声音都不断。引擎为渲染层单例，挂在任何模块组件之外。
- **左栏底部常驻控件**（替换现主题按钮位，`App.tsx` sidebar 底部）：双区交互——图标区播放/暂停（任意模块下一键操作，播放中高亮；图标 Material Symbols `graphic_eq`）；文字区「白噪音」切主栏混音器页。
- **主栏混音器页**：不进左栏模块列表；页内承载场景选择、分层滑杆、主音量、出厂预设、自定义混音管理。切走只是隐藏页面，声音不断。
- **主题按钮迁移**：右栏底部（右下角）常驻——右栏收起细条态放双图标下方，展开态放面板底部，两种状态都钉在窗口右下角，行为不变。
- **零依赖声明**：纯本地合成，无 LLM/MCP/网络/素材文件，无「未配置置灰」问题；App 关闭声音自然停止。

### 4.2 音频引擎（渲染层 Web Audio 纯合成）

- **多场景框架**：每个场景 = 一份配置（层清单 + 出厂预设 + 图标名），引擎只认「层」不认具体场景；首版只注册「雨」。
- **雨场景拟定 8 层**（每层一根滑杆 0–100，实时映射该层增益，拖动平滑无爆音）：

| 层 | 声音 | 合成方式 |
| --- | --- | --- |
| 远雷 | 隔一阵低频隆隆 | 棕噪声 lowpass + 慢起慢落包络，随机间隔（约 20–60s）触发 |
| 雨体·沉 | 大雨厚重底 | 棕噪声 lowpass（~120Hz）稳态循环 |
| 雨体·沙沙 | 连绵雨幕 | 粉噪声 bandpass（300Hz–1kHz） |
| 密雨 | 急促雨点 | 白噪声 bandpass（1–3kHz）+ 轻微幅度抖动 |
| 细雨·高频 | 细碎滴答感 | 白噪声 highpass（4kHz 以上） |
| 屋檐滴水 | 离散水滴 | 随机触发指数衰减正弦 ping（800–2400Hz 随机音高）+ 噪声瞬态 |
| 雨打窗 | 稀疏敲击 | 更稀疏的中频短脉冲 |
| 风 | 阵风起伏 | 粉噪声 + 低通截止被慢速 LFO 扫调 |

  层的数目/命名/频点在实施调参阶段定稿（目标：单层可辨、混起来像真的雨）。稳态层用预生成噪声缓冲循环，事件层由引擎随机调度器触发。
- **播放控制**：暂停 = AudioContext 挂起 + 事件调度器停表；恢复反之。全局唯一 AudioContext，首次点播放时创建；主音量是各层之外的最终增益节点。
- **出厂预设（雨，拟 5 个）**：细雨 / 暴雨 / 屋檐夜雨 / 雷雨 / 微风细雨——各为一组层配比，一键切换后可再微调滑杆。

### 4.3 混音器页、持久化与改动清单

- **混音器页布局**（双主题、禁彩亮色、Material Symbols）：顶部场景选择条（首版只有「雨」一张卡，占位但可见——多场景架构的体现）+ 播放大按钮；中部 8 根竖向滑杆（mynoise 式）+ 主音量；下部出厂预设 chips + 自定义混音区（「保存当前配比」命名保存；点击召回；可删除——**二次确认、彻底删不入回收站**；允许重名按条目区分）。
- **持久化**（零 DB 迁移，复用 settings 通道，主进程零改动）：`noise.state`（当前场景 + 各层值 + 主音量；重启记住参数但默认暂停）；`noise.custom_mixes`（自定义混音 JSON 数组：名称 + 场景 + 层配比，不含主音量）。
- **改动清单**：新建 `src/services/noiseEngine.ts`（引擎单例）、`src/services/noiseScenes.ts`（场景注册表：雨场景层清单 + 出厂预设）、`src/modules/noise/NoisePage.tsx` + `noise.css`（混音器页）；修改 `src/App.tsx`（左栏底部双区控件替换主题位、主栏视图状态扩展出 `'noise'` 页、右栏外包列容器底部挂主题按钮）、`src/App.css`、`src/shared/types.ts`（SettingsKeys 增两键）。
- **边界**：自定义混音按场景归属（同场景下才能召回）；切场景各层重置为该场景默认；引擎单例保证重复点播放不叠音；无 AI 边栏频道映射（默认助手频道）。

## 5. 会话补充确认的实现落点（写 specs 前核查）

- 右栏结构：`AiSidebar` 收起态为顶部两条 `.ai-toggle` 图标的细条（`--ai-width-collapsed`），展开态为完整面板；`DraftSidebar` 展开时 AiSidebar 渲染空。主题按钮落位方案：App.tsx 把右栏（AiSidebar + DraftSidebar）外包一层列容器，footer 挂主题按钮——一份实现覆盖三态，常驻右下角。
- 主栏视图：现 `module: ModuleId` 状态 + keep-alive 渲染。白噪音页类型上不是 ModuleId：App.tsx 本地 `MainView = ModuleId | 'noise'`；`'noise'` 不进 MODULES 数组、不进 keep-alive 区（页面卸载无碍——引擎在组件外）；模块激活/失活自定义事件携带 `'noise'` 时无模块认领，无害。从真实模块进入白噪音页时该模块正常收到失活事件（海龟汤计时等语义保持）。
- settings 既有 `window.api.settings.get/set` 通道，键值均为字符串，JSON 序列化存对象——零 IPC/DB 改动成立。
