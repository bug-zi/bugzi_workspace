# 白噪音

介绍：白噪音是我的全局背景音功能——在任意模块工作（写作/阅读/记笔记）时持续播放合成环境声，参考 mynoise.net 的分层混音玩法。纯 Web Audio 本地合成，零素材零网络零 AI。本文档由 260908 brainstorming 会话与 AI 协作定稿（设计全记录见同目录 `2026-09-08-白噪音-design.md`；开发者原始想法见 `docs/project/新功能开发区.md` 待完成区）。

v1.0：

**定位与入口：**

- 全局背景音：音频引擎为渲染层单例、独立于模块组件，切模块/开关右栏声音不断；App 关闭自然停止。
- 左栏底部常驻控件（占据原「主题」按钮位）：**整块单击 = 切到主栏混音器页**（260908 实施后修订，原「图标播放/暂停 + 文字进页」双区设计作废——两区在实际使用中不可辨识，整块行为与左栏其余模块项一致）；播放中图标 `graphic_eq` 主题色高亮作状态提示；快捷播放/暂停入口在混音器页内。
- 混音器为主栏独立页面，**不进左栏模块列表**（12 模块顺序不动），唯一入口是左栏底部控件；切走只是隐藏页面。
- 「主题」按钮迁至右栏底部（窗口右下角），右栏收起细条态与展开面板态都常驻，行为不变。

**声音引擎（Web Audio 纯合成）：**

- 多场景架构：场景 = 一份配置（层清单 + 出厂预设 + 图标），引擎只认「层」；首版只注册「雨」，后续加场景不动引擎。
- 雨场景 8 层，每层一根滑杆 0–100 实时映射该层增益（平滑无爆音）：远雷（随机触发的低频包络）/ 雨体·沉（棕噪声 lowpass）/ 雨体·沙沙（粉噪声 bandpass）/ 密雨（白噪声 bandpass + 幅度抖动）/ 细雨·高频（白噪声 highpass）/ 屋檐滴水（随机水滴 ping）/ 雨打窗（稀疏中频脉冲）/ 风（粉噪声 + 慢速 LFO 扫调低通）。稳态层循环预生成噪声缓冲，事件层由随机调度器触发。
- 全局唯一 AudioContext（首次点播放时创建）；主音量为各层之外的最终增益；暂停 = 上下文挂起 + 调度器停表。
- 具体层数/频点/配比为拟定，实施调参定稿（目标：单层可辨、混起来像真雨）。

**混音器页（自上而下）：**

- 场景选择条（首版只有「雨」一张卡，占位但可见）+ 播放大按钮。
- 8 根竖向滑杆（mynoise 式）+ 主音量滑杆。
- 出厂预设 chips（雨，拟 5 个：细雨/暴雨/屋檐夜雨/雷雨/微风细雨），一键切换层配比后可再微调。
- 自定义混音区：「保存当前配比」命名保存；条目点击召回；可删除（二次确认，彻底删不入回收站）；允许重名按条目区分。

**持久化（零 DB 迁移，主进程零改动）：**

- `noise.state`：当前场景 + 各层值 + 主音量；重启记住参数但**默认暂停**，手动点播放。
- `noise.custom_mixes`：自定义混音 JSON（名称 + 场景 + 层配比，不含主音量）。

**边界：**

- 自定义混音按场景归属（同场景下才能召回）；切场景各层重置为该场景默认；重复点播放不叠音（单例幂等）；无 AI 边栏频道联动；无网络/素材/LLM/MCP 依赖，错误一律 Toast。

v2.0 备选：

1. 更多场景（海浪/篝火/咖啡馆等，各为一份场景配置）。
2. 睡眠定时（渐弱停止）。
3. 重启自动续播。
4. 托盘快捷控制。
