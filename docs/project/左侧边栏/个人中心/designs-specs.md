# 个人中心 designs-specs.md

> 本文档由 AI 基于 `docs/project/左侧边栏/个人中心/design.md` 与《总需求文档.md》第 7、8、11、13 条生成，是开发的直接依据。依赖：样式/designs-specs.md 的主题系统（背景图机制在此实现）。

## 1. 数据表

```sql
-- settings 为全局 key-value 表（样式 specs 已引用），本模块用到的 key：
-- user_name / user_avatar（头像文件名）/ user_bio
-- font_size / font_family / font_weight
-- theme（'light' | 'dark'）
-- llm_configs（JSON 数组）/ llm_default_id
-- mcp_configs（JSON 数组）/ mcp_enabled（JSON 数组 of id）

CREATE TABLE settings (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

## 2. 个人信息

- 用户名：文本输入，失焦即存。
- 头像：仅本地上传（图片选择对话框 → 复制到 `<userData>/avatar.<ext>` → 存 settings）；非方形图 CSS object-fit: cover 居中裁剪显示。无预置头像。
- 个性签名：文本输入，失焦即存。

## 3. App 设置

### 3.1 字体设置（即时生效 + 自动保存）

- 字体大小（如 12-20px 滑杆）、字体样式（系统字体下拉：默认/宋体/黑体/楷体/等线等，取系统可用字体）、字体粗细（400/500/700）。
- 任何变更 → 写 settings + 立即应用到 `:root` CSS 变量（`--font-size` 等），全 App 无刷新生效，无保存按钮。

### 3.2 主题设置

- 浅色/深色切换项（与字体设置并列）——调样式 specs §1.2 的主题切换机制；侧边栏底部图标为第二入口。

### 3.3 背景图设置（总需求文档第 13 条）

- 浅色/深色各一张：两个「更换」按钮分别选择本地图片 → 复制到 `<userData>/bg/bg-light|bg-dark` → 主题系统即时刷新 `--bg-image`。

### 3.4 LLM 配置

- 列表管理多套配置：每套 = 名称（自定义）+ API 地址 + API Key（输入框密码态）+ 模型名。
- 操作：新增 / 编辑 / 删除（二次确认）；单选标记其中一个为**默认**（radio 交互）。
- 「测试连接」按钮（可选，v1 加分项）：发一次最小请求验证配置可用，成功/失败 toast。
- 不内置服务商名单，任何 OpenAI 兼容接口均可。
- 全 App 的 AI 功能（格言生成/知识卡片/AI 边栏/辩真）一律用默认 LLM。

### 3.5 MCP 配置

- 列表管理：每条 = 名称 + 服务器地址/命令 + 启用开关。
- 可启用多个、随时开关；辩真阁联网搜索读取启用中的搜索类 MCP。
- 具体字段（stdio 命令 vs SSE URL 等传输类型）开发阶段定，UI 先按「名称 + 地址 + 开关」做。

## 4. 首次启动引导（总需求文档第 11 条，归属本模块）

- settings 无 `user_name` 时判定首次启动 → 全屏欢迎弹窗（三步，可跳过第 1、2 步）：
  1. 设置用户名（写入 settings）
  2. 选择主题（浅/深两个预览块）
  3. 提示「先去个人中心配置 LLM，以启用 AI 功能」+「去配置」「暂不」按钮
- 完成或全部跳过 → 进入空白 App（默认格言库页）。
