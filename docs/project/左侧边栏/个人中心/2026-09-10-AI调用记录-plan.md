# AI 使用 · 调用记录（最近 30 条）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 个人档「AI 使用」zone 内新增「调用记录」子区块：展示 `llm_usage` 表最近 30 条调用明细，区块级折叠默认收起，与时间范围切换无关。

**Architecture:** 数据层零改动（`llm_usage` 表 DB v27 已全量记账，只增不删）；新增 IPC `llmUsage:records` 查最近 30 条返回 camelCase 明细；渲染层在 ProfileModule 现有 AI 使用 zone 的统计表格下方加可折叠子区块，刷新复用现有 onActivity 空闲回调与手动刷新按钮。

**Tech Stack:** Electron 44 主进程（node:sqlite）+ React 19 + TypeScript，electron-vite。

**项目纪律（覆盖技能默认，必须遵守）：**
- **禁止任何 git 操作**（add/commit/push 等全部不做，开发者自行提交）——计划中无 commit 步骤。
- **无测试框架**（package.json 仅 dev/build/preview/typecheck/smoke）——验证方式为 `npm run typecheck` + `npm run dev` 人工冒烟，这是项目自 v1.0 起的既定惯例。

```typescript
  // ---------- AI 使用统计（260910 推理角效率优化） ----------
  const [usageRange, setUsageRange] = useState<'today' | 'month' | 'all'>('today')
  const [usage, setUsage] = useState<LlmUsageStats | null>(null)
  const [usageLoading, setUsageLoading] = useState(false)
  const loadUsage = useCallback(async () => {
    setUsageLoading(true)
    try {
      setUsage(await window.api.llmUsage.stats(usageRange))
    } catch {
      /* 静默保留上次数据 */
    } finally {
      setUsageLoading(false)
    }
  }, [usageRange])
  useEffect(() => {
    void loadUsage()
  }, [loadUsage])
  // 调用记录（260910 明细）：最近 30 条滚动展示，与时间范围无关；默认收起、内存态不持久化（同画像 zone 折叠范式）
  const [recordsCollapsed, setRecordsCollapsed] = useState(true)
  const [usageRecords, setUsageRecords] = useState<LlmUsageRecord[]>([])
  const loadRecords = useCallback(async () => {
    try {
      setUsageRecords(await window.api.llmUsage.records())
    } catch {
      /* 静默保留上次数据 */
    }
  }, [])
  useEffect(() => {
    void loadRecords()
  }, [loadRecords])
  // AI 空闲时自动刷新（后台生成结束数字即新）；记录与统计一起重拉
  useEffect(() => {
    return window.api.llmUsage.onActivity((p) => {
      if (p.items.length === 0) {
        void loadUsage()
        void loadRecords()
      }
    })
  }, [loadUsage, loadRecords])
  const fmtTokens = (n: number): string => (n >= 10000 ? `${(n / 10000).toFixed(1)}万` : String(n))
  /** 记录时间：今天 HH:mm:ss，更早 MM-dd HH:mm（滚动 30 条可能跨天，本地时区） */
  const fmtRecordTime = (iso: string): string => {
    const d = new Date(iso)
    const now = new Date()
    const two = (n: number): string => String(n).padStart(2, '0')
    const sameDay =
      d.getFullYear() === now.getFullYear() && d.getMonth() === now.getMonth() && d.getDate() === now.getDate()
    return sameDay
      ? `${two(d.getHours())}:${two(d.getMinutes())}:${two(d.getSeconds())}`
      : `${two(d.getMonth() + 1)}-${two(d.getDate())} ${two(d.getHours())}:${two(d.getMinutes())}`
  }
```

```tsx
          {/* 调用记录（260910 明细）：最近 30 条，默认收起，与时间范围无关 */}
          <div className="llm-usage-records">
            <button
              type="button"
              className="llm-usage-records-toggle"
              onClick={() => setRecordsCollapsed((v) => !v)}
            >
              <span className="material-symbols-outlined">

                  <thead>
                    <tr>
                      <th>时间</th>
                      <th>场景</th>
                      <th>模型</th>
                      <th>结果</th>
                      <th>耗时</th>
                      <th>token</th>
                    </tr>
                  </thead>

                    {usageRecords.map((r) => (
                      <Fragment key={r.id}>
                        <tr>
                          <td className="llm-usage-rec-time">{fmtRecordTime(r.createdAt)}</td>
                          <td>{LLM_SCENE_LABELS[r.scene] ?? r.scene}</td>
                          <td className="llm-usage-rec-model" title={`${r.configName} · ${r.model}`}>
                            {r.model}
                          </td>
                          <td>
                            {r.ok ? (
                              <span className="llm-usage-rec-ok">成功</span>
                            ) : (
                              <span className="llm-usage-rec-fail">失败</span>
                            )}
                          </td>
                          <td>
                            {r.durationMs >= 1000 ? `${(r.durationMs / 1000).toFixed(1)}s` : `${r.durationMs}ms`}
                          </td>
                          <td title={`输入 ${r.promptTokens} / 输出 ${r.completionTokens}`}>
                            {fmtTokens(r.promptTokens + r.completionTokens)}
                            {r.tokensEstimated ? ' ≈' : ''}
                          </td>
                        </tr>
                        {!r.ok && r.errorBrief && (
                          <tr className="llm-usage-record-error">
                            <td colSpan={6}>{r.errorBrief}</td>
                          </tr>
                        )}
                      </Fragment>
                    ))}
                  </tbody>
                </table>
              ))}
          </div>
```
