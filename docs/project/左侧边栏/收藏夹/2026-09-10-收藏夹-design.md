## 1. 背景与定位

左栏新增第 12 个模块「收藏夹」，位置在**藏书架与信息源之间**。定位：个人专属的链接收藏管理器——一切条目都是「URL + 名称 + 简介 + 分类」，超链接文本形式呈现，单击看介绍、Ctrl+单击跳系统浏览器。纯本地零 AI（唯一网络行为是添加时抓取页面 meta，不走 LLM）、零回收站（二次确认直接删）。

适合收藏的内容类型（均为 URL 型，天然被同一模型覆盖）：常用网站/主页、文章/博客帖（待读）、视频链接（B 站/YouTube）、GitHub 仓库/开源项目、在线工具站（格式转换/图片压缩/正则测试）、文档手册（MDN、API docs）、问答帖（知乎/SO/V2EX）、论文或资料 PDF 链接、图片/设计素材链接、音乐歌单、购物/心愿单链接。

**首版不做**（YAGNI，留作后续按需增强）：点击计数自动排序、「最近添加」专区、favicon 显示（与「超链接文本呈现」及禁 emoji 原则冲突）、死链检测、跨大类拖拽移动（走编辑弹窗改分类）。

## 2. 已确认决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 条目范围 | **纯链接型**：一切条目必须有 URL，不允许无 URL 的文本片段/本地文件（避免与灵感泉/草稿本/万象库职责重叠） |
| 2 | 删除策略 | **二次确认直接删**（藏书架/信息源同款），不入回收站、不动回收站模块 |
| 3 | 添加方式 | **粘贴 URL + 主进程自动抓取**标题/简介（HTTP 拉 meta 标签，无 LLM 依赖，失败手填），不提供 AI 生成简介 |
| 4 | 分类层级 | **两级**（大类 > 子类），覆盖个人收藏绝大多数场景 |
| 5 | 方案选型 | **标准全套**：新表 + 服务 + IPC + 完整 UI（大类 tab + 子类分组 + 搜索 + 拖拽 + md 弹窗 + 抓取 + 手动置顶） |

## 3. 数据模型（DB v28）

> 注：v27 已被 llm_usage（260909 第 31 轮）占用，本模块迁移版本为 **v28**。

两张新表：

- **`fav_categories`**：`id` / `parent_id`（NULL = 大类）/ `name` / `sort` / `created_at`
  - 两级约束由服务层保证：建子类时父必须是大类；大类的 parent 恒为 NULL。
  - 常驻虚拟大类「未分类」：不可删、不可改名、不参与排序（固定末位），是删除非空分类时直属条目的去处。
  - 排序：`sort` 字段，分类管理弹窗内上下移按钮调整（不做拖拽排序）。
- **`fav_items`**：`id` / `category_id`（挂大类或子类均可）/ `name` / `url` / `desc`（md 文本简介）/ `pinned`（0/1）/ `created_at` / `updated_at`
  - 条目排序：置顶优先 + 创建时间倒序（新收藏在前），不提供手动排序。
  - 不对 url 做唯一约束（允许重复收藏，见 §6）。

## 4. 主进程服务与 IPC

新增 `electron/services/favorites.ts`，IPC 通道（invoke 风格，与现有模块一致）：

| 通道 | 作用 |
|------|------|
| `favorites:list` | 一次拉回分类树 + 全部条目（个人收藏百级量级，全量返回，前端本地过滤/搜索，不分页） |
| `favorites:addItem` / `updateItem` / `deleteItem` | 条目增改删 |
| `favorites:addCategory` / `updateCategory` / `deleteCategory` | 分类增/改名与排序/删 |
| `favorites:fetchMeta` | 抓取页面 meta |

**fetchMeta(url)**：`net.fetch` 带 UA，8 秒超时；只读响应前 64KB（解析到 `</head>` 为止），提取 `<title>` / `og:title` / `meta description` / `og:description`；失败或无结果返回空对象，由前端手填兜底。

**URL 规范**：用户输入无协议时自动补 `https://` 再校验；服务层与 `shell.openExternal` 双重限制仅放行 http/https（防 `file://` 等协议）。

**删除语义**：条目删除直接删；分类删除时——子类上移一级（删大类时其子类升为大类）、直属条目移入「未分类」——单事务执行，中途失败整体回滚。

**左栏注册**：藏书架与信息源之间，模块名「收藏夹」，Material Symbols `bookmark` 图标。

## 5. UI 布局与交互

**主栏结构**（自上而下）：

1. **顶栏**：大类 tab 行（万象库「百科 | 辩真」同款样式，横向滚动容纳溢出；「未分类」常驻排最后）+ 搜索框 + 「分类管理」图标按钮 + 「新增收藏」按钮。
2. **大类视图**：直属条目区（置顶分组在最前）→ 其下各子类分组（子类标题行 + 条目列表）。
3. **条目行**：名称（主题色超链接文本）+ 一行摘要（URL 域名 + 简介截断）；hover 时行尾浮出「编辑 / 置顶切换 / 删除」图标按钮（非常驻）。

**交互**：

- **单击**条目 → `MdDialog` 全局 md 弹窗：渲染态显示名称、分类路径（大类/子类）、URL（可复制）、简介 md；**双击切换编辑态**（表单：名称 / URL / 分类二级选择 / 置顶 / 简介 md 编辑器）——与其他模块的全局弹窗规则一致。
- **Ctrl（或 ⌘）+单击** → `shell.openExternal` 用系统浏览器打开。
- **拖拽**：条目行拖到本大类内其他子类分组或直属区即改所属（灵感泉跨区拖拽同款手感）；跨大类走编辑弹窗改分类（首版不做拖到 tab 上）。
- **新增收藏弹窗**：URL 输入 + 「抓取」按钮（成功自动填名称/简介，均可改）+ 名称 + 简介 textarea（md）+ 分类选择（大类下拉必选、子类下拉可不选 = 挂大类直属）。
- **搜索**：输入即切「搜索结果视图」——跨全部分类匹配名称/URL/简介，结果行带分类路径标签；清空恢复当前大类视图。
- **分类管理弹窗**：两级树列表；增（大类/子类）、改名、上下移排序、删除（二次确认，文案写明去向）。
- **空状态**：无收藏时居中引导文案 + 新增按钮。

样式全程遵循全局硬性规则：双主题、禁 emoji、无彩亮色、Material Symbols 图标。

## 6. 边界与错误处理

- **抓取失败**（超时/非 2xx/编码异常/无 meta）→ Toast「抓取失败，请手动填写」，表单照常可手填保存，不阻塞。
- **URL 校验**：非法 URL 保存按钮置灰 + 提示；`openExternal` 仅放行 http/https。
- **同 URL 重复收藏**：保存时若已存在，Toast 提示「已收藏于 ××分类」，不阻止保存。
- **拖拽与点击冲突**：设拖拽阈值（位移超过 5px 才算拖拽，可按手感微调），不影响单击/双击。
- **DB 迁移**：v27 → v28 沿用项目现有迁移机制。
