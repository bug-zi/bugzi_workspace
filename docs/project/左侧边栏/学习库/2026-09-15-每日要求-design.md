# 学习库每日要求（每日新学 8-10 + 小测 + 自动打卡）设计记录

> 创建于 2026-09-15 22:20
> 来源：`docs/project/新功能开发区.md` 待完成区任务二（开发者 260915 提出，当日 brainstorm 商定）。
> 定位：学习库加每日硬要求——每日新学 8-10 个新知识点（用户自己解锁，取消系统随机推荐）+ 完成题目练习测试（今日小测），达标自动打卡计连胜。本文件为实施设计记录。

## 一、需求结论（brainstorm 摘要）

| 维度 | 结论 |
|---|---|
| 目标数值 | 每日随机 8-10（`8 + random(0..2)`），启动/零点定档、当日不重抽（同万象库随机先例） |
| 解锁方式 | **取消系统自动抽卡定档**——用户从知识树/随机来一条/手动添加后自己挑着学，学会即计入进度 |
| 打卡形态 | 自动打卡——新学达标 + 小测交卷 → 当日 done=1，连胜从 done 记录推导（同思维墙口径），无手动按钮 |
| 小测判定 | 交卷即完成，不看分数（同现有小测「检验不惩罚」口径） |

## 二、数据模型（DB v39，以实施时实际递增为准）

```sql
-- learn_nodes 加列（mark learn 时写入，今日已学的判定依据）
ALTER TABLE learn_nodes ADD COLUMN learned_at TEXT;   -- ISO 时间；NULL=未学

-- learn_daily 重建（new_ids 列废弃，旧队列数据一并作废）
CREATE TABLE learn_daily (
  date TEXT PRIMARY KEY,       -- 本地日期 YYYY-MM-DD
  goal INTEGER NOT NULL,       -- 当日目标数 8-10，定档后不重抽
  review_ids TEXT NOT NULL,    -- 当日到期复习节点 id JSON 数组（逻辑原样保留）
  done INTEGER NOT NULL DEFAULT 0  -- 当日要求完成标记（显式落库，防删卡丢历史）
);
```

- **done 显式落库而非纯推导**：learned_at 随节点删除而消失，若纯靠 learned_at 推导历史完成数会被删卡改写；连胜只依赖 learn_daily.done，删卡不影响。
- 旧 learn_daily 行（无 goal/done）迁移时作废重建，不保留（历史队列无长期价值，断签无惩罚故无需补记录）。

## 三、每日要求闭环

- **定档**：现有两触发点不变（main.ts 启动延迟 + scheduler 午夜零点）——learn_daily 无今日行则写 `goal = 8 + Math.floor(Math.random() * 3)` 并照旧算 review_ids；已有行跳过（幂等）。
- **解锁路径（零自动推荐）**：知识树点开未学卡「学会了」／「随机来一条」／手动添加后学——任一路径学会都写 learned_at 并计入当日新学数。
- **done 联动两处 check-and-set**：
  - `learn:mark learn`：写 learned_at 后检查——今日新学数 ≥ goal 且今日卷已交（quiz status=graded）→ 置 done=1，返回达成标志给渲染层 toast「今日要求完成！」；
  - `quizSubmit`：交卷后同口径检查——已达标 → 置 done=1，返回达成标志。
  - 任一侧后到达都补判，两处共用一个内部函数。
- **连胜**：从今日（done=1 则含今日）往回逐日数 learn_daily.done=1 的连续天数，缺行或 0 即断（同思维墙 wallStreak 推导口径）；无惩罚、无补签。

## 四、备学池泵（learnStock 重设计）

- 原职责「为今日队列 new_ids 中 content_ready=0 的卡预生成」随队列取消而改：新职责 = **备学池**——保证 `state=todo AND content_ready=1` 存量 ≥ **10** 张；低于则从 todo 未生成卡中领域轮转均摊补生成（均摊口径同现状）。
- 三触发点不变：启动延迟／进模块 `learn:stockCheck`／**消耗后**（mark learn 后 fire-and-forget，替换原「每日队列生成后」触发）。
- LLM 未配置静默跳过；单张失败 warn 继续下次补齐——容错口径全不变。
- 用户侧效果不变：随机来一条、树上点开、手动添加全部秒开。

## 五、今日学习 tab 新布局

1. **今日要求卡**（顶部新增）：「今日新学 x/N」进度条 + 小测状态（未出卷／N 题已答／已交卷）+ 打卡态（未完成／已完成·连胜 n 天）；达成后整卡已完成态样式。
2. 随机来一条按钮：原样保留。
3. **今日已学** zone：`learned_at` 为今日的卡动态列表（取代原「今日新学」定档列表），行样式沿用，点开重看。
4. **到期复习** zone：逻辑不变。
5. **今日小测**（LearnQuizZone）：组件结构不动；出卷取卡口径从「定档队列中已学会的」改为「今日已学（learned_at=今日）的卡」；出卷门槛仍是今日已学 ≥2 张；交卷回调接 done 联动。

## 六、总导览联动

今日学习块从「队列数」改为「今日要求」状态行：`新学 x/N · 小测已交/未交 · 连胜 n 天`；整卡深链仍直达学习库今日学习 tab（go('learn','today') 不变）。

## 七、容错与边界

- **LLM 未配置**：定档、解锁计数、done 判定、连胜完全不受影响（零 LLM）；备学池静默跳过；小测出卷需 LLM——未配置时当日要求无法达成，小测区按全局规则弹「去配置」。
- 当日未完成：无惩罚，缺行自然断签；次日重新定 goal。
- 复习不计入每日要求（要求 = 新学 + 小测两项），复习流转照旧。
- 跨午夜口径沿用 localDateStr（渲染层 todayStr 同口径）。
- 知识点删除入回收站：learned_at 随软删行保留（恢复后不丢）；彻底删不影响历史 done（已显式落库）。
