## 一、需求结论（brainstorm 摘要）

| 维度 | 结论 |
|---|---|
| 痛点定位 | 开发者自述「过于单调、说不上来缺什么」——澄清后锁定两维：**检验感**（只读过不提取，不知道会不会）+ **深度感**（卡片孤立浅散，学完不知道怎么用） |
| 形态取舍 | 四候选（每日小测/复习改主动回忆/实战任务/深挖模式）中选三：**每日小测 + 实战任务 + 深挖模式**；复习改主动回忆不做（复习机制保持 v1.0 现状） |
| 方案取舍 | A（三件套长在现有骨架）＞ B（独立练习场 tab）＞ C（最小版）；开发者拍板 A |
| 硬约束 | 实战任务**小而实用**——30 分钟量级，不超纲不摊大饼（开发者明确要求） |
| 检验原则 | 小测只检验不惩罚——不改复习状态机，「记住/忘记」仍由用户自判 |

## 二、① 每日小测（今日学习页内）

- **入口**：今日学习顶部条「随机来一条」旁加「小测一下」按钮。
  - 可测条件：今日新学队列中 `state='learned'` 的卡 ≥ 2 张（不足置灰 + title 说明）。
  - 当日已出卷：按钮文案变「查看小测」。
- **出卷**（一次 LLM 调用，prompt `generateLearnQuiz`）：读已学卡的 md 正文，**每卡 1 题**，题型由 AI 按内容混合定（选择/填空/简答）。**一天一卷**（`learn_quiz.date` 主键，与每日队列同幂等哲学）；「重做」= 清空作答重答同一卷，不重新出题。
- **答题**：主栏「今日小测」zone 内逐题作答——题面 MdView 渲染（推理角题面同款）；选择点选、填空/简答输入框；**作答实时存库**（每答一题 update，切模块/关 App 不丢）。
- **判卷**（交卷时）：
  - 选择：本地判（出题时附正确答案下标）。
  - 填空：本地宽松判（出题时附可接受答案数组，归一化 = 去首尾空格 + 全角转半角 + 转小写后比对，命中任一即对）。
  - 简答：批量一次 LLM 调用（prompt `gradeLearnQuiz`），逐题返回 对/错 + 一句点评。
  - 全天固定 2 次 LLM 调用（出卷 + 批简答；无简答题则只 1 次）。
- **结果**：交卷后每题展示对错标记 + 解析展开（含正确答案）；**答错题对应的知识点卡在今日新学列表行加警示小标记**（`error` 图标 + title「小测答错」），当日有效。
- **状态机隔离**：小测结果**不回写** `learn_nodes`（不改 state/review_stage/next_review_at）——检验归检验，复习调度仍走 v1.0 用户自判。

## 三、② 实战任务（主题行，30 分钟小任务）

- **入口**：主题行操作区（AI 展开旁）加「实战任务」按钮 → 任务弹窗。
- **生成**（一次 LLM 调用，prompt `generateLearnTask`）：读该主题下知识点标题 + 已学卡正文，结合运维/安全/开发真实场景出任务——**背景场景 + 任务要求 + 验收标准**三段式；prompt 硬约束：单一主题内、30 分钟可完成、给出可自查的验收标准（不超纲、不要求搭大环境）。
- **流程与状态**：`todo（已生成未作答）→ submitted（已交作业待点评）→ reviewed（已点评）`。
  - 任务弹窗：任务描述 md 渲染态；「写作业」展开作业编辑区（textarea，独立于全局 md 弹窗双击惯例——作业是表单性输入非文档）；「提交点评」→ AI 批改（一次调用，prompt `reviewLearnTask`，输入 = 任务 md + 作业全文 + 相关卡正文）→ 生成点评 md + 评分（0-100 整数）→ 弹窗内直接展示。
  - **任务历史**：每主题保留全部任务，弹窗顶部下拉/列表切换查看；生成新任务时若存在非 reviewed 任务，ConfirmDialog 确认覆盖（旧任务保留不删，仅提示）；reviewed 任务随时可再生成新任务。
- **存储**：新表 `learn_tasks`（DB v34）+ 三份真实 md：任务 `md/learn/task/<id>-task.md`、作业 `<id>-homework.md`、点评 `<id>-review.md`（扁平 id 前缀惯例，与 `md/learn/<id>.md` 同构）。
- **删除**：任务**不入回收站**（工具性产物，对齐删书口径）——弹窗内删除彻底删（二次确认），级联清三份 md；**删除主题时级联彻底删其全部任务与 md**（确认文案注明）；不参与主题「清空才能删」判空口径。

## 四、③ 深挖模式（卡片弹窗，零新存储）

- **入口**：学习卡片弹窗 footer 操作条（studyBar）旁加「深挖」按钮，任意状态卡（未学/已学/毕业）可用。
- **行为**：一键组装深挖 prompt **自动发送**右栏「学习·问答」频道（走既有 `onOpenAi(prefill, { auto: true, channel })`，App 层 CHANNEL_BY_MODULE 已映射 learn）：
  - 深挖四角度模板：原理再进一层（卡文没讲到的机制细节）/ 常见误解与易错点 / 知识串联（同主题其他点 + 跨主题关联，带树上下文）/ 实际工作坑点。
  - **上下文注入**：预填文本 = 深挖指令 + 卡片全文引用块（卡文千字级，直接附 prompt，不依赖右栏读文件能力）。
- **零新存储**：会话历史沿用「学习·问答」频道现有持久化；深挖结果不回写卡片（高光笔记已有沉淀路径）。

## 五、数据模型增量（DB v34）

```sql
CREATE TABLE learn_quiz (
  date TEXT PRIMARY KEY,                     -- 本地日期 YYYY-MM-DD，一天一卷
  node_ids TEXT NOT NULL,                    -- 出题节点 id JSON 数组
  questions TEXT NOT NULL,                   -- 题目 JSON：[{nodeId,type:'choice'|'blank'|'short',question,options?,answerIndex?,acceptable?,answer,analysis}]
  answers TEXT NOT NULL DEFAULT '[]',        -- 作答 JSON：[{qIndex,answer,correct,aiComment?}]（实时写入）
  status TEXT NOT NULL DEFAULT 'answering',  -- answering|graded
  created_at TEXT NOT NULL,
  graded_at TEXT
);

CREATE TABLE learn_tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  topic_id INTEGER NOT NULL,                 -- learn_nodes(level=1) id
  domain_id INTEGER NOT NULL,
  status TEXT NOT NULL DEFAULT 'todo',       -- todo|submitted|reviewed
  score INTEGER,                             -- 点评分 0-100（reviewed 后有值）
  task_md TEXT NOT NULL,                     -- md/learn/task/<id>-task.md
  homework_md TEXT,                          -- <id>-homework.md
  review_md TEXT,                            -- <id>-review.md
  created_at TEXT NOT NULL,
  submitted_at TEXT
);
```

- 无迁移数据兼容问题（全新表）；DB 版本号实施定稿 **v35**（设计原写 v34 起算，v34 已被信息源收藏占用，按「撞车顺延」条款顺延）。
- `learn_quiz.questions` 中简答题 `answer`/`analysis` 出题时即生成（判卷参考），用户侧交卷前不展示。

## 六、IPC 与服务清单（electron/ipc.ts）

| 接口 | 说明 |
|---|---|
| `learn:quizGet` | 今日卷（无则 null；联节点标题） |
| `learn:quizCreate` | 出卷（jobId 可取消；读今日已学卡正文，一次调用写 learn_quiz） |
| `learn:quizAnswer` | `(qIndex, answer)` 单题作答：选择/填空本地判并落库，简答暂存 |
| `learn:quizSubmit` | 交卷：简答批量 LLM 批改 → 全卷 graded；返回成绩摘要 |
| `learn:quizRetry` | 重做：清空 answers 回 answering（同卷） |
| `learn:taskGenerate` | 出任务（jobId 可取消；写 learn_tasks + 任务 md） |
| `learn:taskList` | 按主题取任务列表（联状态/评分） |
| `learn:taskSubmit` | `(taskId, homeworkText)`：写作业 md → AI 批改 → 点评 md + score，状态 reviewed |
| `learn:taskDelete` | 彻底删任务 + 级联 md（不入回收站） |

AI 层（electron/ai/services.ts）新增 4 prompt：`generateLearnQuiz` / `gradeLearnQuiz` / `generateLearnTask` / `reviewLearnTask`；深挖为前端模板拼接，无新 prompt。

## 七、UI 增量与复用

- **今日学习 tab**：新增「今日小测」zone（实施落位调整：出卷/重做/换一张按钮放 **zone 头部**而非顶部条——组件自包含免跨组件同步）；三视图（未出卷空态 / 答题态 / 成绩态）；答错卡行内警示标记。graded 态双出口：「重做」= 清空作答重答同卷；「换一张」= force 重出卷（新卷生成成功才覆盖旧卷，失败保留）。
- **知识树 tab**：主题行操作区加「实战任务」按钮；任务弹窗（列表 + 详情 + 作业编辑 + 点评展示，独立新组件 `LearnTaskDialog.tsx`）。
- **MdDialog**：学习卡弹窗 footer 加「深挖」按钮（studyBar 槽位旁，仅学习库传入；其他模块调用方零影响——新增可选 prop `extraActions` 或 studyBar 扩展字段，实施时取侵入最小者）。
- 题面/任务/点评 md 渲染复用 MdView（推理角题面同款）；二次确认复用 ConfirmDialog；LLM 未配置走全局「不置灰 + 点击提示去配置」规则。

## 八、容错与边界

- LLM 未配置：小测/任务/深挖入口全部不置灰，点击走全局提示 +「去配置」；已存作答不受影响。
- 出卷/出任务/批改失败：行内可重试（同既有 handleAiError 口径——取消/未配置/弹窗三分支）。
- 今日队列一张都没学（learned=0）：小测按钮置灰；重做后未交卷再进模块：恢复 answering 态与已存作答。
- 任务弹窗操作中主题被删：IPC 层判 topic 存在性，失效提示后关弹窗。
- 跨天边界：昨日未交卷，今日旧卷保留可继续（按 date 行各自独立）；「今日已学」口径始终按当日 learn_daily 新学行算。

## 九、不做（YAGNI）

- 复习改主动回忆（开发者未选，复习机制保持 v1.0）。
- 小测历史回看（只保留当日卷，跨天旧卷不再展示入口）、错题本/错题重练。
- 实战任务积分统计、排行榜、连续打卡。
- 深挖结果回写卡片、深挖模板自定义。
- 填空题多空、题目手动编辑。
