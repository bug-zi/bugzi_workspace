# 书架模块优化说明

这个文档的内容是开发者在体验了初始化的书架模块后，根据真实体验写下的优化建议说明。

需要你根据这个文档内容帮我对书架模块进行优化升级。


- 当前显示书籍，宽度上，给导入的pdf书籍是合适的，但是给导入的epub格式书籍，当前显示书籍的方框的宽度偏小，导致需要左右拖拽阅读，请你适当增大方框的宽度，使其阅读时候不需要左右拖拽；
- 对于按键，我希望在阅读的时候，赋予wsad和上下左右一样的移动功能；
- 希望有两种模式：上下滚动模式和翻页模式，两种模式可以在书架中进行切换：上下滚动模式和翻页模式：翻页模式下，点击a以及对应的左键的时候是上一页，d以及右键是下一页；w和上键是上一节，s和下键是下一节。
- 获取书的目录结构，在侧边展开收起目录快速跳转；
- 侧边栏添加笔记本功能（具体如何设计还没想好，比如是和草稿本分还是合并，epub文件可以划词，pdf文件不可以，是不是可以给epub加一个划词出现浮窗，然后可以直接保存到笔记，或者是写批注，批注连同原文一起记到笔记中等等）。
- 划词高光改用主题适配颜色。
