# 藏书架

介绍：藏书架是我的本地电子书阅读模块——导入 .epub/.pdf 书籍，复制入库统一管理，内置阅读器打开即接续上次读到的位置（进度记忆）。纯本地零 AI，无 LLM/MCP 依赖，离线可用。本文档由 260908 brainstorming 会话与 AI 协作定稿（书签/高亮/笔记收窄为纯阅读，进 v2 备选；设计全记录见同目录 `2026-09-08-书架-design.md`）。

v1.0：

**模块结构（单板块双视图，主栏内切换）：**

- 藏书架视图（默认）：封面网格，每卡 = 封面 + 书名/作者 + 进度%；顶栏「导入书籍」按钮；排序按最近阅读在前（从未读过的按导入时间排后）。无封面的书显示书名占位卡。
- 阅读视图（点书进入，主栏整体切换）：顶部细工具条（返回 | 书名 | 进度%，pdf 加页码），正文区 epub/pdf 双引擎渲染。照写作台页面化先例——藏书架与阅读同在主栏切换，不遮挡左栏导航。
- 侧边栏位置（260908 重排后）：万象库下方、信息源上方（格言库 → 万象库 → **藏书架** → 信息源 → 文笔坊 → 致知己 → 灵感泉 → 推理角 → 记账本 → 白噪音 → 回收站 → 个人档）。
- 图标取 Google Material Symbols（禁 emoji），候选 auto_stories，以样式设计文档风格为准。

**导入：**

- 「导入书籍」→ 系统文件对话框（可多选 .epub/.pdf）→ 复制到用户数据目录 `books/`，藏书架只认入库副本——原文件之后移动/删除/改名都不影响阅读。
- 复制后解析元数据：epub 从包内取书名/作者/封面图（存 `covers/`）；pdf 书名取文件名（去扩展名），封面用占位卡。
- 按「文件名 + 文件大小」查重，疑似重复弹确认；解析失败的副本自动回滚清理并提示，不留坏数据。

**阅读与进度记忆（核心需求）：**

- epub 用 epub.js 渲染（维护中 fork @flow/epubjs），连续滚动；pdf 用 pdfjs-dist 连续滚动。
- 进度记忆：epub 存 CFI 定位（精确到位置）+ 百分比，恢复时直达；pdf 存页码，恢复时跳到该页。
- 进度写入节流 3 秒 + 退出阅读时落库——App 中途强杀也不丢大体进度。
- 字体与双主题跟随 App 全局设置：epub 注入主题配色（浅色樱花粉黑字 / 深色宝蓝白字）；pdf 纸面白底，容器背景跟主题。

**删除（不入回收站）：**

- 书卡菜单删除 → 二次确认 → 直接彻底删除（删记录 + `books/`、`covers/` 物理文件）。书是可重新导入的外部文件副本，不值得回收站再存 3 天大文件；回收站保持现有八块。

**存储：**

- SQLite 一张 books 表（元数据 + 进度字段）；文件双目录 `books/`、`covers/`；封面经 bzres:// 协议加载（root 命名空间本就映射 userData 子目录，零协议改动）；书籍二进制经 IPC 读出喂渲染引擎。

v2.0 备选：

1. 手动书签（位置标记，可跳转）。
2. 划词高亮 + 高亮笔记（可导出 md，接全局 md 弹窗体系）。
3. 阅读器内字号独立调节。
4. 目录抽屉与章节跳转（epub TOC）。
5. 阅读统计（时长 / 在读总览）。
