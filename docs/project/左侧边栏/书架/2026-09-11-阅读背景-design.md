# 藏书架·阅读背景 设计记录

> 创建于 2026-09-11 00:59
> 来源：`docs/project/新功能开发区.md` 待完成区（开发者 260911 提出）。
> 定位：藏书架子功能（非新模块），直接开发；本文件为实施设计记录，落地后归档。
> 已确认决策：全局一份（所有书共用，不动 books 表）；自定义图单张槽位；图上正文色按图片明暗自动适配。

## 一、需求原文拆解

1. 阅读书时给阅读视图补充背景：**纯色预设** 或 **用户自上传图片**。
2. 全局一份：settings 存储，任何书打开都应用（epub/pdf 双格式）。
3. 自定义图单张：上传新图即替换旧图；可清除回落默认。
4. 图片模式下 epub 正文字色自动按图片明暗适配（深图→浅字、浅图→深字），保证可读。

## 二、数据与设置（零 DB 迁移）

settings 新增两键（`src/shared/types.ts` SettingsKeys）：

| key | 值 | 说明 |
|---|---|---|
| `books_reading_bg` | JSON 字符串 | `{ kind: 'theme' \| 'color' \| 'image', color?: string, textColor?: 'light' \| 'dark' }` |
| `reader_bg_image` | 文件名 | 自定义图 `reader-bg.<ext>`（存 `userData/bg/`，`bzres://bg/` 加载） |

- `kind='theme'`：默认（现状行为，背景跟 `--color-surface-strong` 走，主题切换即变）。
- `kind='color'`：`color` 存预设色值；`textColor` 存该预设配对字色（'dark'=深色字 / 'light'=浅色字）。
- `kind='image'`：`textColor` 为上传时亮度采样的结果；图片文件名在 `reader_bg_image`。
- 坏 JSON 容错回落 `{ kind:'theme' }`（渲染层 try/catch）。

## 三、预设色板（渲染层常量）

低饱和纸感色 6 个 + 跟随主题默认项；正文字色统一两值（不逐色另配）：
深色字 `#2b2b2b`（柔和近黑）、浅色字 `#d8d8d3`（柔和米白）。

| id | label | 色值 | 配对字色 |
|---|---|---|---|
| paper | 纸黄 | `#f5ecd7` | 深字 |
| cream | 米白 | `#f7f3ea` | 深字 |
| green | 护眼绿 | `#cde6c8` | 深字 |
| celadon | 青瓷 | `#d3e3e0` | 深字 |
| warm | 暖灰 | `#e8e2da` | 深字 |
| night | 夜读黑 | `#1e2226` | 浅字 |

色值实施时可微调（保持低饱和、与双主题不冲突）。

## 四、IPC：`image:pick` 扩展（electron/ipc.ts）

- kind 联合类型加 `'reader-bg'`（`'avatar' | 'bg-light' | 'bg-dark' | 'reader-bg'`；`api.d.ts` 同步）。
- 行为完全镜像 bg-light/bg-dark 分支：复制所选图片到 `userData/bg/reader-bg.<ext>`，settings `reader_bg_image` 记文件名，清其他扩展名旧文件。
- 「清除自定义图片」只清 settings 引用（`books_reading_bg` 回 `{kind:'theme'}`、`reader_bg_image` 清空），**不删文件**——文件由下次上传同名覆盖清理（零新增 IPC；单槽位语义下无泄漏堆积，同扩展名直接覆盖、不同扩展名在下次上传时清）。

## 五、UI（BookshelfModule 阅读视图）

- 阅读条（`bk-reader-bar`）新增「背景」按钮：`palette` 图标，epub/pdf 都显示（title「阅读背景」）；位置在书签按钮之前——epub 时即字体按钮组之后，pdf 时即进度文案之后。
- 点击弹 **ActionMenu**（复用字体菜单组件与交互）：
  - 「跟随主题」（kind=theme 选中态 check）
  - 6 色块项：未选中 `circle` 图标 + 透传 `style.color` 染色值；选中 `check_circle` 同样染色（色点语义保留）
  - 分隔线后「上传自定义图片…」（`upload` 图标）
  - 已有图时：「自定义图片」项（kind=image 选中态，点击重新启用不重传）＋「清除自定义图片」（`delete` 图标，回落主题）
- 选择即生效即落库（`settings.set`），无需确认弹窗（非删除类操作）。

## 六、上传后亮度采样（渲染层）

上传流程：`image:pick('reader-bg')` → `settings.get('reader_bg_image')` 拿文件名 → `fetch('bzres://bg/<file>')`（协议已开 supportFetchAPI）→ blob → `createImageBitmap` → 绘制到 32×32 离屏 canvas → `getImageData` 求平均亮度（`0.2125R+0.7154G+0.0721B` / 255）：

- 亮度 < 0.5 → 深图 → `textColor='light'`（浅字）；否则 `textColor='dark'`（深字）。
- 结果连同 `{kind:'image'}` 写入 `books_reading_bg`；采样失败（图解码异常等）静默回落 `textColor='dark'` 不阻断。

## 七、应用链路

**状态持有**（BookshelfModule）：模块挂载时 `settings.get(books_reading_bg)` 读一次存 state（全局一份，切书不重读）；菜单选择后 set state + set settings。

**容器底色/底图**（`bk-reader-body`，epub/pdf 共用）：

- kind=color：`style={{ background: color }}`
- kind=image：`style={{ backgroundImage: url(bzres://bg/<file>), backgroundSize: 'cover', backgroundPosition: 'center', backgroundRepeat: 'no-repeat' }}`
- kind=theme：不加 style（CSS 默认 `var(--color-surface-strong)` 现状）
- 边框圆角保留；pdf 页面白底 canvas 与阴影不变（「纸放桌上」效果，页外区域即背景）。

**epub 正文**（EpubReader `applyTheme` 扩展，新增 `bg` 入参由模块层透传）：

- kind=theme：现状（`--color-text` / `--color-surface-strong`）。
- kind=color：iframe body `background=color`、`color=#2b2b2b|#d8d8d3`（按 textColor）。
- kind=image：iframe body `background='transparent'`（宿主 `bk-reader-body` 底图透出）、`color` 同上。
- 新增 effect 依赖 `bg`：背景变化即时重注入（不重载书、不丢进度），机制同字号/字体变化。
- `::selection` 划词高光色保持主题色不变（深色底上 multiply 混合仍可见）。

## 八、验证点

- epub 滚动/翻页两模式下 iframe transparent 背景均能透出宿主底图。
- 夜读黑/深色图 + 浅色字时：划词高光、批注下划线可见。
- pdf 翻页模式（单页居中）与滚动模式下页外背景一致。
- 主题切换：kind=theme 实时跟随；kind=color/image 不随主题变（重注入时字色维持所选）。

## 九、不做（YAGNI）

- 不做书级背景覆盖（全局一份）。
- 不做多张图库管理（单槽位覆盖式）。
- 不做自定义取色器（就 6 预设 + 默认）。
- 不做背景透明度/蒙层调节、不做背景亮度手动覆盖（自动采样结果即终态）。
