## 一、数据模型（DB v28；**实施实况 v29**——设计后被并行会话收藏夹占用 v28 顺延，v18/v19 先例同款）

当前库版本 v27（260910 LLM 记账），本迁移占 **v28**：

```sql
ALTER TABLE books ADD COLUMN reading_mode TEXT;   -- 'scroll'|'page'；NULL=跟随全局默认
ALTER TABLE books ADD COLUMN font_scale REAL;     -- 字号倍率 0.75~1.5；NULL=跟随个人档全局字体

CREATE TABLE book_marks (          -- 手动书签（epub/pdf 都支持）
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id INTEGER NOT NULL,
  cfi TEXT,                        -- epub 定位（epub 行非空）
  page INTEGER,                    -- pdf 页码（1 基；pdf 行非空）
  label TEXT NOT NULL DEFAULT '',  -- 显示名：章节名，兜底「第 N 页 / 约 X%」
  created_at TEXT NOT NULL
);

CREATE TABLE book_read_log (       -- 阅读统计（按书按日累秒）
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id INTEGER NOT NULL,
  day TEXT NOT NULL,               -- 本地时区 YYYY-MM-DD
  seconds INTEGER NOT NULL DEFAULT 0,
  UNIQUE(book_id, day)
);
```

- `deleteBook` 级联清理追加 `book_marks`、`book_read_log` 两表（book_notes 先例）；书级偏好两列随 books 行自然删除。
- 笔记总览**不落任何新文件**——md 内容按需生成直传弹窗（§三），单一数据源在 DB。
- 类型同步：`BooksRecord` 加 `reading_mode`/`font_scale` 两字段；新增 `BookMark`、`ReadStats` 类型（shared/types.ts + api.d.ts 两处惯例）。

## 二、手动书签

- **加**：阅读条新按钮（icon `bookmark_add`，epub/pdf 都显示）→ 取当前位置 + 当前章节名做 label → 入库 → toast「已加书签」。
  - 位置：epub 用 relocated 维护的当前 CFI；pdf 用当前页码。
  - label：epub 按 `locate.href` 匹配目录 label，取不到用「约 X%」；pdf 用当前页落在的 outline 锚点（`tocAnchorAt` 已有），取不到用「第 N 页」。
  - **同位置去重**：epub 同 CFI / pdf 同页 → toast「已有书签」不入库（同笔记查重先例，渲染层查）。
- **管理**：侧栏双页签变三页签（**目录 | 笔记 | 书签**），书签按时间倒序：label + 相对时间 + 删除按钮；点击跳回（epub `display(cfi)`、pdf 跳页）。
- **删除**：全局 ConfirmDialog 二次确认后彻底删除（不入回收站，同笔记）。

## 三、笔记总览 md 与导出

### MdDialog 渐进扩展（`src/components/MdDialog.tsx`，三可选 prop，不动既有调用方）

- `content?: string`——直接给内容；提供则**不读文件**（`filePath` 转可选）。笔记总览的 md 从 `book_notes` 按需拼，不落盘。
- `readOnly?: boolean`——隐藏「双击正文编辑」提示、双击不进编辑态（数据源在 DB，编辑无意义）；Esc / 遮罩关闭照常。
- `headerAction?: { label: string; icon?: string; onClick: () => void }`——头部「关闭」旁渲染动作按钮（本次用于「导出」）。

### 入口与格式

- 侧栏「笔记」页签头部加「总览」小按钮（icon `article`）→ `books:notesOverviewMd(bookId)` 取生成内容 → MdDialog 打开：title `《书名》读书笔记`，subtitle `作者 · N 条 · 生成于 YYYY-MM-DD HH:mm`，readOnly、无划词 AI（selectionActions 不传）。**epub 专属**（pdf 笔记页签本就占位）；笔记为空时按钮禁用。
- 文档结构（created_at **正序**＝阅读顺序）：

```md
> 摘录原文……（blockquote）

批注内容（无批注的纯高光只留摘录）

<sub>2026-09-08 14:30</sub>
```

- 打开时刻即快照，开着期间新增笔记不实时刷新（重开即新）。

### 导出

- 总览弹窗 headerAction「导出」（icon `download`）→ IPC `books:exportNotes(bookId)`：主进程重新生成（确定性一致）→ `dialog.showSaveDialog` 默认文件名 `《书名》读书笔记.md`（书名清洗文件系统非法字符）→ 写盘 → 返回保存路径；取消返回 null 静默。成功 toast「已导出到 <目录>」。

## 四、每书独立偏好（模式记忆 + 字号调节）

**统一写入通道**：`books:setReadingPref(bookId, { mode?, fontScale? })`——一条 IPC 两用，只传要改的字段，`fontScale: null` 清除书级值（回落全局）。

### 模式记忆

- 读取：打开书 `mode = book.reading_mode ?? settings.BooksReadingMode ?? 'scroll'`。存量书列值 NULL 天然回落现有全局键，**零数据迁移**。
- 写入：切模式**双写**——书级列记本书选择 + 全局 settings 键刷成「最近使用的模式」。切过的书固定自己的模式，没切过的跟随最近习惯；新书默认 = 最近使用。
- 阅读条按钮 UI 不变；epub 切换全量重挂流程照旧（重挂前取最新行，行内含新列值）。

### 字号（仅 epub，每书记忆）

- 阅读条按钮组 `[A-] [100%] [A+]`，仅 epub 显示。档位 **0.75–1.5、步进 0.05**（中间显示整数百分比，NULL 跟随态显示 100%），边界静默钳制。
- **「默认」小按钮**：仅档位 ≠ 跟随（列值非 NULL）时出现，点击清除书级值 → 回落个人档全局字体大小。
- 生效：EpubReader `applyTheme` 的 `body font-size = 全局 body 计算值 × scale`（NULL 不乘）；scale 变化即时重注入主题、epub.js 自动重排，**不重挂不丢进度**（实施时验证重排无排版 wart，若有按模式切换同款全量重挂兜底）。
- 模块层持 `fontScale` 于 `reading` 行，A± 即时写库 + setState，EpubReader 收新 prop 重注入。

## 五、阅读统计

### 计时（渲染层，引擎无关）

- 计时逻辑挂 BookshelfModule 阅读视图层（readers 之上的统一层）：每秒 tick 检查**三条件**——`document.visibilityState === 'visible'`（未最小化/隐藏）、窗口聚焦（blur 暂停）、组件可见（宿主 rect 宽高 > 0，防 keep-alive 切走模块仍挂载却 display:none 时虚计）。三条件同时满足才累秒。
- 每 30 秒 flush `books:addReadTime(bookId, seconds)`（主进程 UPSERT `book_read_log` 按书按日递增）；退出阅读视图（返回书架）时 flush 余量；强杀最多丢 30 秒（与进度节流 3 秒同哲学）。
- 弹窗盖在阅读上（总览开着）照常计——可见 + 聚焦即阅读。

### 统计条 + 展开面板（书架视图）

- header 下常驻一行小字（icon `schedule`）：**今日 X 分钟 · 连续 N 天 · 在读 M 本**；三项全零整行隐藏。点击展开/收起主栏内轻量面板（非弹窗）。
- 面板：每书一行「书名 · 累计时长 · 进度% · 最近阅读」，按最近阅读在前，底部一行合计。
- 口径：
  - **今日** = 当日（本地时区）`book_read_log` 秒和，分钟向下取整（>0 不足 1 分显「<1 分钟」）；
  - **连续天数** = 以今天（今天尚无记录则从昨天）为终点往前数连续有记录（当日 sum > 0）的天数——白天没读数字不掉档；
  - **在读** = 读过且未读完（`last_read_at` 非空 且 `progress_percent < 100`）。

## 六、IPC 汇总（books.ts + ipc.ts + preload.ts + api.d.ts 同步）

| 通道 | 签名 | 行为 |
|---|---|---|
| `books:marksList` | `(bookId) => Promise<BookMark[]>` | 该书全部书签（created_at 倒序） |
| `books:markAdd` | `(bookId, m: { cfi?, page?, label }) => Promise<BookMark>` | 新增书签 |
| `books:markRemove` | `(markId) => Promise<boolean>` | 彻底删除（渲染层二次确认） |
| `books:setReadingPref` | `(bookId, p: { mode?, fontScale? }) => Promise<boolean>` | 部分更新书级偏好；fontScale null 清除 |
| `books:addReadTime` | `(bookId, seconds) => Promise<void>` | UPSERT 按书按日递增 |
| `books:readStats` | `() => Promise<ReadStats>` | 聚合：todaySeconds / streakDays / readingCount / 每书行 |
| `books:notesOverviewMd` | `(bookId) => Promise<string>` | 主进程按需生成总览 md |
| `books:exportNotes` | `(bookId) => Promise<string \| null>` | 生成 + showSaveDialog + 写盘；取消返回 null |
