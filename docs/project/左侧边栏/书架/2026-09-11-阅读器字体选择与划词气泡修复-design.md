# 阅读器字体选择与划词气泡修复 — 设计文档

> 创建于 2026-09-11 00:02

> 状态：已与开发者逐项对齐（书级记忆 / 系统+打包全套清单 / 字体浮层自渲染预览），待审核

## 〇、需求与根因

三项子需求（均为 epub 阅读器；pdf 固定排版字体嵌在文件内，不适用）：

1. **丰富字体选择**：现状阅读器无字体族选择，正文跟随个人档全局字体注入（`applyTheme` 取外层 body computed `font-family`）；全局 7 款全为手写/楷系，无宋体等正文常用字体。书级仅字号倍率（`font_scale`，v29）。
2. **气泡残留 bug**：划词气泡（高光/批注）与标注点击气泡，在正文里点击取消划词时**不消失**。
   - **根因**（epub.js 源码证实）：epub 正文渲染在 iframe 内，**iframe 内的 DOM 事件不冒泡到父文档**。现有收气泡仅两条路：①host（父文档容器）上的 `mousedown`（`EpubReader.tsx` 末段 effect）——只覆盖正文外围空白；②气泡按钮动作后主动 `closeBubble()`。用户在正文内点击取消划词时 host `mousedown` 根本不触发 → 气泡残留。
   - epub.js `rendition.passEvents`（rendition.js:876）会把 iframe 内 `DOM_EVENTS`（含 `mousedown`/`click` 等，constants.js）转发为 rendition 事件 → `rendition.on('mousedown')` 可收。另注意 epub.js `triggerSelectedEvent`（contents.js）只在选区非 collapsed 时发 `selected`，**没有「取消选区」事件**，故不能用 selected 之类事件收气泡。
3. **横向排列**：`.bk-sel-bubble` 为 `flex-direction: column`（bookshelf.css:421），高光/批注两按钮直接 append 为其子节点 → 竖排。

**顺带修的隐藏问题**：全局字体选打包手写体时，书内正文实际早已回落楷体——@font-face 定义在父文档（`src/theme/global.css`），iframe（blob/srcdoc）有独立 document，按 family 名解析不到打包字体，走了回落链里的 `'KaiTi'`。本轮字体功能落地时一并修复（见 §1.4）。

### 1.2 数据链路（与字号倍率完全同构）

- **DB v32**：`books` 表 `ALTER TABLE ADD COLUMN font_family TEXT`（NULL=跟随全局，存量书零迁移）。
  （修订 260911：设计初稿写 v31，撰写计划时发现 v31 已被并行会话万象库待学习区迁移占用，实际落 v32——版本号实况条款同 v18/v19、v29 先例。）

- IPC（`electron/ipc.ts` books 通道）/ preload / `src/renderer/api.d.ts` / `src/shared/types.ts` `BooksRecord` 增 `font_family: string | null`，四处同步透传（照第 34 轮 markUpdate 四处惯例）。
- `BookshelfModule` 新增 `setFont(value)`：null 或 CSS 串经 `setReadingPref({fontFamily})` 落库并 `setReading` 本地回填（照 `stepFont` 样式）。

### 1.3 EpubReader 注入

- `Props` 增 `fontFamily: string | null`。
- `applyTheme(rendition, fontScale, fontFamily)`：`font-family` 一项改为 `fontFamily ?? body.fontFamily`（非空书级优先，空回落全局=现状行为）。
- `[fontFamily]` effect：与现有 `[fontScale]` effect 同构——重注入 themes 即时生效、不重挂不丢进度（epub.js 自动重排，v2.0 §四机制复用）。
- `createRendition` 调用处与 `[theme]` effect 同步传新参。

### 1.4 打包字体进 iframe（@font-face 注入）

- `READER_FONTS` 打包项持字体文件 URL：`import lxgwUrl from '../../renderer/assets/fonts/lxgw-wenkai.ttf?url'`（`src/assets.d.ts` 已声明 `*?url` 模块，零新增声明）。
- **URL 绝对化**：Vite `?url` 产物在 dev 为根相对（`/src/...`）、build 为相对（`./assets/...`），而 iframe 是 blob 文档、无基准路径可解析——注入时以 `new URL(url, window.location.href).href` 转成带 origin 的绝对 URL。
- `EpubReader` 内 `injectFontFaces(doc: Document)`：拼 5 条 `@font-face`（family 名 + 绝对 URL + `font-display: swap`）为 `<style id="bz-reader-fonts">` 注入 `doc.head`；幂等（已存在同 id 跳过）。
- 挂载时机：`rendition.on('rendered', (_section, contents) => injectFontFaces(contents.document))`——每次章节视图重建（iframe 重建）自动重注入；`rendered` 是 epub.js 公开事件（每个 section view 就绪时触发）。
- 与 `applyTheme` 的 `themes.default` 并存无冲突（epub.js 自己也向 iframe 注入主题样式，二者独立 `<style>`）。
- 系统字体无需注入（系统级注册，iframe 内按名可用）。

## 二、气泡残留修复

- **主修复**：`createRendition` 内 `rendition.on('mousedown', () => closeBubble())`——iframe 正文内任意按下即收气泡（划词气泡与标注点击气泡同治）。
  - 点已渲染标注场景顺序安全：`mousedown`（收旧）先于标注元素的 `click`（开标注气泡）触发；`openBubble` 自身也先 remove 旧气泡，双保险。
  - 批注编辑器（textarea）打开时点正文同样收——与「点外围空白即收」一致的标准弹层行为，未保存内容丢弃属预期。
- 保留现有 host `mousedown` effect（管正文外围空白区域）。
- **顺带两条**（同一病灶「气泡与正文脱钩」，各一行）：
  - scrolled 模式：滚动容器（`scrollerOf(host)`）`scroll` → `closeBubble()`——气泡 absolute 定位在 host 不随内容滚，滚动后脱锚悬空，滚动即收。
  - `relocated`（翻页/跳章/笔记跳转）→ `closeBubble()`——坐标失效即收。

## 三、高光/批注横排

- `selected` 处理器中两按钮（`高光`/`批注`）不再直接 append 为气泡子节点，包进一行 `div.bk-sel-row bk-sel-row-center`（`bookshelf.css` 增 `.bk-sel-row-center { justify-content: center; }`，复用现有 `.bk-sel-row` 横排）。
- 气泡其余形态不动（批注编辑器 textarea+保存/取消行、标注点击气泡 内容+编辑/删除行）。

## 五、不做 / 边界

- pdf 阅读器不加字体选择（固定排版）。
- 字号（A-/A+）机制不动；行高、正文颜色等主题注入不动。
- 生产构建 CSP 疑拦 epub iframe（第 34 轮遗留，见 dev log 260910）未修——dev 冒烟无碍，字体注入 URL（`?url` 资产）与 CSP 的兼容性在生产修复后一并复验。
- 气泡随滚动「跟随选区移动」（更复杂的定位策略）不做，滚动即收已解脱锚问题。
- 不新增字体文件打包（沿用现有 5 款文件，`?url` 引用按需加载）。
