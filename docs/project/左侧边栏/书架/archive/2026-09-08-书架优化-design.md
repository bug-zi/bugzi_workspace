## 背景

v1 书架落地后开发者实际体验，提出 6 条优化：① epub 阅读框偏窄要左右拖拽；② 阅读键盘操作只有鼠标（WASD 与方向键同权）；③ 缺翻页模式（滚动/翻页双模式可切换）；④ 缺目录快速跳转；⑤ 想要笔记本（设计未定，本会话定稿）；⑥ 划词高光颜色不跟主题。

## 关键决策记录（会话中逐项确认）

| # | 决策点 | 结论 | 被否掉的选项 |
|---|---|---|---|
| 1 | 笔记本归属 | **阅读器内独立笔记**：epub 划词浮窗（高光/批注）→ CFI 定位存库 → 书内渲染高亮 + 侧栏笔记页签管理，与草稿本完全分开 | 合并草稿本加「读书」频道（丢 CFI 定位/跳回/书内渲染，还得多建一张表，草稿本只剩查看入口）；每书一份 md 笔记文档（md→书内单向，无法同步回高亮渲染与跳转） |
| 2 | 滚动模式左右键 | 上下滚屏（约 85% 视口）、**左右换章**（与浮动按钮同效） | 左右键不生效；左右也滚动（无横向滚动场景，等于无效） |
| 3 | 阅读模式记忆 | **全局记忆**：settings 新键，所有书共用 | 每本书各自记忆（多一次迁移与状态同步，收益低）；不记忆 |
| 4 | epub 宽度根因 | 加宽容器（980→1200px，仅 epub）**+** 内容护栏 CSS（宽图/宽表/代码块撑破 iframe 才是横向拖拽元凶） | 只加宽（书内固定宽元素照样溢出）；只注入护栏（开发者明确要求加宽阅读框） |

## 一、宽度与防横向拖拽（优化点 1）

- `.bk-reader-page`（epub 阅读时）宽度上限从主栏通用 `max-width: 980px` 提升到 **1200px** 居中；**pdf 保持 980px 不动**（开发者确认现状合适）。
- epub 主题注入追加护栏样式（iframe 内生效）：
  - `img, svg, video, table { max-width: 100%; height: auto }`——宽媒体元素收缩到版心内；
  - `pre` 等代码块 `overflow-x: auto`——横向溢出在块内消化，不撑破页面。
- 正文区左右留内边距（约 40px），文字不贴边。
- 验收：任意 epub 打开后正文区**永不出现横向滚动**（iframe 内与容器层都不出现）。

## 二、键盘导航（优化点 2、3 按键部分）

阅读视图统一挂 window keydown 监听（epub/pdf 共用一套映射）：

| 按键 | 滚动模式 | 翻页模式 |
|---|---|---|
| W / ↑ | 上一屏（约 85% 视口平滑滚动） | 上一节 |
| S / ↓ | 下一屏 | 下一节 |
| A / ← | 上一章 | 上一页 |
| D / → | 下一章 | 下一页 |

- **输入保护**：焦点在 input/textarea/contentEditable（批注输入、重命名等）时不触发导航。
- 大小写不敏感（w 与 W 同效）；`preventDefault` 防与原生滚动叠加。
- 翻页模式下 W/S 的「节」：epub = spine 章节（现有 goChapter 逻辑复用）；pdf = 目录章节项（无目录则不响应）。
- 浮动章节按钮保留不动（鼠标场景兜底）。

## 三、双阅读模式（优化点 3）

- **切换入口**：阅读条右侧模式按钮（显示当前模式「滚动」/「翻页」，点击切换）。
- **持久化**：settings 新键 `bookshelf.readingMode`（值 `scroll` | `page`），全局共用，启动恢复（SettingsKeys 新增常量）。
- **epub 实现**：`rendition.flow('scrolled' | 'paginated')` 运行时切换（已核实 epub.js 0.3.93 支持，无需重建实例/重载书）+ `spread('none')` 单栏 + 切换后 `display(当前 CFI)` 保持阅读位置。
- **pdf 实现**：
  - 滚动模式 = 现状连续滚动（占位 + IntersectionObserver 懒渲染）；
  - 翻页模式 = 单页居中视图：当前页 canvas 按容器宽渲染，A/D 前后翻页，相邻页预渲染消除闪白；进度照常按页码节流落库、恢复直达。
- 模式切换不丢进度（两种模式都从当前 CFI/页码继续）。

## 四、目录侧栏（优化点 4）

- **入口**：阅读条「目录」按钮（icon `toc`）→ 正文区左侧滑出侧栏（约 240px，与正文同高，主题色边框分隔）；再点按钮或侧栏收起钮收起。展开状态仅会话内保持（重进默认收起）。
- **侧栏双页签：目录 | 笔记**（笔记见第五节）。
- **epub 目录**：`book.loaded.navigation` → `toc` 树，`subitems` 递归缩进呈现（不折叠子树，最多两级缩进）；点击 `rendition.display(href)` 直达；`relocated` 时按当前 spine href 给目录项加 active 高亮。
- **pdf 目录**：`pdf.getOutline()` 递归树；书签 `dest` 经 `pdf.getPageIndex()` 换算页码；点击 → 滚动模式滚到该页 / 翻页模式翻到该页。
- 无目录的书（两类引擎都取不到）显示「本书无目录」占位。
- pdf 翻页模式下 W/S 上一节/下一节 = 在 outline 顶层序列中前后跳。

## 五、笔记本（优化点 5，方案 A）

### 数据

- DB **v24** 新表 `book_notes`：

```sql
CREATE TABLE book_notes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id INTEGER NOT NULL,
  cfi_range TEXT NOT NULL,      -- epub.js CFI 区间定位
  quote TEXT NOT NULL,          -- 划选原文（截断约 500 字）
  note TEXT NOT NULL DEFAULT '',-- 批注内容；空 = 纯高光
  created_at TEXT NOT NULL
);
```

- 删书（books:delete）级联清笔记；笔记删除为**彻底删除不入回收站**，走全局 ConfirmDialog 二次确认。

### IPC（`books:` 前缀，主进程 BookService 扩展）

| 通道 | 签名 | 行为 |
|---|---|---|
| `books:notesList` | `(bookId) => Promise<BookNote[]>` | 该书全部笔记（created_at 倒序） |
| `books:noteAdd` | `(bookId, n: { cfiRange, quote, note? }) => Promise<BookNote>` | 新增（note 缺省 ''） |
| `books:noteUpdate` | `(noteId, note) => Promise<void>` | 编辑批注内容 |
| `books:noteRemove` | `(noteId) => Promise<void>` | 彻底删除 |

### 交互（仅 epub；pdf canvas 无文本层）

- **划词浮窗**：`rendition.on('selected', (cfiRange, contents))` → 选区矩形（含 iframe 偏移换算到主文档坐标）→ 浮窗两按钮（样式复用万象库 sel-bubble 模式）：
  - **高光**：`noteAdd(note='')` → 书内渲染主题色底纹；
  - **批注**：浮窗就地展开 textarea → 保存 → 原文+批注入库，书内渲染「底纹 + 下划线」区分纯高光；
- **幂等**：同 cfiRange 已存在笔记时不再新增，toast「已有高光」。
- **书内点高亮**：`annotations.highlight` 的 click 回调 → 气泡显示批注内容（若有）+ 编辑 / 删除按钮（删除走二次确认）。
- **进书渲染**：打开书后把该书全部 notes 一次性 `annotations.highlight(cfiRange, {id}, cb, 'bz-hl', { fill: 主题色 })`；主题切换重涂。
- **笔记页签**：该书笔记时间倒序列表（原文摘录两行截断 + 批注内容 + 删除）；点击 → `rendition.display(cfiRange)` 跳回划词位置。
- **pdf**：笔记页签显示占位「PDF 暂不支持划词笔记」；目录页签照常。

## 六、划词/高光主题色（优化点 6）

- epub iframe 注入 `::selection { background: <主题色> }`——取现有 `--color-selection` 变量具体值（浅色樱花粉半透明 / 深色宝蓝半透明），与全局划词色同源（万象库 MdDialog 等已用同一变量），主题切换时随主题重注入。
- 高亮底纹与批注下划线同色系（`--color-selection` / `--color-primary-soft` 系），保持「组件框、按键、弹窗禁止彩亮颜色、用主题相近色系」的全局样式约束。
- pdf 无划词场景，不涉及。

## 影响面与验收

- **改动范围**：`src/modules/bookshelf/`（阅读器三件 + css）、`electron/db/db.ts`（v24）、`electron/services/books.ts`、ipc.ts / preload.ts / api.d.ts / shared/types.ts（通道与类型）、SettingsKeys 增一键；书架视图（封面网格/导入/删除）零改动。
