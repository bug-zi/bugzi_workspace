# 信息源

介绍：信息源是我的 RSS 订阅聚合模块，精简版 Folo——收集我关注博主的更新文章，AI 读文章生成中文总结放在开头，然后我读原文。初始预置三个源（tw93 weekly、aiznb weekly、ursb.me blog），可随时添加订阅。本文档由 260908 brainstorming 会话与 AI 协作定稿（设计全记录见同目录 `2026-09-08-信息源-design.md`；开发者原始想法见 `docs/project/idea/信息源(后面再做)/design.md`）。

v1.0：

**模块结构（主栏内三段式）：**

- 左窄栏·源列表：「全部文章」聚合项（总未读数）+ 各源行（源名 + 未读数徽标 + 拉取失败红点）+ 底部「添加订阅」按钮。
- 中栏·文章列表：标题 + 源名 + 时间 + 摘要前几字，未读加粗，按发布时间倒序；顶栏「刷新」「全部标已读」。
- 阅读视图（点文章进入，主栏切换）：AI 总结卡置顶（主题色边框卡片）→ 标题/源名/时间/「去原文」→ 正文。照写作台页面化先例主栏内切换。
- 侧边栏位置（260908 重排后）：藏书架下方、文笔坊上方（格言库 → 万象库 → 藏书架 → **信息源** → 文笔坊 → 致知己 → 灵感泉 → 推理角 → 记账本 → 白噪音 → 回收站 → 个人档）。
- 图标取 Google Material Symbols（禁 emoji），候选 rss_feed，以样式设计文档风格为准。

**订阅管理：**

- 添加订阅：弹窗输入 URL → 后台拉一次验证并取源名 → 确认入库；无效 URL 报错提示。
- 删除源：二次确认，连源带文章彻底删除（不入回收站，回收站保持八块）。

**拉取：**

- 进模块自动拉全部源 + 顶栏手动刷新；每源超时 15 秒；单源失败标红可查，不影响其他源。
- 文章按 guid 去重；首次进入模块自动预置三个源：`https://weekly.tw93.fun/rss.xml`、`https://aiznb.com/weekly/atom.xml`、`https://ursb.me/blog/feed.xml`。
- 文章不自动清理（个人量级，一年几百篇）。

**正文两级策略（一套数据两用）：**

- RSS 自带全文够长直接用；不足时主进程抓网页正文（readability 系解析）。
- 抓到的正文同时喂 AI 总结与阅读视图渲染——总结的是全文不是摘要，读的也是全文。
- 双失败兜底：显示 RSS 摘要 + 「去原文」外链跳系统浏览器。

**AI 总结（打开时按需生成 + 缓存）：**

- 打开文章时若无缓存总结 → 自动取全文送 LLM 生成中文总结（约 150-300 字）→ 存库，下次秒开。
- 总结期间卡片显示加载态；失败显示原因 + 重试按钮。
- LLM 未配置：按全局规则不置灰，点开文章弹「去配置」直达个人档。
- 总结只喂文章标题与正文，不注入我的画像；不新增 AI 边栏频道（五频道保持不变）。

**已读管理：**

- 基础已读/未读：点开即标已读，列表未读加粗，支持一键全部标已读；不做收藏/稍后读。

**存储与安全：**

- SQLite 两张表（feeds / articles，正文与总结入库存缓存）；正文 HTML 渲染前过 dompurify 消毒；远程文章图片放宽 CSP img-src 允许 https:，其余安全策略不动。

v2.0 备选：

1. 定时自动拉取（接定时器服务，App 未运行错过即跳过，同格言库规则）。
2. 收藏/稍后读标记与筛选。
3. OPML 导入导出。
4. 文章列表虚拟滚动（源多文章量大时）。
