# AI 会话保存与归档（优化建议区第 47 轮）设计

> 创建于 2026-09-17（会话内定稿）。同轮附带的终端悬浮小改（§1）按惯例不单独出文档，实施说明入第 47 轮归档条目与 dev log。

## 背景与目标

优化建议区第 47 轮两条：

1. **终端显示窗口铺满底部**——终端面板横向长度不够（现宽 = 窗口宽 − 左栏 76px，左缘被左栏截住），要求铺满整窗、左右各留 5-10px、居中呈现。
2. **AI 会话记录保存升级**——AI 每轮输出后给三个处置选项：继续对话 / 保存对话 / 归档对话。有用的对话封装成 md 卡片落到对应模块；看过即可弃的归档进回收站；其余继续聊。首期覆盖学习库、万象库、致知己三模块对应频道。

## §1 终端悬浮整窗宽（小改，随轮实施）

- `.terminal-panel` 由文档流改 `position: fixed`：`left: 8px; right: 8px; bottom: 8px`，DOM 位置不动（仍在 `.app-body` 内，fixed 相对视口）。高度拖拽逻辑不变（200px 起步、上限 60% 窗高）。
- 悬浮观感：`border-radius` + 既有 `--color-border` 描边 + 柔和投影，配色全走既有主题变量（零彩亮）。
- z-index 取低于全局弹窗的档位（实施时按现有弹窗 z 值选），ConfirmDialog 等仍压在终端之上。
- `open=false` 行为不变（display:none，pty 不死）；悬浮尺寸变化由既有 ResizeObserver 自动 refit。

## §2 三选条交互（终结式）

- **触发面**：频道 ∈ {learn, wiki, zhijiji} 的两处承载面——右栏 AiSidebar + 弹窗内嵌 ChannelChatPanel（学习库拓展坞 / 致知己追问栏）。抽共享子组件（三选条 + 落点小窗编排），两处复用。
- 每轮 AI 回复**成功落库后**，在**最新一条 assistant 消息下方**渲染三选条（历史消息不挂条）；用户发新消息即收起，下轮回复后重现。三选条状态为会话内 UI 态，不持久化（重启后历史消息不挂条，仅新一轮回复触发）。
- **继续对话**：收起三选条，上下文原样继续。
- **保存对话**：弹落点小窗（§3）→ 卡片入模块 → toast 确认 → 自动切换到新会话（旧会话完整留在历史会话列表）。
- **归档对话**：二次确认弹窗（明示 3 天自动清理）→ 会话移入回收站「AI 会话」块（§4）→ 自动切换到新会话。
- LLM 未配置 / 生成失败 / 中断：无成功回复即无三选条，天然不受影响。

## §3 保存对话：三模块落点小窗

统一 md 封装格式（原样完整对话，双击可再编辑）：

```markdown
# {卡片标题}

> 保存于 YYYY-MM-DD HH:MM · 来自「{频道名}」对话

## 用户
{用户消息}

## debugzi
{AI 回复}
```

（多轮按序重复「## 用户 / ## debugzi」小节；标题默认 = 会话标题，可改。）

| 频道 | 落点小窗 | 落库形态 |
|---|---|---|
| 学习·问答 | 领域 › 主题 两级下拉（主题下拉含「＋ 新建主题…」，需先选领域）+ 标题输入 | 主题下新建**知识点卡**（learn_nodes level=3，state='todo'，不碰 learn_daily）；md = 对话封装 |
| 万象·问答 | 板块下拉（默认第一个板块；无板块时提示先建板块）+ 标题输入 | 板块下新建**词条卡**（wiki_entries state='learned'）；md = 对话封装 |
| 致知己·追问 | 单选：○ 新建问题（标题输入，对话为首版）／○ 附加到既有问题（沉淀区问题下拉） | 新建问题（origin='manual'）+ 首版本；或既有问题**追加「对话存档」版本**（zhijiji_versions 正常行，md = 对话封装） |

- 三通道均**新开专用 IPC**（主进程单点写 md + 落行，防渲染层读改写竞态——深挖入卡同款纪律），不复用 AI 生成路径。
- 空态兜底：学习库无领域/主题时，走「＋ 新建主题…」需先选领域；无任何领域时小窗提示先去知识树建领域。万象库无板块时提示先建板块。
- 保存成功后旧会话原样保留在历史会话列表（消息不删不软删）。

## §4 归档对话：回收站新「AI 会话」块

- **DB v45**（v44 已被同日经验书 wenbi_experiences 占用，撞车顺延）：`ai_sessions` 加 `deleted_at TEXT`（NULL=在用）；既有会话查询（aiSession:list / active 等）一律补 `deleted_at IS NULL`。
- `RecycleSource` 新增 `'ai_session'`（TABLES 映射 ai_sessions，无 md 字段）；归档 = 事务内置 deleted_at + 写 recycle_bin 行，**payload 存快照** `{ title, channel }`（彻底删后仍可显示）。
- 回收站新增「AI 会话」页签：行显会话标题 + 频道徽章 + 归档时间；**恢复** = 清 deleted_at，会话原样回到对应频道会话列表；**删除** = 连同全部 ai_messages 彻底删；3 天自动清理（启动 + 每日零点）照常适用。
- 归档的若是频道当前激活会话，自动切新会话（既有「active 不在列表则兜底」逻辑天然覆盖，激活键回写新会话）。

## 冒烟清单（实施后）

1. 终端：悬浮整窗宽、左右 ~8px 居中、拖高、收起重开、双主题、弹窗压终端之上。
2. 三选条：三频道 × 两承载面（右栏 / 弹窗拓展坞）出现位置仅最新回复下；继续对话收起；下轮重现。
3. 保存：学习库选主题/新建主题落卡 todo 态（队列可见、点学会了才计数）；万象库选板块落卡 learned 态（不进待学习区）；致知己新建问题/追加存档版本两路；卡片 md 双击可编辑；保存后自动切新会话且旧会话在历史列表可回看。
4. 归档：确认弹窗 → 回收站「AI 会话」页签可见（标题+频道徽章+时间）→ 恢复回频道列表 → 彻底删连消息 → 3 天自动清理口径。
5. 边界：LLM 未配置无三选条；生成失败不挂条；归档激活会话后两承载面同步切新会话；其余频道（助手/辩真·核查/格言·解读）无三选条回归。
