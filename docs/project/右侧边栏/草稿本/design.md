# 草稿本 design.md —— 右侧边栏速记本

> 260907 由开发者指令 AI 依据已实现现状整理创建（源自优化建议区第 21 轮「海龟汤侧边记录栏 → 泛化为全局草稿本」，brainstorming 四项定稿实施）；后续维护开发者主导，AI 可提建议。原始设计记录见 `../archive/2026-09-07-草稿本侧边栏-design.md`。

## 1. 定位

右缘常驻速记本，像 debugzi 一样可展开收起、在右侧边显示；分频道管理 md 草稿，增删改查齐全。解决玩海龟汤时随手记线索的需求，泛化为全局随手记。

## 2. 四项关键设计决策

1. **与 debugzi 共存：右缘双面板互斥展开**——同一时刻至多展开一个面板；都收起时右缘细条双图标入口，点谁展谁，永保三栏。debugzi 常驻挂载（草稿本展开时隐藏不卸载，AI 生成任务不中断）；草稿本按需挂载。展开态持久化。
2. **频道固定「通用 + 海龟汤」起步**——频道是数据表普通字段，将来加频道零迁移。否决模块全开（用不上且拥挤）与用户自建频道（第一版成本高）。
3. **海龟汤轻联动**——进入对局（推理角派发对局事件）→ 面板展开时自动切海龟汤频道；对局中「+」新建草稿标题自动「《汤名》」、正文空白不预填（260907 开发者修订：取消汤面预填与线索骨架模板）；草稿永存，局终不动。否决每局自动建草稿（弃汤留垃圾）。
4. **侧栏内编辑 + 大窗逃生口**——正文默认渲染态，双击进编辑；**自动保存**（停止输入 800ms 静默落库，无需点保存，「取消/保存」改为「完成」键 + Esc 同效）；「大窗编辑」经全局 MdDialog 打开同一 md；编辑中切换草稿/频道/收起面板自动落袋保存，速记不丢字。

## 3. 面板结构

```
头部：edit_note 图标 + 「草稿本」 + 收起键
频道条：[通用] [海龟汤] pill
切换条：当前草稿标题 ▾（浮层列表 updated_at 倒序：单击切换 / hover 重命名·删除）+ [＋新建]
正文：MdView 渲染态（双击编辑）/ textarea 编辑态 +「完成」键
底部：「大窗编辑」入口
```

- 左缘 7px 拖宽（280–560px，持久化），交互语言全镜像 debugzi。
- 空频道显示空态 + 新建按钮；删除当前草稿自动切相邻。

## 4. 数据与流转规则

- 正文是**真实 md 文件**（`md/drafts/{id}.md`），元数据存 SQLite（DB v14）。
- **改名不动 updated_at**（列表顺序稳定）；**保存/大窗触碰 bump updated_at**（浮回列表顶部）。
- **删除走回收站**（第七来源「草稿本」）：恢复 = 清删除标记回原频道；彻底删除 = 删行 + 删 md；3 天自动清理适用；删除需二次确认。

## 5. 使用

1. 收起态点右缘细条「编辑」图标展开；与 debugzi 互斥切换。
2. 频道 pill 切换通用/海龟汤，各频道记住各自激活草稿。
3. 玩海龟汤进对局 → 展开草稿本自动在海龟汤频道；「＋」新建即得以汤名命名的草稿。
4. 正文双击进入编辑，停笔即存；长文点「大窗编辑」用全局 md 弹窗继续写。

实现规格见同目录 `designs-specs.md`。
