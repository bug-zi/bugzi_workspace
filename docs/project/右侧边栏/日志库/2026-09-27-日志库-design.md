## 需求

右栏第五面板「日志库」：把主进程运行日志（agent 引擎巡检、定时任务、补库泵等，当前只散落在开发终端 console 输出里）在工作台内显性可查。带格式加工（时间、级别、来源分类）、搜索筛选、最近 7 天留存。纯只读、零 AI、不入回收站。

1. **形态：右栏新面板**（非底栏页签）——与 debugzi/草稿本/资源管理器/画布并列第五面板，互斥展开，右缘细条第五图标。
2. **采集：主进程全部关键日志，全量迁移**——主进程建统一 logger（终端输出保留 + 落库 + 实时广播），现有 25 文件 122 处 `console.*` 全部迁为带 scope 的 logger 调用；`uncaughtException`/`unhandledRejection` 也捕获入库。

## 主进程 logger（electron/services/logger.ts）

```ts
logInfo(scope: LogScope, message: string): void
logWarn(scope: LogScope, message: string): void
logError(scope: LogScope, message: string, err?: unknown): void
```

- 每条日志三动作：① `console.*` 镜像输出（开发终端照旧）② INSERT `app_logs` ③ 推送广播。
- **scope 枚举**（TS 联合类型，UI 分类即此，共 8 个）：`system`(启动/DB 迁移/ipc/未捕获异常) `agent`(超级工作台引擎/队列/采集) `scheduler`(定时任务) `stock`(五泵补库) `llm`(ai/services+llm 层) `podcast` `library`(storage 书架) `whoami`。
- level 映射：`console.log/info` → info，`console.warn` → warn，`console.error` → error；`logError` 附 err 时 message 追加 `\n` + stack。
- **广播合批**：追加行先入待推缓冲，500ms 定时器统一 `win()?.webContents.send('log:appended', rows)`（多条一包），面板未开也照发（渲染层未订阅即无开销，转发量极小）。
- **自举防护**：logger 自身 DB 写失败静默吞掉并置内存降级标记（本会话内不再尝试落库，只保留 console 输出），防「记录日志的日志」递归。

## 数据层（DB v64；260927 v63 已被论文库领域筛选 papers.domain_id 先落地，顺延一号）

- 新表 `app_logs`：
  ```sql
  CREATE TABLE app_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ts TEXT NOT NULL,        -- ISO 本地时间（口径同全项目 nowIso）
    level TEXT NOT NULL,     -- 'info' | 'warn' | 'error'
    scope TEXT NOT NULL,     -- 8 枚举之一
    message TEXT NOT NULL
  );
  CREATE INDEX idx_app_logs_ts ON app_logs(ts);
  CREATE INDEX idx_app_logs_scope ON app_logs(scope);
  ```
- **7 天留存清理**：挂既有「启动 + 每日零点」检查点（同回收站过期清理处），`DELETE FROM app_logs WHERE ts < 今-7天`。
- **单日上限兜底**：入库时当日计数超 2000 则先删当日最旧，防异常刷屏撑库。

## IPC（三通道 + 一推送）

- `log:list({ scope?, keyword?, beforeId?, limit? })` → 游标分页：`WHERE id < beforeId`（首页不传）+ 可选 scope/`message LIKE %keyword%`，`ORDER BY id DESC LIMIT 200`（默认），返回行数组（新→旧）。级别不入查询条件（UI 不做级别筛选，级别只用于着色）。
- `log:scopes()` → 7 天窗口内各 scope 计数（筛选下拉用）。
- `log:clear()` → 清空全表（渲染层二次确认后调用）。
- 推送 `log:appended`（rows 数组，合批）。
- preload 暴露 `api.logs.{ list, scopes, clear, onAppended }`。

  - 打开面板拉最新 200 条 + 订阅 `log:appended`；
  - 跟随态：追加行插底部、自动滚到底；
  - 向上滚动离底 > 80px、或输入搜索/切换筛选 → 自动切手动浏览态，底部浮「回到底部」圆钮（新日志到达时带 +N 计数），点击恢复跟随；
  - 手动态滚到顶 → `beforeId = 当前最旧 id` 向上翻页（游标加载更早）；
  - 搜索/筛选命中即重新拉首页，游标与翻页状态重置。
- 卸载即退订（无 keep-alive 负担）；纯只读展示，不入回收站、零 AI、无 LLM/MCP 置灰逻辑。

## 错误处理

- logger 落库失败：静默降级只走 console（见自举防护），不影响业务流程。
- log:list 失败：列表区行内错误提示 + 重试按钮，不弹窗。
- 清空：二次确认弹窗（全局规则），确认后即时清列表与计数。
- 空态：无日志时显示「暂无日志」引导文案。
