## 需求

右侧边栏接入 Excalidraw 画布：随手涂鸦、示意图、结构草图；多画布管理，与 debugzi / 草稿本同为右缘面板；纯本地零 AI。

## 商讨定稿的四项关键决策

1. **形态：多画布管理**——完全镜像草稿本模式：切换条管理多张画布（新建/重命名/删除），每张画布一个 `.excalidraw` 文件。否决单画布速涂（画多了乱）与仅大窗弹窗（少直达性）。
2. **宽度策略：宽上限 + 大窗**——画布面板拖宽范围放宽到 **280–900px**（其他面板仍 280–560，Excalidraw 在窄栏里画起来挤）；另配「大窗作画」经专属弹窗大窗编辑。否决维持 280–560（受限）与仅大窗（少直达性）。
3. **删除流转：入回收站**——镜像草稿本：删除二次确认后软删入回收站（回收站新增「画布」块），可恢复、3 天后自动彻底删。否决直接彻底删（少后悔药）。
4. **接入方式：npm 包 `@excalidraw/excalidraw` 内嵌（方案 A）**——官方 React 组件，完全离线、画布数据是 JSON 可自由落盘、`theme` prop 跟随双主题、`langCode="zh-CN"` 中文化。代价是依赖体积约 1–2 MB gzip（本地单机应用不敏感）。否决 iframe 嵌 excalidraw.com（需联网、跨域拿不到数据无法落盘、主题不可控）与自研画板（功能差距太大）。

## 面板结构（镜像草稿本，无频道条）

```
头部：draw 图标 + 「画布」 + 收起键
切换条：当前画布标题 ▾（浮层列表 updated_at 倒序：单击切换 / hover 重命名·删除）+ [＋新建]
画布区：内嵌 Excalidraw（theme 跟随 App 双主题、zh-CN、窄栏 UI 适配）
底部：「大窗作画」入口
```

- **右栏三面板互斥**：`rightPanel: 'ai' | 'draft' | 'canvas' | null`；都收起时右缘细条**三图标**（debugzi `forum` / 草稿本 `edit_note` / 画布 `draw`）；画布与草稿本一样按需挂载，debugzi 仍常驻挂载不卸载；展开态持久化沿用 `settings.right_panel_expanded`（新增 `'canvas'` 值）。
- 无频道条（草稿本频道源于海龟汤联动，画布无此需求）；新建画布自动命名「未命名画布 N」。
- 左缘 7px 拖宽 280–900px，持久化 `canvas_width`。

## 大窗作画（互斥挂载，数据同源）

Excalidraw 同一画布不能双实例同时编辑（场景状态分离），大窗打开时**右栏画布区卸载并显示占位提示**（「已在大窗中打开」），大窗关闭后右栏重新挂载、从盘读回。大窗为专属全屏弹窗（复用 MdDialog 样式骨架，内容区换 Excalidraw）。两侧写同一个 `.excalidraw` 文件，随手涂与大图互为续作。

## 数据与接口

- **DB v25**：`canvases(id, title, path, created_at, updated_at, deleted_at)`；无 channel 字段。画布正文是**真实 `.excalidraw` 文件**（标准格式 `{type, version, elements, appState}`，可直接被 excalidraw.com 官方导入导出），存用户数据目录顶层 `canvas/` 子目录（与 `md/`、`books/` 平级；不是 md 不进 `md/`）。
- **自动保存**：Excalidraw `onChange` → 停止变动 800ms 静默落盘 + bump `updated_at`（镜像草稿本停笔即存）；**改名不动 updated_at**；切换画布/收起面板/关大窗时强制落袋。
- **IPC**：`canvas:list/create/rename/save` + 删除走通用 `item:discard('canvases')`；`api.canvas` 暴露于 preload。
- **回收站**：`RecycleSource += 'canvases'`；恢复 = 清 `deleted_at` 回画布面板；彻底删除 = 删表行 + 删 `.excalidraw` 文件 + 删回收记录；3 天自动清理适用（现有启动+零点检查通用机制零改动）；RecycleModule 分组列表新增「画布」块（标题 + 删除时间预览）。
- **设置键**：`canvas_width`（280–900px）+ 最后激活画布 id（`canvas_active_id`，重启恢复）。

## 错误处理

- `.excalidraw` 文件缺失或 JSON 损坏 → 按空白画布打开并可重新保存（toast 提示一次），不崩不阻塞。
- 落盘失败（磁盘异常）→ toast 报错，不丢内存态，下次变动重试。
- 纯本地零 AI 零联网，无 LLM/MCP 置灰逻辑。

## 验证

- `npm run typecheck` 双配置通过 + `npm run build` 通过。
- 人工冒烟：新建→画→自动保存→重命名→删除（二次确认入回收站）→恢复→大窗作画与右栏互斥挂载→重启后展开态/宽度/最后激活画布恢复→双主题切换 Excalidraw 跟随→`.excalidraw` 文件可在 excalidraw.com 导入验证格式标准。
