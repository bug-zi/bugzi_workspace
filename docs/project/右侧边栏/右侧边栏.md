# 右侧边栏 总说明（设计与使用）

> 三栏布局的右栏。260907 由开发者指令建此文档（AI 依据已实现现状整理），作为右侧边栏功能的总入口；两个子模块的详细设计与规格见各自目录。

## 定位与结构

右侧边栏与左侧边栏（八模块导航）对称，承载**两个互斥面板**：

| 面板 | 定位 | 目录 |
|---|---|---|
| **debugzi** | AI 伴学助手——五频道对话（助手/格言·解读/万象·问答/致知己·追问/辩真·核查），会话制历史 | `右侧边栏/debugzi/` |
| **草稿本** | 速记本——通用/海龟汤双频道 md 草稿 | `右侧边栏/草稿本/` |

## 核心设计原则（右缘双面板互斥，优化建议区第 21 轮）

- **互斥展开、永保三栏**：`App` 持 `rightPanel: 'ai' | 'draft' | null`——同一时刻至多展开一个面板；都收起时右缘显示细条双图标入口（debugzi `forum` / 草稿本 `edit_note`），点谁展谁。否决四栏并列与合并 Tab：主栏内容优先，边栏功能切换而非堆叠。
- **debugzi 常驻挂载**：草稿本展开时 debugzi 以 `display:none` 隐藏而**不卸载**——进行中的 AI 生成任务（来 10 条格言等）回填不中断；草稿本按需挂载。
- **展开态持久化**：`settings.right_panel_expanded`，默认 `'ai'`（与早期行为兼容），重启恢复。
- **统一拖宽**：两面板均为左缘 7px 拖条，范围 **280–560px**，各自持久化（`ai_width` / `draft_width`），实时生效松手落库。

## 使用

1. **展开/收起**：都收起时点右缘细条图标展开对应面板；面板头部「›」收起（回到细条）。两面板之间通过细条或面板入口互相切换。
2. **拖宽**：鼠标按住面板左缘拖动，宽度即时生效并记住。
3. **debugzi**：频道 pill 切换场景频道；头部会话切换器管理多会话；输入框支持 `/clear`（清空当前会话）与 `/compact`（历史压成前情摘要另存新会话）。详见 `debugzi/design.md`。
4. **草稿本**：频道 pill 切换通用/海龟汤；切换条管理草稿（新建/重命名/删除）；正文渲染态双击进编辑，自动保存；「大窗编辑」经全局 MdDialog 打开同一 md。玩海龟汤时进对局自动切海龟汤频道。详见 `草稿本/design.md`。
