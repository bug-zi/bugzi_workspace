介绍：一些基础信息的设置，以及一些 app 设置。不需要做账号登录注册。

v1.0：

**个人信息：**

- 用户名：文本输入，即时保存。
- 用户头像：仅本地图片上传（不提供预置头像）；非方形图自动居中裁剪。
- 个性签名：文本输入，即时保存。

**App 设置：**

1. 字体设置：字体大小、字体样式、字体粗细。拖动/选择即时全 App 生效并自动保存，无需点保存按钮。

2. 主题设置：浅色/深色切换项在 App 设置里（与字体设置并列）；左侧边栏底部同时有一键切换图标，两处入口均可切换。

3. LLM 配置：支持配置多个 LLM 服务商（每套含 API 地址 + API Key + 模型名），可设其中一个为默认。不内置具体服务商名单，用户填什么都行。格言生成、知识卡片生成、AI 助手对话均使用默认 LLM。

4. MCP 配置：填写 MCP 服务器地址/名称启用，可启用多个，可随时开关（辩真阁联网搜索依赖于此）。具体字段到开发阶段再定。
