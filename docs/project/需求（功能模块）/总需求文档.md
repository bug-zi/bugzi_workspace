## 技术与数据

2. 技术栈：Electron + React + TypeScript。桌面端应用，单机本地运行，无账号登录注册，无自建后端服务。AI 能力（侧边栏对话、格言生成、知识卡片、辩真搜索分析、推理角出题判答与点评）由 App 直连 LLM 服务商 API 实现：请求在 Electron 主进程发起（规避渲染进程 CORS 限制），API Key 本地存储；UI 与主进程通过 IPC 通信。
3. 数据存储：结构化数据（格言、词条、高光、验证记录、致知己问题与版本、画像条目、汤库、海龟汤对局与问答、每日题、精选题库、预生成题池〔v1.3 待实现〕、设置项）存 SQLite；md 文档（格言笔记、灵感文档、万象卡片正文、辩真记录详情、致知己答案版本、推理角对局记录 / 每日题详情 / 精选题档案）存为真实 .md 文件，可用外部编辑器打开。数据库与 md 文件均在用户数据目录下。
4. App 名称：前端窗口标题：bug子的workspace；安装包名用bugzi_workspace

## 跨模块交互规则

5. 回收站按来源分六板块：格言库 / 万象库 / 灵感泉 / 辩真阁 / 致知己 / 推理角。「恢复」回到来源模块的最初级区（格言库/灵感泉→草稿区，万象库→原板块，辩真阁→历史记录列表，致知己→主列表，推理角→汤恢复回汤库、对局记录恢复回记录列表；每日题与精选题库不进回收站）；「删除」为彻底删除。存放满 3 天自动彻底删除，检查时机：App 启动时 + 运行期间每日零点。
6. md 弹窗为全局统一组件（格言笔记 / 万象卡片 / 灵感文档 / 辩真记录详情 / 致知己答案版本 / 推理角对局记录与每日题详情共用）：默认渲染态，双击切换编辑态，退出编辑即恢复渲染。
7. 主题切换双入口：左侧边栏底部一键切换图标 + 个人中心 App 设置。
8. LLM/MCP 未配置时，所有依赖 AI 的功能按钮不置灰，点击后弹窗提示「请先在个人中心配置 LLM」+「去配置」按钮直达个人中心。
9. AI 助手边栏（右侧）：外壳可收起/展开，内部按场景分频道（260905 频道制）——助手 / 万象·问答 / 致知己·追问 / 辩真·核查。每频道独立会话历史与 system prompt 人设，互不串味；感知当前模块上下文。模块内动作（问 AI / 让 AI 追问 / 开始验证）自动展开边栏并切到对应频道。各频道及全部 AI 功能（格言生成、万象生成、辩真验证等）的上下文注入「我的画像」（个人中心维护，AI 对话中提炼的条目经确认入档）。
10. 定时任务（每晚 10 点格言生成）：App 未运行时错过即跳过，不补生成；手动「来10条格言」随时可用。

## 启动与首次使用

11. 首次启动显示简短欢迎引导弹窗：设置用户名 + 选择主题 + 提示先去配置 LLM；之后进入空白 App。
12. 侧边栏模块顺序：格言库 → 万象库 → 灵感泉 → 辩真阁 → 致知己 → 推理角 → 回收站 → 个人中心。
13. 背景图 bg-light / bg-dark：存放于用户数据目录，App 内（个人中心 App 设置）提供更换背景图功能。
