## 技术与数据

2. 技术栈：Electron + React + TypeScript。桌面端应用，单机本地运行，无账号登录注册，无自建后端服务。AI 能力（侧边栏对话、格言生成、知识卡片、辩真搜索分析）由 App 直连 LLM 服务商 API 实现：请求在 Electron 主进程发起（规避渲染进程 CORS 限制），API Key 本地存储；UI 与主进程通过 IPC 通信。
3. 数据存储：结构化数据（格言、词条、高光、验证记录、设置项）存 SQLite；md 文档（格言笔记、灵感文档、万象卡片正文、辩真记录详情）存为真实 .md 文件，可用外部编辑器打开。数据库与 md 文件均在用户数据目录下。
4. App 名称：前端窗口标题：bug子的workspace；安装包名用bugzi_workspace

## 跨模块交互规则

5. 回收站按来源分四板块：格言库 / 万象库 / 灵感泉 / 辩真阁。「恢复」回到来源模块的最初级区（格言库/灵感泉→草稿区，万象库→原板块，辩真阁→历史记录列表）；「删除」为彻底删除。存放满 3 天自动彻底删除，检查时机：App 启动时 + 运行期间每日零点。
6. md 弹窗为全局统一组件（格言笔记 / 万象卡片 / 灵感文档 / 辩真记录详情共用）：默认渲染态，双击切换编辑态，退出编辑即恢复渲染。
7. 主题切换双入口：左侧边栏底部一键切换图标 + 个人中心 App 设置。
8. LLM/MCP 未配置时，所有依赖 AI 的功能按钮不置灰，点击后弹窗提示「请先在个人中心配置 LLM」+「去配置」按钮直达个人中心。
9. AI 助手边栏（右侧）：可自由对话，且感知当前模块上下文（如在格言库则优先聊格言相关话题）。v1 单会话，历史持久保存；多会话管理列 v2。
10. 定时任务（每晚 10 点格言生成）：App 未运行时错过即跳过，不补生成；手动「来10条格言」随时可用。

## 启动与首次使用

11. 首次启动显示简短欢迎引导弹窗：设置用户名 + 选择主题 + 提示先去配置 LLM；之后进入空白 App。
12. 侧边栏模块顺序：格言库 → 万象库 → 灵感泉 → 辩真阁 → 回收站 → 个人中心。
13. 背景图 bg-light / bg-dark：存放于用户数据目录，App 内（个人中心 App 设置）提供更换背景图功能。
