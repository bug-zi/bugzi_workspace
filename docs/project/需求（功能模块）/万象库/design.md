
介绍：这个模块下是对我非自己专业领域（计算机）知识的一个记录和获取。

v1.0：初始化分成 “经济学” ，“法学”，“心理学”，“博弈论”，“历史神话”五个板块，也可也再自定义添加新板块。然后每个版块下也是以列表的形式呈现知识词条吧——就是一句话概括的知识点。然后点击每个词条也是显示弹窗，弹窗中是该知识点的具体信息。用户可以通过划出文本进行高光标记，或者引用划出的内容提问AI。和AI的交互在右侧边栏AI助手模块实现。然后在这个模块中还需要一个笔记本板块，就是在万象库中划出的高光内容会按时间顺序存在笔记本中。划词的高光和问AI仅限在万象库模块时候有。同样以每一个知识词条为基本单位，每个知识词条右侧具有查看，编辑和放到回收站三个小组件。然后这个知识来源的话吧，一个是模块的总览下有一个随机生成——要求你随机抽一个板块，然后AI随机生成一个该板块的，并且是还没有出现在万象库中的关键词条。然后你围绕这个词条生成具体的知识卡片。或者就是我输入一个关键词条给你，然后你帮我生成。（具体逻辑可能还有待完善，比如说如何规避词条重复的这个问题，你又要如何和我介绍这个知识点的问题，有待商榷。）
