# 我的画像 · 按类别分组 + 展开/收起 设计记录（2026-09-07）

## 背景

画像初始化后共 28 条、9 个类别，原列表平铺（每行重复类别标签），快速定位不便。
开发者要求：按类别分组、每类可展开/收起，方便快速检索查看。

## 决策（方案 A，已确认）

- **zone 级折叠（追加）**：画像 zone 头加 chevron + 点击整头折叠/展开（格言库 zone 同款）；
  `zone-actions`（新增按钮）stopPropagation 不触发折叠；收起时 zone-body 不渲染，计数徽标常驻。
  折叠态 `useState(false)` 内存、默认展开、不持久化。

- 「我的画像」zone 结构不变；`zone-body` 内按类别插入**组头行**：chevron（expand_more/expand_less）
  + 类别名 + 条数，点击组头切换折叠。组头无操作按钮，无冒泡冲突问题。
- 折叠机制与格言库同款：`useState<Record<string, boolean>>` 内存态、默认全展开、不持久化
  （切模块重置）。新增按钮留 zone 头不动。
- 类别顺序：`PROFILE_CATEGORIES` 预设序在前；自定义类别按首次出现追加其后。
- 组内行：内容升为主文本（row-title），不再重复类别标签；AI 徽标、编辑/删除按钮不变。
- 备选 B（每类一张独立 zone 卡）否决：页面纵向变长、检索需多滚动。
- 不做（YAGNI）：搜索框——28 条/9 类分组折叠后扫描已够快，后续有需要再加。

## 改动范围

仅 `src/modules/profile/ProfileModule.tsx`（分组 useMemo + 折叠 state + 渲染循环，约 40 行）+
`src/App.css` 新增 `.profile-cat-header` 组头样式（约 22 行）。无 IPC/DB/主进程改动。

## 验证

`npm run typecheck` 通过；开 App 个人中心画像区人工冒烟（分组展示/折叠/新增编辑删除路径不变）。
