# 草稿本侧边栏设计（优化建议区待完成 → 已实施）

- **日期**：260907
- **状态**：已实施（typecheck 通过，待人工冒烟）
- **来源**：优化建议区待完成条目（海龟汤侧边记录栏 → 泛化为全局草稿本）

## 需求

玩海龟汤时需要随手记录线索；泛化为右缘常驻草稿本，像 debugzi 一样可展开收起、分频道，md 格式，增删改查齐全。

## 商讨定稿的四项关键决策

1. **与 debugzi 的共存：右缘双面板互斥展开（方案 A）**
   - `App.tsx` 持 `rightPanel: 'ai' | 'draft' | null`；null（都收起）时右缘细条显示两个图标入口（debugzi `forum` / 草稿本 `edit_note`），点谁展谁；面板头部各有收起键。
   - debugzi 常驻挂载（草稿本展开时 `display:none` 隐藏，保持进行中生成任务的回填能力）；草稿本按需挂载。
   - 展开态持久化 `settings.right_panel_expanded`，默认 'ai'（与既有行为一致）。

2. **频道：固定两频道起步（方案 A）**——`通用` + `海龟汤`；频道是 drafts 表普通字段，将来加频道零迁移。否决模块全开（用不上且拥挤）与用户自建（第一版成本高）。

3. **海龟汤联动：轻联动（方案 B）**——进入对局视图（TurtlePanel 派发 `bugzi:turtle-game` 事件，App 接住传 DraftSidebar）→ 面板展开时自动切海龟汤频道；对局中新建草稿 → 标题自动「《汤名》」，正文空白不预填（**260907 开发者修订**：原「《汤名》手记 + 预填汤面引用块 + 我的线索骨架」取消，事件链路 surface 字段随之删除）；草稿永存，局终不动。否决每局自动建草稿（弃汤留垃圾）。

4. **编辑：侧栏内编辑 + 大窗逃生口（方案 C）**——正文默认 MdView 渲染态，双击进 textarea 编辑；**260907 反馈修订：编辑态自动保存**——停止输入 800ms 静默落库，无需点保存；底部「取消/保存」改为「完成」键（自动保存下「取消」无法回退，留着误导；Esc 同效）。底部「大窗编辑」按钮用全局 MdDialog 打开同一 md（onChanged → draft:touch + 重载）。编辑态切换草稿/频道/收起面板时自动落袋保存，速记不丢字（兜住防抖窗口内最后输入）。

## 数据与接口

- **DB v14**：`drafts(id, title, channel, md_path, created_at, updated_at, deleted_at)`，索引 channel；正文 `md/drafts/{id}.md`。
- **IPC**：`draft:list/create/rename/save/touch` + 删除走通用 `item:discard('drafts')`。改名不动 updated_at（列表顺序稳定），保存/大窗触碰 bump updated_at（浮回列表顶部）。
- **回收站**：`RecycleSource += 'drafts'`（第七个来源）；恢复 = 清 deleted_at 回原频道；彻底删除走默认路径（删行 + 删 md）；RecycleModule 新增「草稿本」页签，恢复去向「草稿本·原频道」，摘要显示标题；3 天自动清理适用。
- **设置键**：`right_panel_expanded` / `draft_width`（280–560px 拖宽，镜像 debugzi）/ `draft_active_channel` / 各频道激活草稿 id（镜像 AI 边栏 per-channel active session 模式）。

## 面板结构（镜像 AiSidebar 交互语言）

```
头部：edit_note 图标 + 「草稿本」 + 收起键
频道条：[通用] [海龟汤] pill
切换条：当前草稿标题 ▾（浮层列表：单击切换 / hover 重命名·删除）+ [＋新建]
正文：MdView 渲染态（双击编辑）/ textarea 编辑态 + 取消·保存
底部：渲染态显示「双击正文可编辑」提示 + 「大窗编辑」入口
```

空频道显示空态 + 新建按钮；删除当前草稿自动切相邻；频道无上限扩草稿。
