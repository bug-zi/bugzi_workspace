## 修复：学习库题库「查看参考答案」弹窗空白

> 创建于 2026-09-25 00:15

- **现象**（问题疑惑区第13轮）：题库内点题 → 回忆小窗 → 「查看参考答案」，弹窗正文空白。

- **取证**（只读查用户库 `D:\Paper\app_output\bugzi_workspace\bugzi.db`）：`interview_questions` 现有 21 行 answer_path 全为 `''`（source 均为搜集文章，即采纳入库），而 `md/learn/interview/` 下 1.md~21.md 全部在位且内容完整——文件都在、指针缺失，与现象完全吻合；`user_version=52`。
- **修复**（两处）：
  1. `interview:intakeAdopt` / `interview:intakeBatch` 采纳分支：mdWrite 后补 `UPDATE interview_questions SET answer_path = ? WHERE id = ?`（与 questionAdd 同构）。
  2. DB **v53** 迁移（`electron/db/db.ts`）：存量回填 `answer_path = 'md/learn/interview/' || id || '.md' WHERE answer_path = ''`——两入口 md 均固定写该路径，回填全部命中；下次启动自动执行。
- `npm run typecheck` 双配置通过。**验证方式**：重启 dev 后题库点任一题 → 查看参考答案，正文应显示完整参考答案（v53 回填即时生效，无需重新搜集）。
