## 万象库·科普：正式文章统一简体呈现（繁→简）

> 创建于 2026-09-27 01:00

**问题**：科普线「解读完的正式文章」部分为繁体字——繁体中文源文章经 zh 轻加工后保留繁体，LLM 解读/翻译也偶发输出繁体。

**方案**：主进程「落盘前转换 + 存量一次性迁移」双管齐下，渲染层零改动（划词高光的文本匹配机制不受影响）。

- 新增 `electron/services/t2s.ts`：`toSimplified`（opencc-js 繁→简，简体输入幂等直通、异常兜底原样）+ `simplifyJsonStrArray`（tags 等 JSON 字符串数组列逐项转换）。
- 新增 `electron/services/agent/scienceSimplify.ts`：存量数据一次性繁→简，`settings` 旗标 `science_t2s_v1` 守卫只跑一次。覆盖四类：
  1. 解读产物 `md/interpretations/sa-*.md`（translate/light/lecture）；
  2. `science_articles` 的 title/summary/tags/glossary/concepts；
  3. `discover_items`（source_type='article'）的 title/summary/tags/reason；
  4. `science_highlights.text`（与 md 正文同批转换，保持高亮/取消高光匹配一致）。
- `bootstrap.ts`：`app.whenReady` 后调用迁移（不占 db.ts 迁移版本号，避开热点文件）。
- 增量落盘点统一转换：`interpretScience.ts` 三条产线（翻译章块/术语表 zh/加注版 md+concepts/精讲，`parseLightChunk` 内单点转换）+ `headOf` 标题与术语表；`collectScience.ts` 海选入库 title/summary/tags/reason（近重复判定与向量也用转换后文本）；`science.ts` `scienceAcceptRow` 转正分流同口径。
- 提示词加固：翻译/加注/精讲/海选各 prompt 补「简体字、不要繁体字」硬约束（转换兜底在代码层，prompt 只是第一道）。

**验证**：`npm run typecheck` 通过；`npm run build` 通过（主 bundle 含 opencc 词典数据）；冒烟测试确认 `==标记==`/`[术语](wiki://术语)` 链接目标随正文同步转换、二次转换幂等、简体输入原样返回。首次启动后控制台会打一行迁移完成统计（解读 md/转正文章/发现箱/高光条数）。

**备注**：原文全文缓存（`science/{id}.txt`）保持原样不转（源材料保真，仅作解读输入）；深读线论文（论文库）如遇同类繁体问题可复用 `t2s.ts` 同法接入。

## 修复：繁转简迁移的启动时机（DB_NOT_INITIALIZED）

> 创建于 2026-09-27 01:10

初版把迁移挂在 `bootstrap.ts` 模块加载期的 `app.whenReady()` 上——但 bootstrap 由 main.ts 顶部 import 触发，其 whenReady 回调**先于** main.ts 自己的 whenReady 注册执行，此时 `initDb()` 尚未跑，`getDb()` 抛 `DB_NOT_INITIALIZED`，迁移启动即败。

修正：迁移挪入 `main.ts` whenReady 序列 `initDb()` 之后立即执行（与各 `ensure*` 启动任务同处一列）；`ensureScienceSimplified` 改为内部自 catch 永不抛错（失败不落旗标、下次启动重试，转换幂等重跑安全），bootstrap.ts 撤销还原。typecheck 通过。

## 科普链路可观测性修复：原文可读 + 生成进度 + 场景标签

> 创建于 2026-09-27 01:45

**背景**（开发者反馈「转正后一片乱」）：①「全文就绪」的文章在 App 内看不到原文——全文缓存只喂 LLM，「原文出处」仅外跳浏览器；②解读按钮「生成中」却无处看进度——`TaskContext.progress` 是 no-op（v1 预留），逐章生成动辄数分钟全程只有转圈；③右栏 AI 调用面板看不到科普解读——场景标签缺失（显示裸键 `agent:s-translate`），且抓全文/重试退避期无 LLM 在途调用，面板为空属正常；④`runningTypes` 是全类型不分文章的——A 文在生成、B 文详情也误标「生成中」。

**改动**：
- `queue.ts`：`running` 快照扩为 `{type, refId, progress, controller}`；`ctx.progress` 从 no-op 接通——写快照 + 触发广播（engine 500ms 节流）；`runningRuns()` 带出 refId/progress。
- `engine.ts`：`AgentStatusSnapshot` 新增 `runningTasks` 明细（runningTypes 保留兼容任务中心）。
- `types.ts`/`api.d.ts`：快照类型同步 + `LLM_SCENE_LABELS` 补 `agent:s-translate/s-light/s-lecture`（工作台·科普解读/加注/精讲）。
- `interpretScience.ts`/`science.ts`：术语表/翻译/加注/精讲循环上报「第 N/M 部分」，抓全文上报「抓取全文中…」。
- `ipc.ts`/`preload.ts`/`api.d.ts`：新增 `agent:scienceFulltext`（读 `science/{id}.txt` 缓存，复用既有 `readScienceFulltext`）。
- `SciencePanel.tsx`：
  - `showLecture` 布尔升级为 `view: 'auto'|'lecture'|'source'` 三视图；「全文就绪」文章 footer 新增「原文」切换（纯文本转 md 段落展示，只读无高光），「原文出处」更名「网页原链」保留外跳；
  - 忙碌判定改 `runningTasks` 按「任务类型+refId」精确匹配——只有本文自己的任务才标「生成中」，别文任务不再误标；
  - 按钮直接显示进度文案（`解读生成中 · 翻译第 3/8 部分…`）；
  - 生成期间按钮不再禁死——点击可打开实时落盘的半成品 md 围观（done 台账未落按约定路径读文件），详情打开期间每 5s 自动刷新（任务终态事件另有即时刷新）。

**验证**：typecheck 双配置 + build 通过。冒烟（接受候选→抓取→解读全程进度、原文视图、半成品围观、别文不误标、右栏面板中文标签）待开发者验收。

**备注**：typecheck 曾报 `runningTasks` 不存在系 tsbuildinfo 增量缓存未失效，清缓存后通过。
