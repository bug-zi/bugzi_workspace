## 1.0 开发（260902 第四轮，AI 执行）

应开发者要求「完成项目的 1.0 开发」，基于 7 份 designs-specs.md 初始化全部代码。

### 技术选型落地

- **数据库**：node:sqlite（DatabaseSync）+ WAL + 外键，PRAGMA user_version 版本化迁移。弃 better-sqlite3 以避开 Windows 下原生 ABI 重编译；为此将 Electron 从 33 升至 44（需 Node ≥22.13，内置 node:sqlite）。
- **进程架构**：渲染层只做 UI，全部 IO（SQLite/md/LLM HTTP/MCP）在主进程；contextBridge 类型化 IPC，contextIsolation 开、nodeIntegration 关、sandbox 关（preload 需要 require）。
- **图片资源**：bzres:// 特权协议（app ready 前注册 scheme + protocol.handle）服务 userData 内头像/背景图，含路径穿越防护。
- **md 渲染**：marked + DOMPurify，`==高光==` 后处理为 `<mark>`；外链 shell.openExternal。
- **图标**：material-symbols npm 包本地 woff2（遵守禁 emoji 规则）。
- **LLM 客户端**：OpenAI 兼容 /v1/chat/completions，主进程 fetch + Bearer；jsonMode（response_format）；URL 规范化自动补 /v1/chat/completions。
- **MCP 客户端**：仅 Streamable HTTP 传输（JSON-RPC POST + mcp-session-id + SSE 响应解析）。
- **依赖坑**：vite@8 与 electron-vite@5 peer 声明（≤^7）冲突 + React 19 与 plugin-react peer 冲突，`.npmrc` 固化 `legacy-peer-deps=true` 解决（裸 npm install 即可）。

### 代码结构（v1.0 全量）

```

src/shared/         types.ts（SettingsKeys/接口）、api.d.ts（window.api 类型）
src/renderer/       api.d.ts 同步
src/theme/          global.css、ThemeProvider（双主题+背景图+字体即时生效+首启判断）
src/components/     MdDialog（渲染/双击编辑/划词气泡）、AiSidebar、Toast、ConfirmDialog、GoConfigDialog
src/modules/        mottos / wiki / inspirations / verify / recycle / profile（含 WelcomeGuide）
src/App.tsx/.css    三栏布局与六模块挂载
```
