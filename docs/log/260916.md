## 发版：GitHub release v1.17.0（应用版本 1.1.0）

> 创建于 2026-09-16 03:21

首次走通「发 release → 旧版应用内检测更新」全流程。背景核对：本机已装 1.0.2（`D:\app\myapp\bugzi_workspace`，260913 构建，asar 内确认含 updater 代码与 app-update.yml——即当年「自举两版引导」手动装的首版）；GitHub 此前仅发布过 v1.0.1。

流程：package.json 版本 1.0.2 → 1.1.0（改动待开发者提交）→ `npm run typecheck && npm run dist` → 产物三件（Setup-1.1.0.exe 305MB / .blockmap / latest.yml version=1.1.0）→ `gh release create v1.17.0 <三件>` 挂远端既有 v1.17.0 tag（恰好指向本次构建的 HEAD c7d84d9）。

要点沉淀：

- **release 与 tag 解耦**：electron-updater 经 `releases/latest`（仅返回非 draft 非 prerelease 的最新发布）拿 tag → 按 tag 拼 `releases/download/<tag>/latest.yml` 下载 → **版本比较用的是 yml 内 `version` 字段**（1.1.0 > 1.0.2），与 tag 名无一致性要求。开发者的 v1.N.0 里程碑 tag 体系与 package.json 应用版本是两套，互不干扰。
