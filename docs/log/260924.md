## dev server 端口固定为 5183

> 创建于 2026-09-24 00:34

`electron.vite.config.ts` renderer 块新增 `server: { port: 5183, strictPort: true }`，`npm run dev` 时渲染层 dev server 由 Vite 默认 5173 固定为 5183；主进程 dev 模式经 `ELECTRON_RENDERER_URL` 自动跟随（electron/main.ts:70），无需改动。`strictPort` 保证 5183 被占用时直接报错而非静默挪端口。仅影响开发模式，打包产物不涉及端口。
