## 优化建议区第 47 轮：终端悬浮整窗宽 + AI 会话三选（保存/归档）

> 创建于 2026-09-17 22:08

**需求来源**：`docs/project/优化建议区.md` 待完成区两条——①终端显示窗口铺满底部导航栏（横向不够、左右各留 5-10px 居中）；②AI 对话每轮输出后三选「继续对话/保存对话/归档对话」（学习库/万象库/致知己，其余模块由 AI 判断）。

**brainstorming 四决策**（设计/计划见 `右侧边栏/AI会话保存与归档/2026-09-17-AI会话保存与归档-{design,plan}.md`）：

| 决策点 | 结论 |
| --- | --- |
| 终端铺满方式 | 悬浮整窗宽：fixed、左右下各 8px、覆盖内容不挤压布局（文档流挤压案否决） |
| 保存落点 | 原生载体 + 保存时选落点小窗（学习库知识点卡 / 万象库词条卡 / 致知己问题版本） |
| 会话处置 | 终结式：保存/归档后自动切新会话（旧会话留历史列表 / 入回收站） |
| 归档去向 | 回收站新「AI 会话」块（对话非模块原生行，模块块格式别扭；开发者预授权） |

AI 拍板两口径：学习库卡 **todo 态**（不静默计每日新学，用户点「学会了」才计数）；万象库卡 **learned 已学态**（不混待学习区批次）。范围仅 **学习·问答 / 万象·问答 / 致知己·追问** 三频道（助手无归属模块、辩真有验证记录、格言解读产出短，不补）。

**实施**（plan 8 任务）：

- **终端悬浮**（纯 CSS）：`.terminal-panel` 改 `position: fixed; left/right/bottom: 8px; z-index: 50`（低于全局弹窗 100+）+ 圆角/描边/柔和投影走既有主题变量；DOM 与 TSX 零改动（拖高用 window.innerHeight、ResizeObserver 自动 refit、open=false 仍 display:none 进程不死）。

- **保存通道**：新 IPC `learn:saveChatCard`（免 AI 知识点卡挂主题下，查重/NOT_FOUND 兜底，md 落 `md/learn/<id>.md`）+ `wiki:saveChatCard`（免 AI 词条卡 state='learned'，插列/两段式 md 路径对齐 generateWikiCard，summary 取正文首实义行前 60 字）；**zhijiji 零新通道**——新建问题复用 `createQuestion`(空 v1)+`overwriteVersion`(覆写为对话 md)、附加复用 `saveNewVersion`。

**实施**（同日 plan，7 任务）：

- DB v46：`exp_categories` 表 + 条目 ALTER 加 `category_id`/`sort REAL`，存量按 created_at 倒序回填 sort 归未分类（观感不变）。
