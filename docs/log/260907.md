## 推理角 v1.2：思维墙「洞察题」全面重做（题型池换血 + 双层题源 + 质量管线）

- **背景（多轮商讨定稿）**：开发者反馈每日题过于简单；逐轮升级——删真假话推理（开发者强项无训练价值）→ 三类示例全部否决（太基础）→ 认知推理样题 2 分钟解出 → 多轮嵌套变体被点破「只是加壳加计算量」→ 最终共识：**计算难度 ≠ 洞察难度**，题目要「方法本身被发明出来」，难度来自洞察链深度而非簿记量。
- **题型池换血**：旧四类（逻辑网格/真假话/序列/文字陷阱）全部退池；新三洞察题型 `insight_invariant`（不变量与构造）/ `strategy_protocol`（策略协议设计）/ `counter_probability`（反直觉概率）。难度锚点按开发者基准重标：简单=单工具但映射不显然；中等=两层链或含诱饵（如奇偶性恰好放行的假守恒）；困难=三层链或需发明本题特有构造、结论反直觉。历史行旧题型显示名映射保留。
- **两阶段出题管线**（services.ts 重写）：阶段一命题（temp 0.9，prompt 内置禁令「不出已知套路+更大计算量模板题」+ 硬性质量六条自检 + reasoning 标准论证 200~500 字 + 三级提示「方向→工具→关键构造」）；阶段二审题（temp 0.2，半盲——只给题面+标准结论不给论证，独立重新推演，过四关：结论正确/结论唯一/条件自洽完备/实际难度达标且不被模板套解），不过 → 问题清单回注重出一次，仍不过抛错不落库。
- **验证式判答**（judgeWallAnswer 签名加 standardReasoning）：宽松等价升级——同一策略/等价构造也算对；只给结论不论证算对，附带论证则讲解中点评但不因论证改判；讲解 = 判定理由 + 标准论证全文。
- **每日题策略三改**（ipc.ts ensureToday）：连胜曲线 `floor(streak/3)` → `min(2, streak)`（**答对 1 天即升一档**）；题型轮换（近 2 日已出题型不再出）；避免清单（近 20 题题面摘要注入 prompt 防同构重出）。
