## 藏书架阅读器字体选择 + 划词气泡修复 + 气泡横排（优化建议区第 35 轮，全栈）

> 创建于 2026-09-11 00:14

**需求**：`docs/project/优化建议区.md` 待完成区唯一条目三件事——丰富书架字体选择；划词高光/批注气泡在取消划词时不能正常消失；两气泡按钮改横向排列。

**根因取证**（epub.js node_modules 源码级）：

- **气泡残留**：epub 正文渲染在 iframe 内，iframe 内 DOM 事件不冒泡到父文档——现有收气泡仅挂 host（父文档）mousedown，正文内点击取消划词根本不触发 → 气泡残留。epub.js `rendition.passEvents`（rendition.js:876）会把 iframe 内 DOM_EVENTS（含 mousedown）转发为 rendition 事件；`triggerSelectedEvent`（contents.js）只在非 collapsed 选区发 `selected`、无「取消选区」事件。
- **字体隐藏 bug（顺带修）**：全局字体选打包手写体时书内实际早已静默回落楷体——@font-face 定义在父文档（global.css），iframe（blob/srcdoc）独立 document 按 family 名解析不到。

**设计定稿**（brainstorming 三问 + 浮层预览拍板；`docs/project/左侧边栏/书架/2026-09-11-阅读器字体选择与划词气泡修复-design.md`）：

- **字体书级记忆**：与「阅读模式/字号」每书独立口径完全同构——DB v32 `books.font_family TEXT`（NULL=跟随全局，存量零迁移；设计初稿写 v31，被并行会话万象库待学习区占用，实际落 v32——版本号实况条款）；`setReadingPref` 增 fontFamily 五处透传（books.ts/ipc.ts/preload.ts/api.d.ts/types.ts + **api.d.ts 内第二处 BooksRecord**，计划漏计 typecheck 拦下后补）。
- **清单 12 项**：跟随全局（动态显示当前全局字体名）+ 系统 6（雅黑默认/微软雅黑/宋体/楷体/黑体/仿宋）+ 打包 5（沿用现有字体文件零新增打包）；字体定义收敛共享模块 `src/theme/fonts.ts`（FONT_FAMILIES 自 ProfileModule 迁出 + READER_FONTS + BUNDLED_FONTS）。
- **打包字体进 iframe**：`rendition.on('rendered')` 向每个 iframe head 注入 `@font-face`（Vite `?url` 资产，`new URL(url, location.href)` 绝对化——根相对/相对路径在 blob iframe 内无基准可解析；幂等 style#bz-reader-fonts；翻章重建 iframe 自动重注入）。
- **UI**：阅读条 epub 组加字体按钮（font_download 图标）→ ActionMenu 浮层，每项 `style.fontFamily` 用自身字体渲染自己的名字（所见即所得）、当前项打勾、打包组 separatorAbove 分组；ActionMenu 组件通用扩展（icon 改可选 + style 项级透传 + max-height 70vh 滚动）。
- **气泡修复**：`rendition.on('mousedown', closeBubble)`（主修复，正文点击即收，划词气泡与标注点击气泡同治；点标注场景 mousedown 收旧先于 click 开新顺序天然安全）+ relocated（翻页/跳章坐标失效）+ scrolled 滚动容器 scroll（脱锚悬空）三挂点；host mousedown 保留管正文外围。
- **横排**：高光/批注两键包 `.bk-sel-row bk-sel-row-center`（复用横排类加居中修饰），气泡其余形态不动。

**实施**（7 任务全过）：fonts.ts 新建 + ProfileModule 迁移 → db v32 → 五处透传 → ActionMenu 扩展 → EpubReader（fontFamily prop / applyTheme 三参 / injectFontFaces / rendered 钩子）→ 气泡三挂点 + 横排 + css → BookshelfModule（字体按钮 + 浮层 + setBookFont + globalFontName 反查 + EpubReader 传参）。

**验证**：`npm run typecheck` 双配置通过（途中两坑：api.d.ts 第二处 BooksRecord 漏改 typecheck 拦下补齐；tsbuildinfo 增量缓存重放旧诊断——第 23/31 轮同款，清缓存即过）；`npm run build` 通过，5 个字体 ttf/otf 资产正常产出 hash 文件。
