## 办公台模块落地（Word/Excel/PPT 等六格式读写 + AI 文档智能体）

> 创建于 2026-09-30 20:00

**任务来源**：`docs/project/新功能开发区.md` 待完成项「工作台添加读写 Word，Excel 等文档的办公功能」。经 brainstorm 六轮对齐（编辑形态 md 中转 / Excel 轻量网格 / 智能体式文档内指令条 / 下固定槽位互换 / 平铺+搜索 / 双轨真相源架构），产出 design + designs-specs + plan 三件套（`左侧边栏/学习模块/办公台/`），随后按 plan 本会话直接实施。

### 数据层（DB v66）

- 新表 `office_documents`（name/kind CHECK 六格式/source_name/size/deleted_at/时间戳）+ `office_versions`（AI 写入前快照，kind 'doc'|'sheet'，每文档保留最近 10 份）+ doc_id 索引。
- 真相源文件存 `userData/office/<id>/`：docx/pptx = 原件存档（original.*，永不改写）+ content.md；xlsx = book.xlsx 本体；csv/txt/md = content.*。删除走回收站 `office` 源（recycle.ts 全链路：union/TABLES/MD_FIELDS/restore case/hardDelete 特判连版本快照+整目录 rmSync；恢复仅清 deleted_at）。

### 主进程

- **officeConvert.ts**（新，纯函数零 electron 依赖）：mammoth+图片提取 → turndown(md，gfm 表格)；md → docx（marked.lexer → 黑体标题/宋体正文/A4/表格/列表/引用/代码块/图片 ImageRun 含 png|jpg 尺寸嗅探）；pptx 大纲 ⇆ pptx（jszip 提取 `<a:t>` / pptxgenjs 简单版式 16:9）；xlsx/csv ⇆ 网格（SheetJS raw:false 读公式缓存值）。
- **office.ts**（新服务）：list/importOne（50MB 上限、失败回滚删行删目录）/create/rename/open/save/export/discard/versionsOf/snapshotDoc/restoreVersion。
- **runOfficeWrite**（ai/services.ts）：无副作用生成——画像注入（profileDigest）+ scene 三标签 `office:doc/office:ppt/office:sheet`；表格场景输出 JSON 二维数组解析失败重试一次；成功后写快照（doc=写入前全文 / sheet=写入前全簿 JSON）。
- **IPC 十一通道** office:list/import/create/rename/open/save/export/discard/versions/restoreVersion/aiWrite；preload `office` 命名空间；api.d.ts Api 接口同步（内联 import('../shared/types') 风格）。
- **bzres:// 新增 office 命名空间** → userData/office/（路径穿越过滤沿用）。

### 渲染层（src/modules/office/）

- OfficeModule（列表态：新建五钮/导入/搜索/类型筛选 ActionMenu/行操作；文档态：顶栏返回+历史版本+导出）；DocTextView（渲染 MdView ⇄ 编辑 textarea，800ms 防抖 + 卸载 flush + 选区透出）；DocGrid（sheet 页签、单元格编辑、增删行列二次确认、>2000 行提示、aiJson 协议应用 AI 表格）；SlidePreview（大纲 ⇄ 16:9 卡片流）；InstructionBar（动作下拉/选区锁定/取消=忽略标志不应用/LLM 未配置跳个人档）；HistoryDialog（恢复二次确认）。
- App.tsx：MODULES 加 `mode?: ModuleMode`；`office`(bottom, mode learn) 与 `favorites`(bottom, mode life) 槽位互换；下固定过滤按 mode；modeOfView 优先吃 mode（纳入 last 记账与切换回落口径）；keep-alive 挂载。
