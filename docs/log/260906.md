## 优化建议区：第18轮——灵感泉 AI 生成质量优化（口味注入 + 两阶段管线）

- **诊断**（brainstorming 与开发者逐项确认）：四宗罪全中——千篇一律/平庸不惊艳/领域不对味/空泛不落地。查实际库定位根因：①「兴趣画像」取自已有灵感，而库里 11 条全是 AI 自生成、手动条 0、用户画像空 → **AI 吃自己输出，越生成越同质**；万象库经济学/心理学/博弈论等兴趣信号、格言正式区品味信号全没用上；②单趟生成，prompt 只管字数形式（10~25 字）不管内容质量，temperature 0.9 无筛选。
- **口味注入层**（`electron/ai/services.ts` 新 `inspirationTasteProfile()`）：跨模块聚合「用户是谁」——画像摘要（profileDigest 60 字/条）+ 格言库正式区 ≤30 条（只取精选转正的，领会气质而非照抄题材）+ 万象词条按板块聚合 ≤50 条（求知领域）+ 灵感泉手动条标题 ≤30 条（真实意图）；**AI 生成条踢出画像**，只进避免清单（500 条标题防重复）。
- **两阶段管线**（`generateInspirations()` 重构）：阶段一发散——temp 0.95 出 **12 条**粗点子，硬性规则写进 prompt：覆盖 ≥4 种项目形态（工具/游戏/内容/可视化/实验/艺术/社群）、每条带第一步抓手、**明令禁用「XX记录/追踪/打卡/复盘 + 工具/助手/工作台」拼装句式**、禁平庸 CRUD/口号空话、至少一半与口味呼应；阶段二自评——temp 0.4 按新颖/契合口味/具体/兴奋四维评审（分数不输出），淘汰同质与平庸，**恰好挑 5 条**并打磨简介（≤60 字含第一步抓手）。角色设定「挑剔的创意策展人」贯穿两趟。降级：自评两趟均失败 → 回退取发散前 5 条，不空手而归；发散两趟均失败 → 整体不入库（原路径）。
- **手动指引**：`SettingsKeys.InspirationGuide`（JSON `{pos,neg}`）；灵感泉头部「来5条灵感」左侧新增 tune 图标按钮 →「灵感方向指引」弹窗（两个 textarea：感兴趣的方向/不想要的方向，`.field` 样式同格言库先例），保存 JSON 落 settings 并 toast「下次生成生效」；生成时以「我的方向指引（最高优先级，严格遵守）」置顶注入，留空不注入。settings:get/set 通用通道复用，无新 IPC、无 DB 迁移。
- **不动**：解析容错、标题查重、入库位置（草稿区末尾）、origin='ai' 徽标与流转、失败 toast/重试路径、refineInspiration（AI 完善的 prompt 强化不在本条待办范围）。代价：两趟 LLM 调用，「来5条灵感」等待时间约翻倍。

## 优化建议区：第17轮——AI 输入框提示清理与高度自适应 + ActionMenu 整行可点

- **ActionMenu 整行可点**：根因是菜单项 `<button>` 默认随内容收缩、不满菜单行宽，仅文字区域可点 → `.action-menu-item` 加 `width:100%` 拉满行宽，空白处同样响应，hover 高亮同步满行。通用组件改动，当前唯一使用方为格言库，万象库/灵感泉菜单未用此组件不受影响。
