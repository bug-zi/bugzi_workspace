四项设计经开发者确认：5 张随机卡片各 1 题（单次 LLM 批量出题）/ 逐题反馈 / 先入库再审核（加入=保留、丢弃=回收站、直接删除=彻底删、关弹窗默认加入）/ 总览页按钮+独立答题页。

### 测一测

- **后端**（`electron/ai/services.ts`）：`generateWikiQuiz()`——Fisher-Yates 随机抽 5 张卡片（不足全取，0 张报「题库为空」），逐张 mdRead（缺 md 跳过，单卡截 1200 字），一次 `chatCompletion`（jsonMode）批量出题；`parseQuizArray` 容错解析（```json 剥离 + 对象包裹取数组字段），题目须 term 对得上来源词条、选项 ≥2、answer 在范围内才收。
- **IPC**：`wiki:quiz`；preload `wiki.quiz()`；api.d.ts 新增 `WikiQuizQuestion` 类型。
- **前端**（WikiModule）：View 增加 `quiz`；总览页生成按钮组加「测一测」（quiz 图标，出题中转圈态）；答题页逐题渲染（进度+来源词条、四选项按钮、选后锁定并标色——正确=主题色描边/选错=danger 红字、反馈行+下一题/查看成绩）；成绩页得分大字+答对率+再来一轮。样式 `.quiz-*` 入 App.css（全部主题变量，无彩亮色）。
- LLM 未配置走既有 GoConfigDialog 引导；出题失败 failMsg 弹窗并退回总览。

- WikiModule：`reviewing` 状态，三条生成路径成功后置 true 并打开卡片；加入 → toast 已加入；丢弃 → 复用回收站丢弃确认（discardEntry）；直接删除 → 新确认弹窗 → 新 IPC `wiki:deleteForeverEntry`（删词条行+高光+卡片 md，同 hardDelete wiki 口径）。
