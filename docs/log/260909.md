## 书架 W/S 流式滚动 + 切模式后首视图横向可拖修复（开发者反馈两项）

> 创建于 2026-09-09 00:41

- **① W/S 改按住流式滚动**：原实现每按一次 `scrollBy` 85% 视口（smooth），粒度粗。重做——`readerKeys.ts` 新增 `createHoldScroller()`：keydown（忽略系统重发）登记方向并启动 rAF 循环，逐帧小步 `scrollTop`（约 550px/s）→ 长按连续流动、松开即停、轻点小幅位移；window blur 与组件卸载兜底全停。keyup 归一用无输入保护的 `dirOfKey`（防「按住时焦点移入输入框再松开」泄漏滚动）。epub 滚真实容器 `.epub-container`、pdf 滚宿主，两阅读器同体验。
- **② 翻页→滚动切换后首视图横向可拖（跳章即消失）**：根因为首帧视图宽度未收敛（挂载竞态残留）+ epub.js scrolled 模式给 `.epub-container` 设行内 `overflow: auto` 含 X 轴。双管齐下：createRendition 首帧 display 完成后按内容盒净尺寸 `resize()` 强制重排一次（治宽度未收敛）；bookshelf.css 增 `.bk-epub-host .epub-container { overflow-x: hidden !important }`（行内样式需 important 覆盖；竖向滚动与翻页模式不受影响）。
- typecheck/build 双绿。待人工复验：长按 W/S 流式滚屏与轻点小步、A/D 换章不受影响；翻页→滚动切换后首视图无横向拖动；批注输入框内打字不触发滚动且按住切焦点松开能停。git 提交由开发者执行。

## 书架滚动模式 W/S 无效 + 滚动→翻页空白修复（开发者反馈两项）

> 创建于 2026-09-09 00:22

- **① 滚动模式 W/S 无法上下滚动**：根因——scrolled 流式下 epub.js 会给内层 `.epub-container` 设 `overflow: auto`（default manager `updateFlow` 的 scrolled 分支默认值），**真正的滚动容器是它而非宿主 `.bk-epub-host`**，此前 `host.scrollBy` 落空。修复：键盘滚动分支先 `querySelector('.epub-container')` 取真实滚动容器再 scrollBy（找不到时退回 host）。pdf 滚动模式宿主即滚动容器，本就正常。
- **② 滚动→翻页切换空白（翻页→滚动正常）**：同 Book 销毁重建 rendition 在 scroll→page 方向仍空白（epub.js 残留状态方向性 wart，逐层排查 stage/manager/archive blob URL 未定位到单点）。修复改道：**模式切换全量重挂**——BookshelfModule 中 EpubReader 的 key 由 `id` 改 `id-mode`，切换即换新实例（新 Book + rendition + 全套事件主题标注重挂）；切换前先 `books:list` 取最新进度行更新 `reading`（防节流 3 秒窗口内的进度丢失导致回跳到开书位置）；EpubReader 内部的模式切换 effect/modeRef/renditionModeRef 相应移除。pdf 维持阅读器内部重建（无此问题）。
- **顺带收缩**：移除上一轮加的 `'html, body': { overflow: hidden }` 主题注入——核实 `contents.columns()` 在分页模式本就对内容根设 `overflow-y: hidden`，该注入冗余；防拖动靠宿主层 `bk-page-mode { overflow: hidden }` 已足够。
- typecheck/build 双绿。待人工复验：滚动模式 W/↑ S/↓ 平滑滚屏、A/← D/→ 换章；双模式来回切换（含大书）不再空白且位置保持；翻页模式仍不可拖动。git 提交由开发者执行。
