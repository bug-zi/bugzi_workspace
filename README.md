# bugzi's workspace（bugzi_workspace）

一个生活化的个人专属工作台桌面 App。本地单机运行，无需账号登录，无自建后端。本项目为 **AI coding 项目**：由开发者与 AI 协作完成，开发者主导设计，AI 负责依据设计文档生成代码。

> 当前状态：**v2.0.0 已发布**（260923，超级工作台 2.0 收官——主动型助手引擎），持续迭代中。开发进度与每日记录见 `docs/log/`。

## 技术栈与数据存储

- **技术栈**：Electron + React + TypeScript（electron-vite 构建）。功能库按需引入：epub.js / pdfjs（阅读器）、Excalidraw（画布）、node-pty + xterm（终端）、electron-updater（应用内更新）等
- **AI 能力**：App 直连 OpenAI 兼容 LLM 服务商 API（主进程发起，模型池溢出路由、按场景使用统计、全局可取消）；MCP 联网搜索（Streamable HTTP，支持 bearer 鉴权与 AI 辅助配置）。API Key 本地存储
- **数据存储**：结构化数据存 SQLite（51 版本化迁移）；md 文档（格言笔记 / 知识卡 / 答案版本 / 对局记录 / 文章等）存真实 .md 文件，可用外部编辑器打开；书籍 / 音乐 / 字体 / 画布以原文件入库。均位于数据目录
- **发版**：electron-builder 打 NSIS 安装包，GitHub Releases 分发，应用内「版本与更新」一键升级
- **App 名称**：窗口标题「bug子的workspace」，安装包名 `bugzi_workspace`，AI 助手名 debugzi

## 全局硬性规则（摘要）

- 所有「放入回收站 / 删除」操作必须有二次确认弹窗
- 双主题：浅色 = 樱花粉 + 黑字，深色 = 宝蓝 + 白字，背景使用 bg-light / bg-dark 图片
- 禁止 emoji 作图标，图标取自 [Google Fonts Icons](https://fonts.google.com/icons)；组件框 / 按键 / 弹窗禁止彩亮颜色，须与主题色系一致
- 三栏式布局：左侧模块导航（学习 / 生活双模式过滤，常驻入口恒显，切换按钮在右下角最底位）→ 中间主栏（模块切换 keep-alive，AI 生成不中断）→ 右缘四面板互斥（AI 助手 debugzi 统一会话流〔场景徽章标签，模块动作自动切入对应场景会话〕/ 草稿本 / 资源管理器 / 画布）
- md 弹窗为全局统一组件，默认渲染态、双击进编辑态
- LLM/MCP 未配置时 AI 功能按钮不置灰，点击弹窗提示并「去配置」直达个人档
- 定时任务 App 未运行时错过即跳过；首次启动有欢迎引导
- 完整规则见 `docs/project/左侧边栏/左侧边栏.md` 与 `docs/project/样式/design.md`

## 文档体系

`docs/` 是开发者与 AI 共同维护的项目文档库，权责划分：

| 内容 | 维护方 |
| --- | --- |
| `docs/project/{左侧边栏/{常驻模块,学习模块,生活模块},右侧边栏}/<模块>/design.md` | 开发者主导，AI 可提建议（需审核） |
| `docs/project/{左侧边栏/{常驻模块,学习模块,生活模块},右侧边栏}/<模块>/designs-specs.md` | **AI 生成并维护**，开发的直接依据，开发者仅简单审核 |
| `docs/project/样式/design.md` | 开发者 |
| `docs/log/<YYMMDD>.md` | AI（每天一个开发日志，每小节附创建时间） |
| `docs/project/左侧边栏/左侧边栏.md` | 开发者主导，AI 可提建议（需审核） |
| `docs/project/idea/` | **开发者私有**，AI 不读取不修改 |
| `docs/project/优化建议区.md` | 开发者记录使用反馈，AI 据此实施优化 |
| `docs/project/问题疑惑区.md` | 开发者记录疑惑处，AI 不主动查阅 |

**工作流程**：开发者编写 `design.md` → AI 据此严格生成 `designs-specs.md` → AI 按 `designs-specs.md` 开发。

`左侧边栏/` 目录按左栏三类分组（260923 起，260924 起与代码 `MODULES[].seg` 对应）：`常驻模块/`（总导览、文笔坊、收藏夹、音乐吧、回收站、个人档）、`学习模块/`（学习库、论文库、万象库、信息源、答疑店、致知己；工作台已归档）、`生活模块/`（图书馆、灵感泉、推理角、记账本；播客台/副本库/赋诗苑/娱乐城占位待建）。AI 产出的 spec / plan 按模块就地存放，落地后移入所属目录 `archive/`（机制正本见 `docs/project/README.md`）。

## 快速开始

环境要求：Node.js（建议 LTS 版本）与 npm。仓库已通过 `.npmrc` 配置国内镜像与 legacy-peer-deps，国内网络可直接安装。

```bash
# 安装依赖
npm install

# 开发模式运行（热更新）
npm run dev
```

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发模式启动，electron-vite 热更新 |
| `npm run build` | 构建生产产物到 `out/` |
| `npm run preview` | 预览构建产物 |
| `npm run typecheck` | 主进程 + 渲染进程 TypeScript 类型检查 |
| `npm run smoke` | 构建后以 `--smoke` 模式启动 App 冒烟自检 |
| `npm run dist` | 打包 NSIS 安装包到 `release/`（含自动产出的 latest.yml / .blockmap） |

## 使用说明

1. **首次启动**：弹出简短欢迎引导——设置用户名、选择主题（浅色樱花粉 / 深色宝蓝）、提示先去配置 LLM
2. **配置 AI**：进入「个人档」配置 LLM（API 地址 / Key / 模型，可多套并设并发上限）与 MCP。配置后即可使用 debugzi 对话、格言生成、知识卡片、辩真联网验证等全部 AI 功能；未配置时点击相关功能会弹窗提示并「去配置」直达个人档
3. **日常使用**：左侧边栏按学习 / 生活双模式显示模块（右下角最底位单按钮往返切换，启动默认总导览）；右缘四面板互斥展开，全收起时右下角有主题 / 终端 / 音源快捷按钮；点 × 默认最小化到托盘常驻（可在托盘菜单或个人档改为直接退出、开机自启）
4. **数据安全**：所有「放入回收站 / 删除」操作均有二次确认弹窗；回收站条目满 3 天自动彻底删除；每晚 10 点定时生成格言（App 未运行时错过即跳过，可随时手动触发）

## 数据位置

所有用户数据保存在本地数据目录（不随仓库分发），默认 `D:\Paper\app_output\bugzi_workspace`，可在「个人档 → 存储位置」迁移到任意目录（迁移后在 `%APPDATA%\bugzi_workspace` 留 `data_home.json` 指针）。目录内容：

- `bugzi.db`：SQLite 数据库（各模块结构化数据、AI 会话、设置项等）
- `md/`：真实 .md 文档（格言笔记、知识卡、答案版本、对局记录、文章、草稿等），按模块分目录
- `books/` `covers/` `music/` `fonts/` `canvas/` `bg/`：电子书、封面、音乐、导入字体、画布、背景图等原文件资产
- 根目录：头像

## 项目结构
