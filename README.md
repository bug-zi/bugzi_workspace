# bugzi's workspace（bugzi_workspace）

一个生活化的个人专属工作台桌面 App。本地单机运行，无需账号登录，无自建后端。本项目为 **AI coding 项目**：由开发者与 AI 协作完成，开发者主导设计，AI 负责依据设计文档生成代码。

> 当前状态：**初版代码已生成（260902，未验证）**，各模块功能待逐项验证迭代。开发进度与每日记录见 `docs/log/`。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 格言库 | 名言格言三级管理（草稿区 / 沉淀区 / 正式区）。AI 依据正式区风格在草稿区生成格言（每次 10 条、标明出处），每晚 10 点定时或手动触发。正式区每条格言有独立 md 笔记，弹窗打开、实时编辑实时渲染 |
| 万象库 | 非计算机领域知识词条（初始板块：经济学 / 法学 / 心理学 / 博弈论 / 历史神话，可自定义）。支持划词高光存入笔记本、划词问 AI，可随机或手动输入词条由 AI 生成知识卡片 |
| 灵感泉 | 项目灵感四层管理（草稿区 / 立项区 / 开发区 / 归档区），列表行 + 专属 md 文档，支持拖拽跨区移动 |
| 辩真阁 | 输入观点，AI 联网搜索（MCP）验证真实性并保存验证记录 |
| 回收站 | 按来源分四板块（格言库 / 万象库 / 灵感泉 / 辩真阁），「恢复」回来源模块最初级区，「删除」彻底删除，存放满 3 天自动彻底删除 |
| 个人中心 | 个人信息（用户名 / 头像 / 个性签名）+ App 设置（字体、LLM 配置、MCP 配置、背景图更换） |

## 技术栈与数据存储

- **技术栈**：Electron + React + TypeScript，桌面端单机运行
- **AI 能力**：App 直连 LLM 服务商 API，请求在 Electron 主进程发起（规避渲染进程 CORS），API Key 本地存储，UI 与主进程通过 IPC 通信
- **数据存储**：结构化数据存 SQLite；md 文档（格言笔记 / 灵感文档 / 万象卡片正文 / 辩真记录详情）存真实 .md 文件，可用外部编辑器打开。均位于用户数据目录
- **App 名称**：窗口标题「bug子的workspace」，安装包名 `bugzi_workspace`

## 全局硬性规则（摘要）

- 所有「放入回收站 / 删除」操作必须有二次确认弹窗
- 双主题：浅色 = 樱花粉 + 黑字，深色 = 宝蓝 + 白字，背景使用 bg-light / bg-dark 图片
- 禁止 emoji 作图标，图标取自 [Google Fonts Icons](https://fonts.google.com/icons)；组件框 / 按键 / 弹窗禁止彩亮颜色，须与主题色系一致
- 三栏式布局：左侧模块导航 → 中间主栏 → 右侧 AI 助手边栏（可收起 / 展开，模块感知，v1 单会话持久保存）
- LLM/MCP 未配置时 AI 功能按钮不置灰，点击弹窗提示并「去配置」直达个人中心
- 完整规则见 `docs/project/需求（功能模块）/总需求文档.md` 与 `docs/project/样式/design.md`

## 文档体系

`docs/` 是开发者与 AI 共同维护的项目文档库，权责划分：

| 内容 | 维护方 |
| --- | --- |
| `docs/project/需求（功能模块）/<模块>/design.md` | 开发者主导，AI 可提建议（需审核） |
| `docs/project/需求（功能模块）/<模块>/designs-specs.md` | **AI 生成并维护**，开发的直接依据，开发者仅简单审核 |
| `docs/project/样式/design.md` | 开发者 |
| `docs/log/<YYMMDD>.md` | AI（每天一个开发日志） |
| `docs/project/需求（功能模块）/总需求文档.md` | 开发者主导，AI 可提建议（需审核） |
| `docs/project/idea/` | **开发者私有**，AI 不读取不修改 |
| `docs/project/问题疑惑区.md` | 开发者记录疑惑处，AI 不主动查阅 |

**工作流程**：开发者编写 `design.md` → AI 据此严格生成 `designs-specs.md` → AI 按 `designs-specs.md` 开发。

## 快速开始

环境要求：Node.js（建议 LTS 版本）与 npm。仓库已通过 `.npmrc` 配置 Electron 国内镜像（npmmirror），国内网络可直接安装。

```bash
# 安装依赖
npm install

# 开发模式运行（热更新）
npm run dev
```

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发模式启动，electron-vite 热更新 |
| `npm run build` | 构建生产产物到 `out/` |
| `npm run preview` | 预览构建产物 |
| `npm run typecheck` | 主进程 + 渲染进程 TypeScript 类型检查 |
| `npm run smoke` | 构建后以 `--smoke` 模式启动 App 冒烟自检 |

## 使用说明

1. **首次启动**：弹出简短欢迎引导——设置用户名、选择主题（浅色樱花粉 / 深色宝蓝）、提示先去配置 LLM
2. **配置 AI**：进入「个人中心 → App 设置」配置 LLM（API 地址 / Key）与 MCP。配置后即可使用 AI 助手对话、格言生成、知识卡片、辩真联网验证等 AI 功能；未配置时点击相关功能会弹窗提示并「去配置」直达个人中心
3. **日常使用**：左侧边栏切换六个模块；右侧 AI 助手边栏可收起 / 展开，感知当前模块上下文；主题可在侧边栏底部或个人中心一键切换
4. **数据安全**：所有「放入回收站 / 删除」操作均有二次确认弹窗；回收站条目存放满 3 天自动彻底删除；每晚 10 点定时生成格言（App 未运行时错过即跳过，可随时手动「来10条格言」）

## 数据位置

所有用户数据保存在本地用户数据目录（不随仓库分发），可用外部编辑器直接打开 md 文件：

- Windows：`%APPDATA%\bugzi_workspace`
- `bugzi.db`：SQLite 数据库（格言、词条、高光、验证记录、设置项等结构化数据）
- `md/`：真实 .md 文档（格言笔记、灵感文档、万象卡片正文、辩真记录详情），按模块分目录存放
- `bg/` 与用户数据目录根下：背景图（bg-light / bg-dark）与头像

## 项目结构

```
├─ electron/        # 主进程：IPC、SQLite、md 文件服务、LLM/MCP、定时任务、回收站
├─ src/             # 渲染进程（React）：六模块 UI、主题、AI 助手边栏、通用组件（md 弹窗等）
├─ resources/       # 随仓库分发的静态资源（默认背景图 bg-light / bg-dark，首次启动种入用户数据目录）
├─ docs/            # 项目文档库（design.md / designs-specs.md / 开发日志）
└─ out/             # 构建产物（git 忽略）
```
